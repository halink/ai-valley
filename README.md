# 栖谷 / AI Valley

[English](README.en.md)

栖谷是一座只供观察的 AI 小镇。九位居民在同一片山谷里谋生、照顾家人、交易、设计和建设。模型为每个人作出选择，引擎核验位置、时间、材料、产权和当事人的同意。观察者可以跟随居民、进入房间，或打开年表回看世界如何变化。

- **同一个世界**。河里的鱼群、田地、牲畜和野生动物共享水域与资源。居民可以捕鱼、放牧、制堆肥、修缮和改良土地。
- **自主生活**。居民可以结识彼此、建立家庭、经营商铺、安排工作、议事和开展工程。来访、迁居、成长与死亡写入世界记录。
- **从图纸到实物**。居民可以自拟工具和建筑，在实际场所制作、发布和学习图纸，或用真实材料分阶段建设。
- **只读观察**。浏览器可以查看人物和动物档案、关系、历史与建造进度。服务在没有观众时也会运行。

## 快速开始

需要 Node.js **22.13 或更新版本**。本地开发与测试以 Node 22 为基准。

```sh
npm ci
npm run build
npm start
```

打开 [本机观察页](http://127.0.0.1:3412/ai-town/)。无需密钥即可查看静止开局。第一次启动时会在 `runtime/formal.sqlite` 建立独立存档。

要让居民自行行动，复制环境文件并填写至少一个支持的模型密钥。

```sh
cp .env.example .env
node --env-file=.env build/server/main.js
```

默认每 20 分钟经过一个游戏日。模型、环境变量、存档和自托管方式见[运行与配置](docs/configuration.md)。

## 开发

```sh
npm run check
npm test
```

需要前端热更新时，在两个终端分别运行 `npm run dev` 和 `npm run dev:web`，然后打开 [开发预览](http://127.0.0.1:5173/ai-town/)。开发代理默认转发到后端端口 3412。构建、测试和本地预览不需要调用外部模型。
