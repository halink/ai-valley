# 栖谷 / AI Valley

[English](README.en.md)

一个只供观察、由居民自主生活逐步长大的山谷。**新版唯一交付目标是 Godot 3D 浏览器版**，采用手绘风格材质；不交付原生桌面游戏，不考虑移动端。Godot 编辑器是开发和导出工具，不是玩家的安装要求。

## 当前版本：小世界工程 MVP

当前先验证一小块地图、两位居民、一处共屋和食物/水源。已有行动结算、移动轨迹、室内观察、基础姿态、中文界面和绘本风格材质。世界由 Node 后台维护，浏览器显示同一份事实，不替居民直接下达行动。

当前可构建的 Web 入口是**规则驱动的临时演示**，不是已验收的 AI 游戏：不读取 `.env`、不调用模型、不保存世界；重启后台会重置。已有独立持久化和主/备用模型接线，并提供单独的同源持久 Web 入口；未通过真实模型验收。旧后台中的丰富功能不代表已经进入新版 MVP。

## 本机开发演示

构建需要 Node.js **22.13+**、Godot **4.6.3 stable** 和匹配的官方 Web 导出模板，`godot` 须在 PATH 中。

```sh
npm ci
npm run build:godot:web
npm run demo:godot:web
```

在运行后台的同一台电脑上用浏览器打开 <http://127.0.0.1:3414>，点击“连接／重新连接”。这是本机演示地址，不是公开部署地址。浏览器需要 WebAssembly 和 WebGL 2；不要求访问者安装 Godot。详细环境、模板、导出和故障边界见 [Web MVP 说明](docs/godot-web-mvp.md)。

`npm run dev`、`npm run dev:web` 与 `npm run demo:godot:web` 是同一规则 Web 服务入口，不必同时启动。`npm run build` 仅做 TypeScript 检查与后台编译，之后 `npm start` 启动编译后的同一服务；Web 资源仍须单独执行 `npm run build:godot:web`。这些命令都不是持久模型启动入口。

## 验证状态

Web release 已实际导出；静态文件、同源快照和隔离规则短测通过。无界面 Godot 检查与这些测试**不能代替浏览器画面或真实模型验收**。本次验证中，浏览器无法连接另一执行会话中的 loopback 服务，故 3D 画面、GPU、中文显示及交互仍未验收。

持久化由后台服务器负责。现有持久服务的存档锁只支持 Linux；这不是 Mac 浏览器访问的限制。持久 Web 的实际浏览器验收、公开 HTTPS 部署、访问控制和真实模型验证仍待完成。长期运行验证由项目所有者执行，当前不宣称可长期运行的 1.0 已完成。
