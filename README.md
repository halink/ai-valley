# 栖谷 / AI Valley

[English](README.en.md)

一个只供观察、由居民自主生活逐步长大的山谷。**新版唯一交付目标是 Godot 3D 浏览器版**，采用手绘风格材质；不交付原生桌面游戏，不考虑移动端。Godot 编辑器是开发和导出工具，不是玩家的安装要求。

## 当前版本：小世界工程 MVP

当前先验证一小块地图、两位居民、一处共屋和食物/水源。已有行动结算、移动轨迹、室内观察、基础姿态、中文界面和绘本风格材质。世界由 Node 后台维护，浏览器显示同一份事实，不替居民直接下达行动。

当前可构建的 Web 入口是**规则驱动的临时演示**，不是已验收的 AI 游戏：不读取 `.env`、不调用模型、不保存世界；重启后台会重置。已有独立持久化和主/备用模型接线，并提供单独的同源持久 Web 入口；未通过真实模型验收。旧后台中的丰富功能不代表已经进入新版 MVP。

## 本机开发演示

构建需要 Node.js **22.13+**、Godot **4.6.3 stable** 和匹配的官方 Web 导出模板，`godot` 须在 PATH 中。

```sh
npm ci
npm run build:godot:web
npm run demo:godot:web
```

在运行后台的同一台电脑上用浏览器打开 <http://127.0.0.1:3414>，页面自动读取同源世界快照；连接失败时可点击“连接／重连”。这是本机演示地址，不是公开部署地址。浏览器需要 WebAssembly 和 WebGL 2；不要求访问者安装 Godot。详细环境、模板、导出和故障边界见 [Web MVP 说明](docs/godot-web-mvp.md)。

`npm run dev`、`npm run dev:web` 与 `npm run demo:godot:web` 是同一规则 Web 服务入口，不必同时启动。`npm run build` 仅做 TypeScript 检查与后台编译，之后 `npm start` 启动编译后的同一服务；Web 资源仍须单独执行 `npm run build:godot:web`。这些命令都不是持久模型启动入口。

## 验证状态

Web release 已实际导出。2026-11-13 在云端 Linux 的 Firefox 中实际打开同源页面，确认 3D 场景、中文 UI、连接与居民选择；规则演示的行为显示另已做过浏览器检查。另外已在 Firefox 实际确认首次打开规则页和模型禁用持久页会自动连接同源快照，后者仍停表，手动重连保留。这些结果不代表真实模型生活闭环已验收。

持久 Web 已完成一次有界的浏览器人工检查：用空环境启动模型禁用模式，不读取 `.env`，使用独立的合成 SQLite 存档。页面明确显示“模型已禁用、不自动改用规则、世界持久保存”；停止服务后显示断线/数据过期与模型状态未知；写入合成居民姓名标记后，经两次正常停止、重启及重新连接仍恢复该标记，世界保持停表。该浏览器检查只覆盖禁用模型的连接、显示及基本存档恢复。随后一次独立短程存档检查确认：规则引擎生成的进行中动作保存到隔离 SQLite 后，由实际持久服务在模型禁用模式正常载入，两位居民的位置、动作和库存保留，世界仍停表。这只证明正常载入保留，不证明动作续跑、异常断电恢复、真实模型调用或长期稳定性；未新增测试文件。

持久化由后台服务器负责。现有持久服务的存档锁只支持 Linux；这不是 Mac 浏览器访问的限制。公开 HTTPS 部署、访问控制、其他浏览器兼容性和真实模型验证仍待完成。长期运行验证由项目所有者执行，当前不宣称可长期运行的 1.0 已完成。
