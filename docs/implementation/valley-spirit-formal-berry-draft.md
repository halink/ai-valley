# 谷灵：正式世界野浆果落地草案

默认关闭，只读取已提交的同一原生正式世界，并复用 G1 已结束降雨、当前合法落点与实际灌木库存的检查。调用者须明确指定一个地点和隔离草案容量，不扩大选点，不用 MVP 的果实、资源规则或地面容量替代。

输出只是一份不可执行的草案：同一野浆果源计划减一份，公共地面计划加一份 `berry`，居民库存增量为零。草案固定原世界、雨事件、果源位置、落点、当前世界修订与实测源数量；同一世界、同一场雨、同一果源只有一个草案身份，不因更换落点再生成。保持原世界、传入草案记录与已保存源库存不变。与原容量不一致、采空或不合法的地块得不到新草案。

如果草案引用的雨仍在当前保留范围内，起止实测时点须精确匹配。雨自然滚出当前范围后，原草案仅保留结构一致的历史拷贝，不能把拷贝当作权威已落地记录，也不能重新授权或创建旧雨的新落果。历史草案不跨世界或采用时点复用；该层不是跨存档回滚防护。

尚无封存正式库的原子批准／应用、正式地面物品、真实发现或居民拾取、鲜度／食物流转、授权／签批复核、公开页面或调度。下一步需用同一权威事务重新读取天气、库存与实际地面后才可考虑写入。未调用模型、未启用生产或提测。
