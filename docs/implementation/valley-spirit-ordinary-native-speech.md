# 普通规则的原生当面发言凭证（私有）

持有原文件运行锁的本地所有者可在现有普通规则存档、停用自动步进时，显式启用 `privateOrdinaryNativeSpeech`（`{scope:'ordinary-native-addressed-speech-custody/v1', worldId}`）。普通规则仍自行决定是否和眼前熟人问候，不新增对话行动，不替听者回应。它不借封存实验的存档或签名权限。

仅实际传达给指定听者才形成凭证：原生完成路径产生当面事件和对方当分钟收到的个人记忆，且同一存档提交的精确原生分钟、原事件和人物索引均吻合。听到了但没回复也是传达，人在现场却睡着、只看见说者、没有实际收到或缺席都不能当作传达。凭证不复制话语、名字或原始场景数据，不从旧事件推断或补签。

普通但明确启用的原档有单独的私有账。仅匹配的原文件可重开，不将凭证转移到副本。可选写入前后核对存档头及事件人物索引；不认可未知表、归档触发器或临时遮蔽对象。私有账异常只隔离这项功能，不阻断普通游戏或抹去实际传达。当前文件绑定和摘要不是可以对抗全部原始数据同改的签名认证。

没有公开接口、游戏界面改动、发布许可、定时器或模型调用。以后如需公开，还要独立签名、撤回和匿名化，不可借天气或进餐权限。
