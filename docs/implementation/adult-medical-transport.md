# 成年后历史监护记录与医疗转运

## 审计结论与复现

`docs/design/people.md` 明确成年后未成年监护关系结束，失能成人的代理安排仍待实现。正常成长在跨成年阶段时清除 `guardianIds`，但已成年且仍留有旧字段的记录不能因此获得当前代理权，也不能堵住已有的有限急救入口。

本轮先只读审查，再以隔离合成世界验证四项缺陷。在仅复制源代码、替换为修复前 `medical-transport.ts` 的临时测试工作区，四项真实路径均复现：

1. 30 岁患者健康 19、缺少决定与表达能力、没有拒绝，在场童年监护人使最终菜单同时失去 `rescue` 与 `stabilize`。
2. 非危重失能成人可通过真实菜单将 `rescueOffer` 交给旧监护人；对方接受后，实际执行把患者送入床位，错误地记作本人同意。
3. 成人本人另行接受护送后，旧监护人仍可通过计划执行 `cancelRescue`，终止本不属于其决定范围的转运。
4. 未成年时由监护人接受的转运，在患者成年且非危重后仍继续到床位，旧代理接受被延长为成人授权。

新增实施回归在修复前为 **24 项中 12 通过、12 失败**。这些失败包括真实最终菜单缺项、错误代理入口、越权停止和成年后旧代理授权继续。

## 最小实现范围

本轮唯一生产文件是 `src/world/medical-transport.ts`，只修改四处当前实际年龄边界：

- `rescueAuthority`：及时监护阻断仅适用于未成年人。成年历史记录不阻断既有严格急救条件，也不成为权限依据。
- `recipient`：成年人只能由有能力的本人回答新的转运提议；失能成人不会转交旧监护人代答。
- `consent`：成年患者的有效已接受提议必须由患者本人作为 `respondentId`。旧未成年代理接受和缺少答复人字段的旧记录不能当成人同意。
- `cancelRescue`：第三方监护停止权仅适用于未成年患者；患者本人和实际护送人仍保留原有停止权。

年龄由 `bornAt` 和当前时间计算，不依赖可能滞后的 `lifeStage`。不清除历史字段、不新增成人代理类型、不改存档结构、不将历史答复重写成本人同意。

## 保留的权限与终止边界

- 成人既有急救仍要求有能力、足够体力的成年施救者、实际接触、患者本地存活、无明确拒绝、缺少完整决定与表达能力，并满足健康不超过 20 或有效危重病例/严重程度至少 85 的原有门槛。只有表达能力缺失与只有决定能力缺失的原有医疗语义均未扩大或缩小。
- 具有完整有效能力的成人仍需自己的具体同意；非危重失能成人不会因此获得一般转运或用药入口。稳定处理仍要求技能、自有药剂、水和真实工时，转运仍要求自有布料、水、路径、合法接收地和空床。
- 幼儿直接监护、未成年及时监护优先、具备能力的孩子自行回答、监护人对未成年转运的停止权均保留。
- 最终菜单、开工、实际接出、沿途以及到床仍重新验证。拒绝、完整能力恢复、失去紧急门槛或其他实际条件失效时，原例外不能继续。
- 未成年代理转运在成年后若仍满足独立的当前急救条件，可以依已有逐步重验继续；这里不再凭旧代理接受。若不再危重，立即停止。`MedicalTransport.basis` 记录最初接出依据，不被改写成后续权限；它不是沿途授权来源。
- 旧答复人可以撤回自己原来的提议记录，但成人新急救不会绑定已经无效的旧代理提议，撤回该记录不能取消独立急救。
- 本轮保留原有拒绝记录语义：`refusesCare` 阻断急救；`declineRescue`、普通 `cancelRescue` 使对应提议失效，不会生成持续的拒救记录，也不能被当作有效同意。此次没有实现后续失能时对旧拒绝的跨行动延续规则，不能据此声称已审结所有医疗拒绝场景。
- 无新增诊疗预约、持续治疗、床位之外的住房、财产、长期照护或一般成人代理权。成人灾害短程干地撤险保持独立，不把灾害撤险权限转成医疗权限。天气生成保持关闭。

## 回归与独立审查

- `tests/adult-medical-transport.test.ts`：24 项实施回归，覆盖最终菜单、真实接出与到床、稳定处理、年龄边界、具体同意与拒绝、资源与接触条件、进行中权限变化、内存 SQLite 重载及菜单参数注入。
- `tests/adult-medical-transport-review.test.ts`：17 项独立回归，覆盖成年边界前后一分钟、儿童答复、历史提议清理、旧档缺失答复人、能力组合、接收地权限和进行中独立急救重验。
- 原 `health.test.ts` 和 `ferry-rescue.test.ts` 各有一项旧预期把明确为 25/30 岁的患者当作仍有未成年代理。现明确区分成人历史监护正例与 17/13 岁现监护反例，保留原拒绝、能力恢复、泊位变化及床位失败断言；另补两项成人历史监护到场后实际靠泊救援/稳定处理完成的回归。
- [独立审查](../reviews/adult-medical-transport.md)未发现本轮阻断缺陷，并核对了上述旧测试预期调整。

所有新增运行只使用自建隔离世界与 `WorldStore(':memory:')`。未访问密钥、真实存档或运行日志，未调用真实模型、浏览器、npm，未提交或推送。
