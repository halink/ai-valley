# 公共储备粮的有限镇外采购

本批在[有限现物储备](public-food-reserves.md)之上接通新表决授权、既有商人独立接受、既有陆运、经办人独立携运和原共屋交付。不是长期粮食规划、全部运费安排或路线图第三批整体完成。

## 新授权，不追溯扩大旧议案

`foodReserve` 新议案可另带 `foreignProcurement: {merchantId, handlerId}`，指定一位已经存在的商人和自愿担任经办人的提议者本人。正常菜单目前提供芜菁的三家既有商人候选，不透露商人未公开库存。新模板不进入旧领域轮转，仅在原本地储备提案本就可见时用空位或多余目标反思项展示一项；商人轮转保持完整原公共事务周期，避免两层同钟取模导致某商人永不出现，不扩大原菜单上限或挤掉旧进食、拒绝与班次入口。仍要至少三名原登记成年选民、两张独立赞成票、法定人数及真实足额金库。未带该字段的旧议案、旧储备和旧存档不获得镇外采购权。

原食品、单价、共屋、累计数量上限、有限采购款和到期日不改变。外采沿用表决单价，包含现有陆运安排，不允许额外渡船运费、私人交货地址、改商人、出口、借贷或私人垫款。销售税最高预留也从同一有限公共采购预算扣除；报价时锁定所见税率上限，按既有累计零头规则实际结算。税的累计账户属于该储备，不借用经办人的私人零头。

本地采购、原公粮开放和镇外采购共同受累计数量限制。报价时就占用款项与数量，不能先对外承诺全部额度，再让本地供货挤占它。报价转货单只转移占用。实际购入后，即使尚未送至共屋或已腐败，也不恢复累计额度。

## 独立协商和真实运输

1. 经办人先实际走到已知谷口驿站，再选择 `foreignTrade.propose`，动作绑定原 `reserveId`，数量可为1–12份，单价、商人、食品和公共用途不能由回复改写。
2. 只从原储备账户把真实货款及最高税额转入报价托管。此时没有新增粮食，也不替商人接受。
3. 信件实际送达后，既有商人另行选择接受或拒绝。接受时重新检查原授权、经办资格、钱款、商人实际食品及原批次，才将食品转入独立运输货单。
4. 货物沿既有区域运输和真实陆路抵达谷口。到站前不付货款。断路、腐败、撤回或授权失效不能被当作成功交付。
5. 实际到站时才付商人货款及实际税，余预留款回原公共采购账户。货物仍在独立公共货单，不进经办人的背包。
6. 经办人另选 `foreignTrade.collect` 并实际办理提取，只建立随本人移动的公共保管关系。之后仍需自行走到原共屋，另选 `civic.deliverReserve`，到室内真实桌台才入储备货架。交付不再次付钱。

食品始终沿商人原批次运输、携带、变质及入库，不重置保质期。整个携运期间继续使用 `shipment:<id>` 实物容器；提货只改变保管关系，不复制食品。在库粮食沿既有个人营养额度领取，领取后仍需本人另选进食。

## 到期、失能与死亡

未接受报价到期、经办人失去决定/表达/成年资格、死亡或原共屋失效时，报价结束并释放未用公款。已接受但尚未结算的货单进入实际退运，钱款和数量占用须待真实退达后才释放，不能提前退款并又结算。授权尚有效时退回原采购账户，已到期时直接回金库。经办人私人账户和遗产均不接收这些退款。

已经实际购入的公粮不因授权到期变为私产。原经办人仍可另行把它实际送到原共屋一般公共库，不能新增采购、续期或换目的地。原址损坏或失去公共用途则保留货物等待，不凭空替换地点。

自愿提货后，经办人在仍携有公共实物期间须先实际交至原共屋，再选择离谷；议案到期不取消这项保管义务。未提货的公共货单不限制本人离谷。该限制在提案、投票和提货说明中明确披露，本批不支持中途委托或原地卸货。

失能打断旧的提货或交付行动，包括多步计划中尚未执行的旧动作；能力恢复后必须重新选择。未成交旧报价和退运不能自动复活。已购实物仍按原公共货单保管。

死亡时立即冻结本人正在携运货物的实际室外及室内位置，早于遗体搬运；公粮不随遗体移动，不纳入私人遗产或继承。未提货的已购公粮留原交接点。本批没有代替经办人、继任经办或封存货物接管权，这些须以后另行明确授权。

## 账目、重载与观察

- `PublicFoodReserve.foreignProcurement.acquired` 是实际已购数量；`delivered` 是已送原址数量。累计占用为已入库，加已购未入库/损耗数量，加未结束报价和未结算货单。已购部分腐败后只交付剩余实物，原累计占用仍保留。
- 报价和货单各自持久化 `publicReserveId`，公共携运位置在货单 `publicCarrier`。货单不依赖已裁剪的报价历史来识别公共归属。
- 尚有公粮的携运、到站或封存货单保持活动状态，不被160条外贸历史裁剪规则删除。无物可交时结束货单，但累计采购计数不清零。
- 一般公共库存与储备货架仍合计为 `economy.treasuryStock`。在途与携运公粮单独列示，不计作已入共屋、可领取或可即时食用的库存，也不重复计入公共总账。
- 财政页包括报价/运输占款、已购/已交数量、经办人、指定商人、携运/封存位置及现存食品原到期时间。外贸页明确公共归属，不把经办人写作私人货主。
- 本批没有扩展既有私人外贸食品转移证据类型。公共提货不生成虚假的 `shipment → person` 证据；食品容器仍参与既有真实腐败记录。完整公共外采边界账仍待单独实现，不能把缺测补成零。
