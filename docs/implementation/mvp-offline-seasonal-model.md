# 季节居民离线模型入口（合成传输，不开启真实模型）

新增显式 `startOfflineSeasonalModel({mode:'offline-seasonal', database, transport})` 服务。仅由调用方手动推进 `pump()`；没有通用命令行、环境文件启动项、真实凭据、真实供应商调用或规则回退。无合成 transport 则停表，只读观察；未存在的数据库不会被创建成存档。这个窄入口只能在合成档或明确隔离的规则档副本使用，不用于线上原档。

## 一个决定、一条真实动作

- 会话先持世界锁，再对正确 MVP/validation 世界、同一气候状态 v3、农业、土壤、罐藏、个人季节知识和无旧模型历史做只读预检。未知版本/错误不进入工作循环。
- 用专用白名单组装本人身体、现货、已知地址、现场天气感受、新制本人批次和本人亲见田地事实/历史。室内不补猜户外天气，旧制雨日仅用于旧制作物说明。非实际种台/厨房不显示活种源库存或工位状态。木石现场观察与遮挡核实，未知位置仅可重访已知地址附近，不从当前地图猜测道路可用性或采集量。旧模型视图/规则入口不改动；这个窄入口不提供私人对话、社会目标、其他人物状态或自由行动。
- 复用现有菜单和编号回复解释器，最多 32 项，只许从本轮编号接受一项。动作继续经过真实引擎、耗时、库存、实例和权限核验。失败对模型只给复查提示，不透露隐藏远端事实。未决定时不替居民择优执行。
- 所有请求都使用只能通过本模块构造的内存能力，不能注入外部 URL、回调或凭据。每个合成 transport 启动尝试只能认领一次，并发启动、失败启动后也不重复分配。状态页是 loopback 只读的 `/ai-town/api/seasonal-model`，只显示驱动、暂停、匿名工作阶段及请求计数，不返回 World、请求 ID、正文、预算、本人记录或 G0 输入。

## 持久请求与故障

每个存档只有一个合成账户、一个在途槽。复用 `ModelBudget` 及当前合成型号 RPM/TPM 约束；不是实际账户配额、远端用量或账单。无 usage 时保留估计；只缺某一项时仍记录另一项的已知用量；存档预检可以根据已存请求和终态重放并验证预算账，避免删掉预留后重新发放。

SQLite 同一世界事务的私有表保存请求身份、actor/revision、时点、菜单摘要、版本和实际发送的白名单 payload。未写入持久意图和预算前不触达 transport；合成回复经解析后的已接受计划、终态、用量同事务保存。该表不进入 World JSON，在第一笔持久请求意图同事务将显式副本的根格式升至 schema 2，并留下版本标记：新版要求同时存在标记和账表，旧版只认 schema 1，因此都会在写入前拒绝用普通规则打开该专用档。没有请求意图的原档仍是 schema 1。初次在空路径成功创建独立合成世界，普通规则入口仍可正常使用自己的独立档。

动作计划先保存，后由正常引擎时间推进结算；重启恢复同一ID，不重复接受或扣物资。请求可能已经抵达但没有可信终态时，读取 `sent-unknown`，保存原请求预留、不重派、不估造完成、不推进游戏时间；迟到回复也不能在已关闭实例提交。意图前失败不派发；终态写失败会连 World/接受计划一起回滚。世界时钟倒退或账本上限到达停止。此片的账本上限为 1000 条且 32 MiB，以先达到者为准；不是连续运营或共享多用户账户实现。

## 真实入口仍关闭

`startLiveSeasonalModel` 明确拒绝：此前无响应的真实请求远端结果及账单尚未经核对。环境变量、历史免费型号和合成检查不能放行；后续须由受信任审核过的生产准入、时效价格证据、已有账户独占协调和实际持久对账提供，不绕原有气候入口的拒绝门。谷灵模型叙事仍关闭；本片不实现完整分页和出场公平、社交选择、生产价格、真实鉴权或模型质量验收。

### 可选：本机 canonical 居民配额

`startOfflineSeasonalModel({ mode: 'offline-seasonal', database, transport, canonicalResidentQuota })` 可将实际季节居民轮次接到同一套本机协作账户配额。默认不启用，也不能和旧 `sharedAccount`、`almanacFixture` 合用，不启用年鉴、发布或 G2。传入由 `createSeasonalMemoryTransport()` 产生的原始合成句柄，以及 `{ mode: 'explicit-offline-seasonal-resident-quota', worldId, runId, ownership, quota, policy }`。其中 `worldId` 必须是新建临时世界的确切 `godot-mvp-<UUID>`，用于绑定普通季节原生种子；账户 owner、quota 和冻结策略必须是同一真实注册表和租约，不接受复制出的对象，不需要供应商、凭据或网络。

每个运行只绑定一个物理存档。原已存在普通或旧季节存档不迁移；只允许用同一活动账户运行和同一世界文件重开，不能把旧轮次交给新运行。账户绑定若已经落盘而随后世界初始化事务失败，则保留绑定并拒绝换档，不自动修复。轮次先保存世界意图再标记交接，失联持续阻塞，不从缺记录推断未发送或重发。应用关闭不替调用方释放账户，也不清理未知。明确正常停止时，只有已核对同一世界提交、完整轮次账及原账户，且不存在活体派发、世界意图、占位或未知，才清除这个已停止世界的等待标记；失败或此前活体请求均保留。原 owner 保持租约时可用同一运行和同一存档继续，并按当下真实居民重新报告等待。只有 supervisor 独立复核后，且 canonical `sealPendingFree` 确认全账户无等待、占位或未知，才可声明释放。初始化写等待标记若失败而不能证明没写，保守保留。无账户旧入口即使能读只读状态，也不能用合成 transport 写入这个已有 v2 绑定的档（包括零请求档）。即使状态同时完整回滚到旧镜像，本机协作身份也不是外部防回滚锚，不能据此声称可发现整个世界、注册表和配额账本一起回滚。

同进程的季节居民运行和 Formal 离线居民运行不能同时占用同一个配额句柄。已明确按本节绑定过的季节运行，也不能在关闭后改作 Formal。旧 Formal 记录没有这个持久用途标记，不据此推断反向的历史互斥。

#### 可选：仅一处原生整点的私有天气许可

只在新建 canonical 临时世界时额外传入 `privateWeatherUse: { mode: 'explicit-private-seasonal-weather-use', hourMinute, reviewerPublicKeyPem }`。整点必须是原生起始分钟后的第一个整点（当前起始 480，故为 540）；审核人独立持有 Ed25519 私钥，世界仅固定其公钥指纹。以原世界/文件/账号/运行/配额策略进行绑定，旧 canonical 世界不能补装，重开也不能换公钥或整点。

只在实际原生一步到达目标整点并提交世界成功后，独立天气附表才保存受限、带版本的气象点。附表不是世界事务的一部分：故障若发生在世界提交与附表落盘之间，该观察永远缺失，重开或下一分钟不补写；未知、损坏或失败附表隔离，不阻挡居民或世界时钟。不存在整段时段、初始点或其他整点的覆盖承诺。

程序化 `privateWeatherUseTerms` 只返回待签作用域与证据摘要，`recordPrivateWeatherUse` 只记录冻结独立审核人签发的精确许可及其续签/撤回；单次有效窗上限五分钟。每次 `readPrivateWeatherUse` 都复查当前真实租约/世界、原证据、签名和有效期，撤回/期满/缺失时返回空。不使用或修改公开天气权限，不返回原始世界，不启动 G0 调度、不产生模型请求或公开年鉴；普通 API、G2 和未 opt-in 路径不变。独立 canonical 账户注册表逐次钉住原证据摘要、完整许可状态摘要、最新版本和已观察墙钟下限；操作前逐项对照两处。先固定注册表，再提交附表：一侧提交失败即隔离，不从陈旧状态恢复。只有注册表、附表和租约均可信时才读取；已观察到期或墙钟低于持久下限不会复活旧许可。它没有外部可信时钟，不能证明未曾观察的离线墙钟变化，也不能发现全档与账号记录共同回滚。

### 单次私有天气草稿（离线开发）

另一个明确、默认关闭的内部选项只在无端口的 canonical 离线季节运行中生效，并与原 native 小时、公钥以及物理世界存档绑定。原“仅准备”授权不能调用合成；审核人须另签草稿用途、精确 packet 摘要、仍有效的准备许可版本及该世界请求身份。只允许一次有界内置条件选择，既不读取旧天气年鉴或任意返回，也不调用真实模型。

普通居民的就绪、待处理请求和 canonical 等待哨兵在配额前按实际状态核验；保留容量、冷却和账户同一配额权威不变。专用请求身份绑定原账户/运行、同一世界与小时，不随许可换版；世界先留单次意向，交接前再次核对许可并持久化未决状态。交接后再核验后才运行内置选择。真实的本地合成扣账完成后才保存独立私有草稿；该记账按离线字节预算，不声称实际供应商 token 用量。每次显式读草稿同时重验独立账户完成证据、两侧终态摘要与当前授权。撤回、过期、重新批准或存档身份变化不会恢复旧草稿。

仅在独立的私有世界表及账户登记表记录，先提交账户侧递增锚、再提交世界记录，跨库失配时只拒绝草稿，不猜补成功或重发。确知尚未交接才可取消占用；未知请求保留风险并阻断相同运行恢复。账户已记账但世界未成功只保留失败/隔离，不从扣账重造草稿。没有公共刊物、HTTP、UI、后台运行、生产许可配置或 G2 动作。

### 私有天气结构化消息往返（离线开发）

可在上述无端口、同原档、同 canonical 共享账户链路中，以 `privateWeatherWire` 取代 `privateWeatherDraft: true`；两种处理不可同时启动。传入 `createSeasonalWeatherMemoryTransport()` 产生的一次性内存句柄，不能传自定义发送函数、URL、网络凭证或普通对象。审核条款使用相同签章函数，但新用途额外绑定实际发送的 UTF-8 字节摘要；旧编译用途签章不能代替它。两种用途共用该原生小时的同一持久请求身份、账本和单次机会，切换或换许可不能再派发。完成的内容只在原用途的同档私有读口可见。

版本 1 消息只含一个匿名点、实测时间、天气、气温和相对湿度，不传居民、存档、账户、签章、源 ID 或其它原始数据。回复必须用固定 JSON 字段顺序及标准编码，从该点选一个允许的字段并给出同一原值；自由文字、措辞、语气、因果、第二个点、重复字段及附加数据均拒绝。文案由原生确定性渲染器生成，不使用回复的文字。仅显式调用 `pumpPrivateWeatherWireDraft` 才派发，无自动调度。

居民优先、交接前置未决状态、共享配额及两边证据重验沿用原权威。可测定的已返回字节（即便内容不合法或已撤权）按实际 UTF-8 长度完成本地合成计量；内容不合法或失效不显示，不保留原始回复。断开、无法计量、回复超过 512 字节、缺失独立账户结算或跨库提交失败时不猜成功、不重试。读取仍复查当前授权和两边终态，未启用刊登、HTTP、真实供应商或普通玩家流程。

### 私有双整点天气选题菜单（离线开发）

新建 canonical 无端口开发存档时，可在既有 `privateWeatherUse` 固定首整点和独立审核人的基础上，加 `privateWeatherTopics: 'explicit-private-seasonal-weather-topics/v1'`。这是绑定原物理存档和配额登记的独立作用域，不接受旧单点档后装、换审核人或换整点；不与单点编译／结构化往返草稿共启。首点签章字节不变；第二点使用独立签章用途、精确证据摘要与许可纪元，仍由同一预先固定的独立审核人审核。分别使用 `privateWeatherUseTerms`／`recordPrivateWeatherUse` 和 `privateWeatherTopicSecondTerms`／`recordPrivateWeatherTopicSecondUse`，签章都通过 `encodeSeasonalPrivateWeatherTerms` 计算精确字节，两种用途不可互换。

仅在规则真实提交首整点及随后一个整点（目前 540、600）时分别留原生天气见证。首点未能获证，第二点不作记录；任何失落的原生提交都不重补。每个点的附表和账户注册锚各自核对同档、签章、最新许可版本和已观察的墙钟下限。第二点另有独立附表和注册锚；异常只拒绝相应私有读取，不停止居民或时钟。

`readPrivateWeatherTopicMenu` 只在两份许可此刻都有效且两点确实连续时返回五个稳定编号选题：后一时点的实测天气、气温、相对湿度，以及两时点的气温、相对湿度比较。只给出匿名点编号、实测时间、字段及原值，不传居民、世界、存档、账户、源引用或签章。读菜单不选择、不派发、不占配额、不发布、不写世界；不存在由两点推断因果或整小时覆盖的能力。任一点撤回、过期、身份改变或完整性失败即关闭菜单；新许可在真实旧证仍可用时可允许重新浏览，不复活旧签章。普通选题接口和单点草稿模式不变。

### 私有双整点天气的单次编号选题（离线开发）

双整点模式可另传 `privateWeatherTopicChoice`，只接受 `createSeasonalWeatherMemoryTransport()` 创建的单次本机内存句柄，无参数化发送函数、网络地址或模型密钥。不开这个选项时只可浏览菜单；加开或重开不改变原存档、已有两点授权或单次机会身份。单点草稿模式仍不与双整点模式混用。

`previewPrivateWeatherTopicChoice` 给出实际将发送的匿名菜单字节和待签条款；冻结的独立审核人以 `encodeNativeWeatherDraftTerms` 另签编号选择用途。条款固定两点各自精确且当前的证据许可、菜单发送字节摘要及同档同账户的一次性机会。只有显式调用 `pumpPrivateWeatherTopicChoice` 才可能派发。回复必须是版本一致、匹配匿名菜单令牌的规范 JSON，只能附一个 1–5 间的现有整数编号，不能附带理由、文字、外部标识、工具或行动。菜单令牌源于匿名内容，不是世界、来源或账户身份。

复用同一真实本机配额账、居民优先、交接前持久未决及独立账户用量证明。已返回的有界字节按实际 UTF-8 长度合成计量；期限变动、撤回、非法编号或答复格式不合格，仍结算已知用量而隐藏结果，且不留原答复。断线、不可计量、回复超限或跨库状态不明不猜补、不重发，也不会切换成另一机会。只有同档同账户完整终态、两点当下仍保持原签署版本和内容时，`readPrivateWeatherTopicChoice` 才能私下读选中的证据。允许重新浏览当前合法菜单不使旧选择复活。没有公共发行、真实模型、游戏干预提议、排期或 G2 权限。
