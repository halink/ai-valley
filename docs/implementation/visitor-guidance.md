# 访客谷口方向与已知旅途补给

这是[实施批次 1](roadmap.md#批次-1-紧急生存与可观察性)的有限交付。访客可以从正常决定菜单选择已知水点、共屋方向或自愿离开；镇外人物在启程决定中能核对本次路程与自己的实际食品。路牌和提示只提供信息，不替人物选择、取货、借住或进食。

## 谷口路牌

- 正式世界的谷口两格内，实际在室外且能观察的人可以读到最近一处公共会馆和水点的地址，以及由谷口接西南林道的归路。缺少会馆或水点时，该项留空，其他方向仍保留。
- 路牌不显示远处余粮、实时水量、空床、值守人员或通路状态。距离写成四向网格的最少步数，不冒充实际步行耗时或已确认的可达路线。真实寻路和途中阻挡仍由原有行动规则校验。
- 初次抵达时登记已看到的地址，抵达事件和个人亲历记忆中留下方向及限制。旧档中已入谷的人需要在谷口真正观察后才记住；单纯读取决定菜单不会补写知识。离开谷口后已知地址保留，重启仍可使用。
- 新访客通常会看到去水点、去会馆和自愿结束来访三条基本方向。走近水点后才可读取当前水量并决定采集，走近会馆后才核对现有住宿条件。方向菜单不预约床位，不划拨公共物资，也不改变访客身份。
- 最终菜单为这三项保留有限位置，避免大量答复或无关的个人关注领域把归路与基本方向全部挤掉。仍可选择等待、进食、探索等其他行动。

公共会馆方向仍沿用现有自动公开地址的约定；本次没有新增居民制作路牌、定期更新公告或携带远处情报的系统。共屋独立自助领取与借住按各自的权限、实际库存和床位另行验证。

[建筑知情边界](building-knowledge.md)已将已知地址与现场观察分开：远处建筑不再随个人目录附带实时屋况、容量或住户登记，普通班表方向与修缮菜单也不再泄露远处损坏。医疗、家庭及其他约定中的间接条件式信息通道另按该文档的明确边界继续处理。

## 镇外启程提示

启程提示使用当前驿路起点的既有路程。新单人成人访客按[分段行程](visitor-journey.md)执行，途中可另选进食、休息或按真实距离折返。入口发生路阻时，再次检查入口需本人选择等待 30 游戏分钟，保留本人返回或继续等待的选择。

随身补给说明分别列出：

1. 本人实际库存中，有原批次登记且当前未过期的完整食品份数。
2. 不计途中食用、只按原保质期计算，经过本次路程或再次查路的等待时间后，仍未过期的完整份数。恰在该时刻到期的食品不计入。
3. 保质期缺失或无效的食品数量，以及随身清水数量。查询不会把未知食品自动登记成新鲜食品。

估计始终以本人实际库存为上限，不计远处公共粮、未经同意的货物、未采集食源或未来收入。提示明确说明本次公示未提供沿途补给与接待承诺，目的地供给须到场核实。空床后来被占用、路阻或水点变空，都不会生成替代床位、赠与或自动迁居。

镇外人物等待决定时，食品仍按真实批次过期扣货，并同步更新本人的状态版本。过期前发出的请求即使稍后返回启程选择，也不能沿用旧版本启程；正常重试会重新读取当前库存，仍由本人选择来访或留下。重复过期检查和重载不再扣同一批货，不重置食品日期；已经由本人决定并启程的旅程不会被食品过期自动撤销。

这不是营养当量、逐餐计划或旅途生存保证。后续[单人成人分段行程](visitor-journey.md)已增加独立的途中进食、休息、区域距离与原路折返；路程仍以既有分钟尺度表示，旧档与成人亲属同行不反推过去的阶段。接待承诺、消息送达、收到消息后的重新决定及照护接应，仍属于[批次 2](roadmap.md#批次-2-照护继承与人口接续)。

## 旧档与验证

无需存档迁移，不补粮、不改变现有产权、床位或原食品保质期。新知识只写入已有的个人已知地址字段；抵达记录沿用现有事件入口。

[定向测试](../../tests/visitor-guidance.test.ts)覆盖：

- 正式九人地图的谷口地址、未泄露远处水量、无自动补给或分配床位。
- 正常最终菜单选择水点、实际步行与采集，断路失败和水量不足。
- 大量应答与其他关注领域下仍能选择共屋、水点及归路。
- 旧档式空知识访客实际观察、走开、重载和重复读取，不凭查询补写知识。
- 食品已过期、恰在抵达时到期、缺失或无效登记，以及本人库存数量上限。
- 镇外不受未观察到的目的地库存和床位变化影响；到场满床仍可自行离开。
- 途中失去观察能力后不会被强行授予路牌知识。

[镇外食品过期回归](../../tests/outside-food-expiry.test.ts)另覆盖原始三日保质期的实际扣货、旧版本决定被拒绝、返回者唯一人物记录、重复检查与重载，以及运行时真实时钟步进中请求尚未返回便发生过期、旧回复被丢弃、再次请求读到减量库存的完整过程。测试使用内存数据库和可控模型回复，不联网调用模型。

```sh
node --import tsx --test tests/visitor-guidance.test.ts tests/outside-food-expiry.test.ts tests/migration.test.ts tests/formal-population.test.ts
npm run check
```

以上为本机隔离规则验收，不读取真实存档或调用外部模型；不代表批次 1 全部完成，也不代替真实模型的前 15 日和四季长期运行验收。
