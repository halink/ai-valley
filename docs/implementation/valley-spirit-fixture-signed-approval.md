# 谷灵：封存开发库的单次落果签批

这是隔离开发入口，不是谷灵生产开关或测试交接。默认不配置 G2；没有独立的 Ed25519 **公钥**和显式隔离累计效果上限，就不能通过 G1 影子入口执行落果。私钥不进代码、存档或协调器；编号选择、队列评估、运行器、模型和天气档案均不发签批。

外部隔离审批人可读取已通过影子预检的签批绑定摘要，按固定格式独立签署**单份**落果。签名绑定封存库身份、精确候选与评估（包括原权限版本、公开来源、实际雨、果源、地块、规则策略和评估时点）、批准 ID、有效起止时点和累计效果上限。摘要不是签名或授权。预检未通过、不在期限内、签名/公钥/封存库不匹配、一切证据已撤回或规则不再满足，均不改世界。

提交仍由同一个既有 SQLite 权威落果事务负责。事务内重读候选、签名期限、天气授权、雨和现有果源/地面/收据并重验；通过才扣一份已有果实、增加一份同产权地面果实和同事务收据。重复的有效签批只按原批准 ID 回读原收据，不另扣量，旧时机或更换批准 ID不另发一个效果。影子队列不会出现“自动已批准”或代替世界收据。

现有底层隔离落果原语仍供开发夹具的低层单元使用，并非生产权限；本协调器只接受独立签批后的明确调用，不自建世界写入或执行循环，不开放 HTTP，不调用真实模型，不接正式/用户存档。正式运行的批准来源、配置和用户授权另做，不以开发公钥或本地短检替代。
