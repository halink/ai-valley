# 谷灵：正式居民的私有地面浆果观察

只有具有真实封存正式库所有权的开发读取方法才能产生这一视图。该方法从同一已提交世界核验落果出生记录、封存签批、源及世界摘要；不接受调用方提供的落果、草案或世界对象。普通世界没有此读取权限。

查询仅针对一位真实居民。活着、清醒、有能力、实际位于室外，且没有作为患者被护送、在船上或在区域路途，才检查十二格内的现场视线及可通行路线。当前活动灾害、施工、私人土地或其他占用阻止观察。最多四份，单份用稳定的居民／落果标识去重。只返回地面有一份 `berry`、坐标和不可执行标识，不显示雨、果源、签批或他人记录。普通定居居民不因别人看见而自动得知，查询不写知识或审计账。

只显示已在落地时固定原生食品定义和到期时间、且当前确实未过期的批次。旧收据没有这份证据时保留历史记录但不展示，不回填或重置鲜度。实际拾取仍需独立原子事务验证本人现场观察与自主意图、扣除地面一份并增加带同一原始期限的本人浆果批次，防止竞争与重放；这一动作没有接入。没有公开提示、模型、HTTP、生产启用或提测。
