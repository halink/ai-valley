# 家庭共同池食品菜单：有界轮换

本批修复正式九人合成开局 `createFrontierWorld(5401)` 的家庭共同池菜单遗漏。只验证离线规则和居民行动入口，没有读取密钥或真实存档、调用模型，也没有验证九人模型自主生存。

## 原因与修复

原 `householdOpportunities` 按固定 `itemKeys` 顺序只保留建池前2种、存取前3种、赠与前2种物资。正式开局成年人携带木材、石料、浆果、种子、5份根菜、餐食和水，根菜长期被前列物品遮住。赠与的接收者还固定取前3名，后列接收者也可能被永久排除。虽然执行器接受根菜，模型不能自行改写菜单固定的 item，因此这不是提示词可解决的问题。

现在先生成并用既有 `householdReason` 校验所有合法模板，再按完整候选标识稳定排序和轮换。候选包括操作、共同池/住宅、接收者和物品，而不是分别轮换物品与接收者，避免两个周期相互锁住。

- 建池、存入、本人领取、提议赠与的候选上限分别为3、4、4、9，按本人全部池汇总，不随池数或接收者数无限增大。
- 每种操作最多保留1个可直接食用食品模板，其他名额单独轮换现金与材料。没有食品时，全部名额用于现金/材料。食品按 `goods[item].food > 0` 分类，生猎肉等须加工物资仍在材料类。
- 以 `floor(world.minute / 30)` 选择候选，只改变可见菜单，不自动提交动作，不修改库存、人物知识或持久化游标。若合法食品候选静态保持N个，连续N个30游戏分钟窗口覆盖全部候选；变化库存、地点、到期或错过窗口时不承诺同样的期限。
- 不足1份的物资和不属于本人的领取份额先被校验排除，不占预算。只在另一出资人份额里的食品，可生成本人出资0%的提议模板；该模板不扣物资、不代替另一人的独立批准。现金模板同样适用。

## 最终菜单与保护边界

已有全局菜单上限仍为56，未扩大提示菜单。建池、存入、赠与的食品模板不再参加第二层领域轮换，而在已有菜单生成后使用空位或多余目标反思选项，每种操作最多补1项。至少保留一个反思；已有进食、休息、照护、拒绝、供水、个人赠粮、交易等非反思选择不因这次补插而被替换。

**本人领取食品保留原控制选项优先级。** 初版把它也从控制通路抽出，独立复核用“55个移动+1个反思”发现会丢掉原本可见的根菜取回，已修复；补插时去重，不能重复占槽。

如果56项全部占满且没有多余反思，新增建池/存入/赠与食品模板可能暂不可见。不能同时承诺“不驱逐任何既有非反思选择、上限56、任意饱和都显示新增食品”。本批明确保留前两个约束，并用回归记录这一限制；不声称任何负载都能在固定时间内完成家庭供食。

同意、拒绝、撤回及儿童收取继续走原控制菜单与执行器。本批没有改双成年人分别同意、儿童本人接受、本人实际到原储物处、份额独立记账、变质批次保留或完成时库存/竞争重验，没有修改公约每日配额或把家庭池当作公共免费粮源。

## 回归证据

先写两个正式seed回归，修复前均失败：建池缺浆果/根菜/餐食选项，存入缺本人已有5份的根菜。修复后通过。

主测试 `tests/household-food-options.test.ts` 包含：

- 原始九人seed库存的建池/存入可见性，读取菜单不改变世界；原始seed三种食品分别走 `decisionContext → decisionChoices → parseChoice → submitPlan → stepWorld` 的建池、取回、存入、赠与、另一成年人批准、孩子本人走到池旁领取全链。
- parser拒绝改写固定物品与接收者；提议者不能代另一成人批准；儿童不能提前领用；一小步移动不会立即发货；交付不能重放；不产生贷款或改变亲缘/监护。
- 批准过程中另一出资人竞争取回，和已选存入前随身根菜被耗尽，均在完成时重新校验，不透支或复制物资。
- 领取过程中一位出资人的合成批次变质，只退回另一人仍有效的原批次；赠与截止到达也不能晚交付或续同意。
- 内存SQLite重载后候选一致、原批次年龄与独立份额保留，只能交付一次。
- 20种可直接食用物品、后列接收者和材料/现金的完整候选轮换；该项显式扩充合成库存，仅检验菜单覆盖，不冒充原始seed行为。
- 在正式seed菜单加100个合成课堂与80个合成答复，根菜等仍可轮换出现，非反思基线选择保持不变，进食/等待/休息及最后一个反思仍可用。

[独立审查](../reviews/household-food-options.md)另提供7项反例/边界测试，含多池联合轮换、另一出资人独有食品、原食品取回控制优先级及无可替换槽限制。

## 离线验证命令

使用已安装本地工具，不运行 npm：

```sh
node --import tsx --test tests/household-food-options.test.ts tests/household-food-options-review.test.ts tests/household.test.ts
node node_modules/typescript/bin/tsc --noEmit
node --import tsx --test tests/*.test.ts
node node_modules/typescript/bin/tsc -p tsconfig.server.json
node node_modules/vite/bin/vite.js build
git diff --check
```

2026-11-07，在 Node v24.22.1 上完成最终验证：本批新增19项（主测试12、独立复核7），与既有家庭测试合并定向 **33/33**；最终全量 **2,088/2,088**，0 failed、0 skipped。类型检查、服务端编译、Vite构建与 `git diff --check` 均通过。Vite仍有既有超过500 kB的分块警告，本批没有解决该警告。

上述测试不会把菜单被选中等同于模型会自主选择，也不代表九人十五日真实模型验收通过。没有提交或推送。
