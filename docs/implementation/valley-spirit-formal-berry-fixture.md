# 谷灵：封存正式开发库内的原子浆果落地

单独的开发能力只能生成新的私有临时目录和数据库 inode，不导入已有正式库，更不接普通运行或用户存档。封存清单固定的是独立审批方 Ed25519 **公钥**、隔离容量、目录／文件身份和随机令牌校验；不生成、读入或保存审批方私钥。普通入口或 MVP 夹具无法打开这种正式封存库。

调用者只能提交独立签署的单份 `berry` 批准，固定原生世界 ID、隔离库身份、修订、雨、果源标识及确切库存、落点、有效期和批准 ID。不是地形检查、草案、镜像 JSON 或调用者布尔值授权。SQLite 写事务内读取同一权威世界，重新验证闭合雨、鲜果库存与着地条件，从原果源扣一份并持久登记一份公共地面出生记录与对应收据。出生记录与收据合一，与确切修订和世界内归档摘要同事务持久化；居民库存不变。

故障回滚全部变化，凭同一有效签名重试只读回已经提交且仍与封存世界和归档相符的同一结果，不重复扣量。换批准编号不复用旧机会。启动在只读快照中先检查封存、归档结构、触发器、签名和摘要，读取再核查完整地形与来路；未知数据拒绝解释，不覆盖。完整的外部数据库回退不在跨系统防回退保证内。

开发检查用实际正式地图、实际引擎降雨、隔离签名与 SQLite 库，包含故障发生在地面记录写入以后造成的回滚、正常落地、重新打开后的收据复核、普通入口拒绝和异常触发器拒绝。本入口不运行生产调度、公开授权、正式居民发现拾取或食物鲜度处理；未接程序启动、HTTP 或模型，不能据此提测。
