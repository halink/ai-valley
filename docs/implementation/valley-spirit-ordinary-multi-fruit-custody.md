# 普通原生多果源果批凭证

默认关闭。本机明确停自动推进、已有普通开发档才可指定 `privateOrdinaryMultiFruit`：作用域 `ordinary-multi-native-fruit-lots/v1`，固定原世界、统一保鲜分钟数及两到四个不重复的原生果源与位置。这与旧单果源表独立，不迁移、补造旧果批，也不共享 Seasonal 账户。

只有真正提交的原生普通分钟流可以更新同一原始文件下各果源的独立小账。原生自然续生一份且未发生普通采集的分钟才可辨认新生果批；已有熟果总量不能替代果批证据。普通采集、到期及遗漏记录使旧果批不可再读。物理原档、世界修订、提交内容、当前果源位置及原生结存要匹配。私有异常只回滚可选账，不改普通规则和实际世界提交。可选账不是抗本机数据库管理员伪造的外部签章。

没有菜单、自动选择、发布、地面果实或执行授权，也未增加 HTTP 路由。程序化调用只在显式启用后读取同一世界头确实留有的果批；不足两份仍如实返回，不把同果源多个落点当不同机会。
