# 浆果视野与围栏接触

2026-11-07。只修复已有浆果来源的观察和采集边界，不新增食物、权限、自动采集或资源再生。

## 已复现的缺口

1. 当面线索已有真实亲见要求，但旧 `knownResources` 的7格自动发现只核对距离，能穿过房墙或悬崖。旧地址随后通过12格距离筛选进入 `decisionContext.resources` 和最终编号菜单；隐藏余量、容量、采集时点和再生变化会改变模型输入。迟到的浆果采集也会在出发前查询隐藏余量。
2. 相邻寻路可以直接返回零步路径，而浆果最终采集只核对距离。居民隔着透明牧场的闭合围栏边，原地就能扣取浆果；门在别处或不可达也不影响。

## 当前边界

- `berry-observation.ts` 将已知地址、可观察库存和合法接触分开。保持原12格**欧氏距离**，没有改成曼哈顿范围；真实室外、清醒在场和无实体遮挡另行核对。
- `engine.observe` 的浆果自动发现与已有亲见记录同样核对7格实际视线。听闻仍是听闻，旧档已有ID仍保留为地址，不回填亲见证据或数量缓存。
- 决策 context、各模型最终 prompt 和现场浆果菜单使用同一可见规则。房墙、悬崖、树石、预留建筑后方，以及室内坐标或睡眠状态下的浆果实时数量不可见。隐藏地点仍可按已有地址自主走访，不依赖其当前余量或再生。
- 透明围栏继续允许观察。采集路径在闭边前不能提前停止，而是寻找合法相邻站位，并沿当前地图真实绕门；不存在合法路线时不提供采集，迟到选择也实际失败。
- 植物所在格**不要求可行走**。例如临水浆果仍能从合法相邻岸格采集；旧地址查看也保留相邻落脚语义。
- 完成时重新核对真实可见、相邻接触、当前围栏边和剩余实物。劳动中新增围栏、门位置变更、源格被遮挡或被采空，均不能从陈旧菜单取得食物。失败不扣浆果、不新增食品批次或采集事件。
- 旧采集选择可前往已经记住的地址，但隐藏库存不会通过出发前错误泄漏。抵达后不足则失败，不自动改数量、换来源或接着进食。

树、石、泉水、其他行业权限和通用 `findPath` 语义保持不变。没有改变菜单容量、轮换或行动成本，没有增加持久化字段。查询使用当前状态，不跨查询缓存路线或可见性。
