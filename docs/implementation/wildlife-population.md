# 野猪、鹿、野兔与野鸭的有限种群

本项接通现有四种动物的有限本地繁育，移除全部死亡后定时创建成年个体的补充机制。它不增加开局动物，不引入新的栖地迁移、镇外来源、动物疾病或灾害，也不宣称多年生态平衡已经成立。

## 数量与实际繁育

新世界仍有两头野猪、三头鹿、四只野兔和两只野鸭。开局数量与繁育上限分开：默认上限分别为4、6、8、4，给下一代留下有限位置，不再让一雌一雄的开局双只群体因已经满额而无法繁育。上限不是承诺存活数，缺食、缺水、捕食、狩猎和衰老仍可导致整个种群消失。

只有健康、成年、饥渴较低的实际雌雄，在五格以内存在可行地面通路，母体又能到达原物种食源和实际饮水地点时，才可受孕。已记录的亲子和同父或同母手足不能配对；旧档没有的亲缘保持未知，不猜测。食源与水源只是当时的可达条件，不预留或复制食物，动物仍须通过原觅食、饮水行为实际取用。洪水和地面阻断会使这些条件失效。

妊娠沿用既有5、6、3、4日时长，立即占用一个种群位置。到期重新核验母体、实际食水、容量与可通行且没有其他野兽或家畜占用的邻格。暂时不满足可以等待，超过原到期时间一天仍不满足则终止并释放位置，留下事实事件。成功出生或终止后至少再等待该物种一个妊娠时长，才可重新受孕。生父后来死亡不抹去已经发生的受孕，母体死亡则不产生幼崽。

幼崽保存母、父身份与实际出生时间。前七日的野猪、鹿和兔可以从近处存活母体获得营养，母体饥饿和体力实际增加消耗，仍要继续觅食。幼鸭不哺乳，沿用真实食源/鱼群取食并跟随亲代。失去亲代不凭空获得食物，既有饥渴、健康与死亡机制继续运行。

## 驯化与家畜

正常居民菜单仍用本人实物饲料、24分钟劳动及可用畜舍完成驯鸭，完成时再次核验。野鸭沿用身份、年龄、位置、饥渴、健康和已知亲代转为家鸭，野生种群只计一次“驯化转出”，不算死亡，也不会因此补一只野鸭。

已有妊娠保留原生父与原到期时间，畜舍必须同时容纳母体和预留幼崽。途中其他动物占用容量时，驯化失败，不扣饲料、不移走原野鸭、不抹去原妊娠。畜舍占位在驯化、笼内放养、繁育和跨舍护送入口统一计算：存活的同舍与在途转入个体各保留母体及已有胎儿位置，已死亡个体释放预留，同一个体不重复计数。成功后的生育由既有家畜机制推进，保存出生亲代，计入家畜出生而不计入野外出生。亲自护送回畜舍仍是独立行动。

## 旧档与观察边界

首次登记只数当前存活个体，不改身份、性别、位置、警戒、旧妊娠或已经耗尽的食源，也不补配偶。旧档即使缺少早期生态版本字段，也不再自动添入这四种动物。若原存活数和已存在的妊娠超过默认容量，登记容量保留这些实际个体与预留位置，不删除它们；登记后不随死亡降低或随时间增大。

每种的登记后数量满足：现存野生个体 = 登记存活数 + 出生 − 死亡 − 驯化转出。登记前已经死去、驯化或移除的个体不反推计数，过去没有的亲缘与事件保持未知。当前动物列表仍沿用近期死亡个体清理；累计数量与已持久保存的身份事件不依赖当前列表保留全部遗体。

动物档案和生态面板显示有限容量、亲代、妊娠、可达食水与数量核对。受孕、出生和孕育终止事件记录实际动物身份。观察入口不改变世界或居民知识，不给居民额外的全知信息。狼狐仍使用已有的独立栖地迁移与疾病机制，鱼群仍使用分种水域账，未改成这四种动物的本地模型。

## 离线验证与未覆盖范围

`tests/wildlife-population.test.ts` 使用合成世界和内存 SQLite，覆盖四种繁育、配偶/年龄/亲缘/食水/路障/洪水/安全绕路/容量失效、预留与延期恢复、亲代死亡、育幼消耗、灭绝后跨季与旧档不补种、重载与同刻防重、普通菜单驯鸭及完工容量竞态、在途孕畜预留与跨舍容量、真实猎杀一次计数、观察只读和整年逐分钟守恒。

整年测试使用明确的合成初始食源和水库存，检查实际需求继续推进时的数量边界与资源消耗；它不是默认开局长期生存证明，也不是实际模型自主经营或四季供给验收。没有新增非狼狐迁移和镇外来源，种群可能灭绝；这里只保证不由计时器无来源补生。没有用浏览器验收界面布局。
