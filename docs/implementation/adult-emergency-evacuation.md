# 非危重失能成人的紧急短程撤险

本切片只补上非危重、当前不能自行决定的成人，面对当场实际迫近灾害时的短程物理撤离。它复用附近干地的真实接出、室内出口、逐格路线和八步预算，不扩张药物、送床、财产、住房、监护或长期照护权限。新天气调度仍默认关闭。

## 先审视既有权利边界

- `engine.submitPlan` 不接受无决定或表达能力者的一般新决定；实际执行也核验决定能力。`health.advanceHealth` 在危重阶段暂停能力，康复到原阈值才恢复。健康值不低或病例不再危重，并不保证已经恢复决定能力。
- `rescueAuthority` 原有明确同意、幼儿当前监护与危重紧急救护三种依据。这些依据同时供药物稳定处理和送床使用，不能直接放宽为所有失能成人。
- 成人不能表达并不证明不能决定。本切片严格要求 `canDecide === false`；只有 `canExpress === false` 的成人不适用，不把表达障碍变成代决授权。
- 既有 `refusesCare` 继续优先。新运输中本人明确停止会额外保存“本人、原灾害、时间”的拒绝事实，随后换施救者、清理旧运输记录或重载也不能用同一危险重新接出。它不撤销或更改其他照护合同。

因此采用独立 `evacuationAuthority: 'incapacitated-adult'`，只可与 `rescue`、`safe-ground` 和原危险编号共同使用。残留的童年 `guardianIds` 不允许第三人停止或代理安排成人撤险，只有本人或实际施救者能停止本次运输。原医疗 `rescueAuthority` 未扩张；新模式的运输依据记录为有限紧急权限，不伪装成本人同意或监护。

## 可以开始的条件

1. 施救者为在地存活、能决定和表达的成年人，符合原运输的健康与体力门槛，并持有本人1布料、1清水。
2. 对方是在地存活、已满18岁、不能自行决定、没有仍在执行的独立计划或活动、没有有效拒绝的非危重成人。健康不高于20或未结病例达到危重门槛的情况继续使用原医疗制度，不自动升级。
3. 双方在当前同一实际可接触位置，距离至多2格。施救者必须能当场观察；仅知道远方居民、预警或传闻不够。
4. 原灾害必须处于活动阶段、开始时间已到、结束时间未到且强度大于0，实际灾害范围覆盖成人位置，现有建筑遮蔽未能保护他。预警不能启动此成人例外。
5. 室内须有双方原有使用权、真实坐标、合法接近路线和真实出口。不能从门外隔墙接人、补造室内位置或借机取得进入私宅的权限。

菜单读取不创建运输、不移动人物或扣物资。最终菜单与既有监护撤险共享最多两个轮换席位，不剥夺等待、进食和其他个人选择。

## 真实行动与终止

本人选择后，施救者沿实际路线接近并完成15分钟接出劳动。接出前继续核验原危险、失能、拒绝、合法接触、出口与资源；任何失效不搬人、不扣布水。只有实际接出才各扣1布1水，这些物资不是向成人给药或完成饮水。

户外只列出眼前最多八个实际步可达的安全干地。室内不读取门外实时安全点，先逐格走到真实门口，才现场选择八步内干地。没有可达点就停在实际门口。运输记录没有接收建筑、床位、同意提议，不会因为后来有空床而自动改为送床。

途中每次同步和实际移动边继续核验权限、原绑定目标、真实相邻路线、累计步数与新危险。旧路线不能凭重载截短、增加跳格或重新计数。八步为实际户外搬运总预算，不是直线距离；室内出口另按房间真实路径完成。

- 本人一旦恢复决定能力，立即结束例外，即使表达尚未恢复，也不继续代替本人选择去向。
- 仍不能决定但能表达的乘员只获得停止本次运输或最多15分钟暂不表示停止两项选择。暂不表示停止不是医疗、住房或概括授权；不能附带其他行动或停止别人的运输。
- 本人拒绝、施救者失能、病情转危重、路线/目标失效或新危险都会在最后真实位置停止。不会瞬移回家、自动续运或退还已经实际消耗的用品。
- 原危险解除、不再覆盖当前位置、强度归零或开始时间改变，且尚未到既定落脚点时，继续搬运已无当前依据，须停在真实位置。若已抵达安全落脚点，仅完成下放，不再移动。
- 实际到达后记录临时干地落脚，并恢复按本人当前能力决定的入口，不改写身体能力。照护、饮水、住宿和灾后交接仍需另行决定。

## 保存、观察与兼容

动作与运输均保存成人权限标记、原灾害、实际起点、出口、目标和累计步数。旧医疗与幼儿记录无需迁移；成人标记丢失、矛盾或混入其他模式会终止，不能退化成更宽的救护权。

现有公开健康与活动面板按干地模式显示“临时落脚”和“有限紧急权限”，不显示虚假床位。事件审计明确记录原危险、施救人、实际用品以及权限终止条件。本人停止产生的拒绝事实独立保存，不依赖可能被裁剪的事件或运输历史。

既有幼儿测试中“成人无入口”的断言现限定为**监护入口**；成人独立紧急入口由新测试验证。幼儿的监护职责、现有送床规则和危险消退后的照护连续性没有随本切片更改。
