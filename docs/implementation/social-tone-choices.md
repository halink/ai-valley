## 候选与边界

- `decisionContext` 为本人真正看到的人快照提供 `talkEligible` 与 `talkDistance`。候选必须活着、本人认识，且本人活着、未离谷、具备决定与表达能力；后续[精确社交对象修复](social-target-visibility.md)补充真实视线、合法接近与空间权限，不再仅以 `coLocated` 代表看见。
- 距离采用实际室内坐标；真实世界入口现在拒绝缺失房间坐标，不补造入口位置。室外采用原曼哈顿距离，不把同门牌当作室内同位置。
- 按距离与稳定ID排序，保留最近一人；其他候选按30分钟周期一次轮转，最多再选两人。稳定候选集有N人时，至多N−1个周期覆盖所有其他人。对象数不大于3、语气数不大于9。
- 每个对象都生成 neutral / friendly / hostile 三项。亲属、配偶、关系分值、对方库存或隐藏安排不参与选择。不优先友善，不删除表达不满，也不补造陌生或远处对象。
- 未满六岁、仅可撤回照护/撤离、乘员与家庭同行状态不恢复说话。原有船上词表白名单仍存在，但通用真实人物观察不从旧岸边坐标补造船上或岸上交流对象。
- 手工构造的旧 `DecisionContext` 可缺省新增可选字段；真实世界入口始终提供当时事实。这两个字段不写入存档，无迁移或新权限。

## 执行与不自动社交

编号解析绑定对象和语气，仍须本人填写原话；不能用额外字段改成其他目标或情绪。引擎仍在提交与实际完成时验证决定/表达能力、存活、所在地与实际接触，延迟回复或对方离开不授予远程说话权。

观察和菜单恢复均不写世界、计划、事件或关系。正常等候仅让对象候选轮转，不会自动说话、默认友好、同意、赠物或修改关系分值。实际选择任何语气按规则记录说出的文字和事件证据；后续[实际发言语气留存](dialogue-tone.md)同时保留实际语气，仅投递给既有听众。听者如何理解仍需另行决定。
