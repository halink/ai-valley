# 靠泊渡船的有限医疗救助

## 已接通的真实路径

已实际登船的人在靠泊期间失去自主行动能力时，岸上有能力的成年人可以从正常医疗菜单选择有限稳定处理，或在已有具体同意、幼儿监护职责、当前严格紧急权限下接出患者。它复用医疗护送，不把救助者自动安排上船，不增加船位或救援人员。

- 必须是唯一真实船程中的实际乘员，座位为 aboard，或是没有客座的实际操船人；船只的 tripId、船程的 boatId、患者坐标及室外状态必须相符。
- 只处理 posted、docked 阶段。原船在原码头的具体水格与相邻可用码头地格绑定到患者、船程、船只、码头及阶段，菜单选择和持久化中的行动均保留这个快照。多格码头的其他地格不算接触点。损坏但仍实际靠泊的船可以接出乘员，船体状况不等于已经沉没。
- 救助者先沿真实陆路走到这一地格。稳定处理仍需30分钟，耗本人1药剂、1清水；患者继续留船，不转移财产、不收取医疗费。接出需15分钟，耗本人1布料、1清水；必须有真实可达、具有使用权且空闲的诊所或驿舍床位。
- 接出完成时，患者从原船水格跨相邻一格到救助者所在码头，退出原船乘员表。未开航船费按原账目退回，已完成航程不撤销已付费用；只释放该乘员的占位。救助者没有登船，所以满载不需要虚构额外座位。仍有其他乘员或在船货物时不完成船程。
- 此后患者随救助者逐格走陆路、通过真实室内路线到原指定床位。到达床位不代表治愈、有人接班或获得长期照护。

## 同意、占用及中途变化

有决定能力的患者不会因为受伤或沉默而被搬走。船上现在可以接受、拒绝和撤回具体护送提议；这些只是原地决定，不能附带人物目标、码头目标或另一项安排。拒绝与撤回必须单独提交并立即生效，不能在等待五分钟期间被正在完成的接出覆盖；重复提交沿原回执，不再次产生效果。药物稳定处理仍只使用原有监护/紧急权限，运输同意不是治疗同意。

开始、行走期间、每个接触工作步和实际交接时重查原船与靠泊位置、当前意愿/能力/及时代理、物资和床位。开航、船体/船程被换、乘员已经离船、码头受损/撤除、改变停靠点、拒绝、恢复能力、及时代理出现、具体同意撤回或床位失效时，旧行动停止，不扣未实际使用的物资，不把患者移到新船或另一码头。两人竞争接出时只有第一次真实交接成功。

接出后的既有医疗护送也在下一步移动前重查原接收场所、使用权、保留床位和当前权限；途中条件失效，患者留在实际位置，不回船、不回家、不改送其他床位。一名救助者不能同时承担第二项实际医疗搬运。

## 保存与边界

新增快照是行动的可选字段，旧记录不补写历史、乘员、同意或费用。进行中的新救助保存原剩余工作时间和具体接触点，重载后继续核验；不会重新发放物资或退款。旧船上动作若没有真实有效接触条件则失败，须另作当前决定。

本项没有实现移动船只、held 水上停船、船对船救援、落水/游泳、拖船、沉船、替代码头转运、救助者登船治疗、医疗船航行或远程发现。靠泊救助不是自动召集人手或保证活命；患者仍承受真实生理消耗。
