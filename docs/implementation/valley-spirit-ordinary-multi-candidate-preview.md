# 普通规则多机会菜单预览

这是本机普通开发档的显式只读能力。与 `privateOrdinaryMultiFruit` 同时指定 `privateOrdinaryMultiCandidate`，作用域 `ordinary-native-multi-candidate-preview/v1`，原世界、闭雨最大可接受年龄（1–120 游戏分钟）及 2–4 个不同原生果源和不同落点。不得与单果源地理队列、封存或普通玩家运行模式混用。

在整点已提交世界的同一个只读 SQLite 事务内，核对真实闭雨、同世界当前授权的已有对应雨天气存档，以及每个公共果源实际在该头可读的有效果批。每项落点还必须属于可达、相邻、无产权和障碍的原生地理，并通过普通档空地状态及兼容性核对；不安装地面容量、不运行任何落果。果批时限和雨时限取较早者。只剩一个、无凭证或不同授权时没有菜单。读取前后重新核对相同的原生凭证、授权和当前公开天气；世界前进则前一菜单不可作为当前依据。

固定按原生果源键排列，两个落点指向同一果源不算两个机会。可信本机可以读取绑定确切同头原生证据的私有快照；另有只含编号和固定机会类别的匿名预览投影，不含世界、果源、落点、果批或居民标识。没有执行编号、投票、派发、模型、配额、排期、候选队列写入、公开接口或玩家画面。

## 独立签审的本机内存选择

另行配置 `privateOrdinaryMultiSelection`（`ordinary-native-candidate-memory-only/v1`、独立 Ed25519 审核公钥和原生内存测试替身）才可申请单次分离式选择。替身接收随机相关令牌、候选编号及从同一原生快照得出的粗粒度公开生态特征：果源当前可采存量「一／多」、实际有效窗口「短／中／长」。不是果龄、精确存量或地点。若所有选项在这些真实非个人特征上都一样，仍保留普通菜单预览，但不发送选择请求。原有编号预览格式不变。

本机审核签名绑定原物理存档、同头菜单、令牌及实际提交字节。严格编号回包不得附加理由、身份或其它字段；确认后重读世界、天气权限和证据。存档推进、撤权、断线、错误格式或已用过的句柄不会返回选择。成功只返回 `selected-detached-preview`，不持久化，关停或重开后没有原批准或选择结果；只有另一次新的明确签审可以开始新的预览。没有跨重开的耐久一次性账、真实模型、共享配额、候选接受、队列写入或 G2 执行权限。

## 选中编号的原生分离式演练

`privateOrdinarySelectedRehearsal`（`ordinary-native-selected-detached-rehearsal/v1`）要求本机另一把独立 Ed25519 审核密钥，不能使用内存选择的密钥。签名绑定临时选择的原审核字节、相关令牌、实际提交字节、物理原档和确切压缩世界头，以及同头果批、原归属、对应闭雨、落点、有效期和现时授权。签审前后重复核对；选择、签名或过程不进入真实存档、队列和公开接口。重开不继承临时选择。

只在内存副本里把被选果源的一份果作为假想落地，再分别运行两个原生普通分钟，观察居民是否实际看见并自主选择拾取；没有给居民记入库存。看不见、观察了但未核实拾取、接近原到期时间和验证成功是不同状态。正式档只有已核对普通空地兼容性与地理适宜性，不因演练假想物品就有地面容量、转移、排期、配额、G2 或执行授权。
