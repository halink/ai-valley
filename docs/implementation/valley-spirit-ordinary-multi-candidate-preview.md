# 普通规则多机会菜单预览

这是本机普通开发档的显式只读能力。与 `privateOrdinaryMultiFruit` 同时指定 `privateOrdinaryMultiCandidate`，作用域 `ordinary-native-multi-candidate-preview/v1`，原世界、闭雨最大可接受年龄（1–120 游戏分钟）及 2–4 个不同原生果源和不同落点。不得与单果源地理队列、封存或普通玩家运行模式混用。

在整点已提交世界的同一个只读 SQLite 事务内，核对真实闭雨、同世界当前授权的已有对应雨天气存档，以及每个公共果源实际在该头可读的有效果批。每项落点还必须属于可达、相邻、无产权和障碍的原生地理，并通过普通档空地状态及兼容性核对；不安装地面容量、不运行任何落果。果批时限和雨时限取较早者。只剩一个、无凭证或不同授权时没有菜单。读取前后重新核对相同的原生凭证、授权和当前公开天气；世界前进则前一菜单不可作为当前依据。

固定按原生果源键排列，两个落点指向同一果源不算两个机会。可信本机可以读取绑定确切同头原生证据的私有快照；另有只含编号和固定机会类别的匿名预览投影，不含世界、果源、落点、果批或居民标识。没有执行编号、投票、派发、模型、配额、排期、候选队列写入、公开接口或玩家画面。
