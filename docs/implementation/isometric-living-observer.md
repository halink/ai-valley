# 等距生灵与墓位观察

这是在恢复的可选连续等距视图上新增的一批**只读客户端**内容，不修改模拟、模型、存档、正式入口或默认2D。运行方式仍见[连续观察恢复说明](isometric-observer-restoration.md)。

## 当前画面依据

- **六种野兽：**野猪、灰狼、鹿、野兔、赤狐、野鸭。**五种家畜：**鸡、山羊、绵羊、家鸭、牛。每个图形保留快照原ID、类型与整格位置；不从领地、畜舍、活动目标推造当前位置，不生成新个体。身体颜色和轮廓是物种通用程序美术，不是未记录的个体花色、年龄或性别事实。
- 活动目标仅用于朝向；记录中的休息使用低姿态，近处觅食/饮水显示低头，有远处目标显示原地腿部相位。所有相位都不改变位置，不证明进食、饮水、攻击、繁育或产物已经结算。缺失活动保持静态中性姿态。昼夜使用当前世界时刻的统一色调；暂停、断线、隐藏与未启用视图时停止相位。
- 鱼群只读取原 `FishPool.species` 的正存量。七种鱼分别着色，**每个登记品种一个示意符**，一个混合鱼群仍只有原水域ID，共用实际 `shoal.at`。不会生成逐条鱼ID，不根据季节、栖地、当前可钓品种或总量倒推组成。空鱼池只留下两条水纹，不画鱼。
- 鱼种缺失、未知品种、数量无效、逐种份量与总量不符，或鱼群位置不在当前水格时显示带原因的中性问号；缺少位置单独计数，绝不移往附近猜测水面。
- 墓位只在已有记录位置绘制低边框。空位无碑，预留或只有人物ID而没有安葬时间时使用低矮木签。**只有人物ID与有效且不晚于当前世界时刻的 `buriedAt` 同时存在才画墓碑**，包括合法的0时刻。缺失/无效/冲突记录保留问号。未记录墓志、鲜花和仪式不补画。
- 护送中的家畜有准确记录位置时保留问号说明，不画成无人照看的自由行动动物。区域护送不复用旧谷内坐标。死去的动物不画成活体，室内动物仍通过原2D的房间入口观察。未支持种类和位置另计。

## 接线、命中与预算

- 图形使用与地表、住宅相同的2:1投影、整数像素与前后顺序。像素命中和绘制使用同一对象序列，保留原 `animal` / `beast` / `fish` 身份进入原详情页。
- 已支持的动物定位继续留在等距视图。未知位置、死去个体、室内/护送动物或未支持外观回到2D并说明原因。原来的驯化同ID解析仍适用；不会为鸭子新建显示身份。
- 空位、预留位和墓碑均可以点选查看原ID、坐标和状态。墓位不虚构一个人物选择或安葬事件。
- 复用现有离屏桶、可见范围、192对象和60,000像素标记预算。每个获准显示的生灵预留256标记，人物仍预留1,024；以后相位也不得突破预留。500只密集野兽的测试核对省略数和每一相位总量。
- 新快照索引只判断支持范围，**不为全世界生灵预先生成美术**。只生成可见候选；动画使用已接受记录，不重新扫描世界集合，也不重建静态地表。整体页面/GPU性能并未因此验收。
