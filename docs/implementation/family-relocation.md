# 家庭迁居、实际同行与收养后同住

本项是[批次 2](roadmap.md#批次-2-照护继承与人口接续)的一个已实现切片：镇内家庭换房、已经实际入谷的访客家庭定居，以及另外接受的收养后同住。未成年家庭从镇外首次入谷、全家迁出、公共接待人的权限和镇外床位仍待实现，不能把[成人驿路分段同行](adult-family-journey.md)视为这些流程已经完成。

## 由哪些人决定

- 成年监护人可为 2–8 位明确家庭成员提出安排。可以只带一个孩子，也可以与愿意同行的其他成年家人及孩子同行；未同行孩子须有留在原处的合格监护人。
- 提议固定同行者、目的地和门口地址、每个人的实际床位、户外集合点、出发时段、每人旅途餐食与水，以及每个孩子的护送、供给和到达后同住照护人。能够独立行路的孩子仍需本人同意；年龄可核实且未满六岁的孩子由已获同意的监护人接送。一位监护人同时最多抱送一个不能独立行路的孩子，多位孩子需要分别接受责任的多位监护人。
- 房主、同行成年人、全部现有监护人和能够表达的孩子分别接受同一份安排。未核实的远方死亡、失能或离镇不能替代监护人的签署。室内会面必须双方有使用权且实际能接触。
- 签署只确认本人的选择，不替其他人决定。收养登记不自动签署迁居；原监护人与孩子仍分别确认。记录保留完整条款，即使近期记忆已经轮换，答复菜单仍显示成员、床位、地址、集合点、期限和照护责任。
- 原出发窗口尚未结束时，模型回复经过几分钟不会仅因最早出发时间已经过去而失效。已经签署的条款不随回复延迟重写。

### 年龄未知与跨六岁本人签署

[年龄权限补强](family-relocation-age-authority.md)把可核实的幼儿年龄与未知出生资料分开。未知年龄不授予幼儿免签、监护接送或成年权限；原行程暂停且保留原约、原床和实物。跨六岁后需当前有能力的本人实际接受同一安排，已有真实本人签署不重做；补签不改 ID、原出发窗口或期限，暂停后仍须另选复行。本人负向选择不因年龄未知被过滤。

### 连续世界时间与固定出发窗口

世界时间允许小数分钟，真实引擎的 `stepWorld(w, .2)` 及连续累计都会产生小数。`departAfter`、`departBefore` 是绝对世界时刻，不是整数数量：两端必须是有限数，最早时刻非负，结束晚于开始和当前时刻，窗口长度及最晚时刻仍受未来一天的上限约束。普通菜单保留生成时的 `w.minute + 5` 与 `w.minute + 240`，不取整，也不在回复、签署或重载时重新计算。

提议可以在原最早时刻之后完成，但完成时原窗口必须仍未结束；窗口结束后不能补签新提议。已接受安排的启程检查仍使用原来的闭区间 `[departAfter, departBefore]`，且开始行动、实际完成时都重新核验，因此最后一刻入队不保证赶得上启程。床位等整数数量的校验不变，旧整数时间记录也继续有效。

## 床位和原住处

目的地限于有实际产权人独立确认的住宅或会馆，不把公共产权虚构成一位自动同意的接待人。全部签署后预留具体床号。预留与原有居民、临时借床、当前医疗转运和实际室内占用共同核验；不能让多个家庭占用同一张床。原居民即使还没有睡过，也先取得其合法床位分配。

出发、接送、沿路前进和到达门口都不释放原床。每位成年人及能够表达的孩子分别登记实际到达；年龄可核实且未满六岁的孩子由原安排指定的监护人办理。孩子登记前，其照护人必须先实际登记同住并仍在场。登记重新核验房主权限、床位、监护及到达后的随身口粮。

只有这一人的登记成功后，才释放其旧床与临时住宿。另一位尚未登记者保留此前的住宿。已经完成的入住不因其他人撤回而倒退。房屋产权、出生与收养亲缘、继承依据、个人库存和钱款不合并。

## 旅途不是瞬移

- 各人先实际来到户外集合点，并结束本人其他行动。系统不能为了启程而取消任何人的计划。启程必须是一次单独的决定，不得夹带后续独立移动来绕过同行约定。
- 年龄可核实且未满六岁的孩子可由指定监护人另选接送。监护人先实际走到孩子所在的室内或户外位置，再沿室内出口与户外路线带到集合点。接送受阻、能力恢复、拒绝或权限变化时停止在真实位置；没有通路的房间不能被当作已经走到门外。
- 只有各方已接受的行程才逐格推进。同行按仍能独立行走者中的较慢速度行路，身体损耗与世界时间继续发生。同行期间可选择等待或撤回，不能同时另行工作、睡眠或自由移动。
- 成年人自带自己的旅途餐食和清水，孩子使用其已签署供给者携带的现物。出发实际消耗每人一份，之后每 120 游戏分钟再消耗一份，并保留到达后的至少一份供给。过期物品、公共库存、他人未同意的财物和未来收入不计入。不同食品批次只提供各自实际营养。
- 路阻、失能、脱队、当前照护变化或粮水不足会暂停旅程。恢复路线不自动重启，需要本人另行选择；超出已签署口粮的新路程需要重新商量。不到进食间隔的复行不会再次扣粮，也不会在事件中声称已经消耗。
- 暂停、撤回或到期不自动折返。监护人可另选把年龄仍可核实且未满六岁的孩子送回尚未放弃的原住所真实床位，仍须有当前监护、双方使用权及实际通路，不改写住处或瞬移。

途中不会读取远处房屋的新情况来提前告知居民。目的地损坏、床位或产权变化在实际到达后核验。未同行的权利人可在自己所在地撤回同意；房主撤回即不再保留其授予的新床，但消息未实际送达时不会远程让同行者停步。面对面告知或抵达核验后，家人再处理未完成的安排。

## 持久化与观察

`familyRelocation` 保存提议、各人签署与撤回证据、原住宿、床位、旅途剩余路径与小数步进、已消耗餐次、接送阶段以及每人的实际登记事件。加载旧世界只添加空记录和规则定义，不补签、不造物、不移动居民。

重启继续已接受的实际行程，不重复扣除出发口粮，不重置原期限。签署、撤回和到达证据跨近期事件裁剪保留。人物面板显示同行、接送、暂停和各人的登记状态；观察记录不是递送给远处居民的消息。同行期间不会消耗尚未执行的个人惯例次数。

可选的[逐成员供餐证据](family-journey-meal-evidence.md)只在原物理扣减处观察各人实际meal、水和原批次，不新增世界或存档字段。运行时仅持久提交后发布，原签署、行路、到达与模拟规则保持不变；未观测的旧记录仍未知，不是完整消费账。

## 验证与剩余边界

`tests/family-relocation.test.ts` 覆盖独立拒绝、监护变化、收养与同住分离、分人入住、真实路线、供给守恒、路阻与复行、室内幼儿接送与原址返回、多幼儿的分别护送、远方撤回、远方房屋变故、临时床位冲突、模型条款绑定、迟到回复、惯例不丢次数和存档恢复。已有 `rooms`、`commons`、`adoption`、`agency` 和观察状态回归继续验证相邻行为。

小数时钟回归通过真实 `.2` 分钟步进、`decisionContext → buildChoices → parseChoice → submitPlan` 和行动完成验证普通提议持续可见、原窗口不被改写、各方分别接受、实际同行及分人入住。另覆盖非有限值及一天边界、行动执行期间错过期限、SQLite 内存数据库中待执行行动与已签署记录的小数时间往返。所有世界均由测试创建，不读取真实存档或调用模型。

2026-11-07 本轮验证：家庭迁居 24 项及涵盖房间、借床、收养、惯例、医疗、访谷与成人同行的 128 项定向回归通过；全仓离线规则测试 1354 项通过，TypeScript 检查、服务端编译、前端生产构建及差异检查通过。[独立审查](../reviews/family-relocation-clock.md)未留阻塞问题；审查提出的“启程活动已开始后跨截止线”覆盖建议已补上并单独复验。构建仍有既有的大包体积警告，本轮未做浏览器、真实模型或多年长期验收。

本切片没有实现：

- 镇外亲子家庭的首次访谷和有真实接待床位、旅费及照护的迁出。
- 没有具体产权人签署时的公共家庭接待授权。
- 孕产专门转运、医疗急救替代路线、自动呼叫援助或无人接班的连续照护。
- 房屋转让、财产合并、把原监护人移出家庭或变更既有长期照护合同。

因此批次 2 的家庭设计仍是**部分交付**，不能仅因镇内同行测试通过而标成整批完成。
