# 谷灵：G2 地面落果承载模型

这是关闭运行权限的基础，不是可玩的落果功能。地面果实是一份独立有限物品，不是可再生资源点，也不直接进入居民库存。每份绑定效果 ID、实际雨 ID、成熟果源实例与原位置、地面实际位置、放置时间和产权。当前定义只支持小山谷已登记、现有引擎允许公共采集的成熟鲜果源；地面仍是公共产权，不把私人果实改为公共果实。源身份绑定固定的登记编号与位置；当前小山谷不重用编号，未来若增加原址替换，须先登记独立实例世代。

放置预检只检查**指定**的相邻公共草地格。果源与目标之间不得隔着封闭边界，目标不能是田地、自然资源、公共出入口、井树、墓位、有权利或施工限制的地面；还要能从入口按实际通行规则到达。原大型世界的未启用产权定义不被当作当前小山谷的实际用地权。不存在改填别处、补果或自动发现的后备逻辑。

预检必须提供显式的世界总承载量与单格承载量，当前没有生产默认值；两者未批准时不允许运行。4096 条是结构大小的安全上限，不是获批数量或目标容量；每次候选量仍为一份。提供承载诊断不等于系统已支持放置、发现或拾取，这三项能力均报告为未启用。

当前不提供实体写入函数，世界存档预检拒绝任何 `mvpGroundFruit` 字段。以后必须在采用前接好同一世界事务中的果源扣除、地面增加、权威收据、跨重启去重、真实发现与自主拾取；拒绝未知效果依赖，关闭调度不删除库存。放置后地形变化、果源被采空、雨证据窗口过期均不能抹掉原物品或变更产权。跨期再生、承载额度、相态后窗口、冷却和公平约束须在真正启用前审查，不在本切片擅自冻结。

开发验证仅含 TypeScript 构建与本地定向测试：现有小山谷的实际地形预检、纯读取、非法及阻断目标、产权、双层承载、稳定来源结构，以及未获权威前的存档拒绝。临时 SQLite 冒烟经过一次正常规则推进，确认未启用该结构，直接提交仍被拒绝，原保存版本不变。未运行长测、未调用模型；谷灵仍不提测。
