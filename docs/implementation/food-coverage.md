# 可达口粮的保守估计与两日提醒

这是实施批次 1 的一项有限交付，不代表完整补给路径或整批验收已完成。正式居民的正常决定上下文现在附带一个只读口粮估计，低于两日时，模型提示中会明确写出“已核实的可达食物估算不足两天”。它提供信息，不替居民选择、取货、进食、交易或求助。

## 什么会计入

每人的估计包括自己当前携带的可食实物，以及**至多一处**能独立领取的实际存货，取两者合计可用营养最多的一种方案：

- 符合原公约或已通过储备议案、本人已知且在附近核对到的共屋一次有限领取，沿用实际权限和滚动营养限额。
- 成年人已经登记归自己的原址遗产包裹。
- 本人到店前或店内实际可见、尚未上架的自有店货。离店只能知道店址，不能远程读取现存余粮。
- 本人在共同储物处附近核对到的个人份额。另一位出资人的物资不因此变成自己的口粮。
- 双方已同意、实物已预留，且本人到场看见或已经获知的具体赠与。接收者仍须自行决定是否接受。
- 符合旧档救急资格的未成年人，在现有累计一天限额内可取的本人遗产食品。使用与实际领取相同的份额和批次位置，不叠加其他备选救急包裹的限额。

领取检查沿用对应行动的年龄、资格和当前权属规则。步行使用当前实际地图，包含道路耗时、伤病移动速度、室内出入与工位移动、实际领取时间和进食前的五分钟。断路、不能移动、被占用的工作位置、来不及领取的赠与和途中失效的整包赠与不计入。商铺单次最多取 100 份每种食品，共同储物单次最多取 20 份，与现有行动上限一致。

野外尚未采集的浆果、未收获的作物、未来鱼获、尚未取得的牲畜产物、预期再生、商人和其他人的私有库存、未成交的购物、未来照护承诺，以及未经授权的公库存量都不计入。本轮不新增公共领粮权限。正在被护送的医疗乘员只能先等待或实际结束护送，随身食品不算当前可自主进食余量；不会假设取消护送已完成。幼儿或其他不能独立行动的人不会因为身边有粮就被视作能自行取食，会被标记为需要实际照护。

## 营养、保质期与重复计算

食物沿用原批次的营养定义与到期时刻；观察不会给旧食品补登记或刷新保质期。实物数量是上限，批次账多于实际库存时不会多算。缺少可核实保质期的食品不计入，并注明未登记。单独不足一份的可食残余不视作一顿饭。

两日提醒使用本人保存的生理定义计算日常饥饿增长。可用营养按照“能取得的时间至原到期时刻”分时间段，先考虑较早到期的批次；每段最多抵扣一次该人的日常消耗。大量即将变质的粮不能仅凭数量被算成几个月储备。

汇总接口按实际容器、原批次和份额所在区间取并集，不把各人重叠的估计简单相加。共同账户的个人份额与赠与预留分别对应原实物，公共账面余额不再算一份。原址遗产领取后转入本人背包，也不会同时计入原址。汇总的 `uniqueNutrition` 与 `stockDays` 只是去重后的现物营养与集体消耗当量，**没有按个人到期窗口折减，也不代表共同所有或每个人都能吃到**。个人两日提醒只使用自己的 `days`。

## 明确的误差与未完成部分

这个数字是营养当量估计，不是逐顿进食计划或生存保证。它不会预测当前饥饿、体力、健康和天气能否让人活到领取完成，也不承诺途中不会再遇到阻断、撤回、竞争或临时工位占用。实际执行仍重新核验全部条件，紧急决策保护仍使用独立的实际行动预测。

为避免将两条互相竞争的行程同时算成可用，首版只加入一处取货，不把多个仓库相加。两日提醒因此可能偏保守：居民可能还有需要先返回查看的店货、第二处自己的储物、可购买食品或可以自主采集的来源。提醒中的“已核实”不能解释为全世界只有这些粮，也不能解释为居民已经决定领取或接受赠与。

[已知浆果地点与替代采集](known-food-sources.md)另补正常菜单的返回查看与可达备选入口；这不改变本页口粮范围。查看不会保证远处尚有浆果，采集完成之前仍不计入营养余量。

## 只读观察入口

“场所 → 粮食”现在显示社区去重现物与逐人保守估计，人物档案也显示同一份个人口粮。社区数字不是全世界库存，没有按个人到期窗口折减，也不意味着共同所有；个人天数仍核对自己的需求、保质期与至多一处取货。面板分别标记照护需求、医疗护送与保质期未登记，缺少快照数据时不显示假零。临近两日的显示向下取两位小数，避免将尚不足两日显示为已达两日。取货来源与耗时是估计，不是居民已选计划或实际领取回执。

报告在服务端使用原 `settlementFoodCoverage` 生成，作为快照和增量流的独立观察元数据，不写入世界、存档、居民记忆或个人决定上下文。客户端只呈现，不重复寻路或注册食品批次；重连、更新及报告撤除都沿用同一快照版本。旧客户端不需要认识新增字段。

[隔离长期证据输出](isolation-evidence.md)复用同一计算，按日保留端点口粮、实际动作计数、变质增量、等待采样、保护记录损耗与人口。缺少完整数量账本的产量、消费与毛伤害保持未知，不从库存或净健康变化猜测。跨多个地点的可执行补给安排、完整日供需账本、真实模型前十五日及四季供给验收仍按[实施批次](roadmap.md)推进，未因面板交付而视为完成。

所有测试使用代码创建的隔离世界，不读取真实存档，不需要模型密钥，也不产生真实模型调用。
