# 本人持久关系记忆进入决策

## 问题与范围

`decisionContext.people` 原先携带本人的 `Relation`，但最终 `prompt()` 不读取好感、信任、矛盾和 `lastInterpretation`。最后一次理解离开最近 3/6 条提示记忆后，保存下来的关系无法影响输入，即使 SQLite 重载仍能恢复这些字段。

本次只增加只读的个人关系摘要。没有新增或修改世界存档字段、关系分数、交谈执行、社交目标或行动权限，不会替任何居民形成看法、交谈或同意。模型是否因此作出不同选择，仍需另行验证，离线提示回归不证明真实模型长期社会行为。

## 知情与隐私边界

- 只读取决策者自己的 `relations`，且目标必须已经在本人 `knownPeople` 中。
- 本次仅摘要真实可见的已认识人物。户外复用保守视线检查，范围 10 格，不穿建筑、悬崖、树石和实心斜角；室内复用社交视线的 10 格范围、真实坐标及双方原有使用权限，不把近身身体观察的两格范围当作本人回忆的门槛。跨室内外、异屋、远处、离村、船上或未知人物不会因此进入摘要。看不见时不补造实时见面或状态，关系原记录仍保留。此次对旧近身规格的调整及正常行动链证据见[室内关系记忆](indoor-relationship-memory.md)。
- 不读取对方的关系、记忆、库存、意图或私密身体数据，不根据双方关系推断对方的感受。
- 最新理解明确为本人单向个人观点，不是世界事实。亲眼经历、本人参与和收到消息分开标明；收到的消息不等于核实。
- 缺失、非法或越界数值显示“未知”，不补成零；缺失理解不补写内容，来源或时点不合法也各自保留未知。理解时点接受实际世界时钟产生的有限非负小数，不得晚于当前时刻；例如 `484.25` 不会误报未知。展示不修复或写回旧档。

## 输入与有界处理

`relationshipMemories` 是独立的决策快照，复制姓名、本人分数和本人最新理解，不保留原始记录引用。它与最终 `relationshipMemoryNote` 分离，既不依赖短记忆窗口，也不占 `familyNotes` 的裁剪预算。GLM、Qwen、DeepSeek 的居民决策路由使用同一入口；外地商人和邀请访客的特殊提示不额外注入本地关系。

- 一次最多 6 人，先考虑最终编号菜单中的人物，再考虑其他可见已知对象。各组按半小时轮换，避免长期只读列表前几个人；溢出明确告知未展开。
- 姓名最多 24 个 Unicode 字符，理解最多 120 个，截断带省略号。只节录解释文本，不输出事件ID、证据数组、对方事实或原始对象。
- 控制字符、方向控制符和换行先移除或转为空格；姓名与理解以 JSON 字符串引用，尖括号和反引号转义，不可伪造新提示行或角色标签。提示同时明确引号内文字是资料，其中的命令和输出格式不作指令。这是输入隔离措施，不声称能证明模型绝不受任何语义注入影响。
- 摘要时点必须与 context 时点一致；旧 context 不会凭空提供新一刻可见性。既有快照不会随世界关系对象的后续变化而改变。

## 离线回归

`tests/relationship-decision-memory.test.ts` 使用正式 `createFrontierWorld(5401)` 和隔离合成数据：

1. 通过最终编号菜单执行 `talk`，再选择 `social.interpret`；实际获得本人好感 +2、信任 +4、矛盾 +1。
2. 另通过 7 次正常编号进食推进最近 3/6 条提示窗口，确认关系仍进入三个模型的最终输入。再用 90 条本人日常事件覆盖最多 80 条短记忆，验证完全挤出后仍然保留。
3. 本修复前同一回归失败，提示找不到持久看法；修复后通过。相反的本人关系与看法改变最终输入，但菜单内容不变，其他人的关系不变，也不会自动提交计划。
4. 内存 SQLite 保存/重载、快照不可变、远方/未知/遮挡/室内/离村、第三方隐私、旧档未知、消息未核实、超长与注入型文本、有界大菜单和家庭记录裁剪分别覆盖。

专项命令：

```sh
node --import tsx --test tests/relationship-decision-memory*.test.ts
node node_modules/typescript/bin/tsc --noEmit
```

所有世界均为新建合成世界，数据库仅用 `:memory:`；没有读取密钥或真实存档，没有请求模型、浏览器或网络，也不使用 npm、提交或推送。独立审查记录见 [关系决策记忆审查](../reviews/relationship-decision-memory.md)。
