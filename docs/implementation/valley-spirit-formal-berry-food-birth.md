# 谷灵：正式地面浆果食品批次封存

这是封存开发库的落地记录，不是拾取、更不是居民收到食物。新的 v2 独立签批含确切 `food/life@N` 和浆果寿命天数；落地事务在实际同一修订调用原生食品寿命规则，规则不符或期限无效就不落地、不扣源。通过才能同事务固定野浆果源、已扣源收据链接、品种、一份数量、实际落地取果时点、食品定义和确切到期时间；不会增加居民库存，不另造第二份产出或公开事件。

后来切换生效食品版本不改变已落地批次的原定义和到期。若其原定义无法核验，不将它显示为可用。旧 v1 历史收据可继续读取原结果，但旧签批不能创建新批次，既有无食品证据的出生不回填、不推断鲜度、不凭旧签批升级。读取和重开不会改变这些事实。

正式居民选择、拾取原子结算及按原期限入本人食品账仍未实现；不能直接调用普通新增食物规则重置出生时间，也尚未启用生产、公开记录、真实模型或提测。
