# 有限狼狐栖地、繁育与迁移

这是第 5 批的独立生态交付。它替换狼狐“每种最多一只”和本地灭绝后自动生成新个体的规则，不代表完整食物网、地形灾害或真实模型四季平衡已经完成。代码只使用隔离世界验证，不读取或改写正式存档，不调用外部模型。

## 实地栖地与有限个体

- 新世界在地图上为灰狼和赤狐各登记两只成年异性个体。第二只在可步行到达的邻近林地，不是隐藏的无限外来储备。默认地图每种有两个实际巢位、每处最多三只；缺乏可用邻地时不强行生成配偶。
- 栖地需要仍存在的树木遮蔽、至少六格互通草地、未处于活动灾害中，并有可沿实际通路到达的泉水存量或水岸。建房、树木耗尽、围栏、断桥、河流和洪水都可能使条件失效。登记坐标不等于永久可用。
- 食源是当地可达的现存猎物和共享小兽库存。前者沿用原有追踪与攻击，后者只有到场进食才扣量；迁移不会复制食源或给动物免费补满饥饿。多个栖地可能观察到同一份食源，它是可达量估计，不是独占预留。
- 小兽库存仍是简化的种群份量，不是逐只有性别的动物。只要仍有存量，保留原有受季节限制的有限增长；耗尽后清除剩余增长进度，不从零恢复。

## 繁育、幼崽与疾病

春季、至少 28 游戏日龄、健康至少 75、饥饿低于 53、口渴低于 65、无疾病和迁移的成年雌雄，须实际位于同一登记栖地、五步内可达。母兽须在巢位附近，栖地有食水、遮蔽、至少三份可达食源和可预留幼崽的位置。已登记的亲子、同父或同母手足不配对；没有历史亲缘证据的个体不补写家谱，也不声称已实现完整遗传模型。

受孕预留一个位置，灰狼约六游戏日、赤狐约四游戏日后重新核验母兽健康、实际巢位、食水和容量。条件不足最多等待一个游戏日，然后终止孕育并记录原因。成功出生登记独立身份、双亲和栖地，使母兽饥饿增加；同一母兽两次孕育至少间隔 28 日。父兽受孕后死亡不撤销已有妊娠；母兽死亡会清除妊娠，不能从尸体产生幼崽。

幼崽前七日不会自行袭击人畜或追猎。它会跟随仍存的母兽，在近处从母兽已有营养获得补给，母兽的饥饿和体力实际受损；母兽仍须吃到真实食物来补回。也可以耗用实际小兽库存。没有亲代或食源时照常承受饥渴、健康下降和死亡。这是简化营养转移，不模拟乳量或完整育幼行为。

持续两日饥渴、拥挤或实际可达的患病动物接触，会积累野生动物疾病暴露。疾病有发生时间、严重度和可查接触来源；恶劣条件加重，条件改善可以缓解，但期间仍造成健康损失，不被普通进食后的恢复立即抵消。疾病只适用于狼狐，不新增人畜传染规则。缺食、缺水、疾病、狩猎和衰老继续导致真实死亡。

## 迁移与守恒

栖地不适宜、成年后巢位拥挤或春季缺少可达异性配偶时，现存个体可以选择另一处有食水、遮蔽、容量与通路的登记栖地。目的地的迁入和孕育都占预留位。怀孕、患病、未成年或正在攻击的动物不会发起迁移。

迁移每次移动最多一格，继续消耗饥渴和体力，仍可能死亡或躲灾。途中逐次重查道路和目的地；被阻断或食水消失时取消，保留当前位置和原登记栖地。真正抵达后才同时记原地迁出、新地迁入，并更新原个体的巢位。没有瞬移、复制、脱离地图的无限补充或从灭绝自动补种。

每处栖地满足：

`现存登记个体 = 初始登记 + 出生 + 迁入 − 迁出 − 死亡`

迁移中的个体仍计入原地，并在目的地预留空间；这不是声称它仍站在原巢位。登记个体记录不因死亡被原有短期清理删除。当前仅有这些已登记邻地，不动态开辟整张地图的栖地网络。

## 观察与旧存档

生态面板显示栖地人数、出生、死亡和迁入迁出。个体档案显示亲代、疾病、妊娠、迁移、食源估计和栖地账目；开始孕育、出生、迁移开始/取消/抵达、疾病与死亡均产生带动物身份和实际地点的事件。居民是否获知仍走既有目击规则，没有把观察者全知信息直接交给居民。

旧档只给现有狼狐登记栖地与新账目的起点，保留身份、性别、位置、死亡、攻击警报、已有妊娠和耗尽食源。不补雄兽、不补已消失的物种、不回填旧亲代或历史出生。缺少旧小兽库存时登记为空。旧档只有一只雌兽或已全部灭绝时，不能靠升级恢复可繁殖种群。

同一时刻重复推进不会重复消费、移动、出生或死亡。存档保留迁移目的地、预留位、疾病和计数；长步进只在当前状态做有限核验，不倒算多轮历史迁移或出生。此批次不覆盖其他物种。后续[四种野生动物有限种群](wildlife-population.md)接通本地繁育与灭绝不复生；仍未宣称完整食物网守恒。

## 回归与验证边界

[独立回归](../../tests/predator-ecology.test.ts)覆盖新世界雌雄、旧档不补种、十日逐分钟自然推进、两物种出生和育幼、配偶/成年/健康/季节/食水/遮蔽/空间/洪水阻断、妊娠预留与终止、亲代死亡、逐格迁移、途中失效、SQLite 重启与同刻重放、疾病接触/恢复/死亡、灭绝不复生和观察内容。原有追猎、露天牲畜袭击、居民避险与驯鸭测试继续运行。

这些是离线规则和内容验证，不是浏览器像素验收，不是外部模型行为验证，也不保证新世界能长期维持捕食者数量。完整亲缘、疾病品种、栖地扩张、季节资源平衡、足迹转告与长期生态档案仍待后续批次。
