# 谷灵：居民现场发现与自主拾取意图

这是开发进度，不是已开放的落果拾取。内核只接收带合法落果收据与存量的小山谷状态。调用方必须提供已提交的权威世界，而不是观察者快照；模拟拷贝、错误收据、未知状态都不能供给居民视角。

单次检查只针对一位居民：必须本人活着、能作决定、清醒、实际位于室外、未在区域路上、船舱或实际医疗转运中。地面果实须处于当前视线内、附近路可达、无遮挡、保持公共产权与当前地块访问条件。沿用邻近资源的十二格局部范围；一次最多提供四条个人观察。遮挡、走不开、人在室内时不以既有地名、旧门口位置、候选、天气年鉴或谷灵全局视角代替观察。观察不传播给别人，也不写居民记忆；仅返回可供后续公平记录使用的稳定个人发现标识。不向居民透露降雨收据、果源或候选。

自主拾取只允许本地规则选择器的**最终空闲分支**询问，不识别等待交易之类的普通等候为闲暇。饥饿、口渴、休息、已接受计划、实际活动及生理保护优先。只可能选择本人正站着的格子上的一份果实，不为了它改变路线，不自动吃，也不记作已受益。返回的拾取意图绑定本人、版本、现场发现、果实原始放置事实与公共产权。

未接入规则运行器、实际动作、持久发现/拾取、公平计数或权限开关。接入动作时仍需在同一权威事务中重验当前居民、位置、权限、意图与同一份果实，原子扣除地面存量、增记居民库存并写结算证据；重复或竞争不得二次得果。关闭新落果不得清除既有落果或阻止合法处理。本内核不会凭意图修改任何世界状态。

用隔离内存存档内的实际落果收据完成本地单元验证，覆盖本人的可见性和访问权、遮挡/室内/旅途、现有需求的优先级、无副作用、单次现场精确意图。未调用模型、未做长测、不单独提测。
