# 谷灵：落果供给的只读测量

`auditMvpSpiritFruitStock` 是默认关闭的隔离开发读取函数；不接入公开页面、运行入口、生产权限或玩家存档。只有明确指定隔离审计范围、已知作用记录及已经对齐的世界和资源时钟才返回结果。输入为一次可信、已提交的隔离快照；缺少数据不填零。

- **实际库存**：分别读取鲜果源、未拾取地面实物、仍在谷中活着的居民随身鲜果和其他居民记录的随身鲜果。地面合法格数不代表居民看见、走到或获得；合计只覆盖这三类位置，不计建筑、货运、遗产等其他库存，不声称是全谷可用存量。
- **已记录转移**：单列已提交的落果扣源、地面入账、实际拾取扣地面和个人入账，且用收据对账未拾取地面数量。普通采集、库存差或出现在地面都不是第二次谷灵产出。
- **普通自然再生与归因**：历史存档仅保留当前资源和分数进度，没有每次再生的独立完成记录；同期居民采集也会改变数量。历史实际再生量标为未记录，不能从净库存变化反推落果让多少果实长出来。只在显式选择时，从同一已提交快照克隆一个最多 1440 游戏分钟的窗口，不运行居民，直接使用现有再生规则，返回在固定输入假设下的计算结果。该计算不是实际发生记录、不归到谷灵名下。只有无落果、有落果且其他条件受控的对照，才可说明特定样本中的间接差额（见[单次对照](valley-spirit-renewal-audit.md)）。

若后续需要生产评估，须另行明确批准额度和冷却，并在普通资源再生事务中写入实际 **自然产出** 增量或流量收据，与采集、谷灵转移分别落账；单凭这一精确自然总量仍不能构造现场的无落果反事实。当前不冻结生产数值，不启动动态配额、不发通知、不把居民普通供给记为谷灵产出。

普通 Godot 规则会话现在有一个默认关闭的开发观察接点。有显式提交回调和观察者时，它仅在原生再生真正增加已登记公共鲜果源库存、且该刻世界成功提交后，交付该源的毛增量、再生前后数量、位置、时间和修订。同一刻普通采集抵消净增长，也不会抹掉实际自然再生。未接入生产启动、没有持久历史；旧存档仍不能补算，不据此推断谷灵贡献。

另有只读的离线批次鲜度工具。调用方需明确给出生效的版本化期限；工具仅把原生规则真实记下的成熟水果入账时点解释为该试验批次的出生，不用版本升级、旧库存、上次采摘或落地时间推断年龄。从精确到期时刻起视为过期。该工具不判断批次剩余量，不发出可转移对象；要支持普通落果，仍需把每次实际扣源和入账和批次余额一起提交。

普通 MVP 规则引擎已有默认关闭的单提交见证。显式开发观察者只能在世界实际提交后收到精确的期初／期末原生果源库存，由本刻成功采集与实际自然增长逐笔复核；同刻采一份又长一份，仍保留两笔毛流量。无变化的已提交时刻可以作为连续性检查点；启动、暂停、失败提交不产生记录。见证不写档、不公开，不把旧的标量库存解释成已知果龄，也不证明跨重启连续性。它只覆盖目前审查过的普通写入路径：新增能改果源的写入必须先纳入观察或不提供完整见证；只看净量无法发现相互抵消的未观察操作。

单次提交后的离线鲜度审计默认把期初库存视为未获证。只有同一次规则会话里连续交付的同世界、同果源、同库存前后头可以继承上一份内存审计；每份已知批次独立扣减当刻可能从它拿走的全部采集量，所得只是该批可能仍在的保守下限，不假定居民按先入先出拿果。真实再生在采集之后发生，可按显式冻结的离线期限纳入新批。到期仅是审计标记，不会让普通果源减少；零下限也不证明果实已被取走。剩余未覆盖库存不补填年龄。这些信息不授予拾取、落果或其他转移权限，序列化副本不能恢复证明；提交标记只来自受信任的会话提交回调后，不替代数据库收据。

封存开发库可另行运行一次原生规则分钟，若指定已登记果源在该分钟实际获得正整数自然增量，世界提交与一条私有来源凭证在同一 SQLite 事务完成。凭证只记录原生成熟入账时间、毛增量、位置和精确存档头；不回填开仓，也不固定期限。仅同一封存所有权且当前存档头原始内容仍完全匹配时可读，推进后不能沿用；不代表独立签批、保留、转移或落果权限。若同一刻还需要独立话语或供餐托管，本入口整步不写。普通运行和存档不开启该入口，也不写任何新地面数据。

可单独创建固定了独立果龄公钥和显式保鲜期的封存开发库。只有同一存档头的真实再生凭证可生成签名输入；签名绑定封存范围、果源原凭证、真实成熟入账时点与按固定政策算出的到期。验证只读，不改变果源、库存或地面，不让普通鲜果过期，不回填开仓，也不签批效果。换库、推进、改期限或换用途密钥都无法沿用；该机制不防整库恢复旧版本。

封存开发库另有单步普通生态入口：有无指定果源的再生都正常推进一个规则分钟，不指定则不写果源凭证。已实际送达的本人对话、已启用的天气托管和选定果源的真实新增可与世界同一事务保存，开启的托管失败时整步回滚。保留原生供餐行动与事件，不为它们新增私有供餐托管。没有环境外部请求、落果、公开接口或生产接线。

另有双公钥封存变体，只读生成或核对未来落地可能使用的条款编码。它先核对同一存档头的果龄签名、真实闭合雨和旧规则下合法且有余量的相邻落点，再把确切果源、修订、固定出生和到期以及一份数量绑定到另一把目的独立的公钥。携带的 G1 评估摘要没有独立核验；即使签名正确也只返回「G1 未核验」的编码结果，不构成落果授权，不启用新地面或拾取能力，既有 V1 路径不变。

封存开发档的带龄 G1 核对独立于旧版「只验签名」的条款。它必须从真实同一存档修订取得原生果实增量及独立签过的年龄，并重放持久编号候选的雨、已许可且实际观察到的雨点、站点、原候选摘要及有界队列。只读检查保留实际库容和当前冷却约束，不把旧版影子验证译成带龄携带。返回的摘要只可供人工核对；地面鲜度仍未安装，不是扣减、落地、调度或执行批准。

三钥封存审阅档可另用独立审阅密钥签精确带龄 G1 依据。每次核验从当前同一头重新取得真实候选、雨、授权和年龄；通过仅表示已审阅，不能排期或执行。唯一持久审阅状态是封存档里签名可单调递增的撤回代数，撤回立即使同头的旧签名失效，重开不重授权。旧双钥档不能启用此能力，旧版仅验签条款仍独立。整份数据库回滚不受此本地代数保护。

同一已打开的封存存档句柄会记住已提交过的最高审阅代数；若其 SQLite 行在原地被调低，该句柄隔离审阅和撤权，恢复原值也不会自动重新开放。新句柄与整份数据库回退不提供这层防护。

三把独立公钥的封存开发库可只读复核首笔 V2 出生条款。要求旧效果与拾取历史为空，从同一存档头重新核验真实果龄、G1 评估和审核签名、当前天气许可及审核版本，最后用第三把钥匙核对固定为一份、限在真实雨/果龄/提案窗口内的条款。即使核对通过也明确不授权执行，不写入 V2 元数据、地面、库存或事件。将来原子出生需要独立的执行签名域和持久关联防护；这份只读复核签名不能作为该签名使用。

封存实验可显式开启**首笔 V2 出生**，执行必须另用独立的签名域，不能使用只读复核签名。出生前在同一写锁重新核验原生果龄、严格当前 G1 审核版本／天气许可、真实雨、地块及一份额度。扣源一份、公共地面增加一份、保留原始出生及到期、观察事件与不可兼容依赖同事务写入。仅支持空 V1 效果／拾取前史，不沿用不明库存。出生后世界冻结，不允许普通加载、写入、拾取、过期或外部发布；同一签名重试只回原收据，重开走私有只读归档，依赖原始前驱、三份签名、世界/地面与归档事件完全一致。该保护不能抵抗整库回滚或同时替换全部历史依赖，不是生产启用。

封存 V2 归档可只读问某位居民在当前冻结世界内是否能看到并到达这份仍在原期限内的公共果实。校验实际视线、户外状态、可通行路径和公共用地，只返回可见位置或无结果；这不是已经发生的发现，不写记忆、事件、地面物品或拾取资格，也不公开。

首笔 V2 另可在同一显式封存执行句柄中完成一次到期：只有下一次真实原生规则分钟确实跨过出生时固定的期限才提交。临近前的安静分钟不会被推进或冒充到期；这不是自动老化系统。有开发天气托管，或该刻涉及尚不能与此路径共同保存的送达话语、供餐证据、同一果源变化时，整步无写入。该步骤留存所有适用的原生变化，另记一份地面终止事实，不再次扣源或增加居民水果；出生事实与原期限不变。重开仅用私有归档从原出生逐步复走原生分钟，与 SQLite 世界、追加事件和终止收据逐一核对，不允许普通 V2 加载、继续运行、拾取或发布。将来规则变更如不能复走这个版本的原生分钟则拒读，不以新规则反推旧结果。

同一封存 V2 试验还可选择有界连续推进，不混用旧的单步到期格式：显式从已核验修订推进一真实原生分钟，最多八次。每步独立追加确切时钟、前后状态摘要和原生事件；重新打开只可私有重放核对，不继续推进。安静分钟也可前进，但只有实际跨过原期限才终止地面果实。居民必须在原生观察阶段亲自在场、可见可达而且果实仍有效时，才留下一条该居民的第一次私有发现；重复看见不重复记录，到期边界不记录，不写公开事件、通知、记忆或拾取权限。真实话语、私有供餐证据或启用天气托管而无法同时保存时，本入口不提交对应分钟。

封存 V2 可额外验证一笔实际拾取：同一居民须已有原生发现，且在可重放步进中确实完成走到地面的最后一格；仍须站在公共地面、无现行任务，且普通规则本会闲候。有多人符合时按原生逐人决策顺序由第一个实际选择闲候者取得机会，封存调用者只能核对预期居民、不能指定获益者。此时才选择只在该封存事务可运行的本人拾取动作，执行一真实分钟并在原到期点前结算。地面减一，独立本人随身批次加一，原果源、出生与到期不变；普通水果标量完全不增加。拾取后再次冻结，后续仅可走下述专用持有步进或独立到期入口；未实现进食、交易、罐藏或遗产，不开放普通运行。旧到期／拾取互斥，同一请求仅回读原凭证。

持有后的第一条封存终止仍限一步：只有下一原生分钟确实跨过随身果实的原到期点、原持有人仍健在且未迁出、普通随身库存与原果源未变化时，才将随身批次减少一份并追加到期凭证。未到期不推进，不改水果标量、不返还果源、不给营养、不开放遗产或新食用能力。原出生、拾取和地面账保持不变；同一到期请求只回读原终止凭证；终止后重试拾取只回历史拾取凭证，不表示仍持有。重开只在私有归档中复走实际步骤、核对有序事件和索引。


封存持有也可显式选择短链步进，与旧单步到期格式互斥。最多 48 个已验证的原生分钟（包含正常 30 分钟闲候的余量），不是强制让果实过期，也不会缩短普通计划。每次都以当前精确修订与 BLOB 做比较，追加原生时钟、前后摘要、原持有与出生编号及有序实际事件。仍在原期限内时随身批次原样保留，跨过才终止；若步数用尽而未到期，就保持最后的准确状态。普通吃其他已知库存与原有事件照原规则保存，不允许使用、转移或继承这份独立果实。已核验的封存句柄才能推进，重开只读重放；未实现的持有人死亡／迁出或独立托管整步拒写。

封存持有步进可另行明确开启独立随身果实的原生进食，首次开启后续步不得回退到旧无进食模式。它保留先前报价、普通供餐／根菜／鲜果的优先级；仅在正常需求已经需要进食、本人没有更优先食物或候选餐位时，允许停留户外原位工作五个真实分钟，不替代合法餐桌路由或缩短普通闲候。完成仍须早于原到期点；期限不足不开始，恰好到期只终止，没有这份果实的营养。只有真实完成才沿用本地原生水果营养、减少一份独立批次及追加关联凭证，不改普通水果数量。旧封存步进仍可读；有界重放逐分钟核对计划与完成、围栏与历史索引。仍不支持进食这份果实的室内路线、交易、罐藏、遗产、普通启动或发布。

### 封闭随身鲜果：共屋本人餐席（V3 原生分钟回放）
仅显式开启的封闭开发夹具选择该路径；既有禁食与原位食用回放不变。在原有食物选择链的鲜果优先位置，规则从本人已知、仍有效的共屋中取原生实名席位，保留更高优先的普通食物和行为。真实户外路线、门槛、逐格室内移动和逐分钟席位占用均使用原生规则。未到真实许可餐位及取得当分钟占用前，不扣工作量。路途不计入五个完整工作分钟；原保鲜期在最后工作分钟到达时，到期优先且没有营养。

私人终结凭证绑定首次实际工作时间、完成时间和席位；原生世界分钟、营养变化、随身件减一及日志在同一事务回放核对。不向普通标量库存增加果实；不支持跨楼、私宅餐位、生产启用或普通存档加载。采用原生实名席位数量及争位规则，不新增或推断建筑总人数政策。48 分钟封闭回放上限未变；超过上限不补记用餐或到期。

### 封存 V2 带龄落果公平账
只读投影在同一次完整归档重放中区分提议指向、实际落地、居民真正发现、实际拾取。提议层仅证明与这笔执行签批绑定的一条候选，整体候选量未知；光看见的只读诊断、到达、预计收益均不计入事实。过期或吃掉仍保留历史拾取，不再计作持有。实物在地面、地面到期、本人持有、持有到期、吃掉五种状态之间互斥，显示原出生和到期时间。搬运不产生新增供给；自然再生没有在这套效果归档内记账，诱发的间接增量仍需反事实验证。缺失、错档或坏账不给可用读数；不接普通 V1、居民或公开读路由。

### 普通规则存档：原生再生时点的同档私有凭证

独立默认关闭，一次仅配置同一存档的一个原生公共果丛。只在真实普通规则分钟提交时捕获引擎原生再生；同一 SQLite 事务核对完整前后世界和实际入账，保存当前头的最新凭证。只读复核要求原存档头、果丛、当前量和时间完全一致，重开可核对；推进后旧凭证不再作为当前证据。无历史回填、模型、公开入口、落果写入或授权。普通模式不开该选项时不创建私有表，不更改原玩法。

凭证分别记录自然增加的总份数和果丛标量净变化。真实同分钟采走一份、自然补回一份时，前者是 1、后者是 0；不能把总增量归成谷灵额外供给，也不能从标量推断哪一份当前果实按这个时点成熟。它只为后续原生年龄账提供真实的同档入账时点，不创建按份年龄、保鲜期或可选取的果实批次，不复用封存审批，也不解除现有 G1 地理候选的缺地面能力限制。凭证校验可拒绝损坏或不一致，不宣称对任意整库替换提供独立签名或防倒拨。

### 普通规则存档：保守跟踪一份原生果源批次

同一私有登记槽支持显式指定游戏分钟保鲜期。未指定时保留纯再生凭证；默认不建表。只有选定果丛完成一次可复核的单份原生再生，且同分钟本果丛没有采集时，才识别出一份有出生时点的批次。不为既有库存回填、不重新计算已出生批次的期限。逐分钟核对同一存档的完整前后状态及原生收支后，批次才能继续有效；发生该果丛的真实采集即保守撤掉整份资格，不猜先采哪一份。采集与再生同分钟仍可分别核对数量，但不认定新批次。未观察到的提交、更换配置、损坏和到期都不赋权；原保鲜期以游戏时钟计，到期只失去跟踪资格，不更改普通果丛标量或居民库存。

这不是 G1 已授权选取，也不提供真实地面落果能力。只在普通规则宿主做同存档私有读取；不发布、不调用模型、不为 G2 签批或执行。整库替换不由此提供防倒拨。

### 普通规则存档：一格空地面托管

新增独立默认关闭的内部安装选项，仅对明确指定、曾正常启动并已有运行锁的普通规则存档、唯一公共果丛和相邻合法公共地面有效；配置和公共地面在打开可写世界前核对。复用真实公共地形、通路、权属和容量核验；在已取得该档运行独占权且核对确切世界头后，同 SQLite 原子安装一格、一份容量的私有空托管。重开不改安装条款；暂时不合格的落点不返回可用容量。空托管在正常推进及关闭选项时均静置，关闭选项不创建新表、不删除安装信息。无公开读取、模型或普通世界字段变动。

当前持久格式只承认确切的空状态，不接受任何未经签署放置验证的非空行；未知格式、非空状态或不相干的存档会在启动只读预检阶段拒绝，不清空、不迁移、不忽略后继续运行。另有可独立验证的单份到期规则，比较原保鲜期限与实际推进的一分钟，扣除地面份数而不改变公开库存、来源或居民；本切片没有可持久化的实物出生，不是持久实物到期的端到端交付，也未接选取、落果执行、发现或拾取。

普通规则带龄落果的独立发现接口可在真实引擎的居民观察阶段，使用注入的拥有者只读口核对开场时同一世界、修订和分钟的一份有效落地见证。依据的是移动后的本人户外视线与当前可达地块；没有有效凭证、已到期、与世界不符或本人在外，不生成观察。只返回私有未提交观察，不写居民知识、发现账、拾取或库存；现有普通空地面安装没有可提供非空记录的拥有者接口，普通和公开运行均未启用。

普通带龄拾取的独立草案只在内部拥有者提供同一提交头的有效地面实体和已持久、原生的本人发现时准备。候选居民必须已在自己发现的实际地块，且更高优先的普通行动没有占用机会；从原生居民顺序和闲候分支选出一人，真实走完一分钟拾取行动。截止精确分钟、无发现、离地、外来或本人优先需求时不能拾取。结果仅为未提交的规则草稿和原龄完成证据，不转移地面件、不给人加标量库存、未接普通运行或公开入口；后续必须由实际拥有者重新核对并同事务移交。

### 停机的临时普通规则存档：独立单次放置

只在本地新建、私有且有明确归属的可丢弃测试目录中可调用，运行中的宿主或任意用户存档不能作为入口。要求现有原生普通存档恰处于同一版本和游戏时点，重新核验真实闭雨和当前允许的已观测雨点、原果源批次、同一空地块、已签 G1 及不同角色的独立 G2 签名。G2 单独用途绑定精确原世界字节、原提议和审核签名、批次、落点、期限及两把公钥指纹；不借用 G1 作为执行批准。

一次 SQLite 事务从原果丛扣一份、令原批次不再是当前果源批次，并在私有地面增加一份，继承真实出生和到期时间，同时保存同一笔不可变回执与前像。重开隔离工具时须用原私有能力、双签和原像重验完整世界与地面；相同批准重试只返回历史回执，不重复扣减，篡改任一落盘状态拒绝读取。普通宿主对这个已占用格式在只读启动检查时拒绝，未接普通发布、时钟推进、领取、归属变更、模型或客户端。保存能力令牌不是用户或生产审批，不声称防止整个目录连同持有者凭据被回滚。

### 停机临时存档：原生发现和地面到期

双签落果后，原停机工具可在同一独占存档和准确版本上显式推进一个真实普通规则分钟，最多连续八步。不接常规宿主、定时任务或玩家操作。居民照常独立决策；只有自己在原生行动后观察阶段确实看见并能接近有效落果，才记本人的首条私有发现。重复看见不重复登记；到期的同一分钟禁记新发现。没有向其他居民或观察者发送发现，也不追加普通记忆。原保鲜时间到达即只扣地面一份，不凭空恢复来源、补入个人库存或再次扣账。

每步的私有证明、普通原生事件和索引、世界与地面状态同一 SQLite 事务提交。使用原双签放置回执作为起点逐步重放，核对精确事件、索引和世界字节；归档篡改或不可保存的原生用餐、交谈等证明使推进拒绝，不压过规则或吞掉行为。到期后原放置只作为历史可查，普通启动仍拒绝该格式。本切片不接原生拾取结算，不提供自动推进、公众读取或 G2 发布启用。

### 停机临时存档：居民本人拾取和私有持有

同一停机工具还可在指定的真实当前版本尝试一次拾取分钟。没有居民参数：普通规则先处理原有计划、饥饿等优先事项，只有原生空闲决策可开始；须有本人已落盘的亲眼发现、实际身处原地块且能接触，动作必须在原到期前真正完成。成功在同一事务扣地面一份并给实际居民增加一份独立保鲜持有记录，出生及到期不变，不改单品库存、不发广播，普通独立行动和事件索引照常保留。未完成、到期同点或待处理的专用证据都会拒绝，不转给另一个人。

重开按原双签放置与每步原生证据重新推演，旧拾取请求只读原回执；篡改领取人、普通事件索引或档案会拒绝。拾取本身不启用转交、公开或普通存档启动；后续持有结算见下节。

### 停机临时存档：持有后的走时、到期与真实进食

同一持有者可在停机存档续走每个真实普通规则分钟，最多额外 48 步，未处理完的专用餐食、交谈或超出当前能力的人员迁移等会拒绝，不代选行为。只是走时不会刷新原保鲜期。到原期限则只减本人持有一份；原果源和地面不回补，普通标量食物不改。

规则可根据本人饥饿、现有普通食物优先级和实际场地选择原地或已知合法共屋餐席进食，不由工具指定人或输入行动。只在真正完成五个工作分钟、仍早于原到期时扣一份持有并结算一次原生营养；到期结束和进食互斥。原生普通事件及索引、私有证据、身体变化和持有状态同一事务重验；重开或旧拾取重试不得重扣或重复进食。中间行动记录只有隔离逐步重放可读，普通启动仍拒绝。无外部模型、自动推进、公开或正式启用。

普通持久规则入口可额外明确选择原生空地面检查点，默认关闭。原有空地面安装本身不推进世界。第一次真正的规则分钟才在普通世界 CAS 的同一 SQLite 事务中，把空地面行升级为只容许空状态的第二版，并写独立摘要；随后只有同一世界的真实单分钟和确切上个存档头可以推进。源库存、居民、进餐和交谈照常走同一个原生规则草稿，现有各项私有托管选项的边界不变。地面账的失败撤销该次世界提交；未知格式、错档、单侧删除/降级不在运行时修复。已有新标记的存档只在明确传入原地址 pin 与 `privateNativeEmptyAgedGround: true` 时允许可写重开，识别初始 V1 地面表的旧程序或不带相同配置的当前入口拒绝；没有 HTTP 切换，未采用的普通或既有空地面运行不变。空检查点没有地面果实、发现、拾取、落果签批或公开接线；不读停运实验存档的锁或重放。核实原生分钟的内部标记只由受信任的普通 WorldStore 读入，不能由路由或插件传参；它不防已有原始 SQL 写权限与拥有者权限的代码伪造归档，也不防完整回退两个私有锚与存档。下一步需在同一写事务内接入批准的非空实体、原龄及强制托管，不能把空检查点当能力许可。

内部开发可创建一次性、进程内持有权的普通规则存档，在不创建 HTTP socket 和自动时钟的情况下复用同一个普通 WorldStore、引擎和提交路径。只能由创建函数新建私有临时文件，不能导入路径、停运档或已有用户存档；目录和数据库固定身份，接口只提供手动单分钟、现有只读证据与关闭。可在同一进程重开，进程重启后不能恢复该开发句柄。默认普通服务不变，不启用非空地面、落果、消费或真实模型。

一次性存档的第一笔世界提交同一事务写入普通读者原本就拒绝的开发档封印表，封印采用独立 V2 格式和用途，绑定单一世界。所有原生与证据写入完成后、提交前再次核验封印；失败则整笔回滚。世界的逻辑 schema 和物理编码不变。普通规则/正式存档启动与识别 V1 封印的旧入口不能接管它；整档复制或改名不会去掉封印，旧专用 V1 持有者同样不认识 V2。当前开发入口须持有同一进程原始句柄、数据库/目录身份及原生独占锁，且封印须与只留在句柄内的密钥匹配，不提供跨进程恢复或签批权限。检查防误开与错档，不防原始 SQL 权限刻意删除/重写封印，也不防恢复到封印加入前的整库备份。此前未写封印的历史临时文件仍只有路径名检查，不会自动迁移。创建失败只尝试清理能确认属于这次创建的空目录和文件；关闭后若有原生保留锁或未知条目，`dispose()` 只撤销句柄并返回 false，保留原目录以免删到未知文件。

封闭的一次性开发运行可额外固定一个与 G1 审核者不同的 Ed25519 效果公钥。两份签名只接纳当前持久世界头、有效天气权限版本、真实闭合雨事件、已登记地块以及仍可转移的一份原生再生源果；G2 使用与停止档不同的签名作用域，并绑定已签 G1 和现有世界字节。没有签名、审核者与效果密钥相同、换头或缺少任一证据时，不写世界。

命中后，普通世界写入事务在同一游戏时刻减源果一份并注销旧源 cohort，实记一个同档地面果实及不可重复的私有回执。分离的私有地面账拥有从落地到过期的数量权威，旧空地检查不再对该档表示可用；不写公开事件或居民发现、拾取、营养。运行当场从已提交头重建原生会话；若重建失败，旧句柄不能继续推进或返回旧投影，须关闭重开，签名重试只返回已存在的回执。重开须原进程所有权和同一签批及原龄策略。随后普通真实规则分钟在同一写入事务维护私有地面账，到原期限恰好扣地面一份，不返还源果、不制造自然再生。原生再生仍独立运行；在此专用档，原生源果账失败时同一整笔分钟回滚。撤权或权限版本变化不再返回旧私有回执，但实际到期仍照常推进。

该路径仅服务无 HTTP 的开发存档，不启用正式或常规存档；不会导入停止档，也没有真实模型或自动执行。地面账与独立依赖锚的任一单边丢失会拒绝；有原始 SQL 写权限同时移除两者或回退整个数据库的操作仍在可信边界之外，不主张能抵御。开发能力不跨进程，重开指同一进程关闭再打开，未实现生产发布、发现、拾取和消费接线。

一次性同档模式增加了私人发现这一步：世界每次真实推进一分钟时，仅在拥有者从确切已提交世界头验明地面果实仍活跃后，使用原生居民行动结束后的感知阶段。感知依赖现场可达、视野、在场和清醒等现有规则。每一位居民对这一份果实仅保留首次记录，含现场阶段和实际提交修订；准确到期的分钟不记新发现。发现与世界、地面到期账在同一个事务中，读取只按本人且由当前同版授权的开发句柄发起。到期后可核对已经发生的发现，不代表还有一份果实；天气授权撤回不移除已落地的实体，不改变居民在真实场景能否看见它，也不推迟按原期限的物理到期；只阻止开发句柄披露个人证据或旧签批回执。没有公开投影、共享居民记忆、拾取或消费。

在同一无 HTTP 开发档，原生居民已可自主拾取一份原龄落果。只接纳上个已提交世界头中本人的首次发现；只有居民已经实际站在果实的位置、仍看得见且普通优先级已落到闲候时，才由常规居民轮次自行选择并完成一原生分钟的拾取。不规划多格行程、不指定居民，或替换吃饭、补水、务农等既有优先行动；准确与原到期撞期则地面先过期。成功动作走原生规则计划的完成路径，同一世界事务写地面减一、本人原龄私有持有加一；不写普通库存或公开事件，也不因其它原生事件写入而拆账。撤回天气出处权限不影响已经落地果实的实际发现、拾取、持有或到期，只阻断开发读取。已持有时地面不再有货，保持同一出生和到期时间；到期原生分钟只扣持有一份，关闭重开也不重复恢复。当前不支持持有者死亡、迁出或转移监护，若发生则拒绝提交该开发分钟。同一个拾取分钟如另有动作改变该居民的普通库存，也拒绝提交而不猜测归因；拾取完成分钟不记录同分钟的其他首次发现，因为尚无证据可判定它们发生在移出前。没有交易、加工或公开玩家接线。


在同一一次性开发档，现已支持持有者原生在户外原处进食。饥饿达到阈值、没有较高优先级的普通食物或可用优先餐席时，既有规则才能开始；必须完成连续五个实际工作分钟且仍严格早于原到期。真实营养（含普通分钟的生理消耗）、持有减一和去出处的普通动作事件及居民索引在同一 WorldStore 事务。中途活动只能由原进程拥有者按签过的原龄证据、已提交档头和确切活动重开；错误档、事件或索引不完整都拒绝。为免把同一时点的库存变动误记为私有食物，结算分钟目前要求持有者的全部普通库存原样；其它居民的原生事件和正常普通动作仍走原写者。撤回天气出处后仍会实际进食或到期，不返还源果；只屏蔽签批和私人来路读取，通用观察快照不含进行中的私有果实标识，普通动作事件也不带该标识。没有共屋餐位、行程、交易、加工或正式玩家启用。


同一开发档允许本人发现后按普通闲候优先级走一格至合法果实。仅在当前本人仍可现场感知、边可走且安全时，按原生轮次发起最多一次普通移动；同分钟已有通过初筛的在场拾取候选则不发新路线，即使该候选稍后因普通优先级并未拾取。短途活动未结束时暂不发任何拾取，既不预扣果实也不保证发起者最终取得；这是一次性开发档的保守串行边界，不是普通世界的归属或竞争规则。健康导致的部分移动可按原活动及同一存档原样恢复。实际脚步到格与移动结案分开记；下一个独立原生决策才可拾取。更急需求、通路变化、时限或原果龄到期仅停止相应私有移动，不让实际走过的步子倒退、不授予拾取。没有本人记录、超过一格或无可行边不派发。无多格路线、传送、HTTP、来源广播或正式玩家入口。


已开始的一格移动并不预占地面果实。另一位已经在场、有自己更早的真实已提交发现且普通规则选择实际拾取的居民，可以在同一分钟完成动作。只有真实完成扣取时才终止仍在等待结案的旧路线，记录与胜出拾取身份、确切时钟和修订一致的「被实际拾取取代」；若路上人的脚步先于拾取已走完，保留那一步和坐标，若尚未执行则不再迈步。先前已正常结案或因其它原生条件停止的路线仍保留原结案，不伪造到场。失败的拾取不抢占、不结束路线；本分钟未排序的新发现不入账。路线结案与地面减一、胜出者原龄持有加一同一事务且可重开，仍没有多格路线、正式玩家或 HTTP 接线。
