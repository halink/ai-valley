# 救援后成人的有限非侵入式在场

## 本次切片与既有设计

[居民设计](../design/people.md)要求当事人保有独立决定与拒绝权。已有[近身观察](care-observation.md)能看见救援后仍失能、饥饿或虚弱的成人，但观察不授予照护权。既有[紧急基础照护](adult-emergency-care.md)只在原危重条件下使用本人食品和水，不能扩张成非危重成人的常规喂养。残留童年监护记录也不是成人代理。

本切片另设 `adultPresence`，只做真实现场核实和最多15游戏分钟的自愿、不接触身体的在场。它不是医疗方案、代理制度、成人照护合同、自动救助或自动接班。不会改变身体、钱物、居所、监护、床位或原救援结果；不会喂食、饮水、给药或移动任何人，也不增加健康、体力、营养或“已照护”统计。天气调度继续默认关闭。

## 可核验的原救援

- 只有真实护送实际送入床位或真实落脚干地时，才保存 `arrivalEventId` 及 `health/arrival@1` 结构化事实。未完成、途中中断、只有预警、记忆文字或任意事件编号均不成立。
- 来源必须同时吻合原运输编号、提供者、受助者、实际完成时间与事件。记录另外冻结原运输关键字段，继续工作时不能换用后来救援。
- 现有事件的宽泛目击列表不足以授权核实。送达时另记录真实近身且双方都有合法室内使用权的目击者；之后也必须重新实际到场。晚到者、听闻者、远处熟人和历史监护人不能凭身份补造目击。
- 原救援完成后60分钟以外不再创建本回合；旧档没有结构化送达回执时不回填、不重新推断。

## 自愿核实、在场与停止

1. 有完整决定与表达能力、健康大于30、体力至少10的在地成年人，须在合法近身位置看到仍不能自行决定的非危重成人。只有表达受限、但仍能决定的成人不适用。受助者正在独立行动、被运输、同行或睡眠时不启动。
2. 居民从正常最终菜单独立选择2分钟核实。引擎实际核对连续工时、双方原位置、房间坐标与障碍、使用权、拒绝、能力和现实危险；不走向远处目标、不把门口回填成室内位置。
3. 核实排队或进行中，本人只要仍可表达即可立即停止；原施助者也可立即退出。停止绑定原运输、原回执和原提供者，必须单独提交，没有额外行动或代理权限。受助者看不到远方施助者的排队安排。
4. 完成2分钟核实后只形成 `verified` 记录，不自动开始在场。截止时间是核实完成后15分钟与原送达后60分钟的较早值；此绝对期限由原核实事件复验，不因等待、换计划、重载或修改计时器而延长。
5. 提供者须另行从菜单选择 `stay`，只能在核实时的原位置不接触地停留至原截止。每一步复验真实合法近身，累计连续、有限的实际世界分钟。核实并不意味着已经开始在场，在场也不意味着照护完成。
6. 本人表达性停止与施助者退出即时生效，包括最后四分之一分钟。仍失去决定能力的人只有停止与短暂不表示停止，不获得进食、移动、接受新照护或安排别人的权限。短暂停止表达的等待不会重新计时，也不替其同意。

每次原救援最多一回合。核实完成或核实被明确停止时都写入持久的一次性来源回执；本人拒绝另保存为该原事件的拒绝，不写成永久全局 `refusesCare`。换提供者、换计划编号、删除可见记录、SQLite重载均不复活这次来源；不会自动找另一人接班。

## 动态失效与未解决结局

本人恢复决定能力（即使表达仍受限）、明确拒绝、病情转危重、施助者失能或体力不足、任何一方离开原位置、房屋权利丧失、真实通路受阻或新危险出现，都会保守停止。本切片不会把非侵入式在场升级成喂养、给药、再次撤离或代理。

期满、退出和失效均保留真实完成的核实与实际在场分钟，并明确“后续照护仍未解决”。没有人愿意继续、没有另行合法路径，或整个15分钟都未选择在场时，不补造接班或改善结果。已结束记录不再继续计量。异常计量、缺失地点、缺失来源目击或期限绑定失配保守失效，不修补成新权限。

远处变化只进入观察者事实记录，不给居民注入远处记忆、坐标或失效原因。属于本人的原记录停止入口在固定期限内保留，不能通过消失的选项泄露远方施助者是否失能；本人停止本身只按实际现场见证传播。

## 菜单、保存与观察

- 普通菜单保留有界的现场核实和在场席位，等待、进食等个人选择仍保留。停止入口复用已有受保护撤回路径，不受焦点、菜单容量、船上或同行筛选剥夺。
- 类型、精确字段、本人身份、版本、单独行动、来源绑定均在引擎复验。最后完成函数独立复核工时；提前降低剩余计时、重复调用或非有限数不能伪造核实或在场时间。
- 内存SQLite保存原事件、记录、核实活动工时和持久消费回执，重载不重新创建期限。关键来源事件不会被运行时事件窗口裁掉。
- 观察者健康面板与个人详情分别显示“已核实尚未在场”“本回合在场中”“已结束、仍未解决”、原救援和固定截止。baseline/delta/reconnect保留这些事实，不把它们作为居民的远程知识。
