# 普通规则 G2 开发原档

当前只提供非空落果实现的原档前提，不写 V3 地面物或回执。显式调用 `createOrdinaryG2DevelopmentOrigin()` 可建立全新的本机普通规则开发原档。调用者不能传入、转换或领用已有存档；新文件由内部创建，物理身份和秘密固定在原所有者进程。首次原生世界写入和原档标记在同一 SQLite 事务；失败全部回滚。

这一入口没有 HTTP、自动时钟、公开界面、模型、调度或真实生产操作。只可显式推进一普通原生分钟并读取简单世界头；同一原始文件与所有者闭包可以关闭、重开。普通、正式、季节、旧开发档、复制件均不能使用此能力；普通存档加载和写入在识别该标记或保留 V3 账本名时拒绝。保留的非空账本名在当前原档上也会拒绝，即使仅为同名视图。旧单果源与普通档模式不转写。整个进程退出后无法解封原档；它不是面对特权 SQLite 写入者的外部信任根。

尚未接通：在此特定原档内绑定多果源与分离式预检、绑定独立开发型 G2 生效条款、原子转移到 V3 实际地面保管和稳定机会回执、发现/拾取/原龄到期。没有生产执行批准。
