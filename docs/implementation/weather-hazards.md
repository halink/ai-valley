# 有限天气灾害、避难与灾后修护

本项把后续预警接入模拟降雨与阵风，并沿既有格子地形记录有限影响范围。**新世界与旧档默认均不启用新的天气预警调度**；只在隔离验收中明确调用 `setWeatherHazardsEnabled`。观察页没有启用按钮。启用前仍须完成饮水、照护、可达避难和长期供给验收；本交付不代表这些门槛已经通过。

## 采样与地形边界

- 登记不补造过去的降雨、强风或灾害。每次最多采样60游戏分钟，直接跳时不追补历史天气；关闭后停止新采样与预警，已经记录的灾害继续沿原阶段推进。
- 洪水预警取自模拟径流积累，在淡水岸选址，沿连通水格、最多两步岸地扩展，半径最多7格，悬崖阻挡；不会经陆地跳到另一片不连通水域。洪区保存实际格子集合，由导航、伤害与地图共用。
- 风暴来自当地按日确定的模拟阵风，持续强风至少60分钟后才可能预警，范围半径10格。每类新预警有冷却，同期最多两场；洪水预警90分钟、风暴预警120分钟。
- 这些是有界的游戏天气量，不是实际天气单位。地图没有真实海拔、上游水位或完整流域水文，撤离目的地不能称为已测绘高地；风暴也不是完整风场传播模型。
- 旧灾害没有格子范围或天气证据时保留原半径和原事件，不从当前雨量反推旧触发原因。停用不撤销既有受伤、死亡、损害、财物或修护。

## 居民自主避险

居民仍通过正常决定选择实际步行撤离、前往已知且有使用权的建筑，或继续其他事情。预警不传送居民，也不代其接受住宿或物资。抵达时重新核验风险与容量。

建筑容量按实际在场者和既有住户、有效共屋借住、迁居床位、医疗接送、所有尚未到期且已接受的医疗预约，以及已预约或正在值守的照护服务对象去重计算，不能挤掉既有权利。遮蔽需要建筑状况足够完好，且不处于任何同时发生或预警的洪水核心/记录洪区。临时避险不会新增床、粮、水或居住权；离开仍由居民自行选择，没有定时强制驱逐。容量统计也不是保证此人有权进入或能及时抵达。

## 真实损害与修护

新天气证据对应的灾害才扩展到泉水及道路、桥梁、码头；旧灾害不被追溯扩大损害范围。

- 洪水使实际范围内的泉水留下灾害编号和淤塞状态，停止安全取水，不增加或移走原有水量。退水且现场安全后，居民可以自行携带1木2石到场劳动60分钟清理。完成前重验同一损害编号、材料、位置和风险；清理只解除淤塞，不补满水源。动物及捕食者的饮水路径核验也不能使用尚未清理的泉水。
- 受影响的交通设施实际降低现有状况值。完全损坏的道路恢复原地形，桥梁与码头沿既有状况规则影响进入与通行。修复仍走原公共工程授权、材料与劳动链，不提供免费的灾后修复按钮。活动洪水阻止工程劳动；退水后可从普通菜单提议，经独立表决、真实材料投入和分阶段劳动修复。
- 建筑和已经播种的田地保留真实损害与既有修护规则。灾害不会因为写下记录就自动修好设施或保证补给恢复。

路径核验已修正绕行后重新进入洪区的情况。[近处洪区撤离菜单](flood-retreat.md)进一步按真实洪区查找24步内可达出口，菜单与实际撤离共用逐边风险约束，并在途中阻断变化后的路径。[有限监护幼儿护送](guardian-evacuation.md)补上健康幼儿到实际安全床位的正常菜单与原危险绑定核验；非危重失能成人和无床干地抱送仍未实现。这不等于所有灾害路线和受照料者撤离都已完成验收，也不启用天气调度。

## 保存与只读证据

野外面板展示调度是否启用、当前模拟天气量、已记录洪区格数或旧半径、容量占用、淤塞/已清理泉水、受损设施和近期实际记录。地图逐格描绘已保存洪区，旧记录继续使用半径形状。所有观察操作只定位或阅读，不改变世界。

结构化记录以 `hazardFact.disasterId` 串联预警、发生、消退、实际受伤、撤离、进入遮蔽、损害与已完成修护；能记录的数值保留前后值。当前设施受损本身不证明是灾害所致，居民个人解释、同地同时发生的事和无结构化证据的旧记录不能据此推导因果。面板的近期列表不代表完整跨季档案；可点击原灾害编号对应的[持久事件链](disaster-history.md)，从持久年表分页查阅同一编号的留存记录，缺失阶段不补造。

泉水的新增、淤塞与清理状态由资源差量存档单独保留，即使水量没有变化也不会漏存。建筑和交通设施的 `lastHazardDamage` 保存灾害编号与原事件编号，工作事件列表裁剪后，后续实际修护仍能关联原损害；不据当前天气重新推定原因。
