# 谷灵上游：普通交谈的实际指定接收

此切片是上游开发进度，不是公开事实、谷灵运行时发布或提测。

普通 `talk` 在实际行动结束时重新核对同一计划、有效行动、指定对方和合法面对面接触。指定接收者须存活、能够感知，并能在当前物理场景反向确认发言者；不以同房、在场、目击名单或事件参与人替代实际交付。已在合法位置但不能感知，只产生未传达的尝试，不生成对话成功、收听记忆、关系依据或接收收据，不为此停表。原本超出接触范围仍走既有动作失败。

成功时给指定接收者独立写入一条 `heard` 记忆，保留原句及实际发言语气（合法的结构化字段），不向旁观者自动分发，也不替接收者解释、决定或证明对话内容属实。保留既有观察者普通对话编年展示；它和事件参与人/目击字段不是收听证据或谷灵公开许可。

`stepWorldWithAddressedSpeech` 可显式采集本次引擎步内已实际交付的私有记录，含世界、前后版本、有时刻的事件、准确计划及队列动作身份、发送与指定且实际接收的双方。权威检查绑定原草稿对象及终态版本，克隆、历史事件或模拟不生成有效证据。该记录不写入 World、事件、公共观察面或模型投影；保存下来的居民自有记忆也不可逆推收据。

## MVP 私有同事务收听保管

内部显式启用 `captureAddressedSpeechCustody`，并由调用者把同一草稿的捕获结果交给 `WorldStore.commitMvpWithAddressedSpeech`，才接入保管。与世界、权威事件同一个 SQLite 事务；世界提交失败时私有表和新增收据一起回滚，不在随后启动时补录。可选私有写失败、未知结构或超出 4096 条上限只丢弃本次可选写入，不改变原证据或世界提交。未启用或没有真实交付时不创建记录。没有任何普通入口默认启用、本地文件配置、HTTP 路由、共享给真实模型或跨世界恢复。

久存表保留准确世界、事件、指定与实际接收一致身份、来源发送者、行动计划及行动序位、时间及世界提交版本，不保存原话或语气。内部读取可凭同世界准确事件身份取回已经提交的独立随机收据，验证同时检查当前世界提交头和专用记录所关联的持久事件；仅旧事件或现有记忆没有保管记录。完整数据库被恢复成旧备份不等同连续版本证明，不能据此恢复旧公开许可。

保管不授予公开权限。适配生活事实权威后仍须逐个来源获得独立批准；对获准来源只投影 opaque 引用、种类和时点，不投影事件、计划、发言者、接收者、原话或语气。开发夹具检查了专用收听和非收听、提交失败回滚、重启核验、旧历史不补录、未知结构不破坏世界，以及默认私有至显式授权再撤回。尚未接入谷灵常规生活年鉴，不提测。

## 无监听器的普通规则开发凭证

独立的内部 `createDisposableNativeSpeechSave` 开发预设只接受“指定听者能感知”或“在场但不能感知”两种固定场景。它新建受现有进程独占的临时普通验证存档，不接受已有存档、动作或发言内容，不启用 HTTP、自动时间推进、其他私有开发用途、谷灵发布或供应商。固定发言仍经过原本行动执行及确切接收，不把在场或会话事件当成收到。

实际接收时，专用接缝验证本原生时步的世界修订、对应行动及发言事件，要求基础收听凭证与专用认证附档共享同一世界 SQLite 提交；失败会一同回滚。附档使用该持有者独占、进程内的目的域认证。本人不能感知的对话不生成接收凭证。普通存档启动不接受这个私有路径。改名复制的文件也不能当作普通存档或代替该原所有者。

专用只读能力仅返回同一物理文件当前已提交世界头及通过原收听凭证核验的去身份不透明收据；它不返回动作、事件标识、人物、原话或语气。读取头不符、附档认证或形状不符均不给凭证。关闭后同一开发预设可用原进程持有权重新打开，无跨进程导出；不是独立披露批准或生活年鉴刊物。

同一读取快照还独立检查基础收听保管表中当前最新提交与全部凭证索引，再与认证附档逐项核对。缺失附档不能降格为较早凭证，也不等同于从未收到；对外统一不给凭证。在两份受保护的数据库证据同时被完整回滚时，本接缝没有外部防回滚锚。

### 独立签署的单条离线交谈刊物

可在创建同一无监听器开发存档时，明确固定一把独立审核人的 Ed25519 公钥。仅当普通规则生产者已关闭且拥有同一物理临时存档的独占锁时，才可打开内部审签句柄；未指定公钥不能打开。没有普通启动选项、HTTP 路由、账户、自动生成或真实模型。

审核使用固定客观句式，只描述已实际送达的匿名交谈及游戏时点。一次发布和一次不可逆撤回各须独立签署，确切绑定目的域、同一物理存档、世界头、原生收听凭证、正文摘要及当前披露版本。私有审签与回读在同一 SQLite 事务内重验原生证据和整个有界签署序列，失败不留下部分记录。公开形状的开发回读只含匿名行与渲染版本，不含人物、原话、事件、凭证编号或签名。

世界推进导致已签版本不再对应当前头，旧文不继续显示。撤回或发现签署序列被删除、损坏或倒拨，关闭再开也不回退到旧刊。进程持有的权限和已见序列不导出，不抵抗独占存档所有者和整个进程证据同时被替换。这只是本地离线发布闭环的开发证明，不等同于生产披露许可。
