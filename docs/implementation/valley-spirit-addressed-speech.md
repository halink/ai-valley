# 谷灵上游：普通交谈的实际指定接收

此切片是上游开发进度，不是公开事实、谷灵运行时发布或提测。

普通 `talk` 在实际行动结束时重新核对同一计划、有效行动、指定对方和合法面对面接触。指定接收者须存活、能够感知，并能在当前物理场景反向确认发言者；不以同房、在场、目击名单或事件参与人替代实际交付。已在合法位置但不能感知，只产生未传达的尝试，不生成对话成功、收听记忆、关系依据或接收收据，不为此停表。原本超出接触范围仍走既有动作失败。

成功时给指定接收者独立写入一条 `heard` 记忆，保留原句及实际发言语气（合法的结构化字段），不向旁观者自动分发，也不替接收者解释、决定或证明对话内容属实。保留既有观察者普通对话编年展示；它和事件参与人/目击字段不是收听证据或谷灵公开许可。

`stepWorldWithAddressedSpeech` 可显式采集本次引擎步内已实际交付的私有记录，含世界、前后版本、有时刻的事件、准确计划及队列动作身份、发送与指定且实际接收的双方。权威检查绑定原草稿对象及终态版本，克隆、历史事件或模拟不生成有效证据。该记录不写入 World、事件、公共观察面或模型投影；保存下来的居民自有记忆也不可逆推收据。

**限制：** 尚无与 SQL 世界提交共同写入的收听证据表、提交后消耗接线或公开授权，重启后的世界不能补录。类型化临时记录本身不是耐久收据；归档和生活年鉴仍须对此类来源报缺失。未来接线先确认同一真实世界事务和逐来源审批，只投影许可的无身份、无原话计数。
