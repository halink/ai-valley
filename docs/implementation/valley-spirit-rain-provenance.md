# 谷灵：G2 实际雨证据基础

这是谷灵世界机遇的内部依赖，不启用落果、候选调度、居民广播或模型调用。普通临时规则演示、模型入口和旧非气候世界不采用此记录。持久规则入口先按既有方式只读检查存档，再在原世界事务中采用。旧存档从这次实际采用时刻开始，采用时为空；已经下到一半的降水不补记为完整雨事件。

气候 v1 每个游戏日最多一个连续的正降水区间。完整走过区间、经过真实结束点，并且至少有一个精确时刻依原有规则属于纯雨，才生成实际雨ID。纯雪或全程雨雪混合不生成ID；同一降水区间多次跨过相态阈值仍只有一个ID。区间边界沿用原有四舍五入，首个纯雨时刻检查全部相关量化温度过渡，不从步长端点、年鉴或当前下雨状态补造。不改变原气候样本、天气种子、土壤入渗或资源。

保存采用时点、雨ID、开始时点、首个纯雨时点和结束时点。时点使用与气候一致的微游戏分钟十进制字符串；结束不含当点。雨ID为 `worldId:rain:<startedUs>`，不含记录版本。事务后与存档重开读到同一ID。只读解析只查当前真实世界近 28 个游戏日内的记录，至多 29 条；不推断过期历史、预报或隔离模拟中的证据。保留期是本实现的证据上限，不是未来落果窗口；后续 G2 效果收据应持久携带所绑定的雨ID与来源，不能把滚动窗口当长期效果账。

同一世界 SQLite 提交拒绝去除依赖、倒拨、篡改或漏写该次真实时钟推进应有的记录。未知格式或无效时序在只读预检阻断写入。旧代码不能安全继续写入已经采用此字段的存档；需要保留迁移前备份，不能删字段回退。

开发验证：TypeScript 构建、六项本地单元测试（量化边界、相态、已结束与采用门、分段与持久形态不变、解析与坏字段、提交转换保护），以及单次临时 SQLite 规则入口跨过雨结束点、重启读取并拒绝移除依赖的快速检查。未运行长测、未调用真实模型；这不是谷灵完整提测或落果启用。
