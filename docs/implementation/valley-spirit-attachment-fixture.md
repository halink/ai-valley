# 谷灵：隔离的落果事务联接

这一片把现有落果决策协调器接到实际 SQLite 世界事务，最初只在显式采用的内存开发夹具验证；另有[私有临时文件夹具](valley-spirit-private-disk-fixture.md)验证跨进程重启。默认关，无公用路由、后台调度、真实模型、现有存档或生产启用。正常候选预检仍要求真实承载、居民发现与拾取；隔离联接明确只验证承载与事务，不把居民的能力伪报为已实现。

开发夹具读取真实规则保存的已结束雨、确切公共成熟果源和指定地面格，另需独立传入本夹具的已钉选选项、当前权限版本、手动审批排期和效果总量限制。它不把候选、模型文本、 G1 预检或测试审批升级成正式授权；没有批准时完全不执行。冻结时钟不执行新效果。它的权限参数只是测试用显式输入，未接入生产权限服务。

协调器从 SQLite 世界写事务内重新读取当前实际状态。目标失效、容量不足、雨不符、超窗、审批错误或配额不足都不产生效果。通过时扣果源一份、加独立地面一份并写入同一效果收据、历史雨证据和无居民见证的观察者事实。镜像仅接收 SQLite 已确认、属于该提案的收据；镜像失败可以单独重读收据补写，不再执行世界效果。另一份提案竞争同一机会时只读到已消费，不被记为自身成功。

开发验证：TypeScript 构建、五项本地定向检查（显式门与排期、普通和隔离预检的区别、实际目标失效、收支与镜像幂等、SQLite 中途故障回滚），以及一个真实规则步跨越雨结束点后立即完成内存事务的快速验证。未运行长测、未跟踪测试文件。仍缺居民实际拾取与相关效果账、生产授权和配额接入、以及正式世界文件存档开放；谷灵未提测。
