# 谷灵：正式世界落果地形的只读影子核查

默认关闭。开发调用必须给出同一正式世界、原生实际已结束的雨、明确的有效时限和不超过八组果源与落点。只从已提交同一版本读取雨与地图，要求最新雨已结束、当前不是雨中，不能回填预测、未闭合或其他世界的雨。不会枚举后扩大选点。

正式地图原生野浆果灌木的整份存量是现有采集动作实际可采的数量；没有第二套成熟物候字段，不能声称已经验证新物候。只检查现有灌木 ID 与坐标、正整数实际存量、相邻且允许通行的独立草地。果源与落地格都须从实际入口连通，不占农田、私人地块、正在登记的地权、建设院落、牧场、墓位、出入口或活动灾害区域，落地格也不得已有其他自然资源。这里只证明当前空间条件，不推断任何居民看见、同意或已拾取。

结果标记为 `geography_only`，不是已验证的可执行候选。正式世界没有本功能的地面物品容量、产权迁移、发现与拾取事务、公开来源授权或候选调度，不能凭 MVP 能力、默认容量或模型文字补齐。额度和审批不在此入口。不调用模型、不写游戏世界、不提供 HTTP、不提测。

局部验证使用实际正式地图野生库存和实际引擎雨转变，覆盖未闭合/未提交、其他世界、合法与占用地块、采空、时限失效及读后状态不变。
