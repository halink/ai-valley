# 谷灵：G2 权威效果存档的隔离验证

这一层定义世界事务的落果存档边界，**没有接到运行入口、候选队列、审批生产配置或居民行为**。普通文件存档依然拒绝任何已采用效果的数据；仅[私有临时文件夹具](valley-spirit-private-disk-fixture.md)用于跨进程开发验证。旧代码也会因为气候状态的严格字段校验拒绝新嵌套标记。原始顶层 `mvpGroundFruit` 或 `mvpSpiritEffects` 形式不能绕过此门。未知采用版本、孤立效果事件、错误引用均先拒绝，不清理、不猜测或补发。

## 权威数据

`mvpClimate.spiritEffects` 记录采用时点、独立地面库存和已应用效果。每条效果必须绑定稳定效果/机会/提案 ID、审批标识、实际雨证据副本、同位置同时间且无居民见证的固定格式事实、地面物品和果源扣减前后量。账与物品和实际观察者事实一一对应。已应用记录和地面批次只能保留，不能修改、去掉或回滚后再领一份；历史雨证据不依赖近 28 日的候选窗口。4096 是当前结构拒写上限，不清理已执行历史；以后要扩容或开放拾取，先实现可解释的向前迁移和历史索引。

## 隔离 SQLite 验证

内存夹具通过内部显式构造 `new WorldStore(':memory:', {allowMvpClimate:true, mvpSpiritEffectFixture:{worldLots, lotsPerTarget}})` 使用。这个构造选项不允许文件路径、真实模型会话或长跑快照共用。没有生产配额默认值。夹具先保存无效果的普通世界，再以独立同刻空提交采用格式；下一次专用提交核对当前已结束雨、指定果源实例、指定地面、公共产权和承载量，只允许扣一份成熟果、加一份地面果、追加一条权威效果和事实。原 SQLite 事务同时写入世界和事实，不产生居民知识或预算变化。授权、候选重验、动态公平限制、真实发现及拾取仍不在此夹具范围。

开发验证：TypeScript 构建，六项本地定向检查，包括在事件写入后强制 SQLite 拒绝世界提交并验证整笔回滚。另对临时文件存档快速核实已知夹具格式和未来未知版本都在实际写入之前失败，原文件字节与目录不变。没有推送测试、启动长测、调用真实模型或开放生产功能；谷灵未提测。
