# 普通规则的原生进餐凭证（私有）

已有普通规则存档可由持有原文件运行锁的本地所有者，在停止自动步进时显式启用 `privateOrdinaryNativeMeal`（`{scope:'ordinary-native-meal-custody/v1', worldId}`）。这不改变普通起服默认配置，也不借封存实验的签发或读取权限。没有增加 HTTP 路由，现有生活档案仍不读取这种凭证。

只承认该档的一分钟真实进食、实际餐食扣减及同一存档提交中的原生证据。烹饪、库存变化、旧事件名字和其他食品不生成凭证。凭证另存于原文件绑定的私有表，核对事件和单一人物索引以及原始时间；观察到的回退或不兼容数据使本会话私有功能不可用，不阻断普通游戏。可选账写失败回滚该账，不回滚或伪造已经实际发生的进食，也不会事后补签。原档可重开；复制件不能沿用凭证。私有账增加前后都核对完整存档头及事件事实，不通过不可信主库锚表或临时遮蔽对象写入。当前文件绑定及事件摘要未以独立密钥签名，不是能对抗任意原始 SQLite 全量改写的认证系统。

本轮只完成私有证据前置。后续披露另需独立签名发布／撤回、原文件和精确凭证与输出绑定、读前复核与撤回防回退，以及不暴露人物、原始收据或精确游戏时间的展示。天气许可不能代替它，未开启公开发布或真实模型。

## 本机独立审签的匿名进餐记录

只针对上述显式开发存档中已实际提交、仍能核实的一个原生进餐事件。主持程序固定原世界、事件及独立审核人 Ed25519 公钥，配置形如 `{mode:'explicit-local-ordinary-native-meal-editorial', worldId, eventId, reviewerPublicKeyPem}`。不从 HTTP、环境变量、待签请求或原有公共权限取审核公钥；不接受普通事件文字、夹具/V2 凭证、天气权限或旧通用生活授权替代本档原生证据。勿在真实玩家档或共享存档使用此开发接线。

停止规则运行后，由同一原档的独占持有者使用 `openOrdinaryMealEditorial(database, pin)`。用 `preview('publish')` 或 `preview('revoke')` 对照匿名固定文案、物理文件及审核人范围、原生凭证与完整事件证据摘要、精确当前头和前版记录，再在外部独立签署 `encodeOrdinaryMealEditorialTerms(terms)` 精确字节。传回 `apply({terms,signature})` 后，最多独立签批一次发布及一次撤回，不接收旧签、泛化披露或新任审核人替代。记录和目录锚在一个受控 SQLite 事务内写入，并重读签名链、锚、原生事件及世界头核验。视图或未知储存结构、触发器、单独删除撤回尾项、原生证据失效、复制到其他文件、追加失败均不可读；不修复或补造。此保护不声称抵抗绕开协作锁并一致篡改／回滚整个物理存档及其锚。

要用 Godot 看本机开发记录，在同一原档显式传 `privateOrdinaryNativeMealView: pin` 并关闭自动步进。该开关与取证／旧生活夹具等其它私有开关互斥（同档不同审核密钥的本机听见视图除外），只开物理只读视图，没有 HTTP 写功能。既有 life/latest 入口及世界标记仅对 `127.0.0.1` 同源读请求给出该版本。批准后同档重开及推进到仍真实包含原证据的新头可读；每次标记或读取都重验同档、审核人、签章、原事件和固定句子。撤回或无证据时隐藏标记及旧文案，不影响天气或普通世界。玩家只看「生活年鉴」及当天有人进餐的事实。返回的时间／范围字段以游戏日开端作为分桶标记，不表示进餐整点或完整日期覆盖；原生分钟只在私有审签中核验。公开载荷没有人物、位置、原事件、来源引用、签名、凭证或版本流水。按日降低与同分钟记录的直接关联，不保证不能用其他可得信息缩小推断。仅供直接本机回环访问，不适合反向代理；拒绝转发头不表示能识别会改写或丢弃这些头的代理。默认运行仍关闭，不接外部供应商、模型年鉴或 G2。
