# 谷灵：封存库签批排期与收据对账

封存开发库可用 `scheduleSigned` 持久登记仍有效的独立签批，即使指定时点尚未来到。仍须先有完全一致的影子评估、当前允许引用的天气、明确的世界和独立公钥。G2 默认为关闭；普通世界、HTTP、模型、后台计时器均不调用此入口。

`sweepScheduled` 只在显式调用时运行，每次最多检查八条已到约定时间的记录，按真实已提交世界时钟判断。状态分别是待执行、暂无法确认、已过期、已拒绝和已入账。过期前仍须重走签批和原落果事务的精确复核，影子队列永不自行批准或写入游戏世界。暂时缺授权、缺证或收据不明时不执行业务写入。累计排期有隔离上限，不删除旧记录。

排期表不具世界权威。每次重试先查已提交世界的同一签批 ID 和候选 ID；如已落果，即使排期未更新就中断、重开时签批窗口已过，也只回读权威收据，不再次扣果。确认未入账才可以到期关闭或进入正常提交复核。撤销天气授权后无新落果；仍可在原封存库和同一验证公钥下读已发生收据。当前不实现生产调度或对外签批平台。

查询排期状态只打开只读数据库连接；没有表时不建表。非规范表、视图或挂接触发器让该排期入口拒绝访问，不替换或修复原数据。即使本地排期记录声称已经入账，也须在当前权威世界中找到同一签批、候选和效果 ID；存档回退或收据不一致时不显示已入账。
