# 居民屋面提议与有限兼容改版

本项是[第 6 批](roadmap.md#批次-6-新区域发明与运输)的第一种居民可自行发起的兼容改版。它只更换私人住宅、工坊或商铺的木面/石板屋面外观，**不增加功能、容量、耐久或屋况**。公共场所、内室重排、扩建、设备功能升级及多种原型组合仍未完成，不代表完整设施升级系统或长期运行验收通过。

## 正常行动链

1. 有一级建造技能的产权人或当前有效承租经营者，在已知建筑附近选择具体木面或石板方案，实际到门外花 20 分钟提出。
2. 原址记录一份 7 游戏日的具体提议。提议人也不被视为已同意。产权人、承租人、所有登记住户、原址经营及库存所有人、有效聘约的雇主和员工、未完个人批次所有人分别亲自到场阅读，再另选同意。
3. 全体独立同意后，只有提议人能带足**自己随身**的材料，在门外另选预留开工。没有公共拨款、他人材料或自动采购权限。
4. 提议人选择每次 1–120 分钟实际门外劳动。累计材料投入按实际进度取整，到完成时恰好消耗全部报价。劳动与材料随中断和存档保留，没有雇佣工资承诺。
5. 完成只把该建筑指向原定义的兼容新版本。新版本完整复制原结构、成本、功能、依赖与元数据，仅改变屋面外观；不修改全局启用版本，不改其他建筑。住户、房间、商铺、货物批次、固定工位、未完原料、聘约、出勤及已挣工资都不重建或迁移。

实际占地面积为 A 格时，木面用 ceil(A/4) 木；石板用 ceil(A/8) 木和 ceil(A/4) 石。两者均需 30 + 2A 分钟本人劳动。材料用于本次屋面改作，不从旧屋面生成回收物，不提高以后拆除的原结构材料账。

## 同意与失效

- 住户从建筑的 residents 与居民的 homeId 两边取并集，不能因其中一边漏登记而绕过。缺失、死亡、镇外、未成年或不能独立表达/决定的受影响当事人使该场所暂不支持；不以监护人或多数票替代本人同意。
- 每份提议记录原址几何、产权、住户、有效租约、经营地点、工位与聘约的静态条款，以及原/新定义。每次答复、备料和每个劳动步重新核验。普通货架变化、出勤和工资余额本身不改变已同意的静态条款。
- 换产权、换门址、变尺寸/容量、增减住户、新聘约或改工资条款、租约到期/交还、有限用地失效、内容定义变化等使旧同意不能沿用。不能把旧同意转给新的人、地点或版本。
- 未签租约报价、未完招聘、已有建设、经营迁址、家庭迁居、临时床位、设备拆卸以及原址照护/教学/公共班次/文化活动均暂不支持。共同钱物和受保护临时代管不通过此接口扩权。已到期但未结清或重复有效租约记录也按不一致处理。
- 任一当事人可拒绝，已同意者在完成前可撤回，提议人可以停止。原建筑与原约继续，已投入的材料和劳动不退回；未用实物留在原址，原提供者须另选实际领取。期限、失能或权利变化不会自动完成升级。
- 提供者死亡时，只把实际未用材料登记为原建筑处的遗产实物；不把已投入材料、劳动或原屋面变成新库存。领取不随产权改变把材料归给新房主。原址坐标单独保留，建筑移动或删除后仍从原材料位置领取或归入遗产，不随新门址瞬移。
- 新提议不是全镇广播。其他当事人须在原址附近才出现阅读选择；亲自读过后可记住这份提议，但答复仍需要本人到门前办理。未参与者不能同意或领取。

## 旧档与观察

没有此字段的旧档不生成提议、同意、材料或升级。已有底层兼容报价仍按原流程保留，本居民流程使用独立的 optional residentProposal 记录，不伪造旧报价的多方同意。新版本没有全局激活，未完成或拒绝的方案不改变任何实例。

建设观察页只读展示具体屋面、材料报价与已消耗量、原址余料、实际劳动、提议人、各当事人已读/同意状态、期限和中止原因。这里只能定位和查看人物，没有批准或施工按钮。
