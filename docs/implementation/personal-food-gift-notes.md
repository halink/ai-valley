# 本人赠粮交接记录

## 已实现的窄改进

[交接窗口重放](../reviews/food-handoff-window-replay.md)已排除“持续没有合法接受项”的解释。历史失败包括收方选择撤退、交付与离开同时开始，以及返回时供方仍在执行旧等待。最近[十五日合成验收](nine-resident-survival.md)也仍失败，不能靠九人终点存活宣称解决。

本次改进是**让居民在最终决策输入中持续看见自己已知的交接约定及其真实条件**，而不是另写一个替居民选择的供食策略。此前接受事件只说“约在本人当前实际位置”，近期记忆可能被截短；接受后的撤回菜单只显示食物和期限，没有保留收方约定的精确地点。新的独立摘要可从已持久化、凭据完整的本人记录重建，不依赖最近几条经历。

摘要包括：

- 本人是送方还是收方，原食品、份数、固定截止及剩余游戏分钟。
- 本人最后获知的是提议还是已接受。只有已知接受才显示原交接位置，室内同时区分门口及原室内坐标。
- 收方依据**自己的**实际位置知道是否仍在原约点；离开会使实际交付无法完成，返回也不保证对方仍在。
- 送方仍须另选交付、完成真实路程及一分钟近身办理。接受不等于收货，交付不等于进食。
- 本人可以从原有菜单选择短暂停留、其他行动或撤回。停留时间仍由本人填写，身体照常消耗，不恢复睡眠体力；消息不会自动打断已经选择的动作。

没有新增行动、修改编号/轮换/菜单保留、调整等待时间、增加会合次数、延长期限、降低危险优先级或调资源。没有自动接受、交付、喂食或强制留人。生产改动限于个人记录的只读投影、可选上下文字段和最终 prompt 的独立段落。

## 知识、权限与预算

只读取本人参与且 `knownStatus[本人]` 仍为 offered/accepted、尚未到原期限、原始提议和接受凭据有效的记录。全局结束状态、远方另一方的坐标、死亡、库存、能力和活动不用于生成摘要。远方撤回不更新另一方的已知状态，因此摘要始终说“本人最后获知”，并提醒远方变化未知。它不保证此刻还有食物或对方有空。

最多六条，已接受记录优先，然后按原期限和 ID 排序。其余明确标为未展开；旧标识过长时仅截断展示，不改动作的完整 ID。旧档缺少可选记录时返回空，不初始化或补造合同。有效成人 v1 旧约继续可见，不升级权限；假接受标记缺少真实接受凭据时不展示。

新段落独立于家庭综合记录和近期记忆。必要时沿用既有按序列化字节缩减家庭记录的机制，保留交接说明、理解原话及全部动作；核心内容仍超预算则原限制继续报错，不静默删动作。代价是增加提示字节、可能挤掉更多综合家庭记录，以及六条上限下部分未接受记录不展开。这些是明示的展示取舍，并非已验证的模型行为收益。

## 验证与边界

主专项六项、[独立边界审查](../reviews/personal-food-gift-notes.md)十一项合跑 **17/17 通过**，零跳过。清空近期经历后，移除新增段落的原提示确实缺少精确交接坐标；新提示保留该点，菜单完全相同。其他覆盖包括真实最终编号选择、世界只读、三模型提示、远方取消与私有状态隔离、室内原点、内存 SQLite、旧 v1、六条上限，以及实际触发的提示预算裁剪和超限拒绝。只准备模型输入，没有调用模型。

### 同种子短交接对照

以 seed 5401 默认九人为基础，仅把两人的位置放在原地图一段可步行的隔离接触位置，使用原食品、身体、年龄及真正 offer/accept。接受后克隆同一世界，双方分别从现有最终编号菜单选择：

1. 收方选择原地停留六分钟，供方另选交付：六分钟内交付一份原根菜，供者 5→4、收者 5→6，合计仍为十份。
2. 收方选择向东探索，供方仍另选相同交付：交付失败，双方仍各五份。规则没有阻止收方离开。

两条分支使用同一个六分钟观察截止，逐人保留身体、库存和危险饥饿分钟。期间没有进食，九人健康不变、危险饥饿皆零；收方饥饿增加 0.228、体力减少 0.15，等待没有免除成本。成功分支之后另选的进食单独记录时刻和收据，不混入六分钟对照，也不因有五份原根菜就冒称确定吃下赠送的那一批。

另有负例：供方已经选择 120 分钟等待，收方短等不会打断它、不会自动拿到食物或延长期限，仍可选择撤回。上述两分支证明说明里的物理条件和成本，**不是**“新 prompt 导致居民更愿意等待”的试验。选择由明确的测试脚本作出，不能用它证明自主模型行为或长期生存改善。

```sh
mkdir -p output/personal-food-gift-notes/tools
NODE=$(command -v node)
env -i HOME="$PWD/output/personal-food-gift-notes/tools" \
 TMPDIR="$PWD/output/personal-food-gift-notes/tools" \
 TMP="$PWD/output/personal-food-gift-notes/tools" \

 "$NODE" --import ./scripts/acceptance-offline-guard.mjs \
 --import ./node_modules/tsx/dist/loader.mjs --test \
 tests/personal-food-gift-notes.test.ts tests/personal-food-gift-notes-review.test.ts
```

同样的清空环境和加载器下运行 `scripts/acceptance-nine-survival.mjs --offline` 可重新生成当前版本的十五日合成证据。重建变更前基线需要对应源码，不能在当前版本重复两次就冒称改动前后对照。

本地输出位于 `output/personal-food-gift-notes/`，不随 Git 交付。主专项最初的预算夹具未剔除既有理解机会，触发的是理解依据优先的提示尾注而非新交接尾注；修正夹具后通过，原失败日志保留。独立审查的两次饱和夹具容量不足失败也保留。
