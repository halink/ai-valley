# 独立绘本动画与资产伴随契约

基线为本地 `07a6826`，设计依据为未提交的 [绘本方案文字](../design/storybook-valley.md)。本批仅新增独立 TypeScript 契约、只读播放器和离线测试，没有接入画面。两张参考 PNG 仍未取得并检查像素，没有制作正式美术、角色造型或动画图集；不能据此声称视觉、浏览器、性能或自主生活验收。

现有 `storybook-assets.ts`、静态技术样板、默认 2D、旧等距视图、唯一快照 feed、`ObserverMap` 和导航接口均不修改。不改世界规则、决策、时钟、存档、结果提示或模型调用。已有五项赠食候选及五项设计文本不属于本批，没有修改、暂存、提交或推送；远程用户设计未本地整合前不推送。

## 与 v1 图集兼容

新增 `storybook-animation-assets.ts` 的 `parseStorybookAnimationBundle(atlasInput, animationInput, pin)`：

1. 仍调用原 `parseStorybookManifest`，按显式 pack/version pin 严格解析 v1，不向原清单塞动画字段，也不改变静态或四向单帧的含义。
2. `animationInput:null` 明确表示只有静态素材。旧 v1 图集仍可使用，新动画解析器不会把旧四向单帧自动复制成循环。
3. 非空动画伴随清单独立版本为 `animationSchemaVersion:1`，其 atlas 恰含 `packId,packVersion,sha256`，必须逐项匹配 v1。这是元数据绑定，不是实际 PNG 字节、许可或艺术内容验证；真实图像仍须通过原加载器和人工视觉检查。
4. 没有 fetch、文件读取、Phaser、计时器或第二套 feed。只处理调用者提供的元数据与快照。

伴随清单的精确字段为 `animationSchemaVersion,atlas,characters,bindings`。每个 character 包含唯一 `id` 和 `clips`；clips 必须显式包含 `idle,walk,pick`。每段 clip 恰含 `cels`，每个 cel 恰含 `assetId,durationMs`。`pick:null` 表示该角色没有首批采摘素材，不能省略后假装已有支持。

每个 cel 引用一个已有 v1 directional asset；一个引用自带四个方向。因此一人的 idle 两个引用产生 8 帧，walk 六个引用产生 24 帧，pick 四个引用产生 16 帧。两位角色中仅一位有 pick 时，总计 80 帧；测试夹具只是一个角色的 48 个矩形元数据，未生成图片，也未把角色绑定到生产居民。

- 四个世界方向 north/east/south/west 分别映射原四斜向 northeast/southeast/southwest/northwest，不将投影方向压成屏幕左右两向。
- 每段恰有 2/6/4 个 cel。每角色各 cel、各方向不能引用同一个源矩形；不接受镜像、自动补帧、缺向或额外字段。矩形不重用只证明元数据地址有别，无法证明实际像素真的转身或各帧内容不同。
- 首批固定人物占地 1×1，地面锚点 `(0.5,0.5)`；一位角色所有 cel 具有相同未裁切画布尺寸和像素脚点。不得通过素材尺寸改变世界占地。实际画稿的脚底漂移仍须逐帧看像素。
- walk 每帧时长在 `1000/12` 至 `125` 毫秒之间，对应约 8–12 fps；idle 每帧 1–60 秒，支持长时间静止；pick 每帧 100–2000 毫秒，仅控制显示节奏，不表示采摘进度或产量。
- `bindings` 用真实 `residentId` 明确绑定 character，不按数组位置、名字、职业或性别猜测身份。此处只是展示层显式声明，仍须在将来制作时核对原 appearance 与年龄；不写回居民档案，不自动补出成人/少年造型。
- 上限为 64 个角色、512 条绑定、3072 个方向帧引用。重复 ID/绑定、稀疏数组、访问器、特殊原型、隐藏/符号/额外字段都失败关闭。输出与输入分离并深冻结。接口面向 JSON，不是恶意 JavaScript Proxy 的沙箱。

`storybookAnimationFrame` 只从已解析 bundle、明确居民、动作、世界方向与 elapsedMs 取帧。身份、素材或可选动作缺失返回 null；不回退到别人的外观。`storybookCelIndex` 使用半开时间区间和循环余数，没有动画完成事件、奖励、物资或工作结算回调。

## 只读状态与真实位置

`storybook-animation.ts` 的 `StorybookAnimationPlayer` 分两步使用：

- `accept(world, space)` 读取原 feed 已接受的不可变 World。可选 space 必须和原室内适配约定一致。一次接受即复制所需位置、状态与动作标识，不保留可被后续写入改变的 world 对象。
- `sample({nowMs,connected,visible,reducedMotion})` 输出冻结的显示记录。时间由调用者注入，不从 serverTime、世界分钟、系统时钟或角色 ID 生成随机相位。播放器只存少量显示相位与最近已确认方向，不推进模拟。

记录保持原居民 ID、spaceId、真实 at/anchor 和原活动说明，分为 frame/fallback/hidden。未知位置保持 null，不把室内居民放到门口。已安葬、镇外、其他房间的居民沿用原隐藏规则。缺图、未知方向、异常状态明确给出原因并保留原视图。

位置和方向读取已有 `prepareIsometricResidents`，另做首批适用性检查：

- 户外移动仅使用真实相邻下一格和记录的 travelProgress；室内使用该房间的 room.path/progress。显示时间绝不外推位置，不越过第一步，不推算下一段或新路线。
- 户外下一步按现有只读 walkable 检查路阻；室内按真实建筑生成的布局和单步 roomPath 检查，不接受调用方虚构的房间大小。路阻、坏路径、错误空间、未来行动开始时间、非正剩余工时均不播放动作。
- 新快照的世界分钟前进，但角色 anchor 没前进时，行走肢体也停住，直到新快照确认进展。收到清空路径或改向立即停步/改向，不等待完整循环；不在等待期间继续走路。
- 采摘目前仅覆盖已到真实相邻 bush、目标与资源一致、有剩余量、原状态确认为 active 的 gather。到场前仍是 walk；空源、同格无确定朝向、其他资源/树果/工作类型均明确回退。它是有限显示条件，不替代引擎末工时校验或保证成功。
- 自选停留可以采用长间隔两帧 idle。等待决定、等待履约、准备行动与计划时点未到保持平静首帧，仍保留各自活动标签，不循环播放劳动。
- 新打开视图时静止朝向未知，不默认朝南。只在同一场景、连续有效且局部位置连续的观测中保留此前真实行走/资源方向；失去位置、隐藏、异常、跨场景或换世界后不继承旧方向。
- 存在未解除伤病、失能、死亡、婴儿、睡眠、携运者/被携运者、船上、家庭共同行程或首批未覆盖劳动时，不以健康待机/空手步行冒充。首批不绘制工具、成果或病态美术。

旧快照 revision 或 minute 倒退会在修改内部显示状态前拒绝。换 worldId/场景和显式 reset 重新建立基线，不继承历史相位与朝向。观察者仍负责接纳 feed 和重连；本模块不新建连接，也不读事件生成完成提示。

## 暂停与确定性时间

- 世界暂停、断线、页面隐藏和 reducedMotion 都冻结当前连续动作的相位，分别返回 freezeReasons，而不是每次重置为第 0 帧。动作或身份本身发生真实变化时使用新状态，不继续播放旧动作。
- 恢复后的第一段间隔不累计，避免将暂停/断线/后台时间补入动画。大于 250ms 的单次显示间隔全部丢弃并标记 long-gap，避免后台恢复或卡顿时补播。
- monotonic nowMs 必须是有限、非负、至多安全整数范围且不倒退；非法时间在任何相位写入前拒绝。帧循环与世界速度、分钟差、模型等待时间无关。
- 调用方必须在状态切换时及时 sample 新 flags，即使没有新快照；浏览器可见性、断线检测和实际画面绘制尚未接线。未收到新证据时，播放器最多重复当前动作的局部肢体相位，不推进脚点、产量或时间，也不能据此证明居民仍持续工作。

这不是生产渲染器，也没有承诺网络断线检测、浏览器帧率、纹理内存、遮挡效果或 UI 可读性。后续接线应复用现有唯一 ObserverMap 快照和连接状态，保持原视图回退；在实际参考图和生产素材到位前，现有合成技术样板的“无动画”说明仍准确。

## 验证

主测试包括 v1 兼容、2/6/4 帧与四世界方向、来源/锚点/节奏/形状反例、冻结输入、真实状态回退、室内外路径、阻路、停止、状态切换、时钟和重连边界。合成实际引擎测试执行正常 submitPlan → 逐步行走 → 到场采摘 → 真实结算，逐次证明播放器不改变 world；这验证接口，不是模型自主行为。

最终主测 45 项、独立反例 9 项全部通过；包含原绘本基础在内的独立复跑为 169/169。再与原居民状态、室内外观察、导航、工作回执及正式观察 feed 的选定回归合跑为 **248/248 通过，0 跳过**。正式观察 feed 回归仅使用合成内存/临时 SQLite 和本地回环服务，没有连接外部模型或真实服务。全项目 TypeScript 无输出检查、服务端 TypeScript 编译、Vite 构建均退出 0。

为避免读取环境文件、key 或覆盖正式产物，全部检查清空进程环境；服务端输出重定向至本仓库 `output/` 新独占目录，Vite 使用 API 显式指定 `configFile:false,envFile:false,envDir:false` 和原 `/ai-town/` base。没有运行 `npm run build` 的原命令。Vite 仍有原大分块警告，不是运行性能保证。最终日志目录为 `output/storybook-animation-verification-Wtd2JN/`，其中 `regression.txt,typecheck.txt,server-build.txt,vite-build.txt,status.txt` 分开记录结果。

独立审查先红后绿修复两个问题：只有 revision 更新不能解除已确认停步；室内下一步被布局拒绝时，fallback 脚点也应回到实际 roomAt。详情见 [动画契约审查](../reviews/storybook-animation-contract.md)。初始主测试曾因禁止系统时钟的正则匹配到说明注释而失败，之后改为检测实际调用；没有跳过断言或业务测试。

没有运行全仓 `npm test`、真实模型、读取 key/真实存档、浏览器/视觉验收、bwrap 或浏览器 IPC 重试，也没有暂存、提交或推送。上述结果仅证明所列离线契约及兼容回归，不代表绘本画面、完整项目或十五日自主生活验收。
