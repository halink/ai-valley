# 普通规则的共屋入门凭证（私有）

持有原文件运行锁的本地所有者可在现有普通规则存档、停用自动步进时，显式启用 `privateOrdinaryNativeShelter`（`{scope:'ordinary-native-shelter-entry-custody/v1', worldId}`）。普通避雨选项、路径、工位和界面不变。

凭证只来自真实跨门：普通行动已走到共屋的实际门口，原生室内引擎将居民从户外置于真实前室入口并成功登记入口工位。这一刻既不是走到门口，也不是完成之后的五分钟停留。已经在房内、行走失败或紧急需求中止，不会凭旧事件生成入门凭证。共用入口能容纳同一合法小组，不新增排他权限。

凭证与这一分钟的存档一起提交。它核对原档前后状态、行动、门和入口坐标、当分钟的工位登记，但不写入玩家事件列表，也不占用正式赴约的 `arrived` 类型。仅支持原文件私下读取或重开；复制件、未知表或触发器、写入异常不生成可用凭证。可选账异常不阻断普通游戏；若整个世界提交失败，凭证也不会出现。私有账不披露人物或原始事件，原文件绑定及摘要不是抗原始数据整体改写的签名认证。没有新增公开端点、签名发布、模型或普通 G2 能力。
