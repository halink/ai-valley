# 普通规则的共屋入门凭证（私有）

持有原文件运行锁的本地所有者可在现有普通规则存档、停用自动步进时，显式启用 `privateOrdinaryNativeShelter`（`{scope:'ordinary-native-shelter-entry-custody/v1', worldId}`）。普通避雨选项、路径、工位和界面不变。

凭证只来自真实跨门：普通行动已走到共屋的实际门口，原生室内引擎将居民从户外置于真实前室入口并成功登记入口工位。这一刻既不是走到门口，也不是完成之后的五分钟停留。已经在房内、行走失败或紧急需求中止，不会凭旧事件生成入门凭证。共用入口能容纳同一合法小组，不新增排他权限。

凭证与这一分钟的存档一起提交。它核对原档前后状态、行动、门和入口坐标、当分钟的工位登记，但不写入玩家事件列表，也不占用正式赴约的 `arrived` 类型。仅支持原文件私下读取或重开；复制件、未知表或触发器、写入异常不生成可用凭证。可选账异常不阻断普通游戏；若整个世界提交失败，凭证也不会出现。私有账不披露人物或原始事件，原文件绑定及摘要不是抗原始数据整体改写的签名认证。没有新增公开端点、签名发布、模型或普通 G2 能力。

## 本机独立审签的匿名入门记录

在已实际保存原生入门凭证的原档，主持程序可固定 `{mode:'explicit-local-ordinary-native-shelter-editorial', worldId, receiptId, reviewerPublicKeyPem}`。这里的 `receiptId` 只来自上面的私有入门账，不是普通事件、停留完成事件或正式到场的编号。停止运行后使用 `openOrdinaryShelterEditorial(database, pin)`，以 `preview('publish')` 或 `preview('revoke')` 取待签项，由独立审核人在外部对 `encodeOrdinaryShelterEditorialTerms(terms)` 的精确字节签名，再以 `apply({terms,signature})` 校验。原始进门分钟、原档物理身份、前后世界头摘要及入口登记见证、当前世界头和匿名文案均绑定；不允许借进餐、听见、天气或旧生活授权。一次发布后可独立签批撤回，不开放 HTTP 写功能。

停止自动步进且显式传 `privateOrdinaryNativeShelterView: pin` 才会在既有本机回环生活档案显示「第 N 日：有人进共屋避雨。」。只显示游戏日，不返回准确时间、人物、坐标、房间编号或凭证，也不推定停留五分钟。三种本机生活视图共同配置必须同一原档、审核密钥各异；只比较公开日，同日固定为听见、进餐、入门，原有听见与进餐顺序不变。撤回或账本和证据失效时隐藏对应记录，必要时回退到其他仍批准的事实。只删除撤回尾项、换审核人、复制或更改原生凭证都不会使旧记录复活；不能防止绕开本机协作锁且一致改写整个文件和归档锚。没有外部发布、模型或普通 G2。
