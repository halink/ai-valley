# 谷灵：年鉴选题内核（未提测）

G1 的只读年鉴选题与可执行世界机遇分开。选题从 G0 的当前授权公开投影生成有限菜单：最近一个实际时点的天气、气温、相对湿度，以及在集合确有两个时点时比较最早与最近时点的气温或相对湿度。每个细项列出来源引用、发生时刻、字段及实际值。它不是整日统计、不推断变化原因，也不把没进入投影的小时称作档案无观测。

菜单 ID 绑定范围、投影版本、权限版本及准确的来源值。选择只接受菜单 ID 和候选 ID，并重新按当前授权和来源生成完全一致的菜单。撤权、来源变化或不在菜单中的编号均直接拒绝。选中只返回该题对应证据，既不生成年鉴条目，也不推进世界、发请求或执行候选。

目前提供离线合成选择和手动选择校验；没有生产模型调用、玩家入口或世界候选执行。按设计，未来接入选题模型仍须通过共享账户准入和既有权限。未提交本地测试文件。
