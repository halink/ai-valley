# 开发专用绘本 DOM 界面壳

本批只把[文字提案](../design/storybook-valley.md)的界面布局接成可回退的开发样板。两张参考 PNG 尚未取得并核验；没有以本批结果宣称参考图匹配、正式美术或完整视觉验收。原地图、像素头像和全部档案内容继续沿用现有实现。

## 开关与隔离

- 仅 `scripts/dev-observer-web.mjs` 的 serve-only HTML 插件在 **恰好一个** `storybook-ui=1` 参数时注入 `storybook-ui-entry.ts`；入口再次检查 `import.meta.env.DEV` 和同一精确参数。
- 默认页面、普通开发页和生产依赖图均不安装界面壳。带参数也只显示“打开绘本界面壳（开发）”，必须再主动点击才重排界面。关闭或刷新不保存偏好。
- 既有 `storybook=1` 合成绘本诊断与此开关独立，可以共存；本批不增加 Phaser Scene、素材请求、世界连接或世界写操作。
- `main.ts` 未改动，仍独占世界 GET、SSE、重连、历史查询、选择、跟随及档案路由。界面壳消费它导出的同一 `ObserverMap`。
- 开发观察服务器原只读 API 边界保持不变。本批不新增历史端点；开发代理原本不提供的历史读取仍由原面板显示失败，不补写假记录。

可在已有、按项目规约启动的**合成开发观察环境**使用 `/ai-town/?storybook-ui=1`。此说明不要求打开正式服务、真实存档或模型；本批验证未启动任何服务。

## 布局与保留内容

- 纸白 `#F4ECD9`、墨褐 `#3E382F`、细暖灰边、12px 圆角与轻阴影；正文15–16px、说明至少13px，按钮至少44px；焦点轮廓同时使用形状与对比，不只靠颜色。
- 桌面保留居民、关系、交谈、场所、野外、年表六个原按钮。选中卡位于右侧，宽304px。按需长记录使用原详情面板。
- 手机阈值700px，底栏为居民、场所、年表、更多；“更多”中仍是原关系、交谈、野外按钮。不是副本，也不另建一套路由。
- 手机选中卡默认收起，显示原姓名、活动与取消选择按钮；展开后可滚动，常规最大40dvh。详情默认40dvh，用户可主动展开长记录。
- 时间、世界版本、连接/暂停状态、房间提示一直可见。原2D/2.5D与合成诊断工具放入可展开的“开发界面 · 工具与说明”。原地图控制、全图、版本说明、选择卡和详情按钮均保留。
- 选择、详情和状态使用原DOM节点，原事件委托、懒加载、历史筛选、错误/空状态、图中键盘入口不复制。所有原节点通过占位节点恢复原顺序；新CSS仅对启用后的壳生效。
- 没有快照时使用真实文本“日期与时间未知”，隐藏原初始样例日期。所在地点从当前居民实际记录和既有跟随位置判定读取，区分室外、室内精确位置未知、镇外、已故及缺失位置，不使用住宅、计划或目的地冒充位置。

## 交互与清理

- 重复安装返回同一实例，重复打开不新增订阅。关闭释放快照监听与DOM观察器；dispose可重复执行，旧handle不能复活界面。安装中断时回滚已有移动，提示失败并保留原界面。
- Escape依次收起更多、关闭阅读面板、收起手机展开卡，再退出界面壳。关闭详情不触发原全局Escape的退出房间/清选择行为，因此保留原观察位置、选择和跟随。
- 关闭阅读面板回到原入口。手机隐藏入口回到“更多”；断点切换重排按钮后显式恢复可见焦点，包含“收起更多”转桌面时的回退。
- 详情和卡片各自滚动；世界地图仍用原拖动区域。底部按钮使用safe-area。减少动态效果设置禁用本壳过渡/动画，不创建新的显示相位或镜头动画。

## 验证与限制

测试使用合成世界、Mock DOM/事件和实际主入口的独立传输替身；没有浏览器、IPC、bwrap、网络、真实存档或模型。Mock覆盖默认关闭、反复打开/销毁/重装、节点原位恢复、六入口/更多、ARIA状态、分层Escape、焦点回归、断点变化、展开长记录、缺失快照、未知位置和安装失败。

Mock只近似DOM移动后的失焦与隐藏祖先拒绝焦点，不代表真实浏览器焦点或可访问性树。GET/SSE验证执行的是实际main的独立测试及壳的源码约束，不冒称完整页面运行。CSS静态约束覆盖目标色值、字体、44px触点、40dvh抽屉、safe-area和reduced-motion，不代表1440×900、1280×720、390×844的实际排版通过。

独立审查见[审查记录](../reviews/storybook-ui-shell.md)。审查发现并修复：手机重排丢失原`.dock button`状态契约、更多容器的手机CSS覆盖、移动节点后的焦点丢失、收起更多转桌面时焦点落入隐藏按钮。

最终离线检查结果记录在本页末尾。实际三画幅、字体溢出、触控、屏幕阅读器、地图遮挡比例及约80%无遮挡目标仍待浏览器验收；本批不声称性能或美术通过。
