# 绘本观察界面

2026-11-12：绘本布局已从开发样板提升为 `main.ts` 的默认观察界面，正式世界与合成开发世界使用相同布局，不再需要 `?storybook-ui=1` 或“打开界面壳”。旧参数兼容入口只导入主入口，不再另行安装或销毁界面。

## 设计与范围

已实际查看[美术规范板](../design/assets/storybook-valley-art-direction-v1.png)和[早期全景](../design/assets/storybook-valley-concept-v1.png)，以[文字设计](../design/storybook-valley.md)的六入口与可读字号为准。采用纸白、墨褐、浅墙、暖灰细边、圆角和轻阴影，避免全屏纸纹或正文书法。地图、原像素头像仍使用原资产，**UI 重构不是手绘地图、美术资产或 2.5D 引擎验收**。

- 桌面：小型字标/时间/版本，独立连接与房间状态，底部居民、关系、交谈、场所、野外、年表六入口；304px 对象卡；按需阅读面板。
- 手机（700px 以下）：居民、场所、年表、更多；关系、交谈、野外在更多中。对象卡收起保留姓名、活动、取消选择及必要跟随异常提示；可展开至40dvh；详情可继续展开长记录。
- 同一套详情主题覆盖人物与生平、关系图、交谈、场所、建设、家庭/公共事务、产业经营/账本、伤病照护、生态/动物/鱼群、野外、年表筛选/分页和版本说明。保留全部原渲染器、空状态、错误重试和延迟加载。
- 日期缺失显示“日期与时间未知”。位置只读实际记录，区分室外、室内未知位置、镇外、已故与记录缺失，不能用计划或住宅冒充所在地点。
- 原地图控制、全图、跟随、室内与2D/试用2.5D切换仍可用；视图工具收在“观察视图”中，连接状态和室内提示不收入折叠区。

## 接入与交互约束

`mountStorybookUIShell(observerMap, {mode:'live'})` 自动激活正式布局，无退出旧UI或开发提示。`preview` 模式仅保留给独立回归测试。安装失败恢复原节点，不阻断原主入口连接。

所有节点为原节点移动，不克隆ID，不复制点击监听，不新建世界网络连接或写操作。`main.ts` 仍负责原 GET/SSE、重连、档案查询、路由与观察动作；界面层只订阅同一个 ObserverMap。原 `.dock button` 与 `data-*` 委托契约在手机更多区也保持。

Escape只收起最上层：更多、阅读面板、手机展开卡。无层可关时不清选择、不退出房间、不停止跟随，也不退出正式界面。关闭详情优先回到打开它的按钮；快照替换按钮时按语义数据属性找回，已消失则回退居民入口；手机隐藏的导航回退更多。响应式重排后焦点不会停在隐藏导航中。初次装载不抢焦点。

按钮至少44px；正文15px、说明13px；独立滚动、safe-area、可见焦点、减少动态效果与强制色模式。长记录仍是非模态阅读面板，不声明虚假的 aria-modal 或强制焦点陷阱。顶部空白不截断地图拖动，室内状态不再继承旧版居中固定定位。

## 验证边界

UI 模拟测试使用合成世界和简化DOM，不读取 `.env`、真实存档，不调用模型。真实主入口集成测试的网络/Phaser使用替身，生产构建使用 `configFile:false, envFile:false`。既有可选详情仍延迟加载。用户负责长期运行验证。

本轮没有实际浏览器截图、GPU、触控或屏幕阅读器验收：此前环境明确拒绝 Chromium 所需权限，不绕过。CSS合同与模拟断点测试**不等同**1440×900、1280×720、390×844、200%缩放的真实布局通过。地图无遮挡比例、原生焦点/触控和不同字体溢出仍须实际浏览器复核。独立审查和最终测试数量见 [UI重构审查](../reviews/storybook-ui-production.md)。

## 手机可见视区取景

界面用实际 `getBoundingClientRect` 测量顶栏、对象卡、阅读面板、底栏、镜头按钮和更多菜单，通过 ResizeObserver、窗口尺寸及界面变化更新。选择最大未遮挡矩形，至少48×48px；不假定抽屉永远等于某个屏幕百分比。完全遮挡使用零面积状态，保持相机与跟随等待；恢复空间后再取景。相同区域与选择不会因每条世界快照反复发布。

2D与试用2.5D通过同一观察器接收CSS像素区域。已选居民和正在跟随的居民使用真实已知位置，缩放与布局变化后落在可见中心；不会为了取景改变房间、选择、居民计划或启动跟随。室内位置未知只保留房间概览，越界、区域旅途或已故不伪造现场坐标。无选中人物不自动回家；手动拖拽停止跟随后，不因抽屉或尺寸变化拉回原选中者，重新明确选择或跟随才恢复。

取景偏移按相机缩放换算。2D只扩展展示用镜头边界，使四角人物能露在未遮挡区，世界地图尺寸不变；回到桌面恢复普通边界。2.5D在原有约束上加入至多半帧的展示偏移，绘制、可见范围裁剪和命中测试使用同一最终相机，不改资源预算。完整遮挡期间不自动移动；恢复后仍核对实际房间与跟随状态。

本轮补足裸文本容器（如经营流水 article、课堂/动物需求 div）的15px继承，避免旧12px组件规则漏过公共主题。新增回归和独立审查见[可见视区审查](../reviews/observer-view-area.md)。这些几何与DOM替身检查仍不是浏览器截图或触控验收。

显式定位优先于仍显示的居民卡：从档案点坐标、建筑、动物，进入/退出室内或全图/区域/工程/商站定位后，关闭面板不会跳回旧居民。手动观察的纯UI布局变化保留实际相机及固定展示偏移；真正画布resize保留观察中心并遵守边界。点击“停止跟随”后同样不会被抽屉重新拉回该居民，明确再次跟随可恢复。
