# 动物身份与长期年表

本项补上动物档案只能查看近期八条事件的观察缺口，接通既有持久年表。它不改变动物行为、繁育、捕食、疾病、迁移、死亡、驯化或居民决策，也不增加任何居民记忆或模型请求。

## 从哪里进入

- 牲畜、野生动物与鱼群的当前档案均有“查阅完整留存年表”。
- 山谷年表、人物生平等已有历史页面中的动物事件，也可沿明确登记的动物身份打开同一档案。一次事件涉及多只动物时分别提供入口，不重复显示同一身份。
- 动物年表支持年份、原文、事件类别和相关人物组合筛选、较早/较新页、重试及回到最新。阅读旧页时，新记录不挤走当前页；只有同一动物且符合筛选的新事件才提示更新。快速切换动物时，先前迟到的响应不会覆盖新档案。
- 没有当前动物对象时仍可从留存事件打开历史，不把对象缺失解释成死亡或离境。当前状态入口仅用于查看今日状态，不用于重建过去。

## 身份与证据边界

查询只匹配事件原有的 `animalIds`，不按动物名称或正文中的文字猜测身份。野鸭驯化为家鸭沿用原身份，因此野外、驯化、照料或死亡的已登记事件可在同一年表连续查阅。出生事件关联了亲代，只说明亲代在该事件中被登记，不把它们的其他经历归入幼崽档案。

鱼群仍使用 `shoal:水域键`，不是一条鱼的终身身份。迁移事件可以同时属于两个水域；旧事件没有鱼种时不从今日鱼种、库存或分种累计值回填品种，也不虚构逐次繁殖和恢复事件。

档案保留原文和当时记录的字段，不根据当前主人、栖地或健康推断过去的归属和死因。人物解释仍标为“人物自己的理解”；观察者年表不代表居民实际获知了那些事件。没有记录的出生、消失、亲缘或其他经历保持未知。

本项没有新增动物快照、连续移动轨迹、每种数量的完整分时账本或新的生态事件。旧有未标动物身份的文字事件仍可在普通年表按原文查找，不自动归入个体档案。因此“完整留存年表”指该身份已登记且保存的全部记录，不等于完整一生或完整生态史。

## 持久化与旧档

只读 HTTP 入口为 `history/page?animal=原身份`，沿用稳定事件序列游标。动物筛选可和其他筛选组合；游标绑定世界及筛选，不能跨动物混用。未使用动物筛选的既有普通历史及供水游标保持原键值兼容。

SQLite 新增按世界、动物身份和事件序列检索的索引表。旧事件只对已有数组中的明确身份做一次索引，不改写事件正文或补造事件；缺失字段、无标记正文和非数组字段不生成关联。新事件及动物索引与世界状态在同一事务提交，失败一起回滚。重复身份或重试保存不会重复索引。同一事件涉及多只动物时保存多条关联，各动物页仍只显示一次该事件。

已保存记录独立于近期观察窗口和当前动物列表。即使原动物被驯化、死亡、从当前列表移除或服务重启，仍可按原身份读取存档。纯观察查询和界面渲染不改变世界、动物状态或居民已知信息。

## 验证

仅使用隔离合成世界和临时/内存数据库，不读取正式存档、密钥或调用模型，不运行 npm：

```sh
node --import tsx --test tests/animal-history.test.ts tests/history-reader.test.ts tests/history-pages.test.ts
node --import tsx --test tests/*.test.ts
node node_modules/typescript/bin/tsc --noEmit
node node_modules/typescript/bin/tsc -p tsconfig.server.json
node node_modules/vite/bin/vite.js build
```

新增回归覆盖精确身份与组合筛选、同刻稳定分页、游标范围、旧档索引与原文不改写、事务回滚、真实自主菜单到驯鸭再到死亡的跨窗口重启查询、缺失当前对象、鱼群水域边界、HTML 转义、人物理解标签、快速切换、筛选、失败重试和关闭后的刷新停用。
