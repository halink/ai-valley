# 有限本地经营迁址

[生计设计](../design/economy.md) · [路线图](roadmap.md)

## 已接通的范围

这是已有商铺在镇内的有限迁址，不是房屋搬迁、自动物流或租约转让。经营者在原址提出已知的新址，提议有效七日。新址必须是本人有经营权的完好非住宅工坊或店面，不能挤占住户、现有经营和库存、另一份迁址、待签租约或施工与改版承诺。

1. **先处理原址承诺。** 提议后停止新增旧址库存、挂牌和收购单，以及新的招聘承诺。已有交易仍在原址按原约成交、到期或由经营者撤回；原招聘和待接受工资预留须先结清。未完原料批次须先完成或按原聘约结算取回，不能随登记传送。
2. **员工分别知情同意。** 每位员工先亲自到旧址阅读本人的具体提议，才获知新址；再去新址核验并独立接受。原岗位、工资、每日时段和结束日完全不变，同时明确搬运停工期间未工作不计薪、期限不延长。阅读不等于接受；员工可以拒绝，也可在登记前撤回同意。原约失效或变更后，旧同意不能用于另一份聘约。
3. **暂停与实物搬运。** 经营者在原址核对全部仍有效的聘约和答复后开始搬运阶段；正在赶路或履行的旧址工作不能被跳过。经营者须另选原址领取库存、实际携带和行走。货物仍在真实库存或携带者身上，食品保留原批次到期时间，不因迁址重新保鲜。
4. **到新址复核登记。** 原址库存必须为空，经营者须实际到达新址。重新核验产权、租约、工位、剩余期限、日程与通勤冲突，以及每份仍有效聘约的一致性和独立同意。成功只改变商铺和这些聘约的场所，保留原合同标识、工资账户、累计出勤、已挣工资和原结束日。随身货物仍须另行在新址入库。

不转让产权，不移动或续签原租约，不转移公共补贴，也不退回已挣工资。新址所需租约必须另外成立。原址租金、押金、工资与遗产继续依各自规则结算。

## 中断、旧档与重放

取消、到期、经营者失去办理能力或原址权利失效，不会替居民搬货、补货或把已领走货物送回原址。尚在原址的库存保持原处，已领取的货物留实际携带者身上，仍受正常耗用与腐败规则影响。员工撤回同意后退回准备阶段；已搬出的实物也不会回滚。新址条件变化在接受、开始和完成时重验，不能把陈旧菜单选择直接登记成功。

迁址记录位于 `economy.relocations`；旧档没有该字段时按空记录读取，不补造迁址、签名或出勤。行动收据用于防止同一决定重放或换条款。重载不应重复改址、复制库存或重新预存工资。超过240条迁址记录时，工作快照保留全部未完安排与最近120条；旧终态细节可查持久事件，永久行动收据不随列表裁剪删除。

```sh

node --import tsx --test tests/business-relocation.test.ts
```
