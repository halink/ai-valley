# 离线合成选择演示

`npm run build && node build/server/offline-choice-demo-main.js --json` 执行一次演示并输出只读结果；或用 `--port 3418` 在本机提供 `GET /ai-town/api/seasonal-model/demo`。可选 `--web-root output/godot-web` 让独立演示资源与 API 同源。没有开启真实模型，不读取模型设置、密钥、现有存档，不接受 HTTP 提交选择。普通规则及原离线入口行为不变，演示不向谷灵或其他角色广播。

演示用自生成的预设小山谷，不是当前游戏存档。林禾先借真实厨房工位及已有引擎劳动，实际消耗6木6石成功安装罐藏工位。此后同一个起点复制为三个独立临时 SQLite，真实菜单、请求与预算持久化、编号解析、引擎动作和重新读取的终态都复用已有路径。只展示真实菜单两项，不显示原请求数据或私有账。预设起点与不同分支对比明确标识；浏览器仅切换已结算结果。

| 从同一起点 | 游戏分钟 | 实际净库存变化 |
|---|---:|---|
| 做春秋芜菁餐 | 600→620 | −2根、−1水、+1餐 |
| 罐藏鲜果 | 600→660 | −2果、−1水、−1木、+2罐，56日实际到期批次 |
| 越界编号 999 | 600→600 | 拒绝、不生成行动、不消耗物资 |

播种只在本人现场可见空田才进入菜单；罐藏要求本人此刻站在已安装工位，不能把两个互斥现场伪造为同一菜单。当前演示的做饭与罐藏可以被同一个本人、同一起点合法选择。两条成功分支都在接受后关闭再重开推进：仅接受还没物资变化，直到引擎真实完成才发布结果。最后重开确认原终态与原请求不变，临时档均清理。

JSON 固定为 v1：合成标识及真实调用数 0、合成起点与共同摘要、两条真实菜单标签与配方预算、三条实际分支的净库存及类型化证据。开放读取前已经完成所有分支；GET 不启动动作、不推进世界，POST 不受理。此演示不代表实际模型效果、全线世界运行、模型自动升级或冬储充足。

定向验证：`node scripts/acceptance-offline-choice-demo.mjs`，测试会将全局 fetch 替换为直接拒绝，HTTP 检查仅使用 Node loopback。

## Godot 独立只读页

启动原客户端时附加 `-- --offline-choice-demo`，或同源 Web 导出使用 `?offlineChoiceDemo=1`。此显式模式只创建演示页，不启动普通世界轮询或世界输入处理。桌面填写独立服务地址，Web 自动使用当前源；唯一请求是上述 GET，每10秒复查。断线或契约不符清空数据并禁用分支切换。正常客户端入口不改变。

页面常驻标识“离线合成选择，不是真实大模型”“预设独立演示，不是当前游戏”，说明厨房安装已消耗6木6石及劳动，比较的是安装后共同起点。选择框仅切换已结算的做饭、罐藏和非法编号拒绝结果，显示共同摘要、配方工时、前后库存与净变化；没有提交行动。新客户端不写世界或迁移存档。

## 可提测交接（2026-11-19）

功能源码基线 `28bf5da`。开发侧完成后端定向验证、TypeScript 构建、独立源码检查、Godot 脚本导入及独立入口快速启动；导入退出时存在编辑器设置路径保存警告，但未报脚本解析错误。尚未进行本版本实际浏览器画面检查或系统性验收；不以可提测等同 QA 通过。不调用真实模型。

本机准备 Node 22.13+、Godot 4.6.3 stable 与对应 Web 导出模板，安装项目依赖后：

```sh
npm run build
npm run build:godot:web
node build/server/offline-choice-demo-main.js --port 3418 --web-root output/godot-web
```

打开 `http://127.0.0.1:3418/?offlineChoiceDemo=1`。服务启动时会先完成三个有界分支，出现地址提示后再访问；页面只读取结算结果。原生开发冒烟可用 `godot --path godot-client -- --offline-choice-demo`，填入同一服务地址后读取。

交给测试组的建议步骤与预期（不是已执行记录）：

1. 进入独立页，确认常驻合成/非当前游戏标识及工位安装成本 6 木、6 石，无普通世界连接。
2. 切换做饭：时间 600→620，根菜−2、水−1、餐食+1。
3. 切换罐藏：同一起点 600→660，果−2、水−1、木−1、罐藏+2，到期分钟 81300。
4. 切换非法编号：时间仍600，拒绝且库存全不变。切换选择不执行任何世界动作。
5. 停止独立服务，等待连接检查；旧结果应清空、切换禁用。重启读取后恢复固定回放，不读写用户存档。
6. 单独检查浏览器排版、中文、滚动、断线恢复与不同视口；详细/长时验证由测试组安排。
