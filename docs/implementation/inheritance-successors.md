# 未领取遗产份额的法定接续

本项修复已拆份遗产中，继承人尚未登记领取便死亡、且没有后代时，原份额长期挂在死者名下的问题。仅改变未领取支路的接续查找；不重新分配整份遗产，不追回已领财物，也不自动办理继承。

## 复现与修复

合成世界中，父母留下20枚钱款和6块田，两名子女分得各10钱、3田。成年子女先领取，未成年子女随后死亡且无后代。旧代码只对普通未领取份额查找后代，余下10钱、3田无法接续；相反，未成年子女在第一次拆份前死亡时，既有算法允许成年子女继承全部。

`advanceProduction` 现在让普通未领取份额与已有经营补充份额一样调用 `estateHeirs`。本例通过死亡父母的后代找到成年手足，为余下半份生成新的支路。成年人的原领取记录、已领10钱及3田不变；其正常编号菜单出现新的继承动作，亲自完成20分钟登记后才得到剩余钱款和产权。封存实物仍须另选实际取货。

## 沿用的顺位和保护

- 依次查找死者的子女、死亡时配偶、父母、手足。每层沿用原 `successors`：死亡候选人的后代可以递归代位，收养关系同样保留，身份去重，结果排序。不为本次缺陷重新定义初次法定继承。
- 这不是“在世父母绝对排除手足”的新规则。例如一位父母在世、另一位已死，原算法会同时考虑在世父母和已死父母的后代。本项明确保留该既有语义。
- 分配仅使用待领支路自己的钱款、物品登记、田地、建筑、私人地块、产业资产及债权列表。支路编号继续向下追加，已有领取记录保持不变。多人继承只拆这一个支路，不能把先前领走的另一半拉回重新均分。
- 配偶依据使用已保存的死亡时名单，不因丧偶者另行结婚改变。连续死亡继续对尚未领取的支路接续；已经领过的部分仍通过该领取人的独立遗产处理。
- 物资沿用原址分包和食品转移事务，不移动实物、不刷新食品批次或时效。封存工具仅改变产权，位置不变。债权转移不改变债务人的身份，不把债务强加给继承人。
- 原遗产待清算的债务、共同财物、租约、工资等保护和未出生份额限制仍照常生效。成年、能力、本人死亡证据、份额资格、已知登记处及实际到场在动作完成时重验。没有新增代理、监护或照护权。
- 后代循环会终止。找不到合法继承人、死者身份缺失或其遗产记录缺失时，原份额和实物继续保全，不向公共账户或管理员转移，也不凭残缺资料补造死亡时关系。

## 保存、重复和验证

不新增持久字段，不回填旧领取记录。已有旧世界在正常推进时对尚未领取的份额使用同一规则；本次只使用合成世界和内存SQLite验证，不读取或迁移真实存档。原址份额、食品批次、领取状态和钱款收据随正常存档保存，重复推进或重载不会再拆在世人的份额，重复完成已领取动作不能再次付款。
