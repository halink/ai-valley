# 谷灵 G0：公共生活事实投影基础

谷灵只有在持久存档记录了实际行为的专用收据、且当前有该来源的明确公开许可时，才能读取白名单字段。新增独立版本化读适配层，不接原始事件、居民 ID、发言内容、计划或关系；观察者可见、同处现场、目击或被列为参与人都不是公开许可。每次只解析最多 24 个确定来源；其中一个缺失、失效或版本不对时拒绝整个包。

到场、真正发言且收到、本人实际吃掉食物是分开的事实类型，互不推断。提议、同意、排期均不构成这些事实，不进入这一投影。来源引用基于持久随机收据身份，同一事实的更正版本保持来源锚点但改变对应授权绑定。已发送字段的公开版本变化也会使旧包失效；并不承诺撤回供应商已收数据。

**仍未接入运行时。** 后续须把实际行为终态、独立收据和显式许可流程接入持久事实权威，保证每份授权按最新版本从同一个一致性读取提供；不得从旧存档回推许可，也不得从已有事件正文生成此包。接入年鉴后发送前、发布前和所有读取面都须重验。本切片未发送真实模型请求，不构成提测。

## 私有 SQLite 权威

独立可选表在世界写入锁下使用。物理只读连接进行预检与公开读取；未知格式、异常状态和运行中回退会隔离该模块，不改世界基础表。只有已核对的同世界、非未来终态收据可以追加；新来源默认不公开。逐来源审批锚定收据版本和前一授权版本。撤回和重新授权递增授权版本，更正立即使原公开授权失效。读取时再次确认当前已提交收据，单个来源失效则整包不出。有限日志满时拒绝增长，但给每个活跃授权保留撤回空间；不覆盖历史。

实际引擎终态到收据的适配器、显式审批管理入口及年鉴调用仍未接入。不得直接用先前存档、公开观察面板或角色名单替代该权威；完整数据库备份恢复仍需单独设计版本屏障。

## 实际个体进食接线

持久 MVP 会话新增内部、默认关闭的提交后观察钩子。显式接入时，仅用引擎刚完成的 `eat(meal)` 实际扣减证据，并要求恰好匹配本次新写入的类型化进食事件。拒绝未提交草稿、历史事件、做饭、安排、变更量猜测和事件文本。私有保管表以真实事件及准确行动计划固定同一随机收据身份；读取重验已提交的世界版本及类型化事件。原始居民、事件和计划身份不出投影。

该钩子未在运行入口预设启用。私有保管、发布权限及世界写入各自有事务；若世界已成功而进食保管未成功，资料保持缺失，不从历史事项补录或伪造。真实世界未授权公开，不接模型，不构成交接。

## 约见到场与交谈来源审查

本检查点**没有**启用这两类来源。已核实的上游能力与缺口：

| 上游 | 已有真实证据 | 缺少的持久绑定 |
| --- | --- | --- |
| 正式世界 `src/world/social-appointments.ts` 的 `completeSocialAppointment` 与 `advanceSocialAppointments` | 本人实际完成赴约工作的访问时间 `visits[].arrivedAt`；独立的 `metAt` 仅为双方在原窗口内共同到场。MVP 验证世界不能执行 `socialAppointment`。 | 实际成功的 `attend` 必须在提交时产生独立终态收据，锚定世界、约见和原同意版本、本人实际计划/执行、到场时刻和精确终态事件 ID。现在的 `eventIds` 混合提议、接受、赴约、旁白和失败等记录，访问没有对应事件/行动 ID。共同到场也要独立事实锚点，不能由提议、接受、个人单独到场或通用移动轨迹代替。 |
| MVP 普通 `talk`（`src/world/engine.ts`）和通用 `emitEvent`（`src/world/events.ts`） | 完成时确有目标，对话位置及发言条件通过，引擎产生对话事件。当前通用事件可写附近可见居民记忆。 | 实际完成发言/传达时写入独立、持久且同一执行绑定的发送及收听证明，区分预定目标和实际接收者，并记录交付时刻、完成的行动与事件身份。当前 `actors`、`witnesses`、`conversationId`、语气/正文皆不能证明指定对象实际接收；通用记忆会裁剪，且给事件参与人标为 `self`，不是独立接收收据。不得解析正文、把同房等同听见或把双方在场当成已交谈。 |
| 正式世界特定 `shareFoodSource` | 已有发送端一次性收据和实际收听者的 `heard` 记录，仅覆盖特定地址的真实面交。 | 不是 MVP 普通交谈或普遍公开授权；私人地址和人物内容不会借这个能力进入谷灵。将来若单列此类事实，仍须独立公开审批、专用白名单和实际已提交的发送/接收核验。 |

上游收据应由引擎完成相应动作时写入耐久权威，并与世界提交共同存活；裁剪 UI 或居民工作区记录不能挪走确证。接入后仍然默认私有，单来源、精确版本另行授权。在这些依赖存在之前，归档和年鉴对该类型只报缺失，不从旧存档、排期、观察者全景、叙述文本或接近猜测去补。
