# 谷灵：G1 果落候选只读解析

这是开发进度，不是开放候选、真实落果或提测。模块 `src/server/valley-spirit-shadow-offers.ts` 把已提交的小山谷存档、公开天气档案和地面承载诊断接到隔离预检。没有提供给模型、公网、观察者 UI 或常驻运行入口。

调用方须显式提供冻结清单：世界、菜单版本、实际雨事件编号、允许读取的确切天气来源、有效期、指明的果源和相邻地块、承载量与影子策略。没有清单或现行公开授权就不可用；不从当前天气、预报或公开年鉴补造雨事件，不扫描扩大清单，不自动更换落点。候选使用已登记、真实有成熟鲜果的公共果源和真实通行/产权/承载约束。天气档案仅证明可用的公开背景，不代替权威雨事实。

候选固定到这些字段、当前来源及权限版本、确切参数和承载策略。无关世界版本推进不取消候选；每次隔离预检仍重读同一已提交版本下的地面实体、天气授权、实际雨事件、果源、目标和收据/配额事实。缺失事实不默认可用。当前地面实体写入、发现和拾取均未接入，实际诊断返回未启用；所以只能看到标为“能力未就绪”的物理候选，不能通过影子预检或执行。

未来接入须由持久规则运行服务提供同一已提交 head 的只读地面/收据证据和冻结清单，不允许从公开请求或模型文本获得写权限。当前代码没有保存清单或在重启后自动恢复候选读取，也没有配置生产额度。预检只读和记录候选状态是两件事，任何预检结果不代表授权或世界事实。

本地定向单元测试验证：真实天气和果源/落点解析、无写入、能力缺失拒绝、缺失雨/承载/收据不猜、撤权或模拟世界不继续、源被采空及未经清单批准的目标不能通过。未运行长测、未调用真实模型；不单独提测。
