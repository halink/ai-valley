# 谷灵：G1 果落候选只读解析

这是开发进度，不是开放候选、真实落果或提测。模块 `src/server/valley-spirit-shadow-offers.ts` 把已提交的小山谷存档、公开天气档案和地面承载诊断接到隔离预检。没有提供给模型、公网、观察者 UI 或常驻运行入口。

调用方须显式提供冻结清单：世界、菜单版本、实际雨事件编号、允许读取的确切天气来源、有效期、指明的果源和相邻地块、承载量与影子策略。没有清单或现行公开授权就不可用；不从当前天气、预报或公开年鉴补造雨事件，不扫描扩大清单，不自动更换落点。候选使用已登记、真实有成熟鲜果的公共果源和真实通行/产权/承载约束。天气档案仅证明可用的公开背景，不代替权威雨事实。

候选固定到这些字段、当前来源及权限版本、确切参数和承载策略。无关世界版本推进不取消候选；每次隔离预检仍重读同一已提交版本下的地面实体、天气授权、实际雨事件、果源、目标和收据/配额事实。缺失事实不默认可用。当前地面实体写入、发现和拾取均未接入，实际诊断返回未启用；所以只能看到标为“能力未就绪”的物理候选，不能通过影子预检或执行。

未来接入须由持久规则运行服务提供同一已提交 head 的只读地面/收据证据和冻结清单，不允许从公开请求或模型文本获得写权限。当前代码没有保存清单或在重启后自动恢复候选读取，也没有配置生产额度。预检只读和记录候选状态是两件事，任何预检结果不代表授权或世界事实。

本地定向单元测试验证：真实天气和果源/落点解析、无写入、能力缺失拒绝、缺失雨/承载/收据不猜、撤权或模拟世界不继续、源被采空及未经清单批准的目标不能通过。未运行长测、未调用真实模型；不单独提测。

### 普通 Godot 规则存档：同一存档头的地理提议复核

现有默认关闭的整点地理队列可由持久规则宿主做一次只读私有复核。只有已保存的最近提议与当前运行世界、实际 SQLite 存档头（身份、版本、游戏分钟）精确相同，且原生已关闭降雨、当前授权版本下确实存档的雨点、同一公共果丛实例与同一落点重算吻合时，才返回编号 1 的地理候选。提议输入指纹必须与原记录完全一致；不是新存档头就不沿用。复核不创建候选、不补录旧时刻、不扩大授权，旧行仅留档，改动、撤回、重新授权或无法复核时不可读。

状态仍是 `geography_only / missing_ground_capabilities`，不是完整落果预检、通过的效果申请或排期。普通规则游戏不伪装封存夹具的携带、原生库存年龄、收据和放置能力；无模型、公开读写入口或实际落果效果。临时 SQLite 的本地短测覆盖原生整点、同头重开、过期头、缺雨点、授权变更和队列修改。

### 普通规则存档：原生果实批次与地理提议的同头预检

另有默认关闭的内部只读预检。须独立开启既有地理提议队列和同一果丛的原生批次登记；不接受夹具代替。通过同一 SQLite 读取快照核对当前存档头、授权版本与仍有效的真实批次，并复验侧车提议、授权下实际归档的雨点、果丛实例和原落点。任一来源、时间、权限或批次不匹配就不可用，不使用别的果丛或上一次复核。

即使两份证据确实成立，现有普通入口也没有兼容的保鲜地面数量、放置、居民发现和拾取能力。预检明确回报阻断，不假算“果源减一、地面加一”来暗示守恒已验证，不产生合格名额、建议处置、审批、排期或落果，也不新增持久写入、HTTP、模型或客户端接口。
