# 双人日常约见

2026-11-07。把设计中“选地点、约时、实际行路和等候”具体化为一个有限的新能力，不是沿用已有详细约见规则的补丁。它独立于现场多人讨论，也不是节庆、诊疗、雇佣或照护的替代入口。

## 首版规则

- 两名年龄已知、满18岁、具备决定与表达能力的在地成年人。提议与接受须双方能真实看见、合法近身接触；沉默不算同意。拒绝或撤回可以由本人单独决定，只有真正当面的人才会收到这一消息。
- 地点限本人已知的公共共屋（`lodge`）门前。提议时核验当前公共性质、完好及可达条件，冻结建筑身份、地点名称、精确门前坐标和双方当时姓名/出生身份。首版不是完整的历史公共地址系统；新提议候选仍沿用当前公共场所与路线核验。
- 本人填写30–2880分钟后开始、15–120分钟的有限窗口。时间从真实完成提议时计算，之后不漂移、不延长。接受须在开始前完成；原条件改变需要重新提出，不暗中改约。
- 接受仅记双方同意。各自仍须另选赴约，沿真实室内出口和室外路径走到原位置，再完成1分钟到场核验。对方离开、远方撤回、患病或死亡不会让路径追踪其新位置，也不通过约见菜单传知远方原因。
- 到场后可另选1–120分钟等候，且不得超过原窗口。只累计实际执行的等候分钟；走路、预约、站在附近或等待模型都不当作已选择的等候。期间身体照常消耗，无约见专用生理保护。
- 只有双方分别选择过赴约、仍真实共同在原地点、能彼此观察并且处于原窗口内，才记录一次相遇。早到可由本人继续等待；先后到场但没有重叠不算相遇。相遇不自动结束已选等待、不生成对话、不增加关系分值，也不产生合作结果。
- 本人可立即撤回自己的约见，包括途中与等候中。只清除本人这份约见相关行动，不清除本人的进食、睡眠、工作等无关安排，也不改动对方的行动。远处撤回只改本人所知；另一方仍能按原约赴约并看到“此刻未在此见到”，不能得知缺席原因。
- 固定窗口到期只结束尚未履行的约见事实。本人可以凭自己已知的期限知道窗口已过；观察者的终态结算不向居民广播。失败事件和人物活动状态另记本人这次实际行路或等候未成。

## 知识、菜单与观察

`socialAppointments.records` 保留原条款、分别获知状态、本人访问和真实等候分钟。提议、接受的现场证据与回执随内存/SQLite持久化一起保存。旧档缺新字段只初始化为空，不从旧聊天补造约见。直接完成、旧回执换计划ID、伪造非有限/早于行动起点的工时都不能替代实际办理。

本人摘要不放进易裁剪的家庭说明，也不依赖80条短记忆；单独进入三种模型的最终提示，最多展开六项，注明其余数量。保留至原窗口后一天，依据本人已知截止而非远方内部取消时点。对方旧姓名使用当面快照；未知远方状态保持未知。

每次最终菜单至多恢复一个完整约见组、最多两项：接受/拒绝，赴约/撤回，等候/撤回，或单项提议/撤回。本人正在执行的约见优先，其余记录按30分钟轮转；候选不足不补造。新提议对象也在实际可接触成年人中轮转。本人尚有未结约见时不再提新约，但可收到其他人的独立提议。回复和控制始终成组展示，途中、乘船、护送与能力限制照常生效。

这两项在既有56项议程及水源、烹饪、社交语气、理解、浆果线索之后补齐，不挤占已有入口。普通最终上限由80变为82，原照护和赠粮实时停止入口仍按既有规则另外恢复。可见不等于被选择，也不保证本人及时赴约。

人物档案显示最近六项约见的对象、地点、原窗口、世界记录、本人最后获知、实际赴约/离场、本人等候分钟及共同到场时刻；明确分开观察者事实与人物知识。行路和自主等待沿用活动状态，年表记录提议、答复、到场、等候、相遇、退出、失败及原窗口结束。界面只读，不提供玩家替居民接受或赴约的按钮。
