# 青少年自主赠送本人食品

## 有限权限

[人物设计](../design/people.md)中的青少年递送本人食品，在既有 [personalFoodGifts](personal-food-gifts.md) 上接通，不另建照护或交易流程。

- 送出者满13岁；接收者满6岁。年龄必须可核实，两人须在地、在世、有完整决定与表达能力及正健康值，实际相遇时能清醒感知，接收者按既有本人进食能力门槛接收。年龄未知、未来出生日期及非有限日期不授予权限。
- 6–12岁只有本人接受和拒绝入口，不能提出、送出或替他人取消。13–17岁可赠送自己实际随身持有的可直接进食物品。涉未成年每份提议只限1份，成年人之间仍可1–3份；不授予经营、交换、公粮捐赠、代理、代喂、监护、住宅进入或受保护财产取用权。
- 接收者不需要事先有食物；收货也不喂食、不降低饥饿、不加健康。真实最终编号菜单分别选择提出、接收者接受、送出者送达，收方随后另选普通进食。
- 三份未结束的本人送出提议上限、120分钟固定有效期、不预留库存、实际路径、室内权限、原批次转移及末时刻即时撤回均沿用旧流程。没有自动救济或自动同意。

## 版本与生日

新菜单的提出动作携带 `ageTerms`，记录 `version:2`、选择时点、双方原出生时间和固定数量上限，并使用 `personal-food-gift:v2:` 回执。提交与办理再次核对，不允许在生日后删除条款冒充旧成年动作。原出生时间改变时需要重新选择；当前失能、死亡、离谷和实际不在场均不能继续交付。

`personal-food-gift/offer@2` 与 `accept@2` 以独立年龄范围权限记录两次本人的选择，条款连同原物品、数量、期限及接受地点绑定进原始事件。改写或删除已存条款、数量、地点或证据将拒绝履行，不补造同意。

生日不重签旧约。17岁时选择或提出的一份食品，跨18岁后仍只是一份；只有重新从当前菜单选择才能提出成人之间的1–3份新约。13岁和6岁边界按实际出生时间判断，不提前一个四分之一分钟授予权限。

缺少 `ageTerms` 的旧 `@1` 记录继续使用成人权限与原回执，不自动迁移成青少年授权；在原提出时和当前均须有成年资格。真正旧成人提议、独立接受、SQLite重载和交付仍可继续。无该集合的旧档仅初始化空集合。

当前他人的生日、出生资料损坏、失能或撤回，不远程注入送出者菜单、记忆或路线。途中只核对本人和原条款，到场才核对收方当前事实；失败不透露远处原因与位置。
