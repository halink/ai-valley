# 有限营业场所与工位租约

本项交付[批次 3](roadmap.md#批次-3-本地产业与公共供给)的一部分。私人非住宅工坊、店面可以由产权人与承租人分别同意后用于经营。[空屋单人有限住宅住宿](residential-leases.md)已另行接通；有人居住的住宅租赁、多租户共享、损坏索赔、续租改约和第 3 批整体验收仍未完成；有限本地迁址见[独立实现](business-relocation.md)。[生计设计](../design/economy.md)

## 签约与权限

- 产权人亲自在原址向一位已认识的成年人提出具体报价。承租人须亲自到场查看并另选接受或拒绝，不能由产权人代签。报价保留两日，未接受时可以撤回，不产生使用权或扣款。
- 每处建筑同时只有一份待答复或有效租约。只接通完好、无住户的私人 `workshop` 或 `store`，不出租住宅、公共建筑或孩子受保护的财产。原址已有营业、余货、未完加工、招聘或聘约、课堂、活动、建设或改版时，先由原当事人处理。
- 租约列明建筑身份、产权人、承租人、经营用途、2–28 日期限、日租、押金及一处工位。桌台、厨房或已经实际安装的加工设备均可选择，木工作台与桌台共用同一实际位置，桌台时段阻止他人占用该位置，但只租桌台不等于获准使用未列明的木工设备。日窗口为06:00–23:00之间的30–720分钟，不能跨午夜。
- 签约不更改产权、住户、床位、物资归属或他人的工作约定。承租人可以另选开店、投入自有资金和货物、加工、修工具或在明确租用的厨房做饭。租用一个工位不会获得其他工位、设备拆装或居住权限。普通交谈和本人独立的遗产/工具领取权不被工作窗口取代。
- 产权人保留其他合法使用权，但不能在已出租时段占用指定工位，也不能在有效租约中擅自拆装设备、改建、改用途或另排课堂及活动。既有租约不默认授权转租。

## 钱款与到期

签约一次预存全部有限租金及押金，最高为28×100+1000钱。使用现有独立预留账户和持久收据，不扣到负数，也不创建贷款或无限续费。

租金按已经经过的租期分钟累计，取整支付，最多为约定总租金；不是按是否到工位劳动计费。押金全额保留，不自动认定损坏或扣赔。到期、承租人自行交还、承租人死亡/迁出、建筑损坏或产权改变时，未挣租金及全部押金退回承租人本人或其遗产。产权人不能撤回已签订的租约。产权人死亡但产权尚未移交时，原有限使用约定继续，已挣租金进入其遗产，未结算权益先受保护，不能提前重复分配。

期限的结束和钱款结算分开记录。即使遗产账户尚待建立，也记住实际停止时间，不能等待账户期间继续多收租。旧世界只得到空的租约列表，不补钱、不给使用权。重复执行及存档重载依赖原收据，不能再次扣租或退款。

## 工位、雇佣与实物

工位窗口在开始、室内到位和每段实际劳动时核验。赶路和室内移动仍消耗真实时间，站在门口不会产物或计薪。工作可以只完成一个实际批次的部分时长，原料和进度留在原工位；跨过窗口不能继续加工。窗口结束的最后一个实际分钟仍按原区间核验，不把完成后的未来时段误算成已用工时。

租用经营者可发布与原工位及剩余期限相容的招聘。申请、雇主选择、预留工资和劳动者最后接受继续分别办理。发布、选人和接受时都核对当前权利，不能临近到期签出超期班次。实际工作按雇主所持工位权及工人到场情况结算。

租期失效后停止新增营业及未来工作。已挣工资不追回，未挣工资退回原出资方。挂牌余货、商铺库存和雇佣的未完原料保留在原商铺，不因自动停业瞬移到远处的经营者背包。经营者须另选到原址领取。本人独立加工的未完原料须到原室内工位领取，取回原料即结束该批次、放弃已投入的加工进度。食品批次跟随现有实物转移规则，不刷新保质期。逝者物资按原址封存进入遗产。

## 正常入口与观察

`premises.offer / accept / decline / withdraw / surrender / collect` 接入居民的正常最终菜单，报价数量有界轮换，接受与拒绝均保留。可填写租期、日租、押金和窗口，不可改写原菜单指定的当事人、建筑或工位。远离原址时，只保留原已签条款和回访方向，不把远处场所现况自动告诉当事人。

“场所 → 长期雇佣”附只读租约记录，显示双方、建筑、工位、窗口、期限、实际预存、已付租金、退款和余款；没有替居民出租、接受、派工或收货的按钮。年表记录提出、接受、拒绝、交还及结算。

## 验证与边界

定向测试（历史路径：`../../tests/premises.test.ts`，已移除）覆盖双边签约与拒绝、原址到达、身份字段锁定、金额边界、资金守恒、未授权产权/住户变更、到期与提前交还、工位和雇佣时间、已挣工资、原址库存和未完原料、正常菜单、SQLite收据重载、死亡遗产、旧档空初始化、只读输出及文本转义。独立 review 补充了工作完成边界、厨房最后一分钟和独立室内交谈的回归。

这不是完整租赁市场。尚不支持租前安装授权、住宅店铺的住户多方同意、多租户分空间/时段协商、续约、租约转让或损坏责任。搬店搬货及员工重新确认新地址已有[有限本地迁址](business-relocation.md)，不转让或延长原租约。没有进行真实模型长期运行或修改已有运行存档。
