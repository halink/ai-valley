# 合成牧场照护与原奶批次离线闭环

本项仅新增测试及文档，不改变生产规则、菜单、证据 schema 或默认运行时入口。它把[牧场扩建](pasture-expansion.md)、[围栏自然磨损](pasture-fences.md)及[畜产品自然生成](natural-food-growth-evidence.md)连接为一个可重复的离线回归。

## 场景与实际执行

`tests/helpers/pasture-food-chain.ts` 创建独立合成世界：三位成年居民、公开公告板、本人畜舍、可达泉水、空草地，以及明确提供的木石、饲料和清水。它不是正式九人开局，也不是从真实存档提取的个体。

1. 从正常最终编号菜单解析勘察、公示、两名居民分别投赞成票和登记；至少一整日公示由真实引擎逐分钟推进，没有直接写入已批准或已登记状态。投票是测试脚本的明确选择，不代表模型自主意见。到已知地点的导航是显式引擎 `move`，没有瞬移。
2. 编号选择安排牧场，逐阶段完成 30/60/45 分钟实际劳动，扣除 16 木材和 4 石材。断言围栏从 100 开始、牧草从零开始、水槽空且累计送水/饮用均为零，没有顺带生成动物或扩充物资。
3. 添加两个显式合成的 50 日龄山羊个体。母羊从畜舍经正常编号护送进入已建牧场；另一只公羊留作新入场反例。母羊开局饥饿 80、口渴 90、产物为零，产奶进度人为放在 `DAY - 120`，不是模拟完整产奶周期。
4. 将已经完工的围栏耐久显式设为临界值 `0.001`，记录当前时刻后推进普通引擎一 tick，由实际磨损降至零。断言新放牧入口被拒，而既有母羊身份和牧场归属保留，不发生自动维修或搬迁。
5. 从实际最终编号菜单分别选择一次喂食、一次直接供水、一次填水槽。本人饲料减少 1、清水合计减少 2；直接供水不计入槽水流入。只有实际送入水槽的 1 份水可以被动物沿现有规则饮用，核对 `delivered = consumed + water`，并确认实际饮用大于零。
6. 由后续真实引擎推进越过产奶阈值，取得唯一 `animal_product/source_added` 收据及动物库存原奶批次。编号收取后，个人持有同一份原批次，原容器清空；收取计数增加但没有第二条生成收据。过期收取入口、同一分钟自然生成重入及短时间继续推进均不重复产出。

所有业务动作都通过 `decisionChoices(decisionContext(...)) → parseChoice → submitPlan → stepWorldWithFoodEvidence`，没有把候选插入最终菜单，也没有直接调用完工钩子替代劳动。测试保留选项编号、动作、选择和完工时点，以及独立只读食物流收据。普通议程轮转如需等待，也由实际编号 `wait` 推进。

## 持久化及反例

- 主链在已入场、围栏损坏、照护完成、奶已生成和奶已收取五个位置，写入由测试独占创建的临时 SQLite 文件，关闭数据库、重新打开并深比较完整 JSON 世界快照。每次重载均不接触真实存档。
- 未选择照护的对照组只观察菜单并推进 120 分钟，所有居民仍无计划/活动，本人物资不扣、槽水不增加、围栏不修护、奶不生成，也没有自动收取。既有动物的自然移动、放牧和身体需求仍按原规则运行；“无自动照护”指居民没有被代选喂食、送水、修护或收取，不是否定动物本身会吃草或喝已送达的槽水。
- [独立审查](../reviews/pasture-food-chain.md)另覆盖饥饿与口渴各自阻断临界产出、空物资不能免费照护、失权后处分/修护拒绝、编号喂食执行中 SQLite 重载后仅扣一次饲料，以及健康围栏时取得的旧编号入场选择在损坏后被引擎实际拒绝。测试与实现分别审查，不增加生产分支。

## 离线重现

使用仓库已有依赖，无需 npm、联网、模型、浏览器或真实存档：

```sh
node --import ./node_modules/tsx/dist/loader.mjs --test tests/pasture-food-chain*.test.ts
node node_modules/typescript/bin/tsc --noEmit
node --import ./node_modules/tsx/dist/loader.mjs --test tests/*.test.ts
```

服务端及客户端构建也可以只写临时目录，并显式关闭 Vite 环境文件读取：

```sh
node node_modules/typescript/bin/tsc -p tsconfig.server.json --outDir /tmp/pasture-food-server-build
node --input-type=module -e "import {build} from 'vite'; await build({configFile:false,envFile:false,base:'/ai-town/',build:{outDir:'/tmp/pasture-food-client-build',emptyOutDir:true}});"
```
