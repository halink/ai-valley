# 有限协助饮水与未成年人赠桶

本项继续补足[安全水供给第一阶段](safe-water-supply.md)，不启用口渴、脱水、自动照护或饮水健康恢复。只接通两种有明确当事人、期限、材料和现场条件的行动，不代表失能照护与持续供水已经全面验收。

## 成年人本人授权的协助饮水

1. 受助成年人在清醒、具有完整决定与表达能力时，亲自在有权使用的现场向一名具体、具有基础照护技能的成年人授权。授权不由照护者、监护名单、旧记录或系统代填。
2. 授权固定持续24小时，最多完成2次协助饮水，不自动续期。照护者没有强制履约义务，也不会因此获得医疗、财产、进屋或监护权限。
3. 照护者另行自主选择实际协助，每次耗时5游戏分钟，扣除本人随身桶中1份安全水。受助人须仍在世、保有完整决定与表达能力、未睡眠、没有明确拒绝，且健康大于20、不在任何现存伤病的重症或危急范围；每例伤病沿用其绑定的阈值，不硬套同一个版本。
4. 该有限路径只针对已经出现中度伤病行动受限、但仍能自主决定的成年人。完全健康且能自主决定者走自饮。丧失完整决定或表达能力、重症、危急、昏睡或运输中的人不被强行喂水，仍须走原有医疗与照护途径。
5. 双方必须处于同一实际可及地点。室内要有各自真实房间坐标和使用权，短路径不能穿墙、穿过遗体等阻挡；不能把户外门口与室内床边当成同一处。户外两格以内也必须有真实可走路径。
6. 原授权受助人或指定照护者可撤回自己的这项安排，无需追到另一人身边；撤回不自动给远处的人发送消息。撤回通过正常菜单中的单独停止决定执行，计划被有效接受时立即生效，不再安排5分钟等待；另一人已经开始但尚未完成的供水会停止且不扣水。任何当前明确拒绝也在每个劳动步及完成前阻止供水。**现有引擎不会为缺失完整决定能力者调度新决定，因此本轮不向这类人继续独立供水，也不把手动修改拒绝字段当成实际自主拒绝机制。** 丧失能力时停止，恢复完整能力后仍可正式撤回。
7. 撤回、到期、次数用尽、水量不足、原水、运输、地点改变或配合条件变化都会停止未完成的行动，不扣水、不增加授权次数。已完成的真实饮水不撤销、不回补。

授权记录本身不算饮水。自饮、共屋饮用、监护人供水和这项成人协助使用同一受助人滚动24小时2份上限；多名照护者、多只桶、重启或再次授权不能突破限额。

### 与既有照护/紧急权的边界

普通 `care` 的当次餐食清水照护、长期照护合约和医疗救援继续遵守原权限。它们不会自动授予本项新的、可重复的独立饮水权限，原紧急情形也不能代替本人明确授权。

尚未启用脱水风险，本项没有“缺少同意也可以紧急灌水”的规则。当前模型没有独立吞咽能力评估，因此上述有限状态检查不能被描述成完整医疗吞咽安全判定。对无法配合或重症对象的供水仍需专门的照护设计与验收，不为完成路线图而扩大代理或紧急权。

## 向能够自主接受的未成年人赠桶

- 成年桶主可以在现场提出赠送自己实际携带的一只空桶，或其中装有安全水的桶。不能赠送公共桶、他人桶或装有原水的桶。提出时记录具体桶的身份、容量、水量、水质、赠送人及收受人。
- 收受人须为能自主决定和表达的6至17岁居民或访客。提议24小时有效，只有收受人本人另行选择接受，并与清醒成年桶主在有使用权且真实可及的地点完成5分钟交接后，原桶的 ownerId 才改变。
- 提议不移动任何水和桶。接受时再核验同一桶仍归赠送人、仍在随身携带、约定水量/水质未改变、双方资格与地点未改变，且收受人尚未携带8只桶。改变内容须先撤回旧提议，再按新内容另行提出。
- 同一桶不能同时拥有多个未结束的赠送提议。原桶主可撤回，收受人可拒绝；这些停止动作不要求仍有原物资或双方仍在同处，正常单独停止决定被接受时立即生效，阻止尚未完成的交接。它们只结束未履行提议，不能取回已经交付的桶。
- 实际交接保留原桶身份、6份容量与原水量，不新增桶、克隆水或赠送木材。装水桶的交接不算饮用，领取后仍须本人另选装水或自饮。
- 这不是一般桶交易、永久监护、住所安排或遗产继承。未满6岁或失去独立接受能力的孩子不能被代填同意。

撤回授权、撤回赠桶及拒绝赠桶是本人权限的停止操作。在仍可提交自主决定且当前空闲的情况下，船上、医疗护送中或家庭同行者也保留这些正常菜单选项；它们不停止或改变运输，不允许途中接受实物或协助饮水。

## 保存与观察

旧档只增加空的授权/赠桶记录，不从亲属、监护、旧照护提议、长期合约或紧急记录推导新权限，不补桶、不补水。新操作沿用供水动作的连续回执和计划防重：真实完成写入一次，旧回执和重放不能重复转移。

观察面板分别显示限时授权及使用次数、撤回和到期状态、待接受/拒绝/撤回的赠桶提议、实际完成的交接。协助饮水事件记录具体原授权、供给人和实际消耗；没有把授权、提议或赠水误记为饮用。

观察者的全局状态不等于居民已知事实。对方在远处撤回或拒绝不会自动写入本人的记忆，也不会让本人的停止菜单消失。每人仍可记录自己的停止意愿，直至本人已经停止、已知期限届满、共同完成次数用尽或现场实物交接完成。后来另一人再停止只添加其本人的记录，保留首次生效的撤回时间、终止时间及状态，不恢复权限，不补水，也不转移桶。再次授权同一照护者或另向他人赠出同一桶，也须本人先停止其原有未履行安排，或等已知期限届满，不能通过突然出现的新选项获知远程拒绝。实际供水或交接仍会拒绝任何已经结束的安排。
