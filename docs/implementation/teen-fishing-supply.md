# 青年钓具的实际来源回归

## 范围

本次将已经可行的规则路径固定为可重复的离线隔离回归，只增加 tests 与说明，不改变生产规则或直接补发钓具。它补充[青少年自有钓具装备](teen-fishing-equipment.md)：原装备测试从本人已有 rodKit 开始，这里从正式开局成人原有木材开始，连接真实制作、分别同意、实物交付和本人装备。

所有成功动作都从当前 `decisionChoices(decisionContext(...))` 的最终编号菜单中选取，经 `parseChoice`、`submitPlan`、`stepWorld` 执行。测试脚本指定每一步选择；不是模型自主决策。寻找轮转菜单时只以30分钟步进推进隔离世界，设有有限等待上限，不插入隐藏选项、不直接写物资、不替换地图或瞬移。

## 真实资源与行动顺序

使用 `createFrontierWorld(5401)`，保留正式九人开局和成人原库存：

1. 苏庭（`founder-1-1`）在自家工作台选择整理纤维，实际20分钟，用1木材得到3纤维：木材8→7，纤维0→3。
2. 苏庭另选手制钓具，实际45分钟，用2木材、2纤维得到1 rodKit：木材7→5，纤维3→1。批次状态与真实累计工时分别核对，屋内行走另计。
3. 苏庭通过真实移动离开工作台并返回门口，使用原有1份 meal 提议共同储物池；徐澜（`founder-1-2`）另选接受并匹配自己原有的1份 meal。两份餐食继续留在各自份额，没有被工具制作或赠与消耗。
4. 苏庭另选存入实际制成的1 rodKit，再向眼前少年提出赠与。`ownPercent:100` 明确表示钓具全部来自苏庭份额，不虚构徐澜也有半套钓具；徐澜仍须独立选择批准具体赠与。
5. 少年在提议后自行通过编号移动离开储物处，仍处于可知赠与的附近。批准只把那一套钓具从个人份额移至赠与预留，不进入少年库存。少年可独立接受或拒绝；接受后须实际走回原处并工作5分钟才交付。
6. 到手后少年仍没有已装备鱼竿，须另选装备。14.75分钟仍保留1 rodKit；第15分钟才扣除它，生成本人耐久30/30的鱼竿。没有自动捕鱼计划、鱼获或垂钓经验，额外推进30分钟仍不捕鱼、不消耗鱼竿耐久。

测试核对关键选择的本人身份与顺序，物理 rodKit 在成人库存→家庭份额→赠与预留→少年库存始终恰好一套，装备后变成一支本人的鱼竿。原有其他工具保持不变，钱款与少年亲缘/监护关系未改变。这是本链资源核对，不是完整世界经济账本。

## 两类年龄来源

- 原始开局：苏葵（`founder-1-3`）本来就是13岁，无需改年龄或送工具，保留原有个人口粮。
- 真实出生输出加明确合成年龄夹具：给徐澜设置到期妊娠夹具，通过 `advanceLife` 调用生产出生函数，先核对新身份、出生事件、空库存与新生儿尚无决定/表达能力。之后显式把这个孩子的 `bornAt` 改为当前时刻减13年，保持世界时钟不变，再由生命周期逻辑激活能力。该对象仍是空库存，随后走同一完整来源链。

第二种只验证真实出生对象如何接上13岁规则。它没有模拟十三年的成长、实际照护或生存，不验证受孕同意，不宣称模型自主找到路径。主链还断言实际推进不足一个游戏日、模型请求计数为零。

## 授权与限制

- 另一成年批准之前，少年既没有收货菜单，也不能通过伪造完成动作提前领取；提议人不能替另一成年人批准。
- 批准之后但到场交付之前，仍不能装备或捕鱼；远程完成收货失败。实际交付之后，装备仍是单独选择。
- 少年在批准前后都无权制作钓具、建池、匹配出资、存取成人份额、替他人提议或批准赠与。少年获得的是接受/拒绝本人赠与的权利，不是家庭资产管理权。
- 当前家庭池需要两名实际合格的成年成员。第二名成员缺席、未成年、缺决定/表达能力或已经离镇时，建池路径被拒绝且不扣原出资。它不是单亲家庭、独居青年或所有青年的通用工具供给保证。
- 反例测试会直接修改隔离对象的资格来制造失效条件；这些属于明确的负面夹具，不混同成功路径的自主行动。
- 独立审查另覆盖拒绝/取消退回原贡献者、竞争提案不能重复预留、少年末拍失能和编号输入不可改写。审查发现的既有成年失能交付竞态及后续验证单独列于[独立审查](../reviews/teen-fishing-supply.md)，不把正常链通过扩张成所有竞态都安全。
