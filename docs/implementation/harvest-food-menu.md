# 成熟收获的有限自救菜单保留

本项修复一个正常决定入口的缺口，不代表九人长期供给或真实模型生存已经验收。此前居民关注日常、交易等非农事目标时，即使脚下有本人成熟芜菁、随身无粮，收获也可能被普通领域轮转裁掉。默认九人 seed5401 的隔离场景中，原候选有53项，最终菜单仅36项却没有收获；原候选可在15分钟完成收获和另选进食，最终菜单的自救预测却返回否。

## 当前边界

- 只处理已经通过普通年龄、能力、旅程和可见田地过滤的 `harvest` 候选，不新增田地、成熟作物、食物或其他人的权限。居民饥饿至少80，或既有口粮估计不足两日时才检查。已有计划或活动不被替换。
- 在隔离副本中用同一引擎、原作物和食物定义、真实路线、身体损耗与保质期，最多预测60游戏分钟。必须实际完成这次收获，并且完成时的普通四种随身食物菜单中包含相应进食选项，然后真实完成该份进食并解除当前饥饿与耗竭损耗。
- 实际收获产出的原批次必须覆盖这份进食真正扣除的FIFO批次、数量和营养。同期其他人对本人的喂养或照护不能冒充本人收获自救，遇到此类回执保守不作证明；其他人的已提交行动仍照常模拟，没有被冻结或撤销。旧同类高营养食品、非食品、过期产物或营养不足都不能伪造证明。
- 证明只在当前决定快照中有效，不进入存档、居民记忆、模型文字或公开回执格式。精确进食批次证据存在临时弱引用中，读取返回独立副本。SQLite重载后按当前事实重新计算，不补粮、不重置食品期限。
- 至多保留一个有证明且尚未可见的收获。多候选按实际完成分钟数、田地身份排序。只用既有56项普通议程的空位，或替换多余目标反思、尚未接受的日常分支设定、普通新图纸入口；不增加菜单预算，不挤撤回、拒绝、既有自救、照护或现场承诺。若议程完全由受保护选项占满，就不追加收获行。
- 居民仍须自行选收获，收获后再自行选进食。实际提交、行走和完成继续重验产权、成熟度、路线、能力及库存。成熟作物原本允许跨季收获，该规则保持；本项不增加跨季生长、浇水、种植、批量收获或自动生存策略。

## 同步预测的触发范围

预测发生在模型调用计时前。为避免每次构造决定都支付无用成本，先用原有口粮/饥饿口径、是否已有计划或活动、是否看见本人成熟可食作物作廉价排除，再构造普通候选。使用同一份候选和同一最终菜单装配函数产生无证明的基线，按田地身份判断是否确有相关收获缺失。所有相关收获都已可见时，不克隆世界、不执行预测；未计算不等于证明失败。

只要有一项缺失，仍对全部相关候选执行原精确证明。不能看到任意一个收获就跳过，也不能只证明缺失项：可见项可能不可达，而缺失项可救命；反之，可见项已可救命时，即使缺失项更快，也保持原规则不再加一项。证明及省略证明的决定仅对应构造完成的当前快照；改变时间、关注或候选后应重新构造/计算，不能沿用旧快照结论。生产入口目前同步构造并立即使用，无中间异步修改。

合成测试保留官方地图，分别使用9名和扩展到90名内存居民，两块成熟作物；90人是明确的压力样本，不是运行多年的真实世界。一次本地测量：

- 两项均已见：9人和90人的原急切预测分别约71、377毫秒；缺失检查约0.04、0.03毫秒，世界副本均从2降为0。优化后完整构造快照及菜单分别约15、19毫秒。
- 有缺失项：仍是2个副本、合计32游戏分钟的实际预测；90人该次完整快照及菜单约399毫秒。没有缩减预测时长、冻结他人行动或删去安全检查。

上述时间只报告本机单次场景，不作为稳定延迟阈值。优化降低不必要的触发次数，**没有解决最坏同步阻塞**：正常菜单最多两项相关候选，仍可能每项执行60次全世界步进，大人口和复杂历史的最坏耗时没有验收。

## 离线验证

`tests/harvest-food-choices.test.ts` 的默认九人、饱和菜单和SQLite关闭重开三项在修复前均因缺失收获失败。新增边界包括不可达、来不及、不可食、到期、营养为零或不足、非本人田地、未成熟、多候选排序、全保护议程、年龄与旅程限制、旧快照、原作物跨季定义、同期照护、旧同类批次、进食期间FIFO变化、下一菜单食物轮转，以及实际执行前产权/成熟度/道路失效。

性能回归先验证“已在最终菜单仍复制世界”的红灯，再验证零副本路径、独立廉价门槛断言、急切/按需预测的菜单差分、两种混合候选的公开入口、合成9/90人副本计数和耗时。差分参考共用精确预测器，主要核验触发优化；饥饿四舍五入及低口粮触发另有明确断言。测试不以浮动的绝对耗时作为通过条件。

本文件的合成用例只使用代码创建的世界和新临时SQLite。性能补充用本地已安装Node/tsx、干净环境及项目 `acceptance-offline-guard.mjs` 运行，阻止普通网络API和密钥/真实存档路径；这是受信任本地代码的防护，不是操作系统级沙箱。严格隔离全量测试因 `bwrap --unshare-net` 权限被拒绝，未启动替代全量，不能报告全量通过。真实模型十五日、完整四季及成熟大人口的最坏预测耗时仍未验收。

此次扩展定向回归11文件共159项，151项通过；8项既有随身食物测试在重设自己的 `fetch` mock 时与不可修改的离线防护冲突，报 `Cannot redefine property: fetch`，尚未进入业务断言。未关闭或放宽防护来重跑它们。新收获文件的45项及客户端、服务端 `tsc --noEmit` 均通过。这些结果不是全量通过。
