# 有限边界勘察与区域接入

这是[批次 6](roadmap.md#批次-6-新区域发明与运输)的有限正式发起路径，不代表完整区域生成、资源探索、交通工程或长期运行已经验收。[区域设计](../design/building.md#连接新区域) · [既有隔离接入证明](../../src/world/region-extension.ts)

## 已接通的正常行动

1. 有自主决定和表达能力的成年常住居民，可以在东侧或南侧现有边界附近选择勘察。本人实际走到边界，工作30分钟。须携带本人已有、未封存且至少1耐久的斧具，至少一份保质期超过当前两小时的食品及两份原有清水。完成勘察耗斧具1耐久，不自动吃喝，也不发放补给。
2. 勘察记录绑定原地图尺寸、具体边界和公共公告板地址。它不改变地图、不预留土地。申请人自行前往原公告板，公开八格深、七格宽的空草地入口方案。须有至少三位成年常住选民，固定名单独立表决前有至少一游戏日公示。
3. 六岁以上、能自主表达的在场居民或访客可以提出异议，停止本案，不由多数覆盖。表决须原固定选民过半且至少两位独立赞成，不承诺他人的劳动、材料或资金。拒绝与赞成保持成对可选。菜单明确写出申请人、记录编号、边界坐标与权限范围。
4. 申请人实际读到通过结果后，可以另选步行返回原边界。远处只显示按已读记录返回核验，不透露此刻的授权结果。到达后另选15分钟的登记接入，重新核对原授权、边界、道路、食品、清水及本人斧具，完成再耗1耐久。
5. 通过既有隔离证明后，只追加相邻的七格宽、八格深草地入口，其余新增矩形边缘为不可通行的地形边界。不新增自然资源、鱼群、道路、桥梁、建筑、库存、人口或产权。本人留在旧边界，前往新地须另选移动；建设权仍走原独立用地公示、表决和登记。

食品和清水记录只证明当时随身准备，不能保证整个往返旅程安全。食物变质、工具损坏、路线受阻或身体能力变化会停止相应工作，未花完的工作不会自动完成。

## 权限、知识与中断

- 原公告板损毁、转为私人或搬走，会使未完成申请失效。修复或恢复原权属不能复活已经中断的公示期或表决。未开通申请有固定期限，另一项地图扩展改变原边界时必须重新勘察，不按新尺寸自动改写旧同意。
- 申请人可以到原公告板撤回尚未开通的申请。异议、撤回和失效保留已经发生的时间及斧具耐久损耗。
- 远处的申请人不会因未听闻的异议立刻失去返回公告地址的选择，也不会据此自动获得重新勘察资格。需到场读取。原公告板永久失效时，本人仍能到记住的原地址核实失效，再另找真实公告板发起新申请；此现场核实不恢复公示、表决或接入权限。
- 既有通路和地图格逐格保留，原资源余额、地块、建筑、库存和契约不变。只读工程观察页列出申请状态、实际位置、期限、独立表决、异议和持久事实，观察者不能代投票或开图。
- 接入可行性证明在一次性副本中走真实移动规则，既有待办不在副本中替居民继续选择；副本的时间、移动、健康、食物、发现和个人记忆均不提交。真实世界只接收通过核验的地形、区域登记和水域地理边界。

## 旧档、重启与验证

旧档仅初始化空的勘察记录列表，不凭空补写勘察、同意、物资、工具或地形。正在进行的实际旅行、工作、固定选民、已投票、期限与记录随原存档保存；重复计划或完成调用不能重复接入或重复耗工具。

离线定向测试（历史路径：`../../tests/region-survey.test.ts`，已移除）覆盖正常最终菜单及真实时钟链、独立拒绝与儿童/访客异议、无礼物与无瞬移、未达边界、无权工具和失效补给、远处知识、公告板连续性和永久失效、当前成年人数、改变地图及原路线、工作中断、持久事件和SQLite重启。独立 review 已发现并推动修复远处记录消失、公示板中断仍计时及投票标签无法区分方案的问题。

尚未进行本功能的浏览器像素验收、真实模型决策或长期四季运行。北/西向扩展、复杂新地形、实际新资源来源、开路修桥、新区域长期补给、更多探索记录和争议复核仍未实现；不把本切片作为批次6整体完成。
