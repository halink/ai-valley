# 停业余货与后续遗产

## 问题与复现

经营租约由产权人提出、承租人独立接受。承租人开店并投入 8 份木材；两日租期结束时自动停业，资金依约结清，木材仍属经营者并留在原址。经营者随后死亡，旧实现只清点 `closedAt === null` 的商铺；遗产待结算检查也只检查营业商铺。结果是继承登记可先结束，8 木仍留在已关闭商铺，原经营者已不能领取，继承人也没有权利凭证。

`tests/closed-shop-estate.test.ts` 通过实际 `submitPlan`、逐分钟 `stepWorld` 完成报价、接受、开店、入库、租期届满、下一分钟死亡、继承、内存 SQLite 重载、再推进三日和实际领取。测试世界单独使用不累积饥饿与疲劳的生理定义，以隔离合同与保管回归；这不是长期自主生存验收，也不调用模型或真实存档。

## 权利和清算边界

- 停业不等于放弃所有权；在世经营者仍按原有权限亲自领取，房东、路人和继承人不能直接取走其商铺库存。
- 死亡后的清点包含已停业商铺的正库存、余额及未结束报价。报价先取消并退回原账户/库存，后续保全不触碰员工已挣工资或外贸另一方权利。
- 遗产登记和净现金债务清算，在这些经营财产实际清点完成前都被阻止。现金债务仍按原合同结算，木材等非现金财产不被自动变卖，也不产生继承人债务。
- 原址存在时，余货封存在该商铺门口，所有权先留在逝者遗产。自动清点不等于继承登记，也不等于实际取货。建筑产权不因货物保全改变。
- 原址缺失则保持原商铺资产与待清点门禁，不编造地点、不抛出缺失建筑异常、不转给房东。产权或继承关系没有可验证接续人时，相关份额继续受保护。
- 清点不永久标记“完成”：之后真实退回同一关闭商铺的物资或钱款仍须再清点，零余额、空库存时重复推进不产生新转移。
- 自动清点只写观察者账本，不把远处的死亡作为在场顾客新获知的事实。

## 已经分产或 settled 的旧状态

新增清点会将晚发现财产标记为独立的 `business-supplement` 来源。旧已领取份额、金额、房地、领取时间和历史事件保持不变；未领取旧份额的现金仍全额预留。只有全部已知退款/合同义务清结且不存在活跃遗产债务时，新增财产才形成独立的待登记补充分额。

补充分额按原分配的支系结构划分，而不是把现有后代重新平摊。例如原两支各半，其中一支再分给两个子女，8 木仍为 4/2/2。已经死亡的原受领人使用其自己的继承关系，包括有效配偶等既有回退规则；无可验证后继者的一支保留，不分给无权人员。每一补充分额仍须受领人亲自登记，再到原址领取。

旧的 `goodsClaims` 缺省迁移不得吞并新清点的补充来源，否则先领取者会失去应有份额。原有物资迁移和补充分配分开处理。已成立分产同时又存在未结活跃债务的矛盾旧状态不被强行追溯重分；保持保全并遵守现有债务门禁，不能为了可领取而免除或重开债务。已经依约终结的债务不被自动恢复。

## 食物、未成年人和重载

商铺到封存包、封存包到补充分额使用不同食物事务，避免从尚不存在的起始批次串行扣取。明确来源的批次路由保留生产时间、到期日和定义，登记/重载不刷新食物年龄。未成年有限救急查看其全部未领取份额，并按实际包对应的份额扣减；空的原份额不会遮住补充分额食物，也不能取得另一继承人的口粮。

## 验证

- 专项测试覆盖实际租赁/停业/死亡/继承/领取链，以及重载、守恒、越权拒绝、缺失场所、分支继承、有限债务、迟到退款、食物年龄和旧迁移。
- 独立审查发现的旧迁移偏分有单独红灯记录和修复后回归；未成年补充口粮兼容性也有回归。
