# 安全水供给：第一阶段

本项接通[批次4](roadmap.md#批次-4-用地牧场与安全饮水)的有限供水行动，不宣称完整供水保障已验收。**尚未启用居民口渴、脱水、饮水健康加成或自动饮水。** 居民可以自主选择准备和实际饮水，原饥饿、体力和健康规则不因本项增加负担。

## 实际物资与路径

- 成年人亲自到有权使用的桌台，投入本人2份木材和30游戏分钟制作一只空木桶。每桶最多6份水，初始水量为0。自家桌台、共屋桌台、自有场所桌台和有效租约明确开放的桌台可用；地点、室内路线、工位占用和租约时段都须有效。普通菜单在已有2只个人桶后不再持续推荐制桶，规则上限为8只。
- 已知且现场可见的泉水，与原采集及野生动物共用同一个 `Resource.amount`。本人走到可通行取水位置后每份花2分钟，完成时从原泉水扣量、装入本人桶。泉水仍按原生产规则恢复，新链没有第二套泉水库存。
- 成年人可以亲自到真实淡水河岸花10分钟登记一个有限原水点。每个实际水格只登记一次24份自然原水，登记不是抽取，不给予携带水或净化结果。不同人或不同岸侧不能重复登记同一水格，耗尽记录不删除、不自动恢复。每份装桶花3分钟。
- 海岸水格不作为可煮淡水。地理边界与既有鱼群水域边界保留原分类；追加地图不能把原海水变成淡水。新增区域须在通过原区域校验后登记自己的边界。这里只使用游戏现有淡水/海岸分类，不模拟盐度检测或海水淡化。
- 原水与安全水不能混装。成年人亲自到有权使用的真实灶台，用本人1份木材燃料和30分钟，借用厨房既有炊具煮沸整桶原水，再冷却装回原桶。水量不增加，木桶本身不直接放在火上。原水不能饮用、供给幼儿、捐作饮水或转入旧清水库存。
- 自己已有的清水可以实际装入空余桶容；安全桶水可以转回自己的旧清水库存，留作烹饪、灌溉和牲畜用水。两边数量同步加减，转移本身不算饮用。

普通决策菜单提供上述动作。水源库存只在附近现场可见，远处共屋的当前水量不会因知道地址而泄露；普通寻路负责先到已知地址。实际路线受阻、室内工位不通、燃料不足或使用权改变时停止，不另选来源、不创造材料、不替居民改变计划。[本人饮水菜单保留](direct-water-choices.md)在原56项普通预算内，用空位、多余反思或非安全一般位置保留一项合法自有/公共饮水，不能挤掉已有停止、拒绝、撤回与救生优先项；全安全项饱和或原两项供水均为照护时不强插。原供水轮换先完成，原已选供水照护保留，非控制供水合计仍最多两项。没有自动选择或扩大执行权限。

## 个人、儿童及访客

- 6岁以上且仍能自主决定、表达的居民和访客，可从自有桶饮用1份安全水，也可装入自己旧库存的清水或去可见安全泉取水。未成年人的一次装水上限为3份，不能自主制桶、煮水或捐赠财物。
- 成年既有监护人可在现场帮助1至5岁的幼儿饮用1份自有安全桶水。必须仍具监护关系、孩子在同一实际房间或户外可及位置、未拒绝照护且仍在谷内存活。与成人协助、赠桶共用现场检查：户外双方站位均可通行，且实际路径不超过2步；仅直线距离近、隔悬崖或需要长距离绕路不算可及。室内双方须有真实房间坐标、原有使用权及不超过2步的无阻挡路径，不能把门口当作床边。行动中撤回权限、孩子离开或地形/室内阻挡改变会停止；渡运或护送中的孩子须先实际结束运输，不能只因地图坐标重合而在岸边供水。不会授予新监护、紧急照护或私人房屋进入权。
- 未满1岁的婴儿仍走原有营养照护链，不新增独立喂白水动作。[有限成人协助和未成年人赠桶](water-support.md)另有明确授权与独立接受路径；丧失决定或表达能力、或重症成年人的医疗供水、非监护幼儿帮助与照护交接仍待专门验收。
- 供水第一阶段，每人滚动24小时最多实际饮用2份。个人自饮、监护人帮助和共屋饮用合并计数，跨共屋、跨桶、离谷返回和重启不会刷新额度。这是有限试运行上限，不是已启用的生理需求；不饮用不会增加新损耗，饮用也不提升健康。

6至17岁且可自主接受的人，现在也可通过[本人独立接受的现场赠桶](water-support.md#向能够自主接受的未成年人赠桶)取得原有空桶或安全水桶；提议不转移实物，不改变监护或住所。

## 共屋储水权限

成年人可自愿把**水桶及其中安全水一并**交到公共共屋真实桌台。完成后桶转为公共所有，记录捐赠人和地点。其他成年人可以带自己的安全桶水到桌台，补入已经捐出的桶，仍受原6份容量限制。

6岁以上且可自主行动的居民和访客，可亲自到桌台直接饮用这项自愿储备，受同一每日2份限额，无需先拥有木桶。访客不因来访自动获得水；若无人捐赠、桶已空或道路阻断，保留真实供给缺口。

捐赠只授权该桶的饮水用途，不打开金库、已有公共清水、预算物资、他人桶或私人财产。不存在自动征收、自动捐水、自动派送或自动补满。满桶不能再收水，最后一份不能被两人重复取走。

## 保存、回执与观察

- 旧档接入只创建空的供水登记，不补发桶或水，不改旧库存、归属、用途和既有用水动作。
- 每次完成都保存实际数量、供给人、接收人、桶、水源、地点和原行动。相同回执重试不重复转移，不同载荷不能借用旧回执。
- 同一新计划包含多项供水选择时，只在计划成功提交时为其一次性绑定连续回执。计划重放、重启或执行时不重新编号；旧快照不能因更换计划标识获得新供水权限。
- 中途失败保留已完成的真实行动，未完成动作不扣水和材料。屋况、权限及工作时段在实际劳动区间重验，恰好在窗口末端完成可结算，越界不能继续劳动。
- 私人桶随原持有人保留身份和归属；死亡或离谷不自动转给家属或公共库存。桶的遗产收取、继承转运和交易尚未接通。
- “野外与生计”面板只读显示个人/共屋水桶、安全或原水、容量、捐赠人、原水点余量和实际饮用记录。世界事件保留实际供水过程。
- 年表现可单独筛选[带完成快照的供水记录](water-history.md)，核对当次桶、水源、库存及原授权变化。旧文字事件不补造缺失快照，转移、净化与实际饮用分别显示。

## 验证与边界

定向回归见 [water-supply.test.ts](../../tests/water-supply.test.ts)，包括正常决策菜单解析到引擎执行（脚本选择，未调用真实模型）、泉水与原水有限扣量、容量与混装拒绝、净水燃料、真实灶台与竞争工位、租约最后劳动分钟、旧档与重启、多步计划回执、并发最后一份、监护撤回、不同房间、访客/未成年人、公共库存隔离、扩图水质及四个季节日期下断路后的替代泉水。

[child-water-reach.test.ts](../../tests/child-water-reach.test.ts)另覆盖隔悬崖与四步绕路的两格近距、旧菜单选择在地形变化后的开工/完成拒绝、劳动中断路与室内新增阻挡、缺失坐标/使用权/受损房间、不可通行站位，以及正常同格、相邻、两步、斜向替代路径和室内供水。实际决策菜单经过解析后交给引擎，合法供水仍花5分钟、仅扣1份；无效供水不扣水、不记饮用额度、回执或完成事件。开工、每步劳动和完成前均使用同一个实时检查，不缓存菜单当时的可达结果，也不自动绕路搬运人物。

四个季节日期下的规则测试不是完整四季持续供给验收。未运行外部真实模型、未修改真实存档，也未完成本项浏览器视觉验收。[有限天气链](weather-hazards.md)已接通泉水洪灾淤塞及退水后实际清理；[灾害供水联合验收](disaster-supply-chain.md)核验普通菜单替代泉取水、有限协助、清泉与重载，不代表完整污染治理。仍未接通完整水质污染、雨水储存、管线或自动抽水、盐度系统、所有液体统一容器约束、原水直接灌溉、桶的交易/继承、沿途补给、非监护幼儿供水或丧失决定或表达能力/重症成人医疗供水。现有 `water` 与原采集、交易和生产入口保留兼容意义，不宣称已经全部改成新桶模型。

下一阶段须在隔离正式九人世界核验持续供给、常见路阻替代路径、初始及后来来访者、婴幼儿和失能者照护、多季/整季资源账本，再决定是否开启口渴及脱水损耗。不能只凭这组单元测试启用新风险。
