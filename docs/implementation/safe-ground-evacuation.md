# 无接收床时的有限监护干地撤险

后续[成人紧急短程撤险](adult-emergency-evacuation.md)新增独立的非危重失能成人干地入口；不扩张下文的幼儿监护或医疗权限。以下历史验证与其原范围保持。

后续[轻中伤病幼儿的干地再撤险](injured-child-evacuation.md)修复“第二次洪水仅造成轻伤就丢失无床撤险菜单”的缺口：仅干地分支改按实际伤情持续核验，重症不默认可安全搬运；下文零病例条件及1533项结果描述的是原切片历史范围。

这是[户外监护送床](guardian-evacuation.md)和[室内已知地址尝试](indoor-guardian-evacuation.md)之外的一项独立选择。没有接收床时，当前监护人仍可自行决定将眼前受灾的健康、未满六岁幼儿临时带到附近干地。它不是自动疏散，也不安排床位、医疗、住所、财产转移、监护转移或长期照护。新天气调度继续默认关闭。

## 先评估，再分小块

原实现的真实菜单只提供指定诊所/会馆的护送。室内已知地址模式允许先出门，但若最终无床，只能停在接收建筑门口；它不能表示“只撤到附近干地”。直接伪造一个接收建筑或放宽医疗床位规则会混入不必要的医疗和住房权限。

本次保留原有两条路径，新增明确的 `evacuationDestination: 'safe-ground'`：

1. 先加入干地目标、最多八个实际户外步的搜索与明确无床运输记录。
2. 再增加室内延迟选点：先真实接出并逐格走到门外，出门后才查看周边干地。室内不会因远处或门外实时危险不同而暗中增删此入口。
3. 接入真实最终菜单、逐格引擎、乘员停止、只读观察、保存重载，以及独立反例。

首批三个菜单到执行回归在实现前均因没有无床入口失败；实现后通过。未以直接调用底层完成函数代替普通菜单验收。

## 权限与亲见条件

- 护送人须是在地存活、能决定且能表达、具备既有护送体力的成年当前监护人。幼儿须在地存活、未满六岁、没有拒绝且健康值至少45、没有未结伤病病例。
- 监护人须当场能观察并真实接触孩子；尚未结束的亲见灾害须实际覆盖孩子，已有足够建筑遮蔽则不能据此搬动孩子。
- 室内须双方在同一有合法使用权的房间，有真实门口和室内坐标、可接近孩子且能走到出口。门外不能凭共享门口坐标隔墙接出，缺失坐标不补成入口。
- 只有本人选择并完成原有15分钟接出劳动后，才扣本人1布料、1清水。原危险、监护、拒绝、接触、资源或出口在接出前改变都会中止，不扣物资。水是本次接出资源，不代表已经饮水或获得新的医疗权限。
- 有决定与表达能力的乘员保留原停止菜单。只有表达能力、暂时没有一般决定能力的幼儿，也能对自己的这一次干地护送表示停止；另一选项是暂不表示停止，最多15分钟后再次给表达机会。这只是没有物理动作的等待，不恢复一般决定能力，不接受医疗或住房。拒绝立即生效，不能附带另一项行动或停止别人的护送。

## 目标与实际路程

户外菜单只选本人八格视野内、从孩子实际位置最多八步可达的干地。一次有限广度搜索至多覆盖145格，检查真实洪区、其他可见危险、树石障碍、围栏门与损坏交通边界。落脚点不能在未解除的灾害范围、可见威胁范围、水格、悬崖或桥/码头上。

室内菜单不带干地坐标，仅绑定当前房间出口，明示门外未核验。接出后逐格走完房间路线；到达真实出口才能变为户外。此时按原决定的有限目的，现场选择最多八个实际步内的可见干地并将同一目标写入动作和运输记录。无可达干地时就在真实门口停止，不自动换成远方地址或床位。

接出后原灾害结束、或走出原危险区，是正常撤险，不会因此把孩子中途丢下。之后每次同步和每条实际边仍核验当前监护、孩子拒绝、护送人体力、原目标、剩余路线与可见风险。累计户外步数随每个真实相邻格保存，已走步数加剩余路径不得超过八步。不能用直线半径代替实际路长，也不能利用截断或跳格的保存路径制造出口或瞬移。

新风险、阻挡、拒绝或权限失效会在最后真实位置停止；不会自动改道、退回、续送或清空孩子位置。抵达后还需在绑定坐标完成短暂落脚劳动并重验安全，才记为完成。这不保证该地点永久安全，也不安排灾后交接、遮蔽、供水、补给或长期恢复。

## 保存与观察

- 新运输的 `buildingId` 与 `bed` 均为 `null`，没有医疗提议或床位预留。记录原危险、出口、真实户外起点、累计步数和最终现场选定的坐标；室内尚未选点时坐标缺省。
- 原医疗运输、已知地址未核验床位和已送床记录保持原有含义，不迁移成干地记录。新增字段只用于新模式。损坏或互相矛盾的新字段会终止运输，而不是放宽范围或使世界步进崩溃。
- 事件分别记录实际接出、门外选点和实际临时落脚。完成事件带原灾害编号和孩子编号。公开面板区分“临时落脚在干地”与“送入实际床位”，不会显示虚假的预留床。
- 读取菜单与观察面板不提交决定、不移动人物、不扣库存。最终菜单原有最多两个轮换监护撤险选项的限额保持，干地和床位选择一起轮换，不挤掉等待、进食及其他个人选择。

## 仍有边界

此切片不覆盖无当前监护人的健康幼儿、六岁及以上受照料者、非危重失能成年人、船上无床接出、超过八步或不可见的干地、完整灾后接班与补给。无可达干地仍是实际失败结果，不用隐式医疗或住房授权掩盖。不能据此开启新天气预警或声称完整灾害撤离已经完成。
