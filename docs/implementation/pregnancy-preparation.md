# 有限孕期准备与出生核对

## 交付范围

这是第 7 批的供给与地点准备切片，不是医疗接产或孕产风险模型。普通菜单、实际行动、人物家庭面板和出生观察记录已接通。旧档和新档均不增加孕期饥饿、疲劳、伤害、难产或死亡概率；原有出生时间、身份、亲缘、监护和未出生遗产份额处理保持不变。

- 成年且有完整决定与表达能力的孕育者在自己的登记住房内选择现有真实床位。住房限完好住宅或会馆；不创造床位、入住权、房产或医疗预约。
- 每份准备固定最多 24 游戏小时，且不超过原预计出生时间之后 1 分钟。不自动续期。可以暂不指定提供者；一般自愿进食和睡眠不依赖准备约定。
- 如果指定提供者，双方须在有权使用的同一室内现场真实相遇。提供者成年、清醒、有基础照护能力，并独立接受或拒绝；亲属、伴侣或旧照护关系不是同意。
- 接受后，提供者可以另行决定交付最多两份自有随身餐食，或尝试到约定床旁陪伴 60 分钟。接受不强制行动、不保证一定到场，也不转移任何物资。
- 送餐完成前复验双方清醒、能力、当前拒绝、原授权、实际距离、场所与库存。每次只交接一份，保留原批次与保质期。接收不直接减少饥饿，孕育者仍须自主选择进食。
- 孕育者仍用普通睡眠动作走到真实床位。只把有效准备期间、原选床位上的实际睡眠分钟计入记录，不新增或放大恢复效果。
- 床旁陪伴沿已知地址与室内路径真实前往。只有提供者在原床旁、孕育者在原床、权限和能力仍符合条件的工作分钟才算到场。已同意的非医疗陪伴可以伴随孕育者自愿睡眠；不能对睡眠者交付餐食或取得新同意。

## 停止、改约与实际条件

本人可以单独撤回，不必走到对方面前。正常提交的撤回立即生效，停止本人该项已排队或进行中的准备行动，不自动停止其他旅行或普通睡眠。提供者拒绝只停止其参与，不禁止孕育者自行休息。孕育者要改地点或指定另一人时，先撤回旧准备，再在新现场选择并重新取得提供者独立同意。

当事人各自记录自己的停止决定。远处的人不会因对方悄然撤回、缺席或出生而自动得知。提供者可以按原约定地址尝试前往，到现场再核实；实际看见出生后不再提示履行原陪伴。已经交付的餐食属于接收者，不因撤回而追回。

真实床位、现住户、临时借床、家庭迁居预留、医疗运输预留和当时实际占用须受保护。住所受损、搬迁、床位改变、进入权失效、原孕育被替换、到期或本人当前拒绝均不能被旧同意覆盖。路线受阻、提供者体力或能力不足时停止，不瞬移孕育者、不强制转交、不生成替代人手。

## 出生与只读观察

出生继续由原生命模块在实际位置登记。新记录仅核对原选床位与实际位置、是否有仍有效且本 tick 实际履行的指定床旁陪伴。恰好在出生本 tick 完成 60 分钟的提供者仍可据实际在场被记录；过去来过、尚在路上、已撤回、缺席或能力失效不算有效陪伴。

这些核对写入观察档案，不把未在场者的私下约定自动灌入出生见证人的记忆。人物家庭面板只读呈现期限、各方同意与停止、已交付份数、实际休息和陪伴分钟，以及出生核对。不论准备成功、失败或不存在，均不改变基础出生结果，也不影响原未出生份额核对。

## 存档与回放

- 缺少新状态的旧档只增加空登记；不补造同意、物资、床位、历史休息或出生准备。
- 准备绑定孕育者身份、受孕时间、原预计时间和原记录 ID。不同孕育不会继承旧权限。
- 逐动作回执防止重复交付；准备记录、回执、食品批次、房间路径和已实际履行分钟随存档恢复。
- 准备引用的观察事件保留在工作档案中，历史窗口裁剪不抹去证据。
