# 共屋与人物几何纵切片

本批承接[绘本视觉提案](../design/storybook-valley.md)与[高清密度契约](storybook-density.md)，先把建筑与人物共同站立的尺度锁定。它是**独立、非默认、静态开发校准页**，不是正式绘本美术，也不是接入实际世界的运行样板。

已实际查看两张设计参考 PNG。旧探索 `output/storybook-art-slice-v1` 的六张画稿、提示词、未通过结论及 hash 清单保留不动。本批没有重绘、拉伸或修补那些图片，没有新的 AI 位图画稿。新 PNG 来自代码原生几何的离线栅格化，只能作为材质绘制前的结构底稿。

## 打开方式

```sh
npm run dev:web
```

打开 `http://127.0.0.1:5173/ai-town/storybook-slice.html`。此页不需要启动后端，不导入 `main.ts`、ObserverMap、模拟器或任何存档。原默认页、原 2D/2.5D 入口和 `?storybook=1` 箭头诊断预览均不改变。

根 HTML 不在 Vite 默认生产输入图中。入口另有 `import.meta.env.DEV` 检查。DEV 判断仅用于开发隔离，不是私密内容访问控制。不要通过生产查询参数把此页当成正式视图。

页面提供三种固定测量站位：院落、门槛、屋后。每种位置都是显式的几何夹具，没有行走插值、动作时钟、进屋、采摘或结算。屋顶、标尺及屋后局部透视可切换，成人高度可选 28/56/84 CSS px；小屏或近景画面允许横向滚动，不缩小人物后仍声称原标尺尺寸。

## 已锁定的数值

- 逻辑投影仍为 32×16，地面两轴斜率为 +0.5 与 −0.5。
- 共屋占地为 8×6，局部门点为 (4,6)，与既有 lodge 定义相容。校准页将建筑原点平移到 (0,0)，没有修改真实地图。
- 三层建筑：接触面、主体、屋顶。逻辑画布均为 288×256，画布地面原点 (112,112)，门槛/脚点 (80,192)。各层纹理的源脚点为 (160,384)。
- 成人几何高 56，少年高 47.6；头高分别为总高除以 4.5 和 4.2。头发收在头部包络内，布鞋底部对齐脚点。两者是匿名正面比例标尺，没有居民身份、年龄美术保证或四向覆盖。
- 门洞中线净高 70，为成人的 1.25 倍；窗、梁和门洞是校准结构，不表示世界中门窗开闭或室内状态。
- 图集 1728×672、每逻辑单位 2 源像素，8-bit RGBA PNG。五项均为 static；不以重复或镜像同一帧伪造 directional 元数据。

地面四角在建筑画布中的坐标为 (112,112)、(240,176)、(144,224)、(16,160)。占地边长比例为 8/6。屋顶坡边涉及高度变化，不与地面水平边混用斜率要求。

## 资源与绘制

`src/client/storybook-slice-model.ts` 定义有限多边形与椭圆；`src/tools/storybook-slice-build.ts` 用固定采样确定性栅格化，复用原 PNG 编码器与 v2 manifest 校验器。不需要图像服务、外部软件安装或模型密钥。

```sh
node --import tsx scripts/build-storybook-slice.mjs
```

命令明确重建这两项版本控制内的几何资源：

- `src/client/assets/storybook/geometry-slice.png`
- `src/client/assets/storybook/geometry-slice.manifest.json`

当前 PNG 为 15,900 字节，SHA-256 为 `08e6be7fba74ad1418d89db9eb02719156e5334a1ea463d9d72c07a1325faed7`。来源声明为仓库自制、MIT 几何校准，而非正式美术或对参考图的许可背书。

独立入口只请求该本地图集，不携带凭据。经过 `prepareStorybookAtlas` 的维度、RGBA 与 SHA-256 核验后，复制到自有 canvas；每帧摆放复用 `placeStorybookAsset`，不把高清像素当成世界格。画面缩放与 DPR 分开，DPR 最大 2。没有常驻动画循环。

三种样例的显式前后顺序只验证这座矩形房屋的有限关系。红十字与青色占地是最后绘制的测量覆盖层，遮挡时仍可见，不能据此声称人物在建筑上方。门槛站位是边界对齐，不代表合法移动或通用遮挡算法。揭掉屋顶也不是完整室内视图。

加载期间可取消，HMR 清理自有 canvas 与监听器。非 bfcache 导航销毁；bfcache pagehide 保留内容，避免返回时恢复已清空的 canvas。图集或绘制失败时禁用控制并显示失败，不接管原观察界面。

## 验证和证据

专项与[独立审查](../reviews/storybook-geometry-slice.md)核对：确定性 PNG 字节、v2 密度管线、透明边界、无重叠 frame、三层注册、门槛同点、两个人体比例、28/56/84 三档坐标换算、三站位顺序、画布异常时状态恢复、默认入口隔离与生产输出模块图。

独立审查发现初版无条件 pagehide 销毁会破坏 bfcache 返回，已修为仅非 persisted 时清理，并加入源码约束测试。浏览器仍需实测；源码约束不能替代实际 Back/Forward。

本环境 Chromium 在启动时失败，错误为 `socket() failed: Operation not permitted`，没有进入页面。因此未声称浏览器、GPU、Canvas 实显、1440×900/1280×720/390×844 布局、点击、键盘、滚动或性能验收通过。未修改系统安全设置。

`output/storybook-geometry-slice/` 保留测试日志、启动失败摘录，以及院落/门槛/屋后源码合成 PNG。合成图由同一 PNG 与摆放命令输出 SVG，再使用已安装 librsvg/Cairo 渲染，图内明确写有“SOURCE COMPOSITE, NOT A BROWSER SCREENSHOT”。它们没有证明网页已经运行，也没有替代美学验收。ImageMagick 初次尝试因缺少 `rsvg-convert` 委托失败，失败日志亦保留。
