# 已知建筑地址与现场观察

本次修复[访客引导](visitor-guidance.md)中已核实的信息边界问题：记住某处建筑的地址，不再让正常决定上下文自动包含整栋建筑的实时记录。规则仍遵循[世界事实、居民所知与观察者所见](../design/simulation.md#世界事实居民所知与观察者所见)的区分。

## 现在提供什么

决定上下文使用独立的 `KnownBuilding` 投影，明确列出允许提供的字段，不再展开权威 `Building` 对象。

- 已知地址包含 ID、名称、用途和门口坐标。只标明公共归属或本人产权，不提供另一户的产权人 ID。
- 能实际观察、身处同一建筑，或在室外距其门口八格以内时，才附带本次观察时间与建筑状况。人在其他建筑内不能透过房间观察门外同坐标的建筑；睡眠或失去观察能力也不会产生现场数据。
- 公共场所、本人住宅或产权房，以及本人实际进入的建筑，可以在上述范围内提供容量；经过别人的私宅门口只提供可见屋况，不提供其床位容量。
- 完整登记住户名单、内部建筑定义、扩建与改建记录、建筑占地等不放入这份个人目录。看见一个人在别处活动，也不会据此披露其住房登记。
- 本人床位只在现场确认。远处登记住处的 `hasBed` 是未知值，不伪装成“有床”或“无床”。已知回家方向和本人选择的睡眠尝试仍保留，提示说明屋况与床位尚待核实。执行时仍核对真实权利、床位和路线，失败不会补造床位或自动换房。

投影是当次读取的独立快照，不改变库存、建筑、床位、知识或存档。居民走开后，下次查询不再获得现场实时字段。旧档只需原有已知建筑 ID；不补造过往观察证据，不进行存档迁移。观察者的世界快照仍保留原有完整建筑事实，个人知情限制不删改真实世界。

## 同步收窄的普通菜单

仅隐藏对象字段还不够，选项的出现与消失也可能泄露远处情况。本次同时处理：

- 前往已知公共班表的方向不再因远处建筑损毁而消失，到场再查看条件。
- 生产修缮和灾害修缮只对本人当前可观察的建筑提示损坏；本人其他已知产权房可先选择前往查验，不按远处损坏程度排序。
- 普通回家、睡眠与厨房选择使用地址和现场观察的区别，不把未知状态当成可用保证；真实行动校验未放宽。
- 登记居住的空床选项使用同一现场观察规则，不再在九至十格外或隔着另一间房读取空床数量。远处仍有前往已知住处查看的方向。
- 做饭选项明确绑定本人选择的已知厨房，不因其损毁而自动改去另一处未知会馆。出发、抵达进入室内之前和实际劳动时均核验同一厨房的使用权、屋况与工位。无床但仍有居住权的完好住宅不会失去厨房选项。

`cook.buildingId` 是可选字段，兼容旧动作。旧的未开始烹饪计划只在本人住处或已知公共厨房中选择，并在启动时固定目的地；旧档中的在途烹饪保留已有门口目标或室内工位，不因后来换家而自动改道。厨房失败不会消耗原料或补造餐食。

厨房占用按建筑身份与实际室内位置区分，不能因两栋建筑的门口坐标相同而把两个工位合并。不同厨房可以并发烹饪，同一厨房仍保持排他占用；尚在退出另一间房的人不提前占用目的地厨房。普通烹饪、受雇劳动、公厨接餐和遗产应急的公共供餐预测使用一致的占用边界。旧的未绑定活动沿用保存的室内或目标位置识别其工位。

## 明确边界

这不是整个模拟的知情规则重写。地址元数据仍沿用现有已知 ID 对应的登记资料，没有新增逐版本地址传播或远方建筑消息系统。

遗体暂存、同住邀请、已接受的临时床位、经营和有限日常安排等已有菜单，仍有直接依据完整执行条件判断选项是否可用的路径。其中一些可能间接反映远处状态，需要分别处理消息证据、已授予权利和自主履约尝试。本次不改变这些权限与行为，不宣称已经消除全系统的间接信息通道。

医疗目的地后来单独收窄了远方屋况、床位与灾害的菜单判定，并统一启动、途中和实际交付核验，见[医疗目的地安全](medical-destination.md)。这不代表整个医疗系统的患者、预约和消息传播都完成了知情审计。

## 回归

[building-knowledge.test.ts](../../tests/building-knowledge.test.ts)覆盖：

1. 普通访客只知道远处公共会馆地址时，改变屋况、容量、住户登记、床位分配及公共库存，完整决定上下文、最终选择和模型提示保持相同。
2. 到场观察、私宅内外的差别、身处另一房间、睡眠与失能边界。
3. 不因看见某人而暴露其私人住房登记；返回快照不与世界对象共享地址引用。
4. 远方自家床位未知，回家与睡眠尝试仍存在；真实损毁床位被执行校验拒绝，合法床位仍能通过实际行走与睡眠恢复体力。
5. 远处损坏不触发修缮消息，到场后才出现相应修缮选项。
6. 旧档式已知地址重载不增加观察证据，完整建筑事实继续保留。
7. 九至十格外、另一房间内的登记菜单不随隐藏床位变化，八格内才获得相应现场选项；床位不足不会误禁合法厨房。

[kitchen-destination.test.ts](../../tests/kitchen-destination.test.ts)补充指定厨房损毁、在途权限变化、共享门口的两厨房并发、旧活动占用与在途计划重载和参数校验，防止静默改道或权限放宽。室内工位与公共值班测试继续覆盖实际行走、排他占用及重载。
