# 居民卡：做饭和实际进食

持久规则小山谷的居民卡分别显示最近可核实的两件事。已完成的新作物烹饪有游戏时刻和实际配方：两份同种根菜、一份清水，实际做出一份餐食。进食只指该居民真正执行一次餐食进食、实际扣掉一份。今晚吃下的餐不一定是最近做的餐；这个卡不追溯哪块田、哪些批次，也不记作其他居民受餐。

记录使用已有完成事件的可选 v1 观察字段，跟耗材/产出同一事务；不增加 SQLite 表、世界版本、物品批次，不更改食物和动作权限。最近 512 个世界事件之外的历史或旧版本事件可能没有可核实的卡片记录。客户端把未来/损坏字段、过期样本或无字段显示为暂无可核实记录，不回填、不通过事件文案猜测、不影响世界推进。原事件对角色的见证与记忆仍不变，新增结构不进入角色提示。

验证：`npm run build && node scripts/acceptance-mvp-meal-observation.mjs`；`godot --headless --path godot-client --script "$PWD/scripts/check-mvp-meal-observation.gd"`。SQLite 测试包括真实清水/根菜扣账、烹饪与进食各自完成、两次重启以及提交失败不会泄露未提交事件。
