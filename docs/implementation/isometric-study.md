# 固定斜俯视等距小样板

这一批只做独立、可审视的小范围美术样板，**没有替换正式 2D 视图，也没有接入真实存档或模拟循环**。采用 32×16 的菱形地表、固定斜俯视镜头与整数像素轮廓。美术沿用[现有季节与材料色板](../art.md)，屋顶颜色来自已有程序建筑画法，人物劳作复用已有原创像素动作，不加载第三方贴图或生成式模型。

## 可审视的范围

- 一间木屋的双面墙、瓦顶、梁柱、真实门面朝向；小片林木、田地与水岸。画面只使用内存中明确标为合成的构图，不代表山谷发生了这些活动。
- `src/client/isometric-projection.ts` 提供正反投影、镜头偏移/缩放反算、格子边界与足迹排序。多格房屋的前后与侧面按足迹分离关系排序，无法分离的对象使用稳定脚点顺序；这不是对相互穿插、循环遮挡建筑的完整解法。
- `src/client/isometric-study.ts` 是独立只读渲染器。土壤与田块先于所有竖立对象绘制，树根、人物脚点和建筑地基共用地图投影。点选先命中最前方实际绘制像素，再反算地表格，因此屋顶不会误选屋后地格，透明空白也不会吞掉后方对象。
- 劳动姿态只取已有 `personVisual` 的真实到场判断；工具目标转换到同一等距坐标，钓线落在实际邻水格。走在路上不画工作，死亡、镇外、区域旅途、室内或无效坐标不画为室外劳动。样板只支持通用中性姿态与八种既有劳动；婴儿、睡眠、被护送、重病等尚未有对应等距姿态时省略，不画成站立成人。完整人口呈现仍未接通，不能把此样板用作正式观察页。
- 作物形态按记录中的生长天数与该定义的生长期归一化，湿土按当天真实浇水记录；未知定义不猜成熟或产量。现阶段只画通用叶簇，不用根菜图案冒充所有作物。
- 墓位仅有空位/已有纪念身份的基础轮廓，用于回归分层，不代表已实现完整墓园、美术状态或安葬流程。没有凭空放置鲜花、物资、产出、鱼群、动物或成功反馈。

## 在仓库内复现

```sh
mkdir -p output/test-tmp/isometric-tools/home
TMPDIR="$PWD/output/test-tmp/isometric-tools" HOME="$PWD/output/test-tmp/isometric-tools/home" \
  node --import tsx scripts/render-isometric-study.ts
```

输出固定在 `output/isometric-study/`：

- `synthetic-isometric-study.png`：最近邻放大三倍的源码原生合成像素图。
- `synthetic-isometric-study.svg`：同一像素标记序列，可直接检查轮廓与分组。
- `synthetic-phase-0.png` 至 `synthetic-phase-5.png`：0、240、480、720、840、2520 毫秒六个静态显示时点，覆盖农事/伐木四相位，以及垂钓独立节奏中的抛竿、落线、稳定等漂与调竿；不强行对齐成四阶段收获。
- `index.html`：离线自包含样板，六个时点按钮和对象/地表点选。页面不联网，没有自动时钟或服务接口。按钮只切换静态图，不推进世界。

程序仅创建合成内存世界。没有读取 `.env`、密钥或真实存档，没有调用外部模型，没有触碰运行中的临时驱动/正式服务，没有重试或绕过 Chromium IPC 限制。输出目录和最终文件拒绝符号链接；渲染输出不会跟随正式源码提交。

## 验证与下一步

`tests/isometric-study.test.ts` 覆盖投影反算、缩放与边界、多格足迹遮挡、可见像素点选、四季整数像素与画布边界、只读输入、田地状态、实际到场动作、真实邻水、缺失/无效状态和默认入口隔离。静态图已经实际查看并调整窗口高度与前景构图。

**源码原生合成图不是浏览器截图。真实运行画面、手机布局、镜头移动、长时间动画节奏和实际全图遮挡都尚未完成视觉验收。** 本批没有接线默认入口；完整建筑类型、动物、墓园、房间、连续跟随、世界季节/时钟接线与全图性能仍需后续逐项实现和审美检查，再决定正式替换时机。
