# 室内提议与丧偶接续

本项属于[批次 2](roadmap.md#批次-2-照护继承与人口接续)的关系接续部分。镇内家庭迁居和收养后另外接受的同住已有[独立实现](family-relocation.md)；[受保护财产代管](protected-custody.md)与[有限儿童现场喂养](emergency-child-care.md)也已有各自实现，不由关系提议自动授权。镇外未成年家庭首次迁入迁出、完整照护交接与永久监护仍待后续交付。

## 当面提议

交往、结婚、共同育儿与一次基础照护的正常决定菜单，不再只枚举室外相遇。室内必须是同一建筑，建筑仍可用，双方都有使用权，实际房间位置相距不超过两格且该范围内存在未受阻的路径。公共空间、本人所有、已登记住户、有效共屋借住及有效单人住宅租住分别按现有权限核验。住宅租住的室内相处不增加厨房、经营、永久入住或第三方同住权，详见[租赁与现场交互回归](residential-social-integration.md)。室内坐标不等于门外坐标；隔墙、在不同建筑或隔着入口不能当作在场。

双方须清醒、具备当前决定与表达能力。接受和拒绝均为本人独立行动，最终执行时重查实际位置、权限、能力和条款。照护明确拒绝、孕育容量/身体条件变化、原提议到期、或已有伴侣承诺都会阻止相应接受。新交往不由提议、好感或共同住处自动建立。

## 世界事实、个人所知与遗产

- 死亡关闭双方当前伴侣标记，保存既往关系的类型、已知交往/婚姻开始时间及死亡结束时间。档案结束记录仅供观察者，不通知远处居民，也不算一次主动分开或另一例死亡。
- 尚未获知的一方继续记得原来的伴侣承诺，不会因后台标记清除而自动获得新交往选项。亲眼见证、实际查阅登记，或亲自核实者清醒当面送达的消息才改变其所知。
- 收到的已核实死亡消息单独持久保存，短期记忆、通知列表轮换及重启不会让本人忘记丧偶。普通聊天传闻不满足此条件；可信通知仍不等于本人取得了用于登记继承的死亡证据。
- 死亡时保留配偶的后顺位继承人名单。子女和未出生子女仍优先，配偶随后新交往或结婚不会改变原来的遗产权利。登记继承不把原址封存物资搬到身上，也不重复转移钱款。
- 既往婚姻与交往可在双方生平中继续查阅，死亡结束与主动分开分别显示。原伴侣仍可自愿纪念，不因当前伴侣标记清除而丢失墓志资格。住处、亲缘、共同财产、已发生孕育和监护不由这项关系变更自动重写。

## 旧档

正式世界初始化时，仍挂在已故人物名下的伴侣关系只核对关闭一次。先保留尚存的配偶继承依据，再关闭当前标记；已有继承分配与实物不重分。能从已保存关系日期或年表查证的开始时间保留，未知开始时间留空。双方均已故时按最早已知死亡关闭，而不是按人物数组顺序；有一方死亡日期未知、无法核实先后时，结束日期与先亡者留空，并先保留双方原有遗产依据。原有死亡时间与这次档案核对时间分别记录，不伪造早年的交往事件或居民记忆。

旧档中确有当面接收者见证、并关联报告者亲见证据的送达记录，可以保留为本人的死亡消息；仅有已故状态、关系记录或未经核实的已知人物名单不会产生知识。没有证据的旧传闻不会升级。

## 隔离验证

关系接续回归（历史路径：`../../tests/relationship-continuity.test.ts`，已移除）使用新建测试世界及内存数据库，不读取或改写真实存档：

- 从真实、有界的模型菜单选择室内交往、结婚、孕育和照护，分别接受后经世界时钟执行。
- 不同房间、门内外、室内障碍、访问权失效、睡眠/表达能力变化、拒绝与撤回不产生同意。
- 亲见死亡与远处未知分别处理；普通传闻不解锁新关系，实际可信通知不越权变成继承证据。
- 记忆轮换、工作事件裁剪、数据库重载与旧档重复初始化保留正确事实、所知、原始日期和遗产权利。
- 丧偶后新交往仍需另一人答复；原址遗产、现金守恒和重复领取拒绝另行核验。

这些规则回归不代表真实模型已在多年运行中自主完成所有关系道路，也不表示批次 2 整体验收已经完成。
