# 有限遗嘱与安葬意愿

这是[批次 7](roadmap.md#批次-7-孕产晚年与身后意愿)的有限游戏规则切片，不是完整遗产法或现实法律建议。已接通居民本人写下、另一位成年人独立见证、死后实际查阅、现金遗赠的分别同意与接受，以及自愿实际搬运安葬。不会任命执行人，不替任何人作决定，不启用新的健康风险。

## 生前本人签署

有决定与表达能力的成年人，到自己已知的真实公共会馆登记处，填写自己的 1–80 字墓志，可另向已认识的一位居民写下 1–200 钱的现金遗赠上限。没有现金遗赠时金额为 0。文书不是生前赠与，也不冻结或增加随身钱物。

另一位具备能力、清醒在场的成年人收到具体条款，另选见证或拒绝。见证人不能是现金受赠人，可以是另有继承权的家人，但其见证绝不代替后来的继承人同意。草案有效 60 游戏分钟；见证时，立愿人还须在原处、有能力并在世。未见证、被拒绝或失效的草案不会生效。

本人在世时可以撤回。修改通过新草案及新的独立见证完成；新草案尚未成立时不删除旧有效文书，生效后旧版留档并标为被替代。死亡仅保留既有事实，不能补签、改写或自动提出任何安排。见证不授予监护、财产管理、执行或替代决定权。

## 有限现金遗赠

原亲属继承规则保留。遗赠只能由指定受赠人主动接受，且同时满足：

1. 本人已经取得亲见或实际查阅的死亡证据，再到原会馆亲自读到完整文书，包含受赠人、金额上限、墓位偏好与墓志。见证不是死后查阅，听到死亡消息也不是核实。
2. 遗产仍未分配；既有工资、共用钱物、租约、预付款、经营和其他待返还权益完成原清算，原债务先处理。
3. 没有未出生或未成年受保护继承人。每位当前按原规则有权继承的成年人，都有决定与表达能力，已自行查阅并独立同意这一受赠人和金额上限。一个人若同时是继承人与受赠人，仍要分别同意及接受。
4. 最多交付本人写下的上限与净遗产现金四分之一的较小整数。四分之一只是额外限制，绝不是绕过家属权益的授权；现金少于 4 钱时不能交付。不改变实物、房地、债权或其他资产的原归属。

继承人可以明确反对，受赠人可以拒绝。读过文书后的独立拒绝不要求回到登记处，提交时立即生效，不能附带其他行动；不取消本人的不相关出行或工作。若现金尚未交付，两者均结束这份现金遗赠，保留安葬意愿。已完成交付不倒退，其他人的更早拒绝不被覆盖，远方居民的停止选项也不会据此自动消失。执行时重查全部条件，随后用原账本一次转移实际钱款；记录实付、上限和部分未履行原因，不补钱、不负债、不追索孩子。

**普通继承不等待遗赠。** 任一原继承人按既有规则开始登记份额时，未接受的遗赠记为未履行，全部剩余资产继续原分配。无人同意、受赠人不来、未成年保护、缺钱或债务未清时不会自动换人执行，也不会将家属资产无限期扣留。没有原继承人时，未遗赠的余产继续保全，并不自动转为公产。

## 安葬仍需真实劳动和空间

文书默认希望在实际可用空墓位安葬，可写自己的墓志。只有立愿人实际在墓位附近观察，才有指定具体墓位的选项；记录偏好不预占墓位，不保证几十年后仍可用。登记处远离墓园时可使用普通空墓位意愿，不能凭全知目录指定远处位置。

读过有效文书并已经知道死亡的人，可以自主选择按其意愿安葬。沿既有流程亲自找到遗体、完成接出准备、走过室内外路线、运到仍然空闲的真实墓位，再完成安葬及额外 30 分钟墓志工作。指定墓位已占、所有墓位满、路阻或搬运中断时，行为失败或停在真实位置；不替换已有身份、不增加容量、不瞬移遗体、不自动改选。

普通安葬仍是另外的自主选择。已读文书时，菜单明确标注普通安葬不采用该文书的指定墓位或墓志。记录区分实际按文书完成与普通安葬，并不将偶然使用某处墓位解释为知晓或遵从遗愿。暂存、亲属墓志、修墓仍按各自原有规则执行，不因此获得公共预算或他人物资。

## 知识、重载与观察

生前草案只向实际在场的立愿人和受邀见证人留下私人事实。远处家属和受赠人不会自动收到死亡消息或完整文书。死后查阅需要本人证据及真实到场；不把登记目录当成远方财产、能力或同意状态的实时信息。

读过文书后的赠与选项使用本人上次查阅的身份与结果，隐藏的远方能力、钱款、待返还权益改变不会直接改变选项。居民可以到原处尝试，实际抵达后才重验，并可重新查阅了解已变化的结果。旧版本行动、重复支付、途中存档和已先办理的继承均按当前事实拒绝，不补造同意。

旧档只增加空记录容器，不代写意愿、不推定见证或同意、不补发钱物。草案、版本、独立签署、实际查阅、拒绝、实付和安葬结果保存，并保留对应历史证据，避免日志精简后丢失。观察墓园面板可核对这些事实，明确这是观察视角，不是居民共同知识；所有名字和墓志文字转义，读取不修改世界。
