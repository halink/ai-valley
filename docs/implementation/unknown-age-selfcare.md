# 未知年龄的本人最小自理

## 复现与边界

异常出生资料经兼容 `ageYears` 返回0，原最终菜单和提交闸门把清醒、具备决定及
表达能力的人当作幼儿，连吃自有食物、睡已有床位、等待和普通移动都不提供。
旧运行时测试还明确保留了这种无自救菜单状态。本次不修补出生日期、不推定成人
或幼儿、不修改生命周期阶段、能力、原签署、产权或存档格式。

先写合成 seed5401 的主回归：初始13项中12失败、1通过。失败覆盖缺失、null、NaN、
正负Infinity、数字字符串、未来和不安全出生时间的真实最终编号菜单，以及运行时
自救保护。后来新增边界用例，不把只通过辅助函数当作正常行动完成。

## 限定权限

- `unknownAgeSelfCare` 是由当前世界生成的独立窄菜单，不用仅供显示的 `knownAge`
  字段授予权限。未知年龄者必须在世、身处谷内且真实具备决定和表达能力。
- 只可吃本人当前携带的真实可食用库存；不取他人、公共、家庭共同账户、遗产或
  店铺物资，不开放采集、烹饪、代理、行业工作、交易或新床位分配。
- 睡眠仅使用本人已知、未毁坏、仍有合法使用权且确有床位的建筑；登记住处和
  已有公共临住/住宅租约分别核对，不新签约、不续期、不凭 ownerId 代替床权。
  实际室内床槽、门口位置、出入及室内路线均须存在，不能靠旧路径凭空到达。
- 等待仍须本人选择时长。移动沿普通物理路径和实时阻挡规则前进，不获取目标
  建筑的进入、领取或生产权限。家庭同行、医疗乘员及船上原限制仍生效。
- 有效年龄未满六岁继续使用原规则，包括正常幼儿生理休息。年龄恢复可信后
  以当前实际年龄判断，不能沿用未知时的权利，也不替本人生成新行动。

提交、开工、每次推进和实际完工前读取当前条件。最后0.25分钟的年龄/表达/
食物/床权变化会停止原行动，食物腐败仍由原库存和批次处理，不产生虚构营养。
未知者开始的行动若后来成为有效幼儿也停止；若成为合法六岁以上则按原规则执行。

## 等待保护

预测先用当前资格过滤正常菜单及运行时缓存的旧菜单，再以普通引擎模拟不确定
路径。随身食物快速证明同时检查五分钟内未来出生日期是否变成有效幼儿。
睡眠的时长输入占位符使用原预测的具体60分钟时长核验，不能把占位值0误作无床。

只有确实来得及以本人食物/床位解除当前危险的路径才具有原180游戏分钟保护。
过期食物、他人库存、失去的床、不可达路线、表达/决定能力丧失和已来不及进食
均不产生保护；缓存菜单不能维持已失效资格。保护不自动选项、不吃饭、不睡觉、
不补物资、不返还伤害；无效回复、重载和能力变化不续原期限。
