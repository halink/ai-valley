# 青少年自有钓具装备

## 问题与最小修复

开拓聚落的捕鱼规则允许满13岁、能决定且能表达的居民垂钓，但未拆封 `rodKit` 的装备菜单、年龄白名单和产业执行入口仍要求18岁。没有实际装备时，捕鱼又要求本人持有可用钓具，导致有本人钓具套装的青少年无法从真实决策菜单走完这条路径。

这次只接通已有捕鱼资格所需的 `industry.equip` + `tool: rod`：

- 开拓聚落满13岁可看到本人合法 `rodKit` 装备选项，最终编号菜单和 `parseChoice` 保留这个选择。
- 本人必须独立选择，实际工作原规则的15分钟，完成时扣本人1套未拆封钓具，创建本人的可用鱼竿。
- 装备完成不会自动提交捕鱼。本人另选真实水岸、鱼种后，仍须走到现场并完成原捕鱼工时，才扣同种鱼群、鱼竿耐久并取得鱼获和经验。

菜单入口在成人分支前仅增加这一种装备选择。`family.ts` 的年龄过滤和 `industry.ts` 的执行资格同步放行，具体能力、本人库存、可用同类工具、真实工时、地点与既有安排冲突仍用原校验。

## 保持不变的边界

- 13岁之前不允许装备或捕鱼。非开拓的既有产业场景保持18岁门槛。
- 斧、镐、猎矛装备，以及制作、修理、升级、领取封存工具、采矿、狩猎和其他成人产业动作没有降低门槛。
- 他人的套装、他人鱼竿或仍封存在原址的工具不等于本人随身物资。没有套装就不会出现合法装备选择，不赠送或补造任何工具。
- 迟到 revision 不接受；选择后丢失物资、能力或出现同类可用鱼竿，原动作不能重复扣料或创建工具。课堂与公共班次冲突继续阻止执行。
- 继续使用原活动、工具、定义版本与执行回执，不增加存档字段或迁移赠品。内存 SQLite 重载保留中途剩余工时，重复计划不重复装备。

这不是青少年自动捕鱼策略，不新增工具转让、继承领取或采购路径，也不改变其他成人事项。菜单沿用既有有界议程和轮转，不新增永久保留槽位。
