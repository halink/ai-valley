# 有限儿童照护与不足议事人数

[实施批次](roadmap.md) · [失去监护后的照护](../design/people.md#失去监护后的照护) · [聚落复苏](../design/recovery.md)

本次是批次 2B 的有限交付，不是完整孤儿接应、监护或整批验收。正常居民决定、世界步进、实际食品与清水消耗、固定到期和人物观察页均已接通。没有改写真实存档、增加人口或向旧档补发物资。

## 当次救急与连续照护分开

- **当次救急。** 眼前未成年孩子健康不高于20、不能自主决定（包括六岁以下）、有实际进食需要且没有明确拒绝，附近没有能及时决定的监护人时，具备决定能力、健康高于30、体力至少10的成年人可以独立选择，用自己完整的一份餐食或芜菁和一份清水完成20游戏分钟的现场喂养。完成时重新核验。它不建立连续约定，不增加一般医疗、转运或监护权限。下次帮助仍须重新符合眼前条件。
- **有限连续照护。** 成年提供者亲见孩子并核实监护缺口后，可提出从提出时刻起24游戏小时、最多四次喂养的自愿安排。提供者和独立成年复核人须在合法可接触的同一现场。没有登记监护人、双方各自持有监护人死亡证据，或双方亲见原监护人当前失能时可以办理；未知缺席、传闻或单纯读取远处状态不能替代证据。
- **分别决定。** 提供者先提出；指定复核人另行检查；六岁以上且有决定和表达能力的孩子另行接受。复核不能代填孩子同意。暂不能表达的六岁以上孩子保留当次救急，不以新连续约定代替其选择。复核人不得是孩子、提供者、现有监护人及其家庭或经济利益方，检查亲生与收养祖先、共同祖先、当前伴侣、家庭资金、有效雇佣与借贷。
- **到场后再做。** 生效不安排自动工作。每餐仍是提供者自己的新决定，耗时20游戏分钟，并按实际食品营养和原批次扣除自有库存。水不足、食物已腐败、孩子离开、房间不合法、拒绝、失去能力或固定期限到达时不完成喂养。既不动用孩子的遗产或账户，也不动用公共储量或金库。

约定不改变父母、监护人、居留、床位、房屋、田地或其他财产，不产生债务、费用、养老金或公职。住房、护送、医疗、财产代管及永久监护仍走各自程序。现有一般监护交接须有仍有资格并在场的原监护人；旧版无原监护人提议也不能通过迟到接受转为永久监护。

## 到期、异议与知情

孩子（有自主决定能力时）、提供者、复核人和原监护人可撤回或提出异议。原监护人恢复、监护关系变化、孩子达到独立答复年龄或成年、当事人资格失效都会停止原权限。固定24小时及四餐计数跨重启保留，不因开始执行、查看、跨日或无效答复重置。额度用尽后已吃掉的物品不退回、不补发。

全局观察端可查看真实状态，但不会把远处的退出、死亡或恢复自动写入个人记忆。个人仍可到曾亲见的位置探望，也可撤回自己的参与；看到孩子不等于已经收到远处复核人的决定。探望不追踪孩子的远处位置，也不产生进入私人房间的权限。有限救急没有强行入屋或把孩子搬到别处的能力。

人物档案显示提供者、孩子、复核人、单独同意与复核状态、四餐额度、真实消耗和结束原因。实际每餐有审计事件与回执。

## 不足议事人数的界限

新增公共税收、支出和常规授权的议案，至少需要三位登记成年常住选民。提案时固定并去重选民名册，临时失能不移除其代表份额。至少两张独立赞成票、原名册的法定人数及多数条件须同时满足；只有名册内明确的布尔选票计票。旧档一人或两人名册不能借迟到计票获得新权限。

少数居民仍可自愿使用或捐赠自己的物资和钱款，按原有效条件使用共屋限量现物救助；已经生效的有限预算和合同按原金额与期限继续履行或到期返还，不自动扩额、续期或获得新地权。三人最低名册与两票最低赞成是当前明确执行的开拓议事底线，不把“缺少成年人”变成任何人的概括行政权限。

## 验收与剩余缺口

隔离旧档等价场景和正式九人世界均通过普通最终菜单完成提供、独立同意、复核及实际喂养，核对人数、钱款和产权没有增加。覆盖原监护证据、直接和隔代亲缘冲突、拒绝、恢复、生日、腐败、断水、换位置、非法房间、重复提交、四次上限和数据库重载后到期。另核对单人/两人镇、畸形选票、不变的选民分母与既有预算。
