# 访客旅途中实际进食证据

## 本次覆盖与实际扣减

本切片沿用默认关闭的食物证据入口，新增独立 `journeyMeals`，只记录以下两种已成功完成的本人随身进食：

- `visitor-journey`：本人选择 `visitorJourney.eat`，停步五分钟后，在 `advanceVisitorJourneyNeeds` 再次核实原随身食品，实际扣除一份，缓解本人饥饿，并产生原有完成事件。首次尚未入谷、身份仍保存在 migration contact 的访客和已有居民记录的返访者均使用原本人身份。成人亲属同行中的本人独立进食沿用此路径，不代记家人摄入。
- `visitor-aid`：本人选择 `outsideAid.eatMail`，停步五分钟后，在 `advanceVisitorAidNeeds` 实际扣除一份本人库存、缓解饥饿并产生原有完成事件。证据以 `action: visitorAid, operation: eatMail` 标明此路径，不把求助信、接信、发货或收到食物当成摄入。

两个路径的提供者与受益人均为本人，来源是 `person:<providerId>`。收据包含原旅程ID、真实完成事件ID、完成时刻、实际食品数量、可知原批次与营养，以及进食即时饥饿前后和实际缓解。它们不经过镇内普通计划，因此不虚构 planId，也不虚构不存在的动作定义版本。选择进食、等待、休息、继续、折返及未完成暂停均不发供餐收据。

原营养来自食品批次，而不是当前食谱或饥饿下降反推。低饥饿被截断到零时，实际缓解可以小于摄入营养；同一步随后增加的代谢饥饿不计入即时进食效果。原定义缺失时，模拟仍沿用既有 `foodValue` 回退，但证据营养保持 `null`。原批次缺失、同一步初始化修补或原批次数量与实物库存不一致时，原批次与营养均保持未知，不能把修补记录当成原批次。后者尤其避免初始化先裁掉最早批次后，错误地将其归给这次进食。

## 该切片的边界与后续独立扩展

已检查 `family-relocation.consumeRation`：它在一个食品事务中按成员顺序，从各自签署的 provider 库存扣减 meal 和 water，按同一提供者先前已扣份数计算每位成员的营养，再缓解对应成员饥饿。出发、符合条件的重新启程及每120分钟行路检查可以实际扣除口粮。到达登记只核实预留食品，不是再次摄入。

本页原切片没有为家庭迁居加入收据。后续[家庭迁居逐成员供餐证据](family-journey-meal-evidence.md)已用独立 `familyJourneyMeals` 覆盖多人同事务的原批次区间、重复供给者及无独立供餐事件的行路场景；不借用本人供餐字段，不将整组库存扣减复制给成员。旧 `journeyMeals` 覆盖不能当作新切片已观测。其他旅途/商旅消费、`emergencyCare`、其他尚未列出的供餐和动物饲料仍未覆盖。普通 eat、care、tendChild、longCare、加工与腐败仍是各自已有的独立切片，不合并成完整消费账。

## 可选观测、提交与旧记录

捕获只关联一次同步引擎调用的原 World 对象，使用 WeakMap 并在 `finally` 清理。预测副本不继承捕获，世界、居民知识、菜单、存档、旅程时钟和自动行为均不新增字段或动作。关闭观测与开启观测对完整世界深比较相同。

成功物理扣减后才准备收据，并绑定原有完成事件。运行时仍只在 `WorldStore.commit` durable commit 成功且安装已提交世界后发布 `food_step_committed`。失败提交或版本竞争不发布草稿收据；恢复后只记录真实完成一次。捕获本身不是回滚器，失败草稿由原存储事务隔离。观察器或 writer 失败不撤销已提交的模拟，但不能继续声称证据完整。

旧 schema-1 记录可以没有 `journeyMeals`，缺字段表示未知，显式 `[]` 才表示本次有限范围已观测零次。零步会话、缺边界、漏步、失效关闭、缺封存或损坏均不产生完整新增总量。日报分别保留观察分钟、未观察分钟、原始收据和可用总量；缺测后后续零次不能修补当天完整性。收据按 `(fromMinute,toMinute]` 归属，午夜完成属于刚结束的一天，不凭空补日期。

严格白名单拒绝额外字段、访问器、符号字段、数组空洞、非法身份、非有限值、动作与操作不匹配、非本人提供、错误容器、非一份可食用输入、过期批次、数量/营养不一致或不可能的饥饿差。原批次营养已知时，还按这两条既有路径的实际公式核对饥饿下限截断；营养未知时不利用饥饿变化补造营养。审计独立检查会话连续性、修订顺序、重复完成事件以及跨切片重复。审核器不连接世界数据库重建历史，不能对任意输入的真实性作签名担保；实际身份和扣减由引擎与提交回归验证。
