# MVP 个人名义两日营养缓冲

## 范围与来源

连续世界的 112 日及有界续段中，四人保持健康但末态根菜/餐食为零，只有少量野食，未证明冬储充分。本片仅调整本地规则的低优先级补给偏好；不改引擎权限、气候/农业数值、自然恢复、食物损耗、居民压力、模型或公共种源。原全年证据不因此重标。

## 计算与边界

每人 `D=1440×本人绑定生理规则的 hungerPerMinute`，名义目标 `2D`。当前默认为 109.44 营养。纯读取绑定和默认值，不调用会注册定义的 physiology helper；显式坏需求参数拒绝，不用 null 回填默认。

只计本人实际整份、引擎 eat 允许的可食库存，不计种子、他人、公库或未来收成。一般食品按引擎 foodValue 的实际批次/营养计量。当前可播新作物仍以有田 N 的私人目标 N+1 规划，N=0 时目标0；根预留为 `min(持有整根, ceil(max(0,目标−持种)/2))`。已有3或4份种子满足两田目标时，不再预留根。legacy 根保留原无种时1根政策，不扩张为新目标。

预留不是仓库锁或具体批次预约。存在不同营养批次且有种根预留时，估值取剩余可食数量中最低营养组合，避免高营养根被留种后仍高估食物。无批次MVP普通库存数值不变。所有被计入批次都验证非负有限数量与营养。

普通进食**保留此前规则**：无同种种子时至多保留一根，饥饿达到80时可食用这最后一根。不让完整规划留根成为新增饥饿门。缓冲估值和烹饪规划可以更保守，但不强迫居民饿到紧急门才吃原本可吃的根。

`nominalDays=计入营养/D` 只是库存折算，不是断供生存保证。既有饥饿35吃42餐可能截断浪费，未改进食阈值；名义两日目标不等于28日冬储或春首收前供给已足。
