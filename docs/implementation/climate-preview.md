## 本批冻结的 Interface

- 纯 `climateAt(seed, minute)` 仅由种子和旧引擎已提交的分钟端点计算可序列化环境快照；没有第二时钟、模型调用、设备时钟或可变随机源。
- 单一 `mvp.environmentPreview` 字段只在临时规则演示的观察快照出现，不写入 `World`，不送给居民模型，不进入持久入口。
- 原 `world.weather`、旧作物、资源恢复、居民需求与规则选择不改。界面明确“环境预览，不影响旧制作物”；当前可见新天气不表示旧田受到新雨雪灌溉。
- 时间量化采用整数微分钟，消息十进制字符串；版本、种子、时间非法必须拒绝，不能回填零。参数和查表定义由核心模块锁定版本与指纹。
- 暂停或相同时间反复取快照不改变环境；只读取样、JSON 往返和模拟克隆无真实副作用。纯环境快照不生成“居民已获知”或持久雨事件。
- 模块只有无副作用计算 Interface；没有写库/费用/发送器/调度能力。生产存档 schema 没有变化，因此也不在本批“迁移”或补发任何种源。
