# 新开拓聚落的三日口粮

这是实施批次 1 中已交付的新档配置。适用于以后由 `createFrontierWorld` 创建的九人正式开局。读档、重启和旧档规则初始化不会补发口粮，也不改变既有人物、产权或时间。

## 数量与期限

每位居民，包括三个未成年人，独立携带 2 或 3 份浆果、1 份餐食和 5 份根菜。这些食物可直接吃，不依赖成人下厨、另付钱、领取公粮或收获尚未成熟的作物。

按当前食物与生理定义，每人每天增加 54.72 点饥饿，需要至少 164.16 点营养覆盖三日。每人的起始食物含 166 或 178 点营养，九人合计 1,542 点，约 28.18 人日。只计算各人真实携带的库存一次，不计野外资源、牲畜产物、商人库存或公共账面余额。这里的人日表示可食营养量，不保证居民会选择及时进食或补充物资。

食物批次在创建世界的到达时刻登记：餐食三日、浆果四日、根菜十四日到期。三日末餐食会变质，须在此之前实际吃掉。保质期会随存档保留，重启不会刷新。以后调整营养或生理定义时，须同时跑逐人三日余量测试，不能只比较食品份数。

## 后续来源与边界

每位创始居民都能从正常行动菜单选择附近已知、可达且有现物的可再生浆果。聚落另有现成钓具与可达河岸；当浆果耗尽，持有钓具的居民仍可选择实际捕鱼。鱼群有限，获取需要时间、工具和居民的自主行动，向其他人转交渔获也仍需实际交付。这些潜在来源不计入三日开局储备。

这项变更不等于跨季供给验证，也没有开启自动补粮、自动进食或共用家庭背包。正常决定中的两日口粮提醒见[可达口粮的保守估计](food-coverage.md)，不把上述潜在来源当作已经取得的储备。求生决策保护和旧档救急的完成状态见[实施批次](roadmap.md)与[复苏设计](../design/recovery.md)。

## 可复验检查

运行 `node --import tsx --test tests/founding-provisions.test.ts tests/frontier-livelihood.test.ts tests/food.test.ts`，无需模型密钥。

- 三个新世界种子逐人核对实际营养、原库存、有效期限与合计至少 27 人日。
- 九位居民均经正常决策菜单亲自进食，核对库存与批次同时减少。
- 序列化后食物继续按原时间变质，重复初始化不补发、不延长期限。
- 旧开局等价库存连续重启两次，验证耗尽的口粮、身份、家属、住处、产权和时间保持不变。
- 验证每个人的野果路径，以及浆果耗尽时实际存在的捕鱼选项；捕鱼结算另由已有生计测试覆盖。
