# 普通 G1：一次本机选题意向

现有普通持久规则开发入口可显式配置 `privateOrdinaryMultiSelectionIntent: {scope: "ordinary-native-g1-selection-intent/v1", originalScope}`。只用于手动推进的已有普通原档，须同时配置原生多果批、菜单和现有本机内存选择器；不适用于 V3 开发原档、封存档、季节或生产。原档范围使用已有 `ordinaryG1DecisionSaveScope` 核对设备号、inode 和单链接；收到外来范围或字节复制档不接纳。没有新端口、HTTP 路由、真实模型或玩家按钮，也不更改默认启动。

临时签章除了原匿名菜单和应答令牌，还锁定已持久提交的原始压缩世界头与原生闭雨标识。内存替身不会收到头、许可、雨点、身份或归档密钥。接受签章后，在同一原档的 `BEGIN IMMEDIATE` 事务内重新读当前世界、果批、地块、原生闭雨及当前公开天气许可，追加一次意向与同库完整性锚，复核世界与许可后一起提交，最后才调原内存替身。校验在提交前失败时两份记录都不留下，也没有派发。

机会按该原档中的原生闭雨去重，不按签章、一次性令牌、果源候选编号或授权版本。意向提交即消费**本机选题尝试**，即使取消、异常退出、应答未知、撤回后重新授予许可或重开也不在这次闭雨重试。每档最多 32 笔；满额、表或锚损伤、复制件均关闭此选择功能，不阻塞世界推进。已写过此意向的原档也不能通过省略选项回退至旧选择器；未有该证据的普通档旧选择器保持原行为。

回复仍只存在于当前句柄内的隔离预览。意向不是成功应答、执行排期、配额占有、授权、居民动作、落果或库存变化。只依靠原文件协作锁和同库见证，不防有权限者把同一 inode 完整还原到意向之前的备份、同时删除两处证据、重新指定可信根或绕过锁；真实生产反回档仍需要独立登记源。无真实模型调用，也不构成功能提测或 G2 放行。
