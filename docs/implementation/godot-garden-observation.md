# Godot 菜园现场观察

基于 `0ad213b` 的统一美术与观察界面，补齐已有小菜园的只读观察入口，不增加居民指令或改变模拟规则。

## 观察闭环

- 点场景中真实菜园的土畦、木框或植株，或在「场所」选择菜园，即可查看场景卡。场所册使用土畦插画，区别于共屋。
- 场所册选择会定位菜园；从室内选择会先回到室外。居民、建筑、菜园选择互斥，空地、全景、收起和 Esc 可退出相应观察。
- 所属居民、空田、实际生长天数与定义所需天数、成熟、今日浇水和当前雨况均来自快照。不会猜测未来产量、收获时间或居民意图，不改变居民的可见知识。
- 日志仍展示真实播种、浇水、收获与烹饪结算；观察卡不是新的历史数据库。成熟表示当前作物满足定义，不表示已经收获。
- 断线隐藏现场卡，目录标为「状态已过期」；世界切换或菜园消失清空选择。仅显示当前已支持绘制的 `mvp-garden-` 菜园。
