# 求助、地点分享与少年赠粮的同世界回归

`tests/social-help-food-chain.test.ts` 将三项功能串在同一个隔离合成世界中：7岁儿童自行记录、张贴和交托求助；既有商行接受真实木材出口，由实际货运送信；原有镇外成人另选分段来访和旧址探访；成人把途中亲见的浆果旧址当面告诉14岁少年；少年另选核实、采集和赠1份；儿童独立接受，少年完成交付后，儿童再另选进食。

所有选择都来自正式最终编号菜单，并经实际 prompt、`parseChoice` 和相应计划入口；货运、行路和劳动只用 `stepWorld` 推进，不跳写时钟、不直接完成求助/分享/赠粮，也不手写亲见或听闻记录。初始人物位置、年龄、有限物资和既有镇外身份由测试夹具设定。

两项测试分别连续运行，以及在货运途中、分段等待、收到地点、接受赠粮和完成进食后进行 SQLite 内存保存/工作集重载。检查包括：

- 全部物理容器和有限浆果株合计守恒，货运预留不重复计算，钱币与人物身份不增减；只有最后实际吃掉的一份使浆果总量减少1。
- 信件沿旧址，不随远方儿童的位置、死亡或监护变化更新；成人到旧址找不到已去谷口的儿童，不自动追踪。
- 少年听闻时没有亲见、已知资源或采集选项。远处资源删除不会改变其上下文；亲自核实以后才能采集。
- 提议、接受与真实交付分离，涉未成年限1份，交付保留采集原批次；收粮不等于进食。旅途停下、收信和经过时间均不代替下一次选择。
- 重载不重复送信、分享、赠粮或进食，全程不新增照护协议、住房、亲子关系或监护人。

专项运行与包含测试代码的类型检查：

```sh
env -i PATH="$PATH" HOME=/tmp node --import ./node_modules/tsx/dist/loader.mjs --test tests/social-help-food-chain.test.ts
env -i PATH="$PATH" HOME=/tmp node ./node_modules/typescript/bin/tsc --noEmit
```

本回归显式代选合法动作并阻止 `fetch`，不读取 `.env`、密钥或真实存档，不调用真实模型。它证明跨功能规则链与重载边界，不证明模型会自发选择这条链，也不替代浏览器、真实模型长期生存或完整账本验收。各项反例继续由儿童捎信、地点分享和少年赠粮的独立专项负责。
