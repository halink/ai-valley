# 谷灵全量开发交接门槛

设计以 [谷灵](../world-upgrade/GUARDIAN.md) 和相关决策记录为准。**只有 G0、G1、G2 的设计功能全部实现，且开发侧完成本地单元测试与快速功能验证后，才可交给测试组。** 允许独立提交和备份，但中间批次只记为开发进度。详细、长时间及跨浏览器测试由测试组或项目所有者安排；测试源码和执行产物不提交。

| 阶段 | 交接前需有的实施证据 |
| --- | --- |
| G0 客观观测与模型年鉴 | 持久来源、明确缺失、时间和来源可复查；模型只接当前允许的版本化字段（发送字段快照与权限版本可追溯）；发送前、发布前及各读取面重验；无模型时显示客观记录，不冒充模型；更正、撤回、异常中断和恢复有明确状态。 |
| G1 选题及沙盒 | 只读选题、依据和配额；结构化候选、证据、版本、截止、成本与冷却；隔离预检不会改写真实存档、通知、知识或预算，候选不具执行权。 |
| G2 雨后落果 | 权威已发生且持久的雨事件，成熟果源和目标现场合法；源扣除与地面增加守恒，归属不变；居民仅现场发现、自主拾取；版本无关的机会标识、同事务的收据和结果、防重及中断恢复；提议、效果、发现、拾取分别记账。 |
| 横切保障 | 共享账户限额与居民优先、具体类型的批准和默认关闭、版本未知时按影响隔离或暂停、关闭后仍能解释既有效果。以合成输入及注入替身验证，不调用真实供应商。 |

可以实现并验证默认关闭的能力，不能把“具备实现”当作“已启用”。真实模型调度受现行账户授权、共享准入与失败恢复约束；G2 生产执行另需单类型批准。交接时须列出确切版本、启动方式、可重现步骤、预期结果、未验证范围和哪些能力保持关闭。
