# ValleySpirit G0：独立的公共天气手记

这是首个客观观察切片，不是模型年鉴或世界干预。仅接持久规则小山谷入口；不会读取模型配置、调用模型、改天气种子/库存/居民，也不向居民广播记录。

## 已实现接口

`publicWeatherProjection` 显式复制版本、世界身份/提交版本、模拟时刻和当前公开天气数值。无原始 World、事件全文、居民身份/意图/信念/谈话、自然 seed。独立 `ValleySpiritJournal` 只接受该字段白名单。

在权威世界提交成功后，每游戏小时最多留一个实际观察时点。晚启动或停机不会补造缺失小时；时间范围的起止都等于该真实时点，中文模板明确不代表整日天气。固定模板仅陈述事实，标记 `generatedBy: fixed-factual-template`。每条记录保存 sourceRef、全部允许字段、投影/权限版本及世界提交版本，不依赖会被裁剪的 world.events。

持久快照新增 valleySpirit，Godot 的“谷灵”页签显示最近六条当前允许记录及来源标识。`GET /ai-town/api/valley-spirit/source?ref=...` 解析具体持久来源；未知、撤回、隔离统一不可读。没有公开的权限变更 POST，也没有行动/物资/天气写接口。

## 独立持久与故障

旁路事实文件位于已有世界数据库旁；权限锚点在同一世界 SQLite 的独立 `valley_spirit_permissions` 元数据表中，不改变 World JSON。二者复用同一个世界运行锁，不开第二世界进程。权限连接先只读检查表/行格式，未知格式只隔离 G0，不修改或重建，不影响世界表的正常提交。文件必须为单链接常规文件，拒绝符号链接；只读校验版本、世界身份、时序、白名单、模板与来源后才可能写。原子替换前重新核验原内容，临时文件先 fsync，替换后 fsync 所在目录。文件大小上限 16 MiB；不自动删除旧来源。

世界与手记不是同一事务。世界先成功提交，手记再采样；手记故障只隔离自身，不能使已提交世界在内存回退。故障期间的观察缺口不伪造恢复。未来版本、坏结构、世界不符、源世界回退或并发外部改写都保留原文、禁止发布/覆盖；世界继续。写入失败同样隔离，不能把未知提交结果当正常手记继续发布。世界回滚至早于手记的快照时需明确处理该独立历史，不自动拼接两个时间线。

## 权限与未来模型入口

首版公共范围仅为全图共同天气。内部管理方法 `setPublicWeatherAllowed` 先以 CAS 在 SQLite 权限锚点提交新 permissionVersion，再更新 JSON 版本副本；读取、来源解析、未来公共输入包和当前输入重验统一使用当前权限。撤权后历史不可读取，旧输入包失效；重新启用使用新版本，旧版本记录不自动复活。撤权锚点成功但 JSON 更新失败时也必须关闭全部读取，重启不得用旧 JSON 重新发布。恢复旧 JSON 与当前锚点不匹配则隔离；已有锚点却 JSON 缺失、已有 JSON 却锚点缺失，均不默认重新授权。只有两者均未初始化的首次采用可登记默认公共天气范围。已交给观察者的屏幕/字节无法被追溯收回，后续请求与当前客户端页签会更新为不可读。

此保证保护“当前权威世界/权限锚点仍在时恢复记录文件”。若把整个权威数据库连同权限锚点一起恢复为旧版本，属于权威恢复操作，需要另行确认撤权状态；当前没有外部不可回滚的权限服务，不能声称抵抗任意全库回滚。

`publicNarrationInput` 只输出带来源与权限版本的公共包，并硬标 `dispatch: disabled`。`isCurrentPublicInput` 只校验来源与权限仍有效，不代表生成文本已通过事实核验，也不授予发送或发布权。真正模型叙事下一关仍是：共享账户准入/费用身份、持久请求及发送未知恢复、发送前和发布前重新校验、生成文本引用/事实校验。当前没有调用、不另建模型预算，现有气候世界模型入口拒绝门保持。

## 验证范围

局部验证覆盖白名单/纯投影、按小时幂等且不补缺口、裁剪事件后来源可解、撤权对来源/输入包/重启有效、重新启用不复活旧来源、未知版本/符号链接/世界回退隔离、真实 HTTP 来源读取与 POST 拒绝、SQLite 重启不改变世界，以及独立手记故障时世界继续提交。临时检查放在忽略的 output 中。

权限锚点补充用例覆盖恢复撤权前 JSON、删除 JSON、权限已提交而 JSON 写失败的全部读取/重启门，以及未知锚点格式保留原文而世界继续。

整批 30 分钟、真实画面布局、长期文件规模及模型表现均需分别记录，不由局部检查代证。
