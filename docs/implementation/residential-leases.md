# 空屋单人有限住宅租约

本项补上[第 3 批](roadmap.md#批次-3-本地产业与公共供给)住宅租赁的第一段闭环，复用[营业场所租约](premises-leases.md)的双方确认、托管账本与有限结算。**只支持空置私人住宅供一名成年人临时住宿，不代表完整住宅租赁或第 3 批验收完成。**

## 当事人与真实床位

- 产权人在现场向自己认识的成年人提出具体报价；承租人亲到原址，独立选择接受或拒绝。报价只保留两日，产权人可以撤回未签报价，不能撤回已接受的租约。船上、医疗搬运中或家庭同行中的旧岸上坐标不算在场。
- 只接通完好、有真实可达第 1 张床的私人 `home`。签约前须没有登记住户、在世人物的原住房登记、实际室内在场者、床位占用、家庭迁居、照护、建设、经营、受保护代管或共同财物冲突。共同安排即使已关闭、拒绝或过期，未取走的钱物与待交付赠与也须先处理。接受时再次检查，失败不扣租。
- 一处建筑同一时间只承诺一份租约，一人只接受一份未结清的住宅租约。全屋其余床位暂不开放给新增永久住户或其他家庭，避免首版跳过租客的同住意见。租客仅取得固定第 1 张床的有限全天使用权，不取得厨房、工位、店铺、产权、永久入住或邀人同住的权利。
- 不改本人 `homeId`、建筑 `residents`、居留身份、亲缘、监护或个人物资。原来已经接受的“回自家床”安排继续指向原家。租客另选带明确建筑身份的睡眠，室外路程和室内走到床边都消耗实际时间，门口不能恢复睡眠体力。
- 有效租客实际在室内时，有限住宿权也被现场交互识别。双方仍须各自有使用权、处于同一房间并有两格内可达路径；紧急照护、交往回复和可信丧讯仍各自核验当前权限、拒绝、能力或清醒状态。租约失效后，即使身体还在原处、结算尚未更新，也不再凭旧租约授权。详见[跨系统复现与回归](residential-social-integration.md)。

## 有限钱款与结束

租期 2–28 日，日租 1–100 钱，押金 0–1000 钱，完整租金及押金先进入原有独立预留账户。住宅条款固定为全天，不接受改成一段每日工位窗口。其他费用、转租、续约、自动扣损及自动续费均没有接入。

按实际经过租期累计取整支付租金，到期、承租人自行到原址交还、承租人死亡/迁出、住宅损坏或产权变化时，只付实际应挣租金，全部押金和未挣租金退回本人或其遗产。房主死亡后原产权尚在时有限租约继续，已挣租金归其遗产；未结清权益阻止提前分配。结算账户暂未建立时先记实际停止时间，重试不会多收租。

租期失效立即停止继续睡眠的权利，但不强制把身体搬到门外，不移动背包，不强迫迁入另一处住所。住户之后怎么走、睡哪里，仍由本人选择。结束记录与原到期条款均保留，持久收据防止重复扣款、退款或重载后重复履行。

## 正常决策与观察

- 沿用 `premises.offer / accept / decline / withdraw / surrender`，住宅报价只提供 `days / rentPerDay / deposit` 三项可改变的经济条款。身份、建筑、用途和固定床位由原菜单锁定。
- 正常最终菜单保留接受和拒绝，也可独立选“到租用床位睡两小时”。只读租约观察卡分别显示住宅或经营用途、双方、原期限、预存、已付、退款和余款。
- 远离原址时只保留自己原已签条款和回访方向；远方损坏、产权变化不能通过菜单消失自动泄露。本人明确自行交还后不再提示回访原租约。观察页展示全世界事实，不替居民行动。
- 旧档没有租约时只初始化空列表，不补钱、不虚构住房或过去同意。既有经营租约的条款与收据继续有效。

## 验证与剩余范围

### 继承后的空置核实（2026-11-07）

死亡流程会从建筑 `residents` 中移除逝者，但保留其 `homeId` 作为最后登记住宅，也继续供真实继承寻找旧宅。原租赁检查把所有人物的 `homeId` 都视为现行住权，导致成年人亲自接受继承后，真正空置的旧宅仍不能报价，正常决策菜单也不显示出租。

现在只把在世人物的 `homeId` 视为住房占用，不清除或改写逝者的身份、旧宅及身后档案。此例外不等于清空住宅：非空的建筑登记、实际室内遗体或活人、床位占用与各类既存承诺仍阻止出租。在世人物即使远行、在船上或暂不在谷内，其仍保留的原住房登记也不会因本次修复被略过。出租人和承租人仍须亲自办理，船上、医疗搬运、家庭同行或接送中的旧坐标不能签约。

继承住宅专项（历史路径：`../../tests/inherited-residential-leases.test.ts`，已移除）通过真实死亡及亲眼获知、本人接受继承、正常最终菜单报价和独立接受、计时走到租用床位睡眠，验证不是直接改产权或清除 `homeId` 的夹具。SQLite 内存数据库分别重载死亡、继承、报价、接受和到期状态，验证旧宅历史、租约权利、钱币守恒与重复收据。边界回归同时检查报价和接受阶段的活人登记、在途、实际室内在场、床位及家庭/照护/共有/受保护权利，失败时世界不变且不扣款。正常菜单和重载链路在修复前均已复现失败，修复后通过；新增独立反例与复核结果见[继承空屋独立复核](../reviews/inherited-residential-leases.md)。

本次新增 6 项实现者专项及 4 项独立反例；独立复跑住宅/经营/社交等 5 文件 **59/59**，另跑继承、世代、丧讯、安葬、家庭、共财、照护、代管、借住、迁址、经济及房间等 20 文件扩大回归 **267/267**，均通过。集合相互重叠，不相加；这些结果不是本轮统一全量验收。
