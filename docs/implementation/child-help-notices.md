# 儿童照护求助与来访者按址探访

这是批次 2 的一项有限连接：让已经实际入谷的人有机会在谷口读到儿童照护求助，再自行到原址查看。不代替[现有有限儿童照护](emergency-child-care.md)，镇外消息可达另见后续[有限货运捎信与独立来访](child-help-mail.md)，两项均不表示住宿或永久监护已经完成。

## 每一步分别选择，信息实际移动

1. 6 岁以上且能决定、表达、观察的人，可以在合法现场为亲见的未满 6 岁幼儿记录求助。自己已经达到独立答复年龄的孩子也可为自己记录；不能替其他 6 岁以上孩子公开需求。记录要求本人证据：没有登记监护人、本人已获得的监护死亡证明，或亲见所有原监护人当前失能。未知缺席不能当作无监护证据；孩子明确拒绝时不登记。此步骤不要求报告人有饭食或有第二位成年人，因为记录只请求有人来查看，不成立照护权限。
2. 记录包含当时亲见的孩子身份、原位置和时间，从该次观察起固定 24 游戏小时有效。原报告人另选、实际走到已经知道的谷口，花 5 游戏分钟张贴。未张贴的记录留在本人处，不会被访客或镇外商人读到；报告人死亡也不自动完成张贴。
3. 实际来到谷口、能自主决定且清醒的居民或访客可以选择阅读，实际到公示点花 5 分钟后获得原信。正文明确为过去的观察，不证明孩子仍在那里，不把原报告人的死亡证明转交为读者的法律或亲见证据。读信不等于答应照护。
4. 每位读者可另选一次按原地址探访。实际寻路和室内移动耗时，原信不会追踪孩子的新位置。私宅、失去使用权或毁坏房屋不因求助开放进入；到门外只能记录没有找到可合法接触的人，不揭示屋内状态。公共或已有合法使用权的房间仍须走到原室内地点。
5. 如果合法见到孩子，既有正常菜单才依据当前情况提供现场救急或限时照护。喂养仍要另选、实际消耗自己的饭食清水；连续照护仍需独立复核及有能力孩子的单独接受。阅读和探访不自动喂养、搬运、占床、定居、任命监护或移动钱物。

## 撤回、到期与知情

原报告人或已知这份消息、达到独立答复年龄的孩子可以撤回。尚未张贴的记录可由原报告人原地撤回；已张贴的须本人到谷口更正。已离开公示处的读者保留原来知道的线索，不从远处收到撤回、孩子死亡、搬走或监护恢复的新消息。本人再读到更正后停止据此探访；到场仍须检查实际情况。

期限不因张贴、阅读、探访、重新启动或孩子移动而重置。途中到期不能记为已经完成探访。每份原信给每位读者一次探访机会；新的求助需重新现场观察，不能重复执行旧计划或调用原记录制造续期。

## 观察与旧档

儿童、报告人及读者的人物档案增加只读“儿童照护求助记录”：显示未张贴/已张贴/撤回/到期、原观察和截止时间、原地址、实际读信与探访人数。它不向任何居民写入知识，也没有派人或替他人答应的按钮。

旧档没有该记录时按空记录处理；首次真实登记才添加状态，不生成旧信、人口、粮食、床位或过去的救援。完整原信、个人读到的撤回信息、一次探访记录和证据事件随世界保存，引用事件不会被工作历史裁剪移除。

## 验证和明确缺口

[独立复核与最终离线验证记录](../reviews/child-help-notices.md)。

隔离测试通过普通最终选择菜单覆盖：幼儿现场记录、实际张贴、原有镇外人物自主来访、读信、沿路探访、另行提供/复核/实际喂养。另覆盖青少年代幼儿传信、孩子自行求助、未知监护去向、无粮和无人复核仍可传信、无人决定、未张贴、私宅/合法共屋、原地址固定、路阻、途中到期、远方变化不改变个人上下文、六岁生日后撤回的知情边界、重启、重复执行和历史保留。

只使用已安装工具离线验证，不访问真实存档、密钥或真实模型：

```sh
node node_modules/typescript/bin/tsc --noEmit
node --import ./node_modules/tsx/dist/loader.mjs --test tests/child-help.test.ts tests/emergency-care.test.ts tests/opportunity-coverage.test.ts
```

无人能观察或发信、没有实际访客、对方不愿阅读或探访、过期、路阻、私宅无进入权、食品不足或缺少独立复核人时，照护缺口仍真实存在。后续[有限镇外捎信](child-help-mail.md)已经接通报告人另行交托、既有外运实际送达同源居地人物，再由其独立选择分段入谷；仅张贴仍不会自动交托。更多公开地点、访客本人捎儿童信、私宅幼儿接出、跨地点护送、住宿接待和永久监护审查仍未实现。现有驿路食品求助独立运作，不因儿童求助授予商行或货运照护权限。真实模型 15 日与四季长跑未运行，不能用规则回归替代。
