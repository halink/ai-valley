# 居民感知天气与短时避雨

## 实际玩法和边界

在本地 Godot Web 的四人规则小山谷（含持久规则 `3416` 启动入口）选择居民，可在观察卡看到**此人当下**户外的雨雪、定性冷暖和干湿及游戏分钟；此行不同于顶部全谷气象。室内、休息中等没有现场户外信息时显示未观察，断线时不维持新鲜读数。感受与决策共享本人当前感知代码，不暴露别的地点、伪造室外观察或提供精确体表温湿度。卡片使用已提交计划摘要解释计划，实际行动另显示行走与入内；日志只在真实完成后记实际停留。角色未应对不能因HUD下雨就标已避雨。

仅当现有规则本要在户外闲等、且本人确实观察到雨或雨雪时，考虑前往本人已知、可用的共屋公开前室。保留现有吃喝、休息、可行耕作、储备和社交优先顺序；比紧迫阈值另留五点。用真实移动速率核算路程、入门一分钟和屋内短候五分钟，合计不得超过原闲等预算（与现有闲等共用30分钟）；时限以真实接受分钟起算并随原计划持久保存，不以提交方时间或重启时刻重置；不会中断在途等待、搬动交易或会合地点，也不会处理已经承诺的社交安排。未到前室还只是在路上，室内入口按统一真实房间与移动逻辑占用共用入门位置，不占厨房、床、种台或桌位。实际进入后另计五个游戏分钟；报告中只有完结才写成功事件。同一阴雨中已在屋里就不会再选择户外避雨。

途中本人察觉无雨，或将触及既有进食／饮水／休息阈值，或共屋不可用、路线发生真实阻断、移动变慢耗尽原闲等预算，立即取消可选安排，保持当时真实位置，回到原生计优先逻辑。入内后不因全谷下雨状态自行读取外面；已到仍可按同一需求安全阈值提前结束，不能把中断算完整停留。无任何额外伤害、补给、体感变化、体能回血、环境、资源或触发谷灵改写，也不增加观察端控制、模型选项或真实模型调用。
