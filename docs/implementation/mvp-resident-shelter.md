# 居民感知天气与短时避雨

## 实际玩法和边界

在本地 Godot Web 的四人规则小山谷（含持久规则 `3416` 启动入口）选择居民，可在观察卡看到**此人当下**户外的雨雪、定性冷暖和干湿及游戏分钟；此行不同于顶部全谷气象。室内、休息中等没有现场户外信息时显示未观察，断线时不维持新鲜读数。感受与决策共享本人当前感知代码，不暴露别的地点、伪造室外观察或提供精确体表温湿度。卡片使用已提交计划摘要解释计划，实际行动另显示行走与入内；日志只在真实完成后记实际停留。角色未应对不能因HUD下雨就标已避雨。

仅当现有规则本要在户外闲等、且本人确实观察到雨或雨雪时，考虑前往本人已知、可用的共屋公开前室。保留现有吃喝、休息、可行耕作、储备和社交优先顺序；比紧迫阈值另留五点。用真实移动速率核算路程、入门一分钟和屋内短候五分钟，合计不得超过原闲等预算（与现有闲等共用30分钟）；时限以真实接受分钟起算并随原计划持久保存，不以提交方时间或重启时刻重置；不会中断在途等待、搬动交易或会合地点，也不会处理已经承诺的社交安排。未到前室还只是在路上，室内入口按统一真实房间与移动逻辑占用共用入门位置，不占厨房、床、种台或桌位。实际进入后另计五个游戏分钟；报告中只有完结才写成功事件。同一阴雨中已在屋里就不会再选择户外避雨。

途中本人察觉无雨，或将触及既有进食／饮水／休息阈值，或共屋不可用、路线发生真实阻断、移动变慢耗尽原闲等预算，立即取消可选安排，保持当时真实位置，回到原生计优先逻辑。入内后不因全谷下雨状态自行读取外面；已到仍可按同一需求安全阈值提前结束，不能把中断算完整停留。无任何额外伤害、补给、体感变化、体能回血、环境、资源或触发谷灵改写，也不增加观察端控制、模型选项或真实模型调用。

## 持久兼容

未接受过避雨的普通规则存档仍是根格式 1。首次实际接受该动作与计划回执在同一世界事务中升为根格式 3（不是气候版本变化）；拒绝或试算不改真实世界和存档。新版仅允许满足小山谷气候和真实室内依赖的 validation 格式 3，可继续恢复计划和室内剩余时长；缺少动作协议的格式 1/2 不能读入在途避雨。完成并裁剪日志也不自动降回旧格式。旧规则版遇到新格式写前拒绝，回退需用迁移前备份。

离线季节模型专用格式 2 的请求恢复契约不变。此片规则避雨的格式 3 不转入离线模型入口，不能通过换入口或降级格式绕过旧版拒绝；普通规则体验与离线模型试验须使用独立档。

## 局部验证

- Node 编译与有界独立对照：一致的天气生成器构造晴/雨、雨停边界及相同人物脚本；既有直接吃喝和可行田务优先；未知共屋、阻路、即将饥饿和入内后即将口渴均无伪造成功。
- SQL 实际持久规则服务分别在前往共屋途中与入屋短候中途关闭重开，保留同一计划、所在位置和剩余 3 分钟。入门瞬间不抵五分钟，完成只发一次成功，长雨室内不重新出入；本人库存不因避雨改变。

- 验证脚本全部临时，自生成场景、无正式存档，禁全局 fetch。没有真实模型或真实账号测试。受控天气/身体夹具只证明必要情境行为，不能替代自然世界或连续三十分钟规则验收。

## 自然出现窗口（隔离加速规则轨迹）

旧八步上限在此前两条同范围轨迹内均未产生完成记录。新世界 480–11880 中有 1051 个实际下雨/雨雪游戏分钟；2221 人分钟的户外闲等（含旧第 56 日起四日轨迹）中，无人同时满足原安全与八步条件，而新世界其中 233 人分钟能在当时原闲等的剩余时间内走到共屋并短候。统计是机会人分钟，不是预测独立事件，也不解释雨过后一整段生活。

改用既有普通闲等总时限后，在同一默认初态（seed 3414、资源/居民/天气均未经注入）从 480 至 11880 实际产生 8 次完成及 1 次屋外雨停取消。首例乔笙 2067 接受、2081 入共屋前室、2086 完成真实五分钟短候，共 19 游戏分钟；全员逐分钟最低健康均 100，库存未发现负数或非有限值。在同一输入的晴/雨各一组必要饮水、进食、农作对照中，选择及理由与旧入口完全相同；实际避雨后的自然后续位置与需求不应假定相同。此为有界加速轨迹，不是连续 30 分钟或浏览器验收。

用原第 56 日轨迹快照（game minute 80640，不修改库存、天气、田务或目标）至 86400 复跑四个游戏日。旧八步规则在该范围无事件；修正后许砚在 85946 真实接受、85960 入屋、85965 完成，同样为五分钟屋内短候、合计 19 分钟；无避雨失败，全员逐分钟最低健康 100，库存无负数或非有限值。两个起点是不同正常阶段，均属当前规则入口固定的同一个气候种子，不代表多种子或完整跨季验收。
