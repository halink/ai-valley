# 已知浆果地点与替代采集入口

后续[当面亲见浆果地点分享](food-source-sharing.md)另将本人首次亲见与实际收到的旧地址分开，支持独立选择核实、采集和进食，不把听闻当亲见或查询远处库存。[浆果视野与围栏接触修复](food-source-boundaries.md)补齐旧地点自动发现、实时菜单与最终采集的遮挡/接触边界。以下56项仍是本项首次交付时的阶段预算，当前普通上限见[菜单规则](../design/simulation.md)。

这是批次 1 食物行动菜单的有限补充，不是新的食物生成规则或完整多日供给计划。

## 修复的缺口

原采集菜单只取当前观察范围内最近的一处浆果。最近处不足一整份、被断路围住时，另一处实际可采的浆果也不会出现；居民已经认识、但暂时离开观察范围的浆果地点则没有专门的返回查看入口。

正式世界现在分别保留至多两项现场采集和两项按已知地址查看：每类一项最近可达选择，另一项每 30 游戏分钟轮换。选择菜单不会替居民采集、进食或安排后续步骤。低于两日的已核实口粮提醒或严重饥饿时，这些选项进入现有有界食物获取分组；最终菜单仍最多 56 项，保留其他生活领域及拒绝、撤回入口。

## 观察、路径和实物边界

- 只有本人已认识的浆果地点可出现。现场采集沿用不超过 12 格欧氏直线距离，同时要求本人真实清醒在室外、视线未被房墙、悬崖、树石或预留建筑遮挡，且现存至少一整份。旧地址本身不证明眼前库存；7格内的自动发现也核对实际视线。
- 现场采集使用当前地图检查能否走到浆果旁边的合法接触格，跳过不可达的近处，继续寻找备选地点。透明围栏不挡视线，但隔着闭边不能取物；须真实绕门，门不可达时不提供采集。每次至多三份，劳动每份三分钟，路程另计。菜单中的可达不是保证健康足够走完，紧急保护仍须独立预测实际采集及随后进食。
- 视野外或本人在室内时，只能提出到已知地点旁查看。选项不依据远处余量、容量、采集时间或未来再生改变内容；空浆果地点也可以按旧地址访问。未知地点不会凭全局库存暴露。
- 查看使用真实可站立的相邻格，不要求走上不可通行的浆果格。室内居民须有实际出门路径，选定后先正常走出房间，再沿实际路径前往。到场可能没有浆果，查看本身不产生采集、粮食或后续计划。
- 采集、进食仍是居民分别选定的既有动作。旧采集选择可前往历史地点，但出发前不以隐藏库存是否不足返回不同结果；实际接触后再核对。行走、资源不足、其他人抢先采完及动作完成时的真实视线、位置与围栏边，由引擎重新核对。采下的实物从原地点扣除，登记实际食品批次；进食再从本人背包扣除。重复提交和服务重载沿用原计划回执，不重复交付。
- 未采集的浆果仍不计入可达口粮天数，也不计入社区去重现物。远处查看不是已验证的紧急自救或获得食物承诺。

## 兼容和明确限制

本项没有新增存档字段、迁移、权限或资源再生。旧档沿用已有认识的地点和现存余量，不补发食物；六岁以下、不能独立决定/表达或已经无法移动者不通过本入口自行取食。验证世界保留原简化采集菜单。

本项只补浆果，不包括跨多仓库取货、其他可再生食源的完整经营路径、四季生产消费账本、真实模型长期生存或多人口性能验收。当前寻路仍读取实际地图，选项只保证生成时的路线存在；本项没有新增道路知识系统，也不能预测随后出现的路阻、竞争或损耗。更多地图规模下的观察与寻路成本仍须单独验收。

独立审核发现大量断路地点会反复扫描同一地图，已改为首次寻路失败后建立一次本次查询专用的居民起点连通图，后续不可达地点直接跳过；不截断地点清单，晚出现的可达来源仍能选出。连通图与实际寻路保持相同洪水出入、牧场门和损坏设施规则，不跨查询缓存。在 160×160、100 处被封住地点的合成样例中，独立复核约由 401ms 降到 15ms；这是环境相关的局部测量，不是大型人口或长期运行性能保证。

## 离线验证

所有场景由代码构造，只使用内存数据库，不读取真实存档、密钥或调用真实模型。

```sh
node node_modules/typescript/bin/tsc --noEmit
node --import tsx --test tests/food-source-opportunities.test.ts tests/food-source-navigation.test.ts
node --import tsx --test tests/food-source-opportunities.test.ts tests/opportunity-coverage.test.ts tests/food-coverage.test.ts tests/decisions.test.ts tests/agency.test.ts tests/decision-protection.test.ts
node --import tsx --test tests/*.test.ts
node node_modules/typescript/bin/tsc -p tsconfig.server.json
node --input-type=module -e "import {build} from 'vite'; await build({envDir:false});"
```

专项覆盖断路与不足一份的近处、替代地点轮换、远处库存不泄漏、室内真实退出、先查看再采集再进食、空地点无补货、陈旧选择、路途中断、劳动中被取空、内存重载和重复提交、拥挤正常菜单、年龄及失能边界。连通性回归逐格对照实际寻路，另对大量不可达地点限制地图读取次数，不以易波动的时间阈值作为通过条件。独立审核见[食源入口审核](../reviews/known-food-sources.md)。
