# 有限公共储备粮

本项交付[本地产业与公共供给](roadmap.md#批次-3-本地产业与公共供给)中的本地采购与现物领取，不代表长期供给或第三批整体完成。后续[有限镇外采购](public-food-procurement.md)仅依据另带具体商人和经办条款的新议案执行，不扩大本页旧本地授权。

## 表决与有限授权

居民从正常议事入口提出 `foodReserve`：指定共屋、可食食品、累计入库上限、收购单价、采购预算、个人滚动24小时营养上限和有效天数。水、种子与材料不能成为本议案的口粮。同处共屋同时只能有一项有效储备。

新议案须有至少三位原登记成年选民及两张独立赞成票，并通过既有议事程序。通过后实际从公共金库预留有限采购款，金库不足或对象失效不能创建可执行储备。后来的议事人数减少不会扩大、续期或新增原授权。

## 实际入库与领取

- 有能力的成年人实际到共屋办理 `supplyReserve`，交出自己的食品并按批准单价领取预留款。钱或货不足、期限结束、累计入库额度用完都会阻止成交。
- `openReserve` 只把该共屋现有、尚未承诺的公共食品搬入独立储备货架，不支付采购款。仍有效的本处服务/修缮预算或尚未结束的资助班次保护原公共库存，不能借此改作储备。
- 两种入库合用该项授权的累计数量上限。领走、变质和损耗都不恢复入库额度，不会自动补货或承诺未来供货。
- 6 岁以上且有自主行动能力的居民与访客，可从正常菜单选择带明确 `reserveId` 的 `commons.takeFood`，到实际室内桌台领取一种食品的一完整份，再另行选择进食。食品和营养额度不足完整一份时不拆份、不补发。
- 个人滚动24游戏小时累计营养同时计入所有共屋公约与储备领取记录。跨地点、跨午夜、换议案、重启都不能绕过当前领取规则的上限。
- 菜单所知、路程、实际库存、原批次保质期和领取权仍需核验。保守口粮估计可考虑合规现物，但不把未来采购承诺当作已到手的粮食，也不承诺来得及吃到。

## 钱物与期限

`World.civic.reserves` 保存各次有限授权、采购账户、实际货架库存和入库收据。`public-reserve:<id>` 是独立食品容器，原批次生产与过期时间随交付、领取及到期转移，不因换容器获得新保质期。一般公共库存与储备货架合计为 `economy.treasuryStock`，总账不是第二份实物。

到期未用采购款退回金库，剩余食品在同一共屋转回一般公共库存，保留原批次与原位置。到期不瞬移食品，不追溯追回已合法领走的物资，不开放种粮或已有专款。领取与入库收据持久保存，重放不得重复付钱、转货或增加额度。旧档没有此字段时视为尚无储备，不补钱、不补粮，也不改变已有公约领取历史。

## 观察与验收边界

财政观察页单独列出储备议案、采购预留款、实际货架存货、累计入库与领取、采购支出、退款、个人营养上限和授权期限。展开可看最近入库与领取记录，并查看现存食品原批次的到期时间。观察不代居民投票、买卖或领取。
