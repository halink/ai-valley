# 现场劳作像素动作：首批

本批修正“标签在工作，身体却不动”和不同劳动共用敲打姿势的问题。沿用 [素材来源](../art.md) 中的原创程序像素画、人物配色与乡村轮廓；没有引入贴图库、模型生成画面或新的模拟规则。

## 现场依据

- 名册与人物姿态共用只读 `atActionPosition`。空路径不再直接等于到场；室内需真实工位与坐标，离室和未走完的路线仍属于赶路。
- 野外采集允许真实曼哈顿邻格，修正已在树旁采集却仍标为赶路的问题；果树与田地工作保持当前执行器要求的实际目标格。
- 伐木、采摘、播种、浇水、收获、垂钓另有采石、取水，共八种独立姿态。接通 `industry.cutTree / plantTree / harvestFruit / tendTree`、温室种植照料收获和 `production.plantCrop`。
- 工具/手的方向从已到场的目标取得，钓线指向 `waterAtShore` 确认的真实邻水。坐标无效时不画劳作。与脚下同格的农事保持朝前，不捏造另一块田。
- 动作仅表示居民正在尝试该劳动，不表示资源、权限或产量已通过最终核验。工具和空容器是姿态符号，不据此新增或宣称工具库存、等级或所有权。

## 像素表现

- 伐木与采石：预备、抬手、落下、回收，斧刃与镐头有不同轮廓，脚步不再原地走路。
- 采摘：短距离抬手、探取与收手，不画出凭空取得的果实。
- 播种：俯身探手和斜挎种子袋；收获使用更深的俯身与空编篮，两者不共用同一件工具。
- 浇水：壶身与壶嘴、短水滴；取水使用提桶俯身。水滴不修改田地或水库存。
- 垂钓：抛竿、落线、较长等漂、调竿四阶段。循环不画咬钩、水花、鱼或收获数量。
- 64×64 透明动作画布把脚锚固定在 (32,44)，为竿线与四方向工具留空间，不放大人物本体。现有 18×28 静止/其他姿态保持原锚点。
- 场景采用暂停感知的显示时钟：停表保留当前相位，恢复不跳回起手或追赶停表时间。该时钟不推进居民或世界时间。

## 成功反馈

只在已有成功事件上附加有限 `workCompleted` 身份。当前范围为野外采集、旧式田地播种/浇水/收获、果树种植/浇护/摘果/伐除、垂钓及正式作物播种。只有完成函数返回成功、活动身份一致且该结算新产生唯一对应行动/生产事件时才登记；不新增事件、知识、物品或模拟结果。

客户端只对新见到且合法的完成身份显示短暂金色完成点，不表示产量，也不把库存增长、倒计时归零或一段文字当作成功。完成点固定在事件原地点/房间，不能跟着已离开的居民移动。初次加载、断线重连、世界替换、旧历史、重复/倒序快照、无结构旧记录与区域事件均不补播。失败、未完成和停表不会生成成功记录。

## 离线验证与限制

全部场景为内存合成，不读取真实存档、`.env` 或密钥，不调用模型，不触碰在运行的 `output/assistant-driven` 接口，不重试或绕过浏览器 IPC 限制。

- `tests/action-position.test.ts`：邻格、对角线/距离、路线、室内工位、离室、未知位置、真实邻水和只读。
- `tests/person-work-art.test.ts`：四年龄 × 八动作 × 四方向 × 四相位，共 512 帧整数像素与边界检查；成人静态像素哈希、动作映射、钓鱼节奏、真实场景方法的暂停/恢复和锚点恢复。
- `tests/work-feedback.test.ts`：实际引擎成功、缺料/耗尽失败、未完成/暂停、所有本批登记动作、首次/重连/重复/过时快照与原室内位置。
- `tests/work-visual-review.test.ts`：独立复核死亡/镇外人物、四帧纹理释放、场景只读、无效/区域反馈及无效坐标。
- `scripts/render-work-art.ts`：从同一绘制源输出 `/tmp/ai-valley-work-actions.svg` 静态动作与方向表，可指定独立输出文件。静态像素图已检查，**这不代表浏览器、实际地图遮挡、手机布局或运行中动画节奏已视觉验收**。

完整检查使用 `npm test`、TypeScript 类型检查/服务器编译及 `vite.build({envFile:false})`，明确禁用 dotenv 加载。具体结果见本批交付记录与 [独立审查](../reviews/visible-work-actions.md)。未推送、部署或重启运行中的游戏。
