# 医疗护送跨六岁本人同意

## 范围与原问题

幼儿的医疗护送提议原本可由当前监护人接受，但旧 `consent()` 直到十八岁才区分监护答复和本人同意。孩子满六岁后，答复对象已经变成本人，旧代理接受却仍可接出、送床，本人也无法回答原提议。

现在保留原提议 ID、原收件人、创建时间、接收建筑与到期时间，新增可选 `personalAcceptedAt` 和 `proxyAcceptedAt`，分别记录实际完成的本人接受和监护答复。它们不是自动同意默认值。

- 六岁前发出的代理提议，在真实年龄满六岁时进入 `awaitingPatient`。有决定和表达能力的本人可在原提议上独立接受、拒绝或取消；没有能力则继续等待，原期限届满仍过期。
- 判断使用实际出生时间，不依赖 `lifeStage` 或生命周期处理顺序。只读菜单、纯权限判断、每步实际行动之前、最后接触工时、接收床位工时都会核验，不以一次同步代替完成事务验证。
- 既有六岁以上无能力未成年人的新代理提议路径保留；其本人恢复能力时，旧代理答复也不能替代本人选择。成年历史监护、危重标准、及时当前监护人在场、拒绝和灾害撤险边界没有放宽。
- 本人明确拒绝的原提议不会因后来丧失能力、监护人答复或重新同步而恢复。接受护送不能清除 `refusesCare`。

## 已启动与撤回

已经接出的护送在权限失效时立即中断，孩子保留在真实位置，解除实际运输占用和床位预留，原提议仍可由本人选择。不会自动恢复路线。本人接受后，护送人仍须自行选择并完成新的真实接出过程；已经使用的布和水不返还，也不重复记作同一次接出。

普通医疗护送中，只有表达能力的本人也能即时拒绝或停止。该入口允许一项本人撤回或最多十五分钟的暂不表达，不授予接受同意、移动、工作或一般决策能力。即使本人正在等待或其他安排中，运行时仍能提供这个有限选择；停止提交即时生效，不排队等待五分钟答复劳动。混合动作、附加移动目标、非本人安排和失效范围均拒绝。

最终菜单为一份当前护送提议保留接受、拒绝、取消完整组，多份提议轮转。已经通过年龄、能力和同行过滤的实时护送拒绝与停止可在普通议程裁剪后恢复，不绕过这些过滤。

## 船、旧档和资源

靠泊接出沿用原船、原船程、真实靠泊点、实际工时和床位检查。生日失权发生在最后一分钟时，孩子仍在船上，不释放座位、不退款、不扣布水；本人可在船上回答原提议，之后另行真实接出。

旧档不补写未知签署时间。只有旧记录可证明创建时已满六岁、原收件人就是本人且已接受，才保留其合法个人同意。缺收件人、缺创建时间、明确空同意时间、六岁前时间或未来时间不能成为本人同意。实际新选择可以生成新的真实时间证据，但不改写历史代理答复。SQLite 使用现有世界版本并发检查，迟到的旧工作副本不能覆盖已持久化的生日拒绝。

没有新增费用、补发物资、延长期限或修改他人资源。未接出阶段不消耗布水；真实接出仍只扣一次布和水；到达不等于已经治疗或取得后续医疗、监护、住所或长期照护权利。
