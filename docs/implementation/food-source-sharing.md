# 当面分享本人亲见的浆果地址

这是[所知、交谈与关系](../design/people.md#所知交谈与关系)与[已知浆果地点](known-food-sources.md)之间的有限单跳消息，不是自动救济、实时库存查询或通用传闻系统。

## 四次独立选择

1. **说出地点。** 本人从最终编号菜单明选已经合法近身的对象和一个自己亲眼见过的浆果地址，在原地实际交谈1游戏分钟。需要双方在谷、至少6岁、清醒、有决定与表达能力；室内须双方有使用权、真实房间位置和短通路，室外不能隔水、穿墙或隔围栏。本入口不会自动走近或追踪对象。
2. **接收线索。** 只有指定且实际听到的对象获得历史地址、说话者身份和当时姓名、说话者首次亲见时点及本次送达时点。未听到的人不获知。本次并不改变任何库存、饥饿、健康或关系分值，也不赋予进入私宅或采集权限。
3. **自主核实。** 听者另选去旧地址旁查看的普通移动行动，实际行走并按既有规则观察。线索仅说明说话者过去见过，不说明现在是否还有资源；空、已删除或改址的资源不改变收到的地址，不自动补货、改道或授予采集。
4. **自主取食。** 真正看到地点以后，听者才按原菜单另选采集，并在取得实物后另选进食。采集照旧检查现场数量、位置和劳动时间，进食照旧扣除本人实物。收到消息或前往查看都不是获得食物，更不计入口粮估计。

第一版每个说话者对同一听者、同一亲见地点只分享一次；不会自动重复，也不提供无限转述。听闻不能当作本人亲见证据。听者后来实际看到的地点则形成自己的亲见记录，此后分享的是这次本人观察，不是转发原话。普通自由交谈及三种语气保持原样，不从任意聊天文字中解析或补造地址。

## 证据、保存和旧档

正式世界的真实室外观察在7格范围与实际视线成立时，记录浆果地点的首次亲见地址和游戏时点，不保存或传送库存。该记录固定保留第一次观察，后续观察不会把旧报告改写成新鲜消息。旧 `knownResources` 只有身份，没有来源和时间，不能据此补造可分享的亲见记录；须以后真正观察一次。未知出生资料不推定已满6岁。

`foodSourceKnowledge` 的 `seen`、`heard` 与 `shared` 分别保存本人亲见、实际收到的消息和本人已完成的传达。听闻不加入 `knownResources`。事件记录明示原说话者、指定听者和原地址，听者短记忆标为 `heard`；短记忆挤出后，独立的听闻地址仍可进入下次最终编号菜单和提示。没有此字段的旧档保持无记录，不解析旧聊天或补造历史消息。

分享是单独提交的行动，绑定本人当次版本、原亲见快照和回执。每一步重验实际接触与双方能力；真实工时须连续达到1分钟，不能通过改剩余时间或直接调用完成函数提前传达。对方走开、睡着、离谷、失权或出现实际通路阻挡时，这次尝试失败，不改送旁人。重载保留未完工的实际工时；成功回执和事件随同一存储事务保留，工作集也保留相关原始事件，旧选择换计划编号不会重复传达。

## 菜单和明确限制

- 分享对象与地址的完整组合每30游戏分钟轮转，最多1项；听闻地址核实另最多1项，跳过本次无法到达的地址。
- 两类选项绕过基础议程的二次轮转，最多额外增加2行，不挤掉既有生存、自由交谈、拒绝、停止或目标入口。当前普通最终菜单上限由78变为80，实时停止入口仍另外恢复；年龄、乘船、护送和家庭同行过滤保留。
- 来源和时间直接写在对应选项中，不依赖短记忆或综合记录摘要。生成菜单只读，不表示居民已选择、已交谈或已前往。
- 第一版只支持已近身对象、浆果地址、首次亲见与指定听者，不支持远程传话、任意转述、其他资源、批量广播、自动救助、路线知识或新鲜度保证。寻路沿用真实地图；不能保证后来路况不变或居民一定愿意去。
- 观察者可以看到事件和当前行动标签，但世界完整资源状态不会因此进入远方居民的决定输入。未做新的浏览器视觉验收。

## 离线验证

主测试使用代码构造的平地世界、真实最终编号菜单、`prepareModelDecision`、`parseChoice`、`submitPlan`、`stepWorld` 与内存SQLite，覆盖分享→核实→采集→进食、过期空地址、资源删除/改址、未听到的人、自由聊天、年龄能力、失去接触、真实四个四分之一分钟、短记忆、重载防重、轮转与饱和菜单。首次主测试的失败来自测试夹具资源种类写错，不作为实现先红后绿的证据。[独立审查](../reviews/food-source-sharing.md)另保存反例与复核结果。

所有检查都使用隔离合成世界，不读取 `.env`、密钥或真实存档，不调用真实模型或浏览器，不提交、推送或部署。离线规则通过不证明真实模型会主动分享、接受线索或长期存活。
