# Godot MVP 中文观察界面

此迭代只修改只读表现层，不改动作协议、服务端决策、存档或模型配置。

- 启动预设、连接状态、居民需求、库存、行为、错误分类及住宅提示改为中文。
- 端口和地址仍按原值展示；选择预设不启动服务、不自动调用模型。
- 资源显示名称与剩余数量；住宅显示已验证布局中的床位数，不推测床位归属或占用。
- 缺失数字仍显示“未知”，不转为零。未知动作/物品/资源显示中文未知类别，不回显内部标识。
- 居民名称缺失时显示“未命名居民”，不使用居民 ID。房间不显示建筑 ID。
- 原始行为失败、未知模型错误、暂停原因不回显。仅显示安全错误类别；HTTP 429 保留错误码。居民自由文本意图暂不显示，避免把内部字符串当作已执行行为。
- 近期事件仍为服务端提供的原文，不翻译或补写事实。当前界面不提供语言切换；枚举词汇集中于 `snapshot.gd` 的命名函数，未来新增类型时须添加译名与测试，协议字段保持不变。

## 操作与验证边界

桌面使用中键拖动、滚轮缩放、左键选人；也可用“下一位居民”选择室内居民。左侧面板支持滚动、自动换行。界面始终区分规则合成演示、已配置模型与真实模型验收。

现有环境安装了 Noto Sans CJK SC 系列字体，依赖 Godot 系统字体回退，未引入新的字体资产。发布到其他桌面系统时应确认中文字体可用。Headless 测试验证文字、状态与布局约束，**不能证明实际 GPU 窗口中文字形、清晰度、遮挡或 3D 标签排版已验收**；还需在目标桌面人工确认。

本轮执行 `npm run test:godot`：11 套离线 headless 测试全部通过，包括中文长文本滚动/换行、未知标识回退、错误脱敏、床位计数、断连重连状态。独立静态审查复查通过，`git diff --check` 无误。最初两轮发现语法误替换及旧英文断言，修复后完成全套重跑。此处不包含 HTTP 服务联调、真实模型调用或长期运行验收。
