# 灾害事件链独立审查

日期：2026-11-11。结论：本轮审查未发现阻断问题。结论限定于下述源码检查与隔离合成测试，不等同于真实浏览器视觉验收或完整套件通过。

## 范围与判断

检查 `src/shared/history.ts`、`src/server/history-query.ts`、`src/server/store.ts`、`src/client/history.ts`、`src/client/disaster-history.ts`、`src/client/weather-hazards.ts`、`src/client/main.ts`，以及末轮 `src/client/styles.css` 的灾害标题/事实块样式。

- 查询要求存档 JSON 的 `hazardFact.disasterId` 为字符串并精确相等；不会从原文、相邻时间、同一地点或受损设施状态推断身份。仍按入账 rowid 倒序分页，不按灾害日期重排。
- 灾害身份参与游标范围哈希。另一灾害及无灾害范围不能复用该游标。无灾害参数时，原有普通、供水及动物游标哈希保持兼容。
- 新增索引只读取 JSON 字段，未回填或重写事件。使用带格式空白的合成旧事件建库、开启新索引、关闭重开，逐字比较 body，保持不变；时间倒序、同时间及分页途中追加均未污染已获取游标范围。
- 年表记录、当前预警/发生灾害、已消退灾害及有明确灾害编号的泉水记录提供可见入口。无编号的损坏建筑不建立归因链接。近期列表和已消退列表有显示上限，界面明确说明快照不是完整历史，旧事件仍可从持久年表进入。
- 缺失快照、对象和单侧数值明确保留未知；页面没有声称未记录即零损害、安全或修复。身份与原文按 HTML 转义。
- `main.ts` 复用现有阅读器与阅读位置机制；同灾害重复点击不再取页，切换灾害中止旧请求且拒绝晚响应。失败的回到最新保留原页和位置，重试成功才重置位置。离开后返回同一灾害保持阅读位置。重复翻页点击不会同时创建重复请求。
- observer 匹配精确灾害编号，仅提示新记录，不自动换页、发请求或推进世界。新增展示不写世界、居民记忆或灾害状态，不提供执行撤离、修护或开启风险的按钮。
