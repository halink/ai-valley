# 成人亲属分段同行复核

2026-11-06，本次范围为新发起的两位成年亲属驿路同行。没有把它计作未成年家庭首次迁入、全家迁出或完整照护交接。

## 独立复核与修正

独立代码复核检查了有限独立同意、共同实际距离、慢者速度、个人食品和原批次、拆队与真实折返、失能/死亡、保存重启和旧计时旅程兼容。

1. 已修正：本人已同意下一段、等待另一人期间，如果另一人失能，旧实现只移除同意却仍让本人等到 30 分钟截止。现在同步撤销待确认状态，恢复本人的下一次选择并增加修订号，不困住自理或拆队选择；已有专项回归。
2. 已修正：观察状态先处理镇外旅程时，把失能者标成“等待本人决定”。人物状态和人口簿现在明确显示失能停步，而有能力的亲属仍保留自己的下一次选择。
3. 补充事实用语核对：拆队记录区分仍有能力、失能和已故的亲属，不声称死者会继续自理或作下一次决定，也不在缺失共同位置时声称双方仍在眼前。死亡和遗产原址仍保持原路程标识。

修正后的独立定向复核未发现剩余实质问题。没有修改或读取真实存档、环境密钥与私人日志，也没有调用外部模型、提交或推送。
