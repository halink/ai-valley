# 幼儿现场供水可达性复核

## 问题与修复

监护人与幼儿户外距离2格，即使隔着贯穿地图的悬崖、`findPath` 返回 `null`，旧 `serveChild` 仍只检查 `coLocated`。动作目标又是监护人原地，菜单及引擎会接受隔墙饮用。

`src/world/water-supply.ts` 改为复用成人协助、赠桶已有的 `waterSupportTogether`，不改变通用社交或观察距离：

- 户外双方站位可通行，实际路径不超过2步。仍能绕路但需要4步，不算近距供水。
- 室内双方实际坐标、使用权、建筑完好及短路径均有效，不能以共同门口或缺失坐标替代真实位置。
- 原年龄、监护、拒绝、运输及滚动24小时额度检查保持有效。
- 菜单、开工、每步劳动和最终扣水共用实时规则，不保存旧菜单的可达性结论。失败不扣水、不登记饮用或完成回执。
