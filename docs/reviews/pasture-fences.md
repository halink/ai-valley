# 牧场围栏修护复核

日期：2026-11-06。

## 范围与结论

对已完工牧场的耐久、实际入口修护、材料与工时批次、旧档迁移、碰撞和观察文字进行独立只读复核。最终未发现阻断实现的问题。

检查过普通决策菜单与 `industry` 执行链，确认每次劳动重新核验责任人、实际位置和当前围栏。中断和在途快照重载不会再次扣木，重复同一时刻的劳动不重复计工；完成批次身份不能被重放。设施归属变化后，原修护者的下一 tick 停止；继承不自动指派新主人劳动。用地到期后修护只保全原围栏，不续期、不重新开放、不迁移动物。

## 发现与处理

1. 初版路阻测试在执行路线建立前设置障碍，居民正确重新规划，未真正覆盖途中阻断。现已先推进一 tick，再封堵已选路线的下一格，并断言不扣材料、不累计工时。
2. 旧档测试在 `delete p.fence` 后直接读取副作用生成的字段，TypeScript 仍将字段缩窄为 `undefined`。现已通过 `Pasture` 类型引用读取，类型检查通过。
3. 按复核建议补充执行中所有权改变、活动快照继续与同 tick 重复劳动测试。

最终独立复跑：围栏专项 12/12 通过，`node node_modules/typescript/bin/tsc --noEmit` 退出码 0。相关五个测试文件合计 72/72 通过；随后完成全仓离线测试 1281/1281，无失败或跳过。服务端编译和 Vite 生产构建通过；Vite 仍提示主包体积大于 500 kB。

边界：本复核未运行真实模型、未读写真实存档，也没有浏览器视觉截图或长期成本平衡证据。未完工围栏、灾害迁栏、雇工和动物逃逸不在本次交付范围。
