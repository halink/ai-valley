# 无床附近干地撤险：独立安全复核

## 范围

复核当前监护人对健康、未满六岁幼儿的一次有限灾害撤险。阅读真实菜单、动作验证、室内外移动、运输记录、客户端说明；新增 `tests/safe-ground-evacuation-review.test.ts`。仅使用代码创建的隔离世界和 `WorldStore(':memory:')`，不访问真实运行存档或密钥，不调用模型、浏览器或 npm，不提交或推送。

正常流程经 `decisionContext → decisionChoices → parseChoice → submitPlan → stepWorld` 执行。针对恶意或损坏的持久化状态，另在实际接出后修改单一动作/记录/路径字段，确认下一次同步或实际移动会停止，而不是扩展权限。

## 已发现及回归的问题

1. **户外路径范围。** 仅验证起点至终点的曼哈顿距离，不能保证最多八个真实步，也不能阻止被篡改的保存路径跳格。独立回归覆盖非相邻终点跳转及九步绕行。实现者已增加实际相邻边验证、持久化累计步数及剩余路径总预算，两个回归通过。
2. **空室内路径不能等同真实到门。** 接出后把保存的室内出口路径截成空数组，原移动代码会直接清空室内位置，即使本人仍不在真实入口。已修复：退出前检查真实门位及旅程绑定，回归确认在原室内位置停止。
3. **空值目标须安全失败。** 把进行中动作的 `evacuationGround` 改成 `null`，原同步经 `sameOptionalPoint` 访问 `null.x` 抛异常。已修复：新增点位结构验证，回归确认拒绝该状态、终止运输且保留当前位置，不再使世界步进崩溃。

## 覆盖的边界

- 室内外灾害实际覆盖不同，但室内菜单内容和接出结果一致；不从室内查询出口外干地可达性。
- 实际出门后找不到八步内干地时，仅停在真实门口，不凭空送达或换目的地。
- 接出后原灾害结束仍完成原有限护送；新目标预警或真实道路障碍立即停止。
- 拒绝、监护关系改变、护送人体力不足，以及幼儿本人选择停止，均保留最后真实室内位置。
- 新增室内障碍不允许踩入；截断室内路径不能制造出口。
- 混合干地与医疗字段、伪造建筑/床位/权限依据/目标均失败，不新增医疗、住房或财产权。
- SQLite 内存重载覆盖室内同行及已走一个户外步的阶段，保留真实位置、路径和累计步数，仅扣一次布料与水。
