# 私人空地转移复核

## 范围

复核已有空闲私人整块地权的原址报价、指定买方独立接受、价款与唯一产权交割，及其旧档、观察和回放边界。不是土地租售完整验收，也不涉及真实存档或外部模型。

## 独立复核结果

独立只读复核首先确认应使用 `production.parcelOwners` 保留原地块定义，成交前重验双方、产权与占用，并在调用幂等钱账前拒绝已结束记录。

发现一项 P2 问题：原实现只检查工程矩形，相邻工地的门口及库存可能位于待出售地块内。复现为出售地块 `(6,18) 9×7`，相邻工地 `(6,16) 2×2` 的入口 `(7,18)` 存有 5 木。现在同时拒绝仍有效或保留材料的工程入口，以及牧场施工入口和现有牧场门的接入位置；报价前和接受前都执行相同检查。

修复后独立复核未发现剩余阻断项，并独立执行新专项 16 项，全部通过。补充测试还验证二次真实转售不会重新激活旧成交回执，购买地块在买方死亡后仍归其遗产，须由其实际继承人独立领取，不返还原卖方。

## 本地验证

- TypeScript 全项目检查、服务器编译、禁用环境文件加载的 Vite 生产构建及差异空白检查通过。Vite 仍提示既有主包超过 500 kB，未将其视为构建失败。
- 新地权转移、原有限用地、施工、场所租赁、模型路由本地假服务和正常菜单覆盖：109/109 通过。
- 另一组包含原生产与继承、三年隔离居民计划运行的地权/施工/租赁回归：91/91 通过。两组有重叠，不相加为独立测试数。
- 原有长跑使用隔离测试世界与已安装工具，不访问实际存档或调用真实模型。

尚未执行全部仓库测试、多季真实模型长期运行或浏览器视觉验收。默认 npm 检查曾因注册表网络行为被拦截，后续使用已安装的本地 TypeScript、tsx 和 Vite 入口完成离线检查；前端构建显式禁用环境文件加载。
