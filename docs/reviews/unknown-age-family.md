# 未知出生时间与永久监护：独立审查

## 结论

本次定向审查未发现可复现的新增永久监护授权漏洞。未知出生时间不被当成幼儿豁免，已知不足六岁、六至十七岁与成年人路径仍沿用各自权限；未知本人可拒绝原提议，拒绝不等于取得成年人权限。

审查范围为 `time.ts` 的 `knownAgeYears`、`family.ts` 的监护/幼儿喂养、`guardian-consent.ts` 的真实选择证据，以及 `life.ts` 的阶段、能力、幼儿休息和到期清理。未修改生产源码或主测试，未审查并行修改的医疗、长照、收养或迁居模块。

## 独立反例

新增 `tests/unknown-age-family-review.test.ts` 共 17 项：

- 出生时间与当前时间都拒绝 null、缺失、非数字、非有限数及不安全时间；未来出生和不安全差值不作为年龄。
- 六岁和十八岁生日的前一个可表示浮点仍低于门槛；负出生日期、小数时间和较大时钟在生日时达到门槛。
- 监护人或志愿者在真实引擎最后 0.25 分钟丢失可知年龄，不能沿用原选择完成永久交接。
- 监护人先签，孩子签署排队后出生时间损坏，不能写入同意或新增监护人。
- 当前时钟损坏后，原有效本人选择不能完成交接，原证据保持。
- 旧格式及新格式真实本人同意在出生时间未知时失效；恢复原出生时间后可重新核实，未删除、改写或续期原证据。
- 未知年龄保留缺失或现有的各个生命阶段及决定/表达能力，不获得幼儿休息；到期监护提议与同住邀请仍清除。
- 已知五岁、六岁、十七岁从最终编号菜单到实际引擎完成正确交接，六岁以上仍须孩子独立签署。

主测另外覆盖未知本人/监护人的真实编号拒绝、迟到同意不能撤销拒绝、提议与接受最后 0.25 分钟竞态、内存 SQLite 重载和幼儿喂养拒绝。既有跨六岁审查覆盖成年、能力丢失/恢复、旧证据及提议身份绑定。
