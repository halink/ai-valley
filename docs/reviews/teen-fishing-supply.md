# 青年钓具来源独立审查

## 审查发现及修复核验

本审查只写独立测试与说明，生产修复由另一任务承担。正常来源链与“所有失效竞态都安全”是两项不同结论，不能混写。

**独立发现并复现既有完成顺序缺口：两名成年已批准后，若另一成年在少年实际领取的最后 0.25 分钟之前失去决定能力，旧实现仍可交付。** 旧 `householdReason` 的 `acceptGift` 分支只检查赠与 ready、有效期限、本人身份/能力及地点或知情；不再次检查成年资格。`stepWorld` 先执行居民活动，再调用 `advanceHousehold`。后者虽会把成年失能的未交付赠与作废并退回预留，但晚于该拍的领取完成。

独立复现用真实出生后明确设为13岁的合成对象、成人原开局木材制作的那一套钓具，实测旧结果为 `delivered`，少年得到 rodKit。提前调用清理的对照则正确退回。未把现状刻画的通过当成安全通过。收到生产修复任务安排后，最后一项已经改为目标回归断言并通过：末拍失能阻止交付、赠与过期、原贡献者份额恢复1套、少年仍无工具，恢复能力也不能复活旧赠与。修复版将相同有效性检查用于菜单、目标和实际完成，并保持原定期清理退款语义；不增加成年批准后必须继续在场的条件。最终复跑结果见下文。

## 覆盖及来源核对

- 阅读了真实出生、家庭池、成年签署、行业装备、年龄权限、最终菜单及引擎完成顺序实现，并对照既有家庭池和青年装备测试。
- 主测试从 `createFrontierWorld(5401)` 的正式开局原库存出发，经实际编号菜单、`parseChoice`、`submitPlan`、`stepWorld` 完成整理纤维、制作 rodKit、建池及两成年分别同意、少年自己领取、另选15分钟装备。不把预留当作交付，不把装备当作捕鱼。
- `birth-then-synthetic-13` 先由到期妊娠夹具调用 `advanceLife` 的真实出生路径，核对新生儿库存为空、无决定及表达能力；随后显式修改 bornAt 为13岁边界并运行生命周期激活。这不是模拟十三年成长，不证明长期照料存活，也不是模型自主规划。
- 独立反例增加：少年拒收、成年撤销后原贡献者取回预留；两个提案争用同一套实际钓具不能重复预留；少年决定/表达能力在领取最后一拍失效不能收货；编号选择不能改写收件人、giftId、操作或物品；成年失能提前清理与最后一拍缺口的对照。
- 两成年资格不足时，这条现有家庭池来源路径不可用。它不是所有青年都能获得工具的通用供给保证。两名成年签署也不表示两人各贡献半套钓具：该夹具由制作者贡献100%，另一成年对具体赠与独立批准。
- 主测试另覆盖 SQLite 重载中的提案、预留、领取与装备中间状态以及重复计划；独立测试复用来源构造 helper，但自行选择反例及断言。

## 验证边界

只运行新建隔离内存世界和内存 SQLite，使用已安装依赖；没有读取 `.env`、密钥、真实 runtime 存档，没有调用模型、浏览器、包管理器，也没有提交或推送。

正常链中的期限、能力与菜单条件由当时世界状态决定；测试只固定这一来源链的可复现规则，不声称覆盖全部家庭、市场赠与、工具供给、长期生存或所有并发撤权场景。物资守恒只核对本链的木材/纤维/钓具/家庭份额及相关钱款，不是完整世界经济账本。
