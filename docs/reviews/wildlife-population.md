# 四种有限野生种群离线复核

## 范围与结论

复核范围为野猪、鹿、野兔、野鸭的登记、繁育、死亡、驯化转出与旧档兼容，以及孕鸭转为家畜后的容量、亲代和重载。采用合成世界与内存 SQLite；未读取真实存档、密钥或连接外部模型。

最终独立复跑正式专项40项及附加9项反例，共49/49通过；另复跑既有开拓生态5项，5/5通过。范围内没有剩余阻断。类型检查、构建和全仓测试由实现阶段单独运行，结果见[实现说明](../implementation/wildlife-population.md)，不以这里的54项替代。

## 审查发现与修复

- 驯化孕鸭时，原容量检查只把在途孕畜计作一位。四位畜舍的一只原有家畜、一个在途母幼预留和一个新孕鸭实际需要五位，却被允许进入。
- 跨舍护送孕鸭时只计母体，目的舍只剩一位也被允许进入。这是既有移动路径的缺口，本次保留野鸭妊娠后直接关联新流程。
- 新增野生食水核验先选择最短路再拒绝危险格，没有搜索实际存在的安全绕路，可能错误报告食源、水源不可达。

三个反例均先失败、修复后通过，并纳入正式回归。畜舍现统一按存活本舍或在途目标舍的母体和已有胎儿计位，以“或”去重，跨舍移动排除自身后再计所需位置。笼内放养与新繁育同样不能占用原在途预留。新增野生路线在搜索过程中排除危险格，保留合法绕行。

## 附加核对

独立用例另核对真实捕食孕兔后的单次死亡及释放妊娠、母体死亡后的空位再利用、超出默认容量的旧个体与妊娠保留、新生身份避开现存野兽和家畜、旧岸已无水时拒绝受孕，以及正常菜单孕鸭驯化后两次 SQLite 重载、家畜出生与同刻防重。确认野生转出只记一次，家畜出生不算野生出生，亲代记录保留。

旧开拓生态回归不再要求旧档升级时从两只补成十二只，改为保持原两只并核对登记数。原死亡、位置、耗损食源、有限镇外运输笼及重载检查仍保留，没有跳过该验收。

## 边界

合成整年推进证明所测条件下的有限数量与真实消耗，不证明默认开局长期平衡或实际模型自主经营。四种动物没有新增迁移、镇外来源或疾病；允许自然灭绝，不再定时补种。未进行浏览器视觉验收，也未全面改写既有家畜出生位置与照料语义。
