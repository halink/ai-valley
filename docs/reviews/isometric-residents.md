# 等距居民独立审查

审查日期：2026-11-10。范围是 `src/client/isometric-residents.ts`、人工夹具及专属测试，并对照只读姿态、室内外行路、医疗携运、幼儿接送及实际安葬的既有语义。实现由另一工作线程修改；本次只读实现，仅新增本报告。

## 结论

**所报实证问题已修复，当前居民纯模块可接线。** 最后一次纯类型 API 补丁后专属测试 22/22 通过；此前门口过渡版本的居民及观察器定向测试为 21+13，共 34/34 通过。未发现本轮范围内剩余阻断问题。此结论不等同于整个观察器、最终接线、全量测试或浏览器验收。

## 本轮发现与修复复查

1. **残缺路径会使整批准备抛异常。** 删除 `activity.path` 或把 `room.path` 设为 null，原实现直接读取 length。现按居民返回明确 fallback，保留已知原格，不推算目的地。
2. **残缺相关账本仍可绕过单人 fallback。** `health.transports` 非数组、缺 `ferries.trips`、船程缺 `aboard`、迁居记录缺 `members`，原实现会在 filter/find/includes 崩溃。现先验证关系账本；无法判断谁被抬或在船上时，居民返回 `at=null` 的明确未知位置，不把损坏账本当空列表。缺 `industry.tools` 的狩猎者单独回退，不补造猎矛。重复居民 ID 的拒绝已移至该提前回退之前，另以组合反例复查。
3. **失能/婴儿携带者和危急残留路径可能被画成正在携运或步行。** 原关系检查只有 alive。现验证携带者决定/表达能力、正健康、非婴儿；医疗与接送另核实已知成年及体力条件。危急或失能状态与残留移动路径冲突时回退，不画成继续行走。原合成反例已复查消失。
4. **已确认床位睡眠的婴儿被普通婴儿坐姿覆盖。** 现真实睡眠优先为卧姿，重病婴儿也不画成成人站姿。追加回归已通过。
5. **真实睡眠路线的门口过渡曾被当成未知睡眠位置，导致跟随中断。** 整合线程发现，真实引擎完成最后一格户外路径后、尚未入屋前，居民会在本人真实住宿门口保持 `inside=null`、空路径、目标为门且没有室内 journey。现仅在 `sleepBuilding` 确认住宿、当前坐标及目标都精确等于门口、仍在户外且无室内 journey 时，保留当前非睡眠姿态，并明确标注“尚未到床，不表示睡眠”。没有把居民挪到门口，也没有把睡眠安排画成已睡着。
6. **明确隐藏原因，不让接线层凭被抬者旧位置猜测场景。** 最后补丁为 hidden 记录增加 `hiddenReason: 'buried' | 'outside' | 'other-space'`，不改变原渲染行为和说明文字。独立核对全部五个返回点：实际安葬为 buried；本人或携带者非本地为 outside；本人或携带者位于其他本地场景为 other-space。追加测试确认患者旧 inside 不能覆盖携带者离谷事实。

以上修复和新增回归由实现线程完成，审查线程没有修改业务或测试文件。

- 医疗、遗体及幼儿载荷须与携带者当前实际行动一致，随携带者的场景、坐标和保存进度，不采用被抬者旧坐标。失踪携带者、多载荷、循环、冲突关系返回未知位置。室内外切换和非本地隐藏均有专属测试。
- 只有非未来、非负、有限的实际 `buriedAt` 才隐藏死者；预留、null、未来与非法安葬时间不冒充已葬。未被抬的死者不沿遗留路径移动，暂存位置冲突回退。
- 船上乘员和家庭共同旅程保持明确 fallback，不拿个人旧路径画水上/独立步行；区域旅途和谷外居民不在本地复制。未知室内精确位置没有猜测格子。
- 冻结世界输入、调用前后深比较、渲染闭包不重扫源世界、各相位像素整数与预算，以及原居民 ID 的可见像素点击均通过。
- 另做携带者/患者同位置组合检查：交换两者 ID 的排序先后，两个原 ID 都仍有可见像素，不只在单人物隔离测试中成立。

## 只读与接线前提

- 模块只读取快照并生成像素与说明，没有模拟推进、规则写回、居民知识更新、模型调用或对外传输。
- 调用方仍需提供有效顶层 World、唯一真实 ID 和已经验证的室内边界。本模块不是完整存档 schema 验证器。
- `hidden`、`fallback`、`render` 须分别接线。隐藏分类应使用 `hiddenReason`，不能解析说明文字或借用被抬者旧 inside。`fallback.at=null` 只能计为未知位置，不能画到默认点、门口或旧坐标；有位置的 fallback 必须明确标记。保留原 ID、脚锚足迹、暂停时钟和绘制预算。
- 关联账本整体损坏时，对居民统一未知位置属于保守降级；它不代表所有居民实际上失踪。
- 未验证浏览器、GPU、触屏、实时快照、真实存档、完整最终跟随/导航接线或全量构建。没有读取真实 `.env`、密钥或真实存档，没有启动正式服务器或模型。观察器自动化测试包含隔离的只读合成后台与 VM 交互测试，不是浏览器或实际服务验收。
