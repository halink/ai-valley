# 绘本界面壳独立审查

日期：2026-11-11。范围：开发专用 DOM 界面壳、样式、入口与开发服务器的 HTML 注入；对照 `docs/design/storybook-valley.md` 桌面及手机要求。未修改正式入口、世界规则或用户已有功能工作。

## 发现与修复复核

1. **移动端导航状态失联。** 原实现把关系、交谈、野外按钮移出 `.dock`，而 `main.ts` 用 `.dock button` 更新和清除选中状态。当前更多容器保留 `.dock`，继续使用原按钮与事件路由。已复核选择器合约。
2. **更多容器的 CSS 层叠冲突。** 添加 `.dock` 后，手机规则会把更多容器覆盖成四列网格。当前移动端显式恢复纵向 flex、left、宽度与按钮布局；更多按钮规则的优先级也已修正。已复核源码层叠顺序，未作像素验收。
3. **移动节点后的焦点丢失。** 响应式布局使用 append/insertBefore 移动原导航按钮，浏览器可能清除其焦点。当前布局记住原焦点，并在重排后显式恢复可见导航按钮的焦点；移入隐藏更多容器的按钮改为聚焦更多入口。
4. **更多关闭按钮的桌面切换焦点。** 原实现从手机切到桌面时可能尝试聚焦已隐藏的更多入口。当前按视口选择可见目标，桌面回到居民按钮。新增独立回归断言覆盖此路径。

## 其他检查

- 时间、连接状态与房间提示留在原 HUD 中，不随开发工具 details 收起；房间提示本身仍服从原有隐藏状态。
- 未发现新增 GET/SSE 客户端或写入接口。壳复用现有导出的 ObserverMap；正式 `main.ts` 不导入界面壳。开发注入限定 serve，并要求唯一且精确的 `storybook-ui=1`。
- 复核原节点恢复、订阅释放、重复激活及 Escape 分层处理；未发现其他阻断问题。
- 新增 `tests/storybook-ui-shell-review.test.ts`：更多关闭按钮跨断点焦点、六个原导航节点身份及选择器合约、状态不进入折叠工具、开发入口隔离。

## 验证边界

本审查使用离线源码阅读与合成 DOM 合约测试。未使用浏览器、网络、真实存档或模型调用。合成 DOM 不等于浏览器：布局、原生焦点细节、可访问性树、触屏滚动与安全区仍需实际环境验证。CSS 文本或选择器断言不能证明视觉验收通过。

1440×900、1280×720、390×844 的遮挡比例、长文本换行、按钮不互盖、实际触控和屏幕阅读器表现尚未实测。GET/SSE 既有测试分别检查主入口请求次数和壳的源码边界，不是同时运行两者的浏览器集成测试。测试运行结果以最终执行日志为准。
