# 室内本人持久关系摘要独立审查

## 审查范围

针对同屋真实可见、可合法走近的已知熟人，在超过两格但仍处于十格社会视野时丢失本人关系摘要的问题。本次是对旧“室内摘要限近身两格”规格的明确调整，不是扩大身体观察或面对面接触距离。

独立审查仅编辑 `tests/indoor-relationship-memory-review.test.ts` 与本文件。阅读 `CONTRIBUTING.md`、既有关系记忆与社会目标可见性实现说明，以及关系摘要、身体观察、社会观察、房间布局、房间权限和租约查询实现。

## 关键边界

- `canSeeSocialTarget` 已验证真实同室、在世和未离村目标、双方有效门口坐标、真实房间坐标、房间布局遮挡、保守对角视线、十格范围及本人观察能力。缺失坐标不退回入口，船上不能冒充岸上。
- 该函数本身不验证房屋权限。室内摘要仍需双方 `socialRoomAccess`，沿用产权、登记住户、公共房屋和有效租住规则。测试独立覆盖有限租约的到期、结束和产权变化。
- 本人能够观察却暂时不能表达时，自己的旧看法仍存在。因此不能直接把包含 `canExpress` 的动作可接近条件当作关系记忆权限。
- 身体观察、实际接触继续保持原两格边界。三至十格可进入关系摘要不代表可在原地发言、诊断身体、读取背包或得知对方看法。
- 理解时间使用游戏分钟，允许真实的四分之一分钟。有限且处于 `[0, 当前分钟]` 的小数不能被当作旧档未知；负值、未来、缺失及非有限值仍未知，不写回存档。

## 独立反例

新增十项离线测试，参数化子情况在各测试内运行：

1. 三至十格每个整数距离都保留本人看法，最终三语气 talk 仍可选，但身体观察和即时接触均为 false。
2. 双方缺失、小数、NaN、Infinity、越界及家具占据的室内坐标一律排除。
3. 家具横向遮挡与对角实心角不因可绕行而变成视线。
4. 未知身份、缺关系、十一格、异屋同门、室内外混用、错误门口、无房间或 rooms、损坏、离村、死亡、无法观察、本人睡眠、船上状态均排除。
5. 双方私宅权限分别撤销均排除；公共权限保留；本人失去表达能力不丢失可见看法。
6. 三模型纯提示构造保留本人单向数值与旧理解，不包含对方秘密看法。远处弱病、饥饿与疲惫不通过身体观察放出。摘要键集合不含身体、背包或证据ID。
7. 零、整数、小数和当前分钟合法，负值、未来、非有限、缺失时点未知。
8. `:memory:` SQLite 重载保留本人看法与小数时间，重载后新增遮挡即时过滤，原关系仍保存。
9. 旧档缺字段保持未知；姓名与超长理解里的控制字符、角色标签、引号和反引号只能作为有界引用资料；收到的消息仍标注未核实。
10. 有效有限住宅租约授予原对象使用权；到期、结束、产权变化后不能沿用旧权利。

多项测试核对世界前后深相等，模型测试禁止 fetch，不启动模型。此处关系初值是独立合成 fixture；真实编号 talk→独立 interpret→睡床/厨房以及短记忆挤出由主实现测试负责，不能把本组合成值说成真实行动产生。
