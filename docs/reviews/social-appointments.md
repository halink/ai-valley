# 双人日常约见独立审查

审查范围为首版两个成年人在公共共屋门前的约见，不扩展多人讨论、室内访问权、远程消息或自动生活安排。仅使用源码、自建合成世界与内存 SQLite；未读取 `.env`、密钥或真实 runtime 存档，未调用模型、浏览器，未提交、推送或部署。独立审查只修改本说明及 `tests/social-appointments-review.test.ts`，生产修复由实现者负责。

## 独立发现与复现

1. **非有限累计工时可绕过完成验证。** 初版完成函数以大小与差值比较检查工时，`NaN` 使比较均为 false，可直接产生提议。独立反例设置匹配行动及非有限工时，要求无提议、返回失败。实现者增加有限数检查后复跑通过。
2. **远方取消影响本人记忆保留时间。** 初版摘要以内部 `endedAt` 决定保留期限，远方提前撤回使另一人的摘要比未撤回世界提前消失。独立反例比较两份相同世界，只在一份远方撤回，推进到原窗口结束后1439分钟，要求本人摘要一致且仍含原条款。改为按本人已知固定窗口结束时间保留后通过。
3. **自洽但早于真实行动的伪造工时。** 真实提交并仅执行0.25分钟后，把累计工时伪为完整1分钟且提前开始，初版完成函数仍成功。独立反例保留其余真实活动状态，要求拒绝。实现者增加实际第一tick起点、剩余工时及路径校验后通过。独立反例同时将 remaining 置零，确保不是仅由剩余工时挡住伪造。
4. **远方姓名实时进入旧约摘要。** 初版摘要读取对方当前姓名，远处改名即可在未传达消息的情况下改写本人记得的邀请。独立反例要求当面约定的历史姓名保持不变。实现者把双方当时姓名快照绑定到提议与接受证据，摘要使用历史姓名后通过。

5. **接受证据缺少本人演员与完整审计校验。** 静态复查确认初版接受证明只检查绑定、时间相等及双方见证，不要求接受者作为第一个演员。改为仅提议者、第三人、空演员、反向演员或额外第三人，仍可能把见证误认为独立接受；保留原提议后复制成新的接受事件也能伪造接受。实现者加强双方事件的审计authority/provider/scope/resources、接受演员精确顺序及时间范围。新增四项独立测试覆盖上述演员变体、复制提议伪接受、两类事件各四种审计字段篡改，以及接受早于提议、来自未来、NaN和Infinity。实现修复先于这些测试首次执行，首次执行已通过，不将其描述为实测先红后绿。

最初“不重叠赴约”反例有一处测试夹具错误：两次实际路程总计超过30分钟窗口，导致第二次赴约正常过期。已把起点放在门前邻格，仍经真实提交、逐步行走及1分钟到场办理，未放宽生产规则。

## 其他独立覆盖

- 缩短 activity.remaining 不能替代真实办理时间。
- 远处撤回后，另一人约见机会、摘要、个人 revision 保持不变。
- 近处第三者不获得两人提议或接受的私人记忆；观察者事件仍存在。
- 两次访问不重叠不产生相遇；仅把两人放在原地点，也不替他们完成独立赴约。
- 本人撤回约见保留自己正在进行的普通等待及对方状态，忙碌时最终菜单仍保留撤回入口。
- 删除提议回执、篡改固定结束时刻或移除实际见证证据，都不能再授权接受。
- 挤出80条短记忆后，内存 SQLite 重载仍保留原约证据、本人条款、实际赴约机会与防重回执。
- 真正沿路径赴约时远端撤回，只结束本人该行程，不改变对方已知接受状态。
- 两人已选5分钟等候，相遇事实不打断任一人的剩余等候；实际计时完整，相遇只记录一次，双方关系保持原值。
- 原窗口末1分钟等候由四个0.25分钟完整执行，末tick不丢失，正常过期且不虚构相遇。

## 第六项：小数时钟下的原整数条款

本项由实现者先复现，不是独立审查首发现。世界从480.2开始、实际办理1分钟后，以30分钟延迟和120分钟窗口生成的原约为481.2→511.2→631.2；二进制减法结果120.00000000000006会被原上限比较错误排除。修复从存下的时刻差值四舍五入还原整数延迟和窗口，先验证30–2880与15–120范围，再要求原始 `start === offeredAt + delay`、`end === start + window` 精确成立。独立只读检查认为这在本次整数条款和正常模拟时钟下可靠：没有使用容差扩展授权窗口，也不改写原时刻；明显非整数偏差或范围外条款仍不能仅靠round通过原加法回验。此结论不宣称任意超大浮点时钟都有整数分钟精度。

独立首次运行新增小数专项时，480.2/120链通过，480.9/15夹具的“减法必须出现漂移”断言失败，因为实际差正好为15。该失败属于测试夹具，不能算第二条链通过；独立算术核实480.3/15或480.8/15可产生14.999999999999943，已报告实现者调整。实现者随后仅将第二种合成起点改为480.3，保留减法漂移的前置断言，没有放宽产品检查。独立复跑 `node --import tsx --test --test-name-pattern='fractional clock preserves' tests/social-appointments.test.ts`：1/1通过，内部两种真实编号链均完成，0失败、取消或跳过。最终冻结全仓和构建仍由主实现另行报告。本轮只修改审查说明，不改生产或测试。
