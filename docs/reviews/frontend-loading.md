# 前端按需加载独立审查

审查日期：2026-11-07。范围：`main.ts`、`lazy-module.ts`、`panel-renderers.ts`、加载测试与测试替身、产物图测试、测量脚本。没有改动业务实现，没有读取真实存档或环境/密钥文件，没有启动服务、浏览器或使用 npm，没有提交推送。

## 结论

未发现本次按需加载改动的阻断缺陷。保留 Phaser、连接状态、基础面板和档案错误处理在入口的选择合理；可选面板共享一次加载，成功后缓存，失败后等待用户明确重试。

- 加载完成回调按当前面板及当前快照重绘，不持有旧面板、人物或快照；关闭后不会自行重开。
- 多次打开、快速切换、重复重试复用进行中的 promise；观察更新不会造成失败后的请求循环。
- 加载失败不会覆盖已切换的基础面板；关闭后失败再次打开可看到重试提示。
- 等待期间人物被删除，完成后显示记录不可用，不会恢复旧人物档案。
- 生产入口没有静态 chunk 依赖，只有延迟面板的动态边；HTML 没有提前加载延迟面板。延迟 chunk 静态引用已加载入口的共享导出，不会因此把延迟 chunk 提前加入首屏。

## 独立构建结果

使用本地 Vite API：`configFile:false`、`envFile:false`、`base:'/ai-town/'`、`build.write:false`。

- 入口：1,421,155 字节，gzip 412,215。
- 延迟面板：91,575 字节，gzip 31,765。
- 总 JS：1,512,730 字节，gzip 443,980。
- 对比任务提供的原单块 1,509,520 字节、gzip 440,956：首屏减少 88,365 字节（约 5.85%）、gzip 减少 28,741 字节（约 6.52%）；总传输略增，不能声称全量 JS 变小。

测量脚本的静态依赖递归统计涵盖首屏闭包，比只统计入口文件更可靠。生产图测试同时检查 Phaser 在首屏、关键可选模块不在静态闭包、延迟 chunk 非空壳以及 HTML 没有延迟预载。
