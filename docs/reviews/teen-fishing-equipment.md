# 少年自有钓具装备：独立审查

## 结论与范围

在本次离线合成审查范围内未发现阻断问题。修复仅使 frontier 中具备决定与表达能力的 13–17 岁居民可以主动拆封并装备本人库存中的 rodKit，接续原本已允许的垂钓；没有免费发竿或自动捕鱼。

审查生产入口：`src/server/industry-opportunities.ts`、`src/world/family.ts`、`src/world/industry.ts`。家庭年龄白名单本身不接收场景参数；town 的成人门槛仍由行业候选与执行资格检查约束。town 在当前世界类型中以缺省 scenario 表示，测试使用该真实表示。

其他工具装备、工具修理/升级、领取封存工具和其他成人产业操作未被少年白名单放开。装备仍走原有本人库存检查、真实行动时长、工作冲突、完成时重验和回执去重。

## 独立测试

文件：`tests/teen-fishing-equipment-review.test.ts`。

1. 12、13、17、18 岁分别检查 frontier/town 的行业候选、最终菜单和目标验证；额外核对距 13 岁生日最后 0.25 分钟。
2. 从最终编号菜单经过 `parseChoice`、`submitPlan`、`stepWorld` 完成装备：14.75 分钟没有工具，15 分钟后恰好消费本人一个 rodKit 并生成本人一支竿；没有鱼产出或后续自动计划。
3. 伪造 pick/axe/spear/__proto__ 与修理、升级、收取、制作操作仍被年龄/行业检查拒绝。制作完成回调本身是既有空操作，因此制作的拒绝核对在目标验证层，不把空回调当授权。
4. 他人的 kit 和已装备竿不成为本人资源，伪造他人工具 ID 不消费他人物资。
5. 工作最后 0.25 分钟失去库存、决定能力或表达能力，均不能产竿。
6. 完工前已出现本人可用同类竿，旧行动不能再消费 kit 或重复发竿。
7. 既有公共班次排斥装备候选、目标与旧动作完成。
8. 内存 SQLite 保存/恢复 7 分钟进度后仍须完成剩余 8 分钟；重放原完成身份即使又有 kit 也不重复消费或产出。
9. 原编号选项在居民 revision 改变后不能通过旧版本计划提交。

## 验证与限制

执行：`node --import tsx --test tests/teen-fishing-equipment-review.test.ts`，9/9 通过。
