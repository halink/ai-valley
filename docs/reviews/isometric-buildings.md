# 等距建筑与资源独立审查

审查日期：2026-11-10。审查范围是 `isometric-buildings.ts`、`isometric-resources.ts`、对应人工夹具及专属测试。实现由另一工作线程完成；本次只读实现，仅新增本报告。

## 结论

**纯绘制模块可接线，未发现本轮范围内的阻断问题。** 这不是整个观察器、浏览器或真实存档验收。调用方仍须验证世界边界和原始 ID，保留实际足迹，并按最终 `marks === null` 提供明确回退。`buildingArtSupported()` 不能替代最终像素预算结果。

## 验证

- `node --import tsx --test tests/isometric-buildings.test.ts`：10/10 通过。
- 另以临时标准输入执行 220 项合成检查，没有添加测试脚本或修改实现：四季、八种建筑、1×1、1×79、79×1、40×40、7×5 足迹；整数有效像素与预算；三种资源的零、小数、1、满额余量；果实有量但不逐份绘制；工程时间、材料、阶段索引、阶段缺失与完工冲突。
- 补充检查中成功返回的建筑最大 7,232 marks，资源最大 148 marks，分别不超过 16,000/512 的单对象预算。超预算返回 null，而不是假称正常建筑。
- 实际查看已有春、冬两张源码原生合成 PNG。23 个对象中的建筑角色、损伤裂纹、空/非空资源、三种果树状态和四个新建阶段可区分。冬季仍保留已有果实，温室未补造作物、工坊未补造设备、商店未补造货物。
- 冻结输入、精确平移、分数镜头的原 ID 像素点击、建筑旁/后的足迹遮挡顺序均由已运行的专属测试覆盖。

## 真实性边界

- 八种外观来自实际 `Building.kind`，屋顶元数据只选合法色板。可见面没有门时，不从背面虚构一个入口。
- `condition` 仅控制记录支持的磨损，0 不自动画成被烧毁或坍塌。缺失、非有限、越界状态回退。
- 新建工程只接受原三阶段、新建模式、预留仍有效、工时/开始与完成时间/阶段索引/实际投入材料一致的记录。扩建、转换、地形与矛盾记录返回 null；未画成完成建筑。
- 资源正余量仅意味着有存量。耗尽泉没有水、耗尽浆果没有果、耗尽石矿没有完整矿块。图形不宣称具体产出数量、品种、设备或服务。
- 果树成熟由状态决定，不从增长数值或季节推断。冬季风格变化不删除实际果实。
- 模块没有世界推进、状态初始化、写回、网络、模型或居民知识写入。像素生成不扫描整个世界，后续缓存/总场景预算属于接线层责任。
