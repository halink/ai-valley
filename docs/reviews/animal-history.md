# 动物长期年表独立复核

本次为新增动物身份历史检索的独立只读审查。以任务前文件副本对照改动，未将仓库既有未提交内容算作本项交付。

## 结论

未发现此次新增改动的实质缺陷或阻断项。

- 动物索引只从明确的 `animalIds` 数组生成，不从原文或当前对象推断；旧档索引迁移幂等且不改写历史事件。
- 新事件、动物索引与世界状态在同一事务提交，失败全部回滚。重复身份不复制事件。
- 既有普通历史和供水筛选游标保持兼容；动物游标绑定世界及筛选。人物与动物组合筛选取交集，同刻分页和新记录插入不遗漏或重复旧记录。
- 驯鸭沿用原动物身份；鱼群限定于 `shoal:` 水域身份，不表示单条鱼或回溯鱼种。动物状态消失后仍可读已保存历史。
- 查询与渲染不改变动物行为或居民知识。人物理解与已发生事实继续分别标注。
- UI 入口、异步切换过期响应防护、关闭停刷新、错误重试与分页路径通过代码检查。
