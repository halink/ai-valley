# 绘本观察 UI 正式接入：独立审查

日期：2026-11-12

## 范围

核对 `docs/design/storybook-valley.md`、两张设计 PNG、正式入口、绘本壳与既有观察操作。此批是 DOM UI 重构，不是地图手绘素材或完整 2.5D 场景交付。长期运行验证由项目所有者负责。

## 已核查

- 正式入口默认激活 live 模式；不要求开发查询参数，不显示开发启动、退出或预览声明。
- 六个入口保留；手机将关系、交谈、野外放入更多菜单。沿用原 DOM 和委托事件，不增加世界连接或生活控制操作。
- 选择卡仍可承载居民、动物、建设项目和建筑；无居民标识时不显示虚构居民位置。
- 未取得世界记录时显示时间未知，保留连接/暂停/室内状态。
- Escape 只处理当前 UI 层，不触发旧处理器的一次性清选择、退出室内行为。
- 订阅、观察器和移动的节点在销毁时恢复；生产模式重复挂载不增加订阅。
- 已查看参考 PNG。纸白、墨褐、克制页边卡与六项导航符合方向；参考图不是功能或世界事实来源。

## 发现并修复的问题

1. 快照替换档案按钮后，直接保存旧节点无法返回焦点。实现改为按语义路由查找替代按钮；对象消失时回退居民导航。
2. 桌面打开档案后切换手机，关闭档案可能把焦点交给折叠卡中 CSS 隐藏的按钮。独立审查提出后，改为回到可见的对象卡展开按钮。
