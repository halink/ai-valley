# 非危重失能成人短程撤险：独立审查

审查对象：`adult-emergency-evacuation.ts`、`medical-transport.ts`、`health-opportunities.ts` 与共有运输类型。审查不修改实现。

## 范围与边界

- 新权限使用显式 `evacuationAuthority: incapacitated-adult`，限定干地撤险，没有加入既有 `rescueAuthority`；因此不能凭灾害撤险资格获得药物、床位运输或替代同意。
- 入口要求成年、本地存活、`canDecide === false`、非危重、没有当前独立计划或活动，以及施救者具备能力且现场接触。仅失去表达能力不足授权。
- 当前灾害必须实际活动、时间有效、强度为正且覆盖当事人；预警、已结束、远方或有有效遮护的灾害不足授权。
- 搬运沿实际房间与户外路径进行；室内不能提前窥探外部落脚点。户外累计步数上限为8，续载保留计数。
- 决定能力恢复，无论表达能力是否恢复，都在下一移动前中断。有限表达只提供当前运输的停止和短等待，不能混合一般行动。
- 本人停止记录绑定原危险，续载和更换施救者不消除拒绝；不自动恢复一般决定能力。

## 独立反例

`tests/adult-emergency-evacuation-review.test.ts` 覆盖入口失效、能力恢复、无新增财产权/住房权/医疗权限、表达边界、室内知识隔离、伪造路径、内存 SQLite 续载、拒绝持久化、持续危险消失、病情转危重和运输权限标记篡改。

## 发现与复验

初次17项通过。追加危险动态变化发现：接出后把灾害强度改为0，或把开始时间改为未来，续运仍可保持 carrying。原因是续运危险检查缺少入口已具备的强度和开始时间条件。实现者已补齐续运阶段的开始时间和强度检查。独立重跑22项，全部通过；两项反例已转为回归保护。本人仅恢复表达时停止，会立即中断并持久保存对同一危险的拒绝；再次失去表达、换施救者、内存 SQLite 续载均不能复活该次撤险。动作与运输记录权限标记不一致或被删除、伪造床位，都会中断。危险结束、强度归零或开始时间变为未来，在下一实际边前终止搬运。

最终结论：本次审查范围内未发现未解决的阻断问题。独立22项测试通过；此前 TypeScript 无输出检查通过。全仓回归由主工另行执行，本报告不代替全仓结论。

最终窄改动复核：成人撤险的停止权限只属于本人或实际施救者，不会因为残留的童年 `guardianIds` 将停止权授予第三人；原幼儿监护停止边界保持不变。对应 `prior childhood guardian list grants no new adult proxy power` 定向测试独立通过。

## 验证限制

全部使用隔离世界、已有依赖和内存 SQLite；没有连接外部模型、浏览器、真实存档或运行服务，没有读取密钥或 `.env`，没有安装依赖、提交或推送。此报告的独立测试结果不是全仓测试声明。
