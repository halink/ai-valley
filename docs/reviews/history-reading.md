# 年表阅读稳定性独立审查

## 范围与方法

独立审查 `HistoryReader`、`archive-position.ts`、`main.ts` 的年表接线，以及本轮新增阅读测试；未把工作区其他既有修改计入本轮完成范围。

核对 `CONTRIBUTING.md` 与观察设计后，采用注入响应、可控请求完成次序、几何尺寸替身和真实前端入口转译执行。新增反例文件为 `tests/history-reading-review.test.ts`。测试只使用新建合成世界，不使用浏览器、正式入口、真实存档、环境密钥或外部模型；没有提交、推送或发布。

## 发现与修复核验

### P2：屏幕外事件被当成阅读锚点

初版 `rememberArchivePosition` 仅检查记录下边缘是否在容器顶部以下，没有检查记录上边缘是否在容器底部以上。因此人物概览仍占据整个可视区、第一条年表记录位于屏幕下方时，概览异步加载导致该记录下移，会把用户从概览顶部自动往下滚。

独立反例先红：容器可视范围 100–500，记录顶部 1000，原 scrollTop 为 0；概览增加 200 高度后恢复函数将 scrollTop 改为 200，预期仍为 0。应只选与容器可视范围相交的事件，否则按原像素位置恢复。

已修复：锚点要求记录 `bottom > viewport.top` 且 `top < viewport.bottom`。独立反例由失败转为通过，可见记录的局部偏移恢复也保持通过。

另外补充主动 configure 换世界后尚未收到新观察快照的回归：旧 latestWorld 不得在新响应的 finally 中清掉新页。最终实现清理跨世界旧快照，回归通过。

## 已核对行为

- 观察到新事件只保留提示，不自动发起最新页请求，也不替换当前阅读事件集合。
- 明确点击回到最新才刷新；请求未完成和失败时保留旧页及提示，成功后清理旧分页游标并重新定位。
- 双重最新页请求乱序完成、忽略 abort 的迟到响应、世界替换及销毁后的回调不会发布过时页。
- 错误世界和非数组事件响应不能覆盖旧页。
- 新事件提示以本次阅读初始 head 为基准，翻页不重设基准；缓存淘汰保留第零页，避免返回第零页时悄悄重新取最新集合。
- 真实前端入口的合成测试核对 SSE 更新后仍显示原记录、保留滚动像素，只在明确刷新成功后显示新记录并归顶。

## 仍不包含的保证

- 关闭再打开面板、从年表去人物或交谈再返回的导航栈与跨入口滚动恢复，仍未实现，本轮不宣称解决。
- 合成 DOM 不提供真实布局、滚动锚定、焦点或触屏行为的视觉证明；桌面和手机浏览器验收未运行。
- 未执行全量测试、正式运行或真实模型长期验收。本文只声明列出的离线专项验证。
