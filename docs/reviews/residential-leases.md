# 空屋单人住宅租约独立复核

日期：2026-11-06。复核在隔离测试世界中进行，没有读取密钥或真实存档，没有模型调用、提交或推送。

## 发现与处理

1. **床号分配可能无穷循环。** 最初的单人租住保护把任意床号都视为被占，旧的床号搜索会一直加一。已限制为建筑容量内的真实床号，并用非租客 `residentBed` 返回 `null` 验证终止；不制造额外床位。
2. **旧共同安排的余钱余物被遗漏。** 只检查 `offered/open` 会让已关闭、拒绝或过期但还留有份额的空屋出租。现在同时检查所有同址账户的实际余款、余物和 `proposed/ready` 赠与。专项覆盖三种终态，先清钱仍有物、全部清空、赠与待交付及交付后分别验证。
3. **自行交还后仍有回访提示。** 本人明确交还后停止原租约的回访和条款提示。不能统一按远方真实状态筛选：房屋损坏或产权变化尚未亲眼知道时，仍保留原来已签的历史条款与回访方向，避免菜单泄露远方事实。两种情形均有回归。

独立复核最终确认上述修复有效，没有剩余阻塞问题；专项独立重跑 **17/17** 通过。

## 已核验范围

- 成年当事人独立、原址、有限期限的同意与拒绝；船上旧坐标不授予现场签约资格。
- 只提供明确床位，实际室内步行后才能恢复睡眠体力；失效按每分钟检查，不瞬移身体或物资。
- 保留永久住所、产权、监护和原财物，不附带厨房或经营权限，不接纳未经另行商量的同住家庭。
- 继续复用托管、死亡遗产、延迟账户结算冻结边界及持久收据，防止重复扣款与退款。
- 旧世界空初始化，远方知识边界，只读卡片与转义。

实现者另跑住宅租约、原经营租约、家庭迁居、共财、共屋、健康、居民改版、建筑迁移、经济、雇佣、施工与土地交易 **217 项** 扩大回归，全部通过。随后离线全量测试 **1298/1298** 通过，类型检查、服务器编译、禁用环境文件加载的 Vite 生产构建与差异空白检查通过。构建仍有既有主包大于 500 kB 的提示。上述测试集互相重叠，不把计数相加。
