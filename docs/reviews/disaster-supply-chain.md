# 天气灾害与供水联合验收复核

独立只读复核了 [联合测试](../../tests/disaster-supply-chain.test.ts)、[验收范围](../implementation/disaster-supply-chain.md)，以及安全供水、天气灾害文档中的关联修订。结论：未发现阻断项，没有改动生产规则或开启正式天气。

## 已核实

- 居民动作经过最终普通 `decisionChoices`、`parseChoice`、`submitPlan` 和 `stepWorld`。没有直接调用完成函数、在灾后传送人物或把脚本选择说成模型自主决定。
- 降雨预警由引擎累计生成，之后停用新调度，既有洪水仍按原期限推进；预警不改变位置、计划或物资。
- 满员拒绝保留现有入住者，不补床位或库存；受伤后替代水源、本人授权、撤回和重症边界均保持原权限。
- 正向链16份水最终为15份存量加1份实际饮用；8木8石修护后为5木5石。淤塞和清理不改变原泉水量，失败和重复操作不额外耗水。
- 正向链确实新建临时SQLite文件、关闭并重开；另一分支以真实 `WorldStore` 重载未完成协助，随后即时撤回使行动停止。
- 文档明确三人合成场景、脚本选择、菜单轮换等待及医疗重症拒绝，不宣称正式九人、四季、真实模型或完整饮水救助已验收。

独立复跑10个专项文件115/115通过，零失败和跳过（7.96秒）；独立TypeScript检查通过。
