# 等距小样板独立审查

范围为独立离线样板，不是正式等距模式上线验收。审查读取新增渲染、投影、夹具与导出脚本，实际查看源码原生合成 PNG，并独立运行专项与边界探针；没有使用浏览器、真实存档或模型。

## 发现与修复

1. **非二进制缩放边界误点。** 原先直接 `floor`，0.1 等缩放可使精确格角被浮点抵消误差推到前一格或界外，像素左上角也会误命中后方地格。两处现在共用考虑运算幅度的数 ULP 边缘稳定处理，不作宽范围点选吸附。独立复查 1,560 个格角及实际绘制标记的缩放边缘，均无不一致；回归同时保留四边真正外点与内点的区别。
2. **未支持姿态误画为站立者。** 原先通用 fallback 会把婴儿、被护送或重病者画成普通站立身形。现在明确省略婴儿与尚未支持的非劳动姿态，回归覆盖被护送、重病及恢复。文档明确这种省略不适用于完整人口观察，不能据此替换正式入口。
3. **垂钓周期覆盖不全。** 原四个时点只覆盖抛竿/落线。新增 840 与 2,520 毫秒，六个时点覆盖等漂及调竿；独立查看新增静态图，鱼漂位于真实邻水的等距投影位置。时点按钮不再把所有劳动误标为统一四阶段完成。
4. **静态合成与运行镜头边界。** 离线 raster 导出明确拒绝非 1 倍缩放或非整数 origin，避免无声忽略镜头参数而被误当作已验证实时相机。

## 审查结论

当前小范围、未接线的离线样板没有剩余阻塞。房屋、林木、田地、水岸与人物的像素轮廓和视角已做静态审美检查；默认 `main.ts`、`scene.ts` 与 `index.html` 未导入样板。所有显示函数仅读取输入，合成时点不推进世界，也不补造产出或成功事件。

**未验证：** 浏览器实际交互、手机布局、相机移动、连续动画、全图性能、复杂循环遮挡、完整建筑/动物/墓园/室内呈现。不得把离线检查描述成浏览器视觉验收或正式 2.5D 已上线。

最终冻结后的全量回归 4,956 / 4,956 通过，0 失败、取消或跳过；本批 19 项回归包含后补的静态 raster 相机断言。类型检查、服务器编译与禁用环境文件加载的 Vite 构建通过，保留现有分包体积警告。
