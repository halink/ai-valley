# 停业商铺遗产复核

## 红灯证据

2026-11-07，在未修改经济清算代码前运行新增专项测试：

1. 实际双向租约、8 木入库、逐分钟两日到期后自动停业，下一分钟经营者死亡。期望商铺库存清空并原址封存，实际仍是 `{wood: 8}`。
2. 死亡与经济清算之间，`pendingEstateReturns` 期望阻止提前登记，实际返回空值。

独立复核又确认一项旧存档迁移错误：两名继承人，一人已领取，另一人旧份额没有 `goodsClaims`。若先封存新发现商铺余货再执行旧迁移，全部 8 木会进入尚未领取者的原份额，先领取者得到 0。新增回归先复现红灯，再以独立补充来源隔离修复，期望恢复 4/4 且不改已领取记录。

## 独立审查范围

- 关闭商铺仍属经营者，不归场所产权人。
- 已成立分产与新发现库存的隔离、分支比例、无后继权利人保全。
- 未完成合同、现金债务的结算顺序及不追索继承人。
- 食物事务不能串联消费新生成的来源批次。
- 缺失原址不崩溃、不传送；后续实际退回财产不被一次性封存标记漏掉。
- 一名未成年有多个待登记份额时，救急口粮必须按实际来源份额检查和扣减。
