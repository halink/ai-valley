## 已核验边界

- 观察者必须能观察，且不能正在原地睡眠。被观察者须仍在本地存活，不能是本人。
- 两格为实际曼哈顿距离和至多两步可接近路线，不沿用十格附近人物名单作为身体信息权限。户外地形阻挡、非整数坐标、室内残留坐标均保守拒绝。
- 室内要求同一个真实建筑、双方真实门外坐标、真实有效房间坐标及短路径。缺失房间坐标不得补成入口；不同房间共享地图位置也不可观察。
- 船上人员暂不参与身体观察，岸上和船内地图点重合不能突破边界；包括双方在船内的保守关闭情形。
- 投影白名单只有 `atMinute` 与 `signs`；未暴露原始能力布尔值、身体数值、库存、私人意图、病例诊断或未来安排。
- 表达受限明确不等于不能决定或同意。睡眠对象只产生睡眠迹象，不能同时读出饥饿、虚弱或失能。没有独立口渴信号，未从清水库存虚构缺水状态。
- prompt 只呈现当前分钟的投影。监护人的身体备注复用同一投影，不再通过旧分支暴露精确饥饿和健康数值；登记监护关系不能证明远处现况。
- 在相同 decisionContext 中移除身体观察元数据，行动列表保持相同。新增观察不参与行动授权验证。
- UI 将已登记持续伤病与能力/接续核实分开。无病例但自主能力受限者仍可出现；恢复、死亡或外出不再列为当前接续项目。历史救援记录仍保留。
- 空床位字段及旧记录缺失床位字段都不会被标为已送入实际床位。送达、附近有人及已有约定不作为已接班、已饮食或无人照护的证据。
- 新 helper 和 UI 读取不改世界、库存、知识、同意或运输事实；姓名和运输原因转义，未添加可执行照护控件。
