# 谷灵（ValleySpirit）

[总览](README.md) · [共同契约](AGENTS.md)

谷灵无固定人形，是守望者，不是居民/玩家化身。此文件名沿文档习惯，代码命名须独立ValleySpirit，不复用照护guardian。首批只观察回顾/年鉴；世界机遇方向保留，具体类型未在首批启用。

## 1. 模式与权限

G0客观回顾不需要模型；G0模型年鉴须公共投影和账户安全，实际调用/测试不得绕过现行授权限制。G1年鉴选题只读；G1世界候选可沙盒验证，但没有执行权。G2实际机遇须单类型批准和全部依赖，不因用户认可谷灵概念自动获得。

模型只接版本化publicProjection，不接原始World/事件全文；保存实际发送字段快照、sourceRefs、投影/permissionVersion。发送前与发布前重验；发送后撤权无法收回供应商已收数据，只能记录并阻断发布。受限结果整条丢弃或按新合法投影重生成，不删一句掩盖隐含泄漏。缓存/索引/历史/导出同权限，旧链接不能绕过。私人信念、未公开计划和私人谈话默认不输入。

不控制天气种子、居民意图/记忆/关系，不替别人同意、不强迫相遇、不制造苦难或隐形救济。谷灵全局观察不是居民知识；传播必须真实渠道和接收记录。

## 2. 年鉴

保存entryId、时间范围、事实引用和允许字段、文本/更正版本。以持久事实而非工作数组为唯一来源，裁剪/重启仍可解析；缺失标缺失。提议、接受、到场、交谈、进食分别写，不把缺席推断恶意或时间相近当因果。事实与氛围分开，后者不能捏造情绪/动机/天气。

来源更正或撤权需supersedes/retracts及访问控制；同源传话不是多重证明，年鉴不广播居民。无摘要时保留客观回顾，不用规则文案冒充模型生成。关闭旁白/特效不改变世界。

## 3. 候选与执行（后续）

候选包含proposalId、worldId、schema/菜单版本、输入快照与来源、类型/参数、时间窗口/过期、权限、成本/冷却及简短理由。自由文本不能当可执行脚本。状态为proposed→验证/拒绝→待授权/排期→执行→成功/失败/取消/过期，验证和接受均非事实。

隔离预检不写真实DB/知识/预算/通知。执行按原时序重验并写权威收据。资源、实体、事件、收据和效果终态同一世界事务；跨库候选队列仅镜像，以effectId查收据恢复，提交后队列崩溃不重复执行，无法确认时阻塞不猜。

雨后落果候选：真实已有成熟果、持久实际雨ID、合法目标、产权不变；扣源q加地面q，候选单次最多1未定额批准。没有地面实体/承载/发现/拾取能力不开启。源已采空、容量不足、不可达就失败，不在别处刷物品。居民现场发现并自主拾取，无人拾取不是系统失败；休眠不抹已有库存。

跨版本稳定opportunityId由worldId、语义族fruit_fall、rainEventId、sourceResourceInstanceId决定，不包含事件/schema版本；世界事务内唯一约束，升级沿用消费记录。雨ID必须规则真实持久，不能从当前下雨或年鉴回填历史。源转移释放容量会间接增产，须审查累计自然恢复和实际供给，不能当新增落果产量再记一次。

## 4. 故障、配额与公平

可写store前只读分级预检。独立G0/G1未知隔离原文禁发布/覆盖，世界继续；已接受未执行G2无世界预留可停调度隔离。已执行/有预留/实体依赖未知版本无法安全解释时，世界暂停拒写，不删除效果或退款来绕过。关闭生成/调度不删除既有效果解释和恢复能力。

真实账户RPM/TPM/并发与居民共同准入，居民保留容量优先。冻结谷灵token/并发、保留阈值、退避及跨窗未知风险政策；低优先级不等于可以抢满后再退款。模型不可用延后摘要，规则世界继续。不同模式和事件有明确请求/冷却上限，未冻结不启用，不无限重试。

四层公平账分别记提议指向、实际效果、实际发现、真实拾取。均匀提议不等于均匀受益，不能给没发现的人自动通知以“修公平”。不按听话程度或戏剧性奖惩，不为改善生存统计偷送果。
