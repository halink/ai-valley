## 给用户的结论

我选择先建一个可信的世界，再逐步增加它的变化：模型决定居民做什么，规则保证真实成本和后果；四季先改变生活节奏，不用未验证的伤害制造难度；新作物给一次有限启动种源，此后靠真实留种；谷灵先记真事、讲真事，不操纵居民。其后可加入守恒的有限机遇，但不在首批偷偷开放。
