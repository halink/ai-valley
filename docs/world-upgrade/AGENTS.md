# 居民驱动与持久事实

[总览](README.md) · [实施验收](IMPLEMENTATION.md)

## 1. 单向职责与模块

世界→本人观察/获知→机会与个人目标→驱动提出计划→引擎校验执行→持久事实/各人实际获知。模型不持有World写接口。世界执行Module的Interface包含权限、排序、错误、事务和重试语义；居民/谷灵效果使用共同核验能力但不同主体权限，不另开无成本写入口。事实投影、决策轮预算、气候和谷灵各封装内部复杂度，不复制费用或权限逻辑。

当前既有guardian指照护监护人。谷灵在新设计使用独立命名域 **ValleySpirit**，不得复用guardian类型、监护权限、代理权或照护行为。居民的私人信念、谷灵公开投影与观察者画面不是同一份上下文。

## 2. 决策请求和行动

请求持久记录requestId、actorId/revision、worldId、模拟时刻、观察快照ID、菜单/目标版本、证据引用、driver、模型/提示版本与费用身份。事件触发而非逐tick：计划完成/失败、重大本人获知、紧迫需求或选择点；合并小幅变化。行路、劳动、睡眠按已有规则继续。

接收/开始/到场/完成分别核验适用条件。硬失效包括身份/能力、必要权限/同意、作物实例、本人必需库存、未知动作版本和重复结算；软变化如非危险气温变化可保留意图。天气不一定改变actorRevision，因此核验相关事实/版本，而非只看revision；也不以全局revision变动取消所有回答。

已知远处地址允许出发调查。远处未知耗尽/工位占用不能通过菜单消失、排序或错误泄漏；到场观察后才核验相应现场动作。内部诊断与给居民的changedFacts分开，后者再次按感知过滤。失败使用结构化code/retryability，不以中文字符串判断恢复。

请求终态、接受的计划身份与执行绑定同事务；动作实际扣产、事件、结算身份与完成状态同事务。外部模型发送不在数据库事务内：先持久dispatch-intent，崩溃后可能已发则sent-unknown，不能当未发送重发退款。重启策略逐入口冻结，已接受计划和在途动作恢复同一身份；无证据显式阻塞，不重放产出。

## 3. 候选、记忆与公平

自理、田务/工作、社交/约定、调查已知地点、本人目标五类提供稳定分页。每页受原上限约束，cursor绑定同一观察快照；查询本身不推进时间但不冻结后台，最终行动重验现状。预算内至少可发现各合法类别代表及必要详情；未查看、接口故障与不可达分开，不能用全世界信息补截断。查询次数/机会界在P0冻结。

个人获知记录含knowledgeId、observerId、worldId、来源事件/获知ID、receivedAt、type、实际字段快照及版本、渠道证据；转述包含实际发送者与接收事件，但不自动授权底层来源全文。actors、witnesses、mentioned不是同一知识授权。工作事件裁剪后引用仍可解析；先按人和权限过滤再召回，旧档没有证据不逆推。

目标/约定/关键事实用稳定ID、版本、supersedes/retracts/resolved。旧摘要必须带本人已知最新状态，区分当时知/当前信/已知作废；未收到取消者不自动更新。多次同源转述不算多份独立证据。摘要和索引重建不能复活已知作废安排。

模型可放弃目标、继续雨中劳动、紧急吃留种粮，不强制最优生产。规则演示原全知模式与新增有限认知模式分开标注，不能拿两者结果相互代证。

## 4. 预算与等待

实际供应商账户只有一个准入权威，居民与ValleySpirit按用途分账但共用RPM/TPM/并发约束。居民保留容量优先；谷灵不能另建ModelBudget重复占用全账户额度。未发送确证才能撤销费用预留；已发有可信usage按实际结算，无usage保守估算且标未知。跨窗仍在途未知风险继续约束新准入，不能计零或重复真实费用；费用账与并发槽各自幂等。

区分temporary_budget_wait、request_unadmittable、invalid_request；永久错误退出自动重试，可按已冻结压缩政策生成新版本，否则显式阻塞，不堵其他居民队头。调度单位round包含分页/重试，不能换ID重置年龄；生命周期、退避、保留容量及有条件最大绕过K在P0冻结。分别计首次服务、有效决定、行动完成；服务不可用/预算不足/安全约束豁免逐次计数和计时，长期豁免本身是阻塞。

默认模型不可用走既有显式等待/重试/暂停，不隐藏规则接管。按入口/时钟/活动状态冻结保护矩阵：什么停、谁可继续、哪些损耗保护、期限及恢复。新气候需求不得绕过保护或让保护变成免费食水。记录实际食水取得，不用健康没降证明获救。

## 5. 无副作用和启动

new WorldStore之前独立只读预检，不触发建表、迁移、回填或保存。未知权威世界版本无法解释则暂停拒写；谷灵独立内容按其分级隔离。formal/MVP分别验证，不能拿历史正式世界覆盖小山谷。

planStartError、hasTimelySelfRescue、菜单探测、迁移预演、离线回放均使用simulation能力：只改隔离克隆、返回结果，允许克隆内获知；禁止真实DB/知识/费用/槽/调度通知/外发。依赖拒写替身而非仅口头约束。重复预检与错误退出后真实状态和外部计数不变，真实执行才结算一次。

## 6. 最小社会闭环

提议包含地点、时间窗口、参与者和版本；对方独立接受/拒绝，各自决定赴约。改期/换地点/参与者需独立接受新版本。共同到场才算见面；交谈需实际发言/接收；共餐需真实食物及各人进食。缺席不推断恶意，远方取消不自动通知。该闭环首批包含，不推到泛未来。


## 7. 跨库恢复不以请求账替代

共享请求费用账不替代world/session/journal各自的事实和恢复契约。P0逐入口映射世界动作终态、会话请求状态、供应商发送/usage证据及持久journal权威位置，跨库用稳定身份/收据对账，不能假称一个数据库事务覆盖全部外部请求。世界请求被拒绝或动作已经终结，不意味着外部模型请求已确定结束；仍在途/未知usage按真实证据保留风险占用和transport状态。对账失败只阻塞相应未知步骤，必要世界依赖无法解释才按安全门暂停，不为清队列删除费用或重复发送。
