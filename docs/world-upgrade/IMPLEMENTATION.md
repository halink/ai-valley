## 3. 必要契约用例

- 时间：锚点带小数，0.1/0.25/混合分块，格内播种/灌溉/采集/进屋/保存；相同事件轨迹同结果，事件越界1微分钟暂停拒写；满仓采集前不积攒恢复。
- 迁移：新旧种源独立，early-return不漏；跨版本grantId一次发放；收据坏不当未发。旧在田/在途动作完整完成，之后旧seed仍能再播；土壤不因收获重置。
- 持久：资源amount等旧字段不变，仅新实例/权限/季相变，重载不丢。选择完整比较或独立sidecar须原子一致；formal/MVP分验。
- 种植：两田停长无替代种但公共有种可领取→本人清田→再播；取消/重提不重复领。四人两田不会因个人备种形成3/3/2/0；紧急吃种根记录断种、不救济。
- 供给：冻结真实前季初态与各库存/在田进度；冬季到春首收离散缺口，不暗补；人工压力fixture不能证明正常能积累；木石水耗材全账。
- 认知：参与/目击/被提及/转述不同授权；远处耗尽/占用双世界对照不泄漏；旧档无证据不推知；取消只更新真实接收者，摘要重建不复活。
- 试算：重复planStartError、自救预测、菜单/迁移预演和离线回放，真实revision/库存/事件/知识/费用/槽/外发不变；一次live执行只一次产出。
- 请求：重复/迟到响应、接受后崩溃、执行中保存、sent-unknown恢复；永久不可准入退出重试，其他居民仍可服务；K有条件界和豁免实记。
- 预算：未发送撤销、已发未知usage、迟到usage、跨窗口、并发取消分别核验；共享账户不得双花。服务机会不等于有效回答或完成行动。
- 社交：接受/拒绝/改期/迟到/取消/到场/实际进食各分支；不自动关系变化或补餐。
- 谷灵：撤权前后发送/发布/缓存历史；独立内容未知隔离vs未知世界效果停机；同雨同源v1执行后v2/重启不再落；跨库提交后队列崩溃按收据对账。
- 视觉：关闭旁白/低动态不改世界；季相不假报休眠；浏览器缺WebGL时明确未验收，不用原生替代。

## 4. 证据不互相替代

静态设计/源码、隔离合成契约、30分钟真实规则、跨季定向回放、真实浏览器、真实模型分别记覆盖。每开发增量遵守现有30分钟规则运行约定及独立代码审查；临时脚本/日志不入库。此前要求删除当时全部测试文件、避免无用测试，并非永久禁止新增测试套件。新增测试须有明确风险覆盖与维护价值，本次措辞更正本身不新增任何测试。真实模型测试仍禁止，除非用户另行授权；规则脚本不能证明模型记忆/性格/社交质量。

每次冻结源码SHA/未提交指纹、存档schema/fixture、算法/内容版本、driver、推进方法倍率、症状/预期、原始证据/覆盖。不同驱动和初态不得混算；版本/标准变化重定基线。预算和轮数上限停止，安全违规立即停，政策未授权停门前，证据不足就报告不足。

## 5. 发布与回退

先备份、只读预检、隔离预演、完整事务提交；预演不写真实DB或外发。必要世界依赖失败不半提交。回退使用兼容代码与迁移前备份，说明备份后进展丢失，不能降级解释新档。关闭可选生成不删除事实，未知效果按依赖分级。首批完成后暂停复盘，不自动打开减产/灾害/谷灵机遇。


## 6. 本轮独立反馈新增验收

- 气候关闭：新作物/PAW/资源倍率/居民需求分别存在时请求停气候，必须整世界安全暂停拒写，消费者不读冻结缓存继续；纯显示低动态/关闭特效则世界照常。未知依赖版本同样不能切回legacy绕过。
- 时间序列化：微分钟以十进制字符串保存/重载；超过JSON安全整数的合法已批准范围样本仍精确。非法字符、负数、溢出、未知版本被拒且不改原存档，不能JSON Number舍入或BigInt编码失败后回填0。
- 自主清田：合成模型意图在无替代种或已有成熟作物时清本人田，满足地权/位置/实例/工时后真实移除且不返种；规则演示可选保守策略但引擎不强迫。无权清他人田、重复/过期实例仍拒绝；公共种源缺口限制不因此放宽。
- 跨季：完整112日，多组固定天气序列覆盖连续干旱、寒冷与湿雨；每次固定人口、库存归属/种子、田地作物进度、资源、迁移时刻及日期，禁止暗补。规则全知/有限认知驱动分记，不能以人工富裕初态代证前季可积累。
- 水与储备：饮用/灌溉/做饭/工作逐项守恒，降雨只因实际省灌溉而省水；他人/留种/未取得物品不计S_onhand，新储备不为负。
- 跨库/请求：世界动作终态已写但外部请求仍未知、session恢复与journal迟到、跨预算窗口等组合，费用/风险不凭世界终态清零，不重复发送或重复世界产出。

- 私人留种自主性：合成模型意图选择超过“计划田数+1备种”默认目标的私人留种，实际拥有合法根菜且工位/耗时满足时可逐次执行，扣真实收成并产真实种子，不被演示规划阈值拒绝。相同居民向公共种台领取超过本轮缺口的种子仍拒绝且库存不变；两项权限不能混用。私人过量留种造成食物不足不自动补粮。
