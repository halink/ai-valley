# 栖谷领域术语

这些词区分实际世界、不同角色的所知与未来安排，不描述存储实现。

**世界事实**：已经实际成立的状态或事件。避免：提议结果。

**个人获知**：某居民通过真实观察、亲历或传话获得的有限内容。避免：全局知道、参与即知情。

**信念**：居民对其获知内容的理解，可能错误、过时或改变。避免：客观真相。

**意图**：居民准备做的事，不保证能够完成。避免：已执行行动。

**约定**：参与者独立接受的某个版本安排。避免：已履约、已到场。

**谷灵**：见证山谷生活、无固定人形的守望者，非居民或玩家化身。

**公开投影**：允许观察者或谷灵阅读的事实字段集合。避免：全量世界、居民共享记忆。

**机遇提议**：谷灵建议由规则审查的有限机会，不是已经发生的变化。

**机会身份**：同一真实情境下同一来源的一次机会，不因规则升级变成新机会。

**效果收据**：某次规则执行实际完成后留下的结果依据。避免：队列接受通知。

**可用水（PAW）**：土壤供植物使用的水分指数。避免：空气湿度、真实体积含水率。

**启动种源**：内容首次加入时登记的有限公共种子，不是季节自动补种。

**规则演示**：固定规则负责选行动的演示方式，与居民模型选择不同。
