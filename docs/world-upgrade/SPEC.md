# 权威总览规格

[返回总览](README.md)

## 问题与目标

当前小山谷有规则世界和模型居民入口，但规则演示读取全世界，模型只获得有限观察；季节作物、长期记忆和谷灵不是已经完整上线的系统。升级目标是在确定约束中保留不确定选择：居民各有经历、目标和认知，自己决定行动；规则核验地点、资源、权利、同意和耗时；选择的真实后果留在世界。自然随机必须有版本和seed，模型行为不能假称同seed重现。

用户意图：既有生活系统都应能被模型居民主动使用，天气与生态提供真实环境，谷灵守望并记述生活。不是每tick调用模型，也不是允许模型随意改库存、天气或别人的心智。

## 助手最终选择

- 新作物首次加入，包括旧档，登记一次有限公共种源，居民实际领取；不刷新、不自动随人口补发，不把赠予伪装成自然产出。数量按品种首次窗口、人口与田地验证，不固定为旧候选8份。
- 四季首批保留现有野食恢复底线，不新增天气健康伤害、冬季旧食源减产、腐败或灾害。保底不是自动喂食或无限库存。轻度热渴/体力调整也必须验证间接健康风险。
- 谷灵首批只读事件回顾和年鉴能力；实际世界机遇留后续受控批次。当前不做模型测试，不能把真实调用改名“试运行”绕过。
- 谷灵默认读取可观察行动与公开事件，不读私下内心、未公开计划或私人谈话。公开全局事实不倒灌居民。

## 职责与状态

| 主体/记录 | 可以 | 不可以 |
| --- | --- | --- |
| 世界规则 | 生成天气、积分生态、核验和提交真实后果 | 替居民接受交易/决定人生 |
| 居民模型 | 根据本人所知提出目标和短行动计划 | 直接改世界、替别人同意、获得远处真相 |
| 规则演示 | 明确标注地驱动可重复验证 | 冒充真实模型表现 |
| 谷灵模型 | 从公开投影提出年鉴或获批类型候选 | 操纵居民、改自然seed、凭空救济 |
| 观察者界面 | 展示已授权事实、证据和状态 | 隐形发种/指挥居民/启用灾害 |

世界事实、个人获知、信念、意图、约定、效果收据必须区分。提议、接受和排期不等于效果；共同到场不等于交谈或吃饭；旁白不是因果证据。

## 首批范围

共享安全基础、有限认知和跨季目标；确定性四季天气及可读视觉；三类根菜领取/耕收/留种/供餐、清田周转；一个材料真实的木器工作和一个双人实际履约闭环；谷灵客观回顾及年鉴契约。按[实施依赖](IMPLEMENTATION.md)逐批交付，不把此清单当一次性大开关。

首批不做：致命寒热、灾害、旧食源冬停、免费救济、全产业迁入、动物模型化、谷灵落果执行、全知读心、真实模型测试、自动上线。后续不是自动授权。

## 现行规则优先级

本集合内共同驱动/权限契约由[AGENTS](AGENTS.md)定义，天气农业由[SEASONS](SEASONS.md)定义，谷灵可选模块故障与效果由[GUARDIAN](GUARDIAN.md)定义；[IMPLEMENTATION](IMPLEMENTATION.md)统一启用门。未知版本采取依赖分级，不是一律停世界，也不是一律忽略。

旧稿被废弃的解释：日照乘生长、PAW超过80抑制、天气字段混用、积分格就是时间精度、所有请求终止退款、actor等于知道、事件类型版本参与落果机会去重、谷灵故障一律停世界。不得从历史段落恢复这些行为。

## 文档结束不等于实现完成

数值和新能力仍未验证；获得开发授权后，先冻结实际参数与契约并实现依赖，再验收功能。参数验证属于工程工作，无需再问用户替工程师填写数字；不得因此改变上述产品选择或暗增费用/权限。
