# 观察与呈现

[返回游戏设计](README.md)

观察者可以守在一个地点看事情怎样发生，也可以从档案追溯来由。人类决定视角，居民决定是否交谈、投票、工作和改变计划。

前两节描述现行观察体验；连续跟随现已接通客户端，长期追溯仍按下文逐项推进。

[当面浆果地点分享](../implementation/food-source-sharing.md)的事件和行动标签记录真实传达；居民收到的只是带来源、亲见与送达时点的历史地址，观察者看到的当前库存不会随消息泄漏给远处听者。未听到的人不获知。

[双人日常约见](../implementation/social-appointments.md)在人物档案分别展示原时间地点、世界状态、本人获知及实际到场/等候；相遇不等于已交谈，远方撤回不等于另一人已经收到消息。

## 地图与镜头

- 地图占据主要画面。全景帮助读者理解各地的距离和通路，跟随镜头可以观察同一居民在室外与可观察房间内的行动。姓名随指向或选看出现，名单和关系图各有自己的入口。
- 读者可以手动进入或离开室内视角，查看在场居民及其活动。主动跟随时，居民实际跨过门槛后镜头切换；手动进入、退出或拖动会停止跟随，保留读者选择的视角。
- 像素画用不同的地表、植被和建筑轮廓区分地点。季节改变景色，昼夜改变光线。鱼群的位置、工地进度和灾害范围都表现山谷当下的状态。[地图与生态](world.md) · [美术参考](../art.md)

固定斜俯视等距小样板（旧客户端实现已退役；设计意图保留）已独立提供菱形地表、足迹分层和像素点选的离线审视。正式默认视图保持现状；完整建筑、动物、墓园、房间、全图性能及真实运行画面仍待逐项实现和验收。

## 从眼前的活动读到前因后果

| 入口 | 能看到什么 |
| --- | --- |
| 居民 | 查看人物活动、身体状况、住处与生平。人口和家庭面板补充迁入、迁出、出生、死亡和共同生活记录。 |
| 关系 | 人少时可纵览全村。人物增多后，可围绕一位居民查看其关系。箭头标明好感、信任或矛盾来自哪一方。 |
| 交谈 | 全村交谈按每次相遇分开，读者能按发言先后读完一场交谈。讨论和文化活动也有各自的记录。 |
| 场所 | 查看住处和生产地点，进入粮食余量、生计脉络、居民图纸、施工、学堂、产业、照护、排班、经营及公共账本等面板。 |
| 野外 | 鱼群可见位置、可捕量和恢复情况。动物档案呈现身体状态、当前活动和近期事件，并可按原身份查阅完整留存年表。 |
| 年表 | 按人物、年份或文字追查已经发生的事。新事件到来时，读者仍可继续阅读原来的历史位置。 |

年表、人物和动物年表、交谈记录现保持当前阅读集合（旧客户端实现已退役；设计意图保留）：新匹配事件只提示，选择“回到最新”并成功读取后才更换正文。世界继续运行；跨入口返回（旧客户端实现已退役；设计意图保留）按视图与当前记录版本恢复阅读位置，换筛选或世界后不复用旧位置。浏览器视觉验收仍待完成。

关系图给出人物现在的关系，生平和年表可查相关经历。图纸区分构想、公开的知识与已经落成的实物。生计脉络把鱼、牲畜、农田和近期生计变化放在一起，读者可以结合现场与年表理解发生了什么。[人物与世代](people.md) · [建设](building.md)

年表与人物生平现可筛选[带完成快照的供水记录](../implementation/water-history.md)，展开核对当次水桶归属、水量水质、水源余量和木材或旧清水库存变化。饮用与转移、净化、授权分别显示；旧文字记录不补造历史快照，不据此宣称完整供水或口渴系统已完成。

## 待实现设计

### 跨室内外跟随

**客户端已接通，浏览器视觉验收未完成。** 实现范围与离线回归（旧客户端实现已退役；设计意图保留）覆盖同一身份跨房间、室外与渡船位置，手动接管、失去目标和重新跟随。旧档没有室内精确位置时保持房间全景，人物示意位置明确标注且不画精确选框；不补造坐标、不改变居民决定或模拟时钟。

主动选中跟随一位居民后，镜头随同一人经过房门、庭院、山路与渡口。进入可观察的房间时切到该房间，离开后回到人物的室外位置。拖动地图或改看其他对象时交还镜头控制，观察者可随时重新跟随。目标离开可观察区域或已经离世时，镜头停在最后可见的位置并显示原因，再由观察者决定看档案或留在现场。

### 活动与危机状态

[首批现场劳作像素动作](../implementation/visible-work-actions.md)已接通真实工作位置与朝向，区分伐木、采摘、播种、浇水、收获和垂钓。动作循环不表示产出；完成提示仅来自已有事件的成功结算身份。暂停保留当前动作相位，首次加载与重连不补播历史成果。已做离线静态图和内存场景验证，浏览器运行画面仍待视觉验收。

**当前已实现。** 名册、地图人物选框和档案区分实际睡眠、赶路、现场行动、自选停留和等待自主决定；诊疗、教学与提前到岗还可显示有记录依据的等待履约。室内入口不算已经到达床位或工位，渡运与医疗护送另按实际在途状态显示。人物档案把全镇停表和个人活动分开，显示决策保护原期限、剩余游戏分钟、起止原因、身体快照和保护期间记录的损耗来源；年表保留同一保护的历史快照。不补造缺失的等待开始时间或健康账目。[实现范围与验证](../implementation/resident-status.md)

伤病页与人物档案现将持续病例、当前能力及救援后待核实的接续照护分开显示；没有病例或已送到干地不表示恢复、进食饮水或交接完成。居民只在真实近身、能观察且可接近的位置获得粗粒度身体迹象，不能借旧救援身份或亲属登记读取远方数值，也不因此获得新照护权限。[边界与离线回归](../implementation/care-observation.md)

人物出生记录无效或缺失时，选择卡、名册、档案、本人决策提示与监护登记明确显示“年龄未知”；人口簿单列未知，不当成0岁或未成年。实际0岁和分数生日仍正常显示，不据旧成长阶段猜测年龄、不改写出生资料或授权。[实现与离线验证](../implementation/unknown-age-display.md)

人口簿的西南驿路现已显示[单人成人来访](../implementation/visitor-journey.md)的实际区域距离、方向及分段行走/进食/休息/等待本人选择，不把预计时刻当成已到达。

镇外贸易页现已显示[有限驿路食品求助](../implementation/outside-aid.md)：张贴、货运信使或实际访客捎信、访客去程/折返及暂停原因、商行独立应答或拒绝、预留、运输、路阻、到站、实际领取与退运；年表保留对应事实。它是观察者记录，不向远处居民泄露消息。镇外旅程健康/死亡保留区域位置，不广播给谷口旁观者；镇外遗体、遗产及工具不绘制成谷内可领取物资。“场所 → 粮食”和人物档案现已显示[个人保守口粮及社区去重现物](../implementation/food-coverage.md)：个人最多计一处可领取存货，社区数字不按个人到期窗口折减，不表示共同所有或生存保证。仍待实现完整粮水供需账目、多处补给路线、包含入镇照护的完整求助追踪与跨所有约定的等待时间线。

居民面板分别显示赶路、现场工作、实际睡眠、自选停留和等待自主决定。前往床位的人仍显示赶路，自选等待显示余时。身体有危险时，可查看居民的饥饿、口渴、伤病、目前可达的补给及已发出的求助。世界时钟暂缓与个人在等待决定是两种状态，各自显示范围与原因。[生存与恢复](recovery.md)

村落概览分别显示常住、访客和无在世照护者的孩子，连到具体迁居、照护或死亡记录。粮水显示实际库存、已经预留的部分和估计可用天数。读者能从短缺追到居民选了哪条补给路线、有没有抵达、取得什么，以及哪项条件导致后续中断。[公共储备](economy.md#储备粮与短缺采购)

### 长期个体档案

**已接通动物身份年表。** 牲畜、野生动物与水域鱼群可从当前档案或年表事件进入[同一身份的长期记录](../implementation/animal-history.md)，按年份、类别、人物和原文分页查找。驯化沿用原身份；没有当前个体对象时仍可查旧记录。只关联原事件明确登记的身份，不从文字、当前主人、今日鱼种或栖地补造历史。未登记身份的旧文字仍在普通年表保留。完整时段快照、移动轨迹及鱼种数量历史仍待实现。

人物档案跨季保存迁居、健康、照护和财产接续等记录。牲畜和野生动物从出生或进入山谷起保留可追踪的身份。换主人、转栏、迁移、驯化或死亡均保留原记录，驯化后可继续从同一份档案查到野外经历。当前鱼群详情提供[按品种的有限累计数量与变化](../implementation/fish-species.md)，捕捞、捕食和迁移事件保留水域与地点。完整按时段追踪繁衍和恢复仍待长期档案接入；早期仅有水域总量的记录仍按水域展示。狼狐详情另列[栖地累计账目、亲代、疾病与迁移](../implementation/predator-ecology.md)，仅从登记时开始计数。档案中的空缺保留为未知。[地图与生态](world.md)

### 从记录核实影响

同一灾害、工程、交易或救助可从地点、参与者和实际影响向前后查看。例如一次山洪留下哪口井受淹、哪条路中断，居民随后换了什么取水点、交付是否改道、修护消耗了哪些材料。只有当实际记录给出影响、资源转移或行动所依据的关系时，才把两条记录连成因果。同地或相近时间发生的事可以并列，居民的解释保留说话人和所据见闻，尚未知晓的缘由标为未知。[地图与生态](world.md) · [生计与交易](economy.md)
