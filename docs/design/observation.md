# 观察与呈现

[返回游戏设计](README.md)

观察者可以守在一个地点看事情怎样发生，也可以从档案追溯来由。人类决定视角，居民决定是否交谈、投票、工作和改变计划。

## 地图与镜头

- 地图占据主要画面。全景帮助读者理解各地的距离和通路，跟随镜头让读者看清一个人怎样度过一天。姓名随指向或选看出现，名单和关系图各有自己的入口。
- 室内视角延续室外发生的事。读者可以看到谁在房间里，以及照料、生产或交谈占用了什么空间。
- 像素画用不同的地表、植被和建筑轮廓区分地点。季节改变景色，昼夜改变光线。鱼群的位置、工地进度和灾害范围都表现山谷当下的状态。[地图与生态](world.md) · [美术参考](../art.md)

## 从眼前的活动读到前因后果

| 入口 | 能看到什么 |
| --- | --- |
| 居民 | 查看人物活动、身体状况、住处与生平。人口和家庭面板补充迁入、迁出、出生、死亡和共同生活记录。 |
| 关系 | 人少时可纵览全村。人物增多后，可围绕一位居民查看其关系。箭头标明好感、信任或矛盾来自哪一方。 |
| 交谈 | 全村交谈按每次相遇分开，读者能按发言先后读完一场交谈。讨论和文化活动也有各自的记录。 |
| 场所 | 查看住处和生产地点，进入生计脉络、居民图纸、施工、学堂、产业、照护、排班、经营及公共账本等面板。 |
| 野外 | 鱼群可见位置、可捕量和恢复情况。动物档案呈现身体状态、当前活动和相关事件，读者可以从中追查觅食、捕食或饲养的来由。 |
| 年表 | 按人物、年份或文字追查已经发生的事。新事件到来时，读者仍可继续阅读原来的历史位置。 |

同一件事可以从多个角度追溯。关系图给出人物现在的关系，生平和年表保留形成这些关系的经历。图纸区分构想、公开的知识与已经落成的实物。生计脉络把鱼、牲畜、农田和居民的实际收获放在一起，让读者追踪一次捕食或灾害怎样改变接下来的生活。[人物与世代](people.md) · [建设](building.md)
