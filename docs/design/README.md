# 栖谷游戏设计

栖谷是一座只供观察的山间小镇。九个人在同一片河岸起步，周围是有待探索的大流域。小村让观察者能看清每个人怎样生活，广阔的山谷则给人口迁入、跨河探索和聚落扩张留下空间。

季节、耕作、探索与乡村生活借鉴《星露谷物语》。在栖谷，这些事由每位居民自行安排，观察者可以跟随他们，或从留下的记录回看村落如何变化。

各章先说明现行玩法，再标出待实现的规则。复苏方案是待实现设计，适用于衰败后仍保有历史的聚落及未来的新开局。

## 设计原则

- **选择属于当事人。** AI 根据每位居民所知决定其行动。共同生活涉及多方时，各自作决定。婚姻、迁居和新工程都由当事人的选择与眼前的条件共同促成。
- **后果留在同一个世界。** 走路、劳动和照料占用时间。用掉的材料、改变的土地、转移的钱物、建起的房间和建立的关系会影响后面的生活。
- **世界有自己的过程。** 天气、水系、庄稼、动物和人体遵循可重复执行的规则。动物有各自的需求和行动。居民需要在这些过程之间权衡，并承担错过机会和遭遇风险的后果。
- **旁观不介入。** 人类能选择看谁、看哪里、追溯哪段往事。居民的生活在无人旁观时照常进行。

## 系统如何相互影响

- 河流提供水、鱼和跨河路线，也会在险情中改变通行。渔获进入储存、饮食或交易，捕鱼和动物捕食会改变同一片水域中的鱼量。补充食物的需求可能让居民改用其他地点、工具或工作方式。[世界](world.md) · [生计](economy.md)
- 新居民或新生儿增加住房、食物和照护的需求。照护会占用当事人的工作时间。居民可以在条件允许时协商同住、接手照护、募集经费或发起建造。分家、迁走和去世也会改变人手、住房与财产的安排。[居民](people.md) · [经济](economy.md) · [建设](building.md)
- 居民提出图纸、筹集材料、约定报酬并到场施工。完成的工具或建筑扩充下一轮可做的事。经营收入、公共账本与材料库存又会影响修缮和下一次投资。[建设](building.md) · [经济](economy.md)

## 待实现规则的先后关系

1. **生存与接续。** 先让粮水和危险有可行的应对路径，再接上孤儿庇护、外来接应、家庭迁居和临时代管。后续的饮水与脱水规则依赖可达的安全水源。
2. **营生与扎根。** 有人能照料家庭和财物后，再把开店选址、工位招工、批量交易、新建设用地和牧场连成日常生计。承诺和产权持续生效。
3. **扩张与变化。** 现有村落的供给与通路有接续条件后，可逐步增加可探索区域、新工艺、渡船货运，以及有可行应对方式的孕产和灾害风险。观察记录沿各阶段保留事件经过。
