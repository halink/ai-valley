# 居民创造、建设与地图扩展

[返回游戏设计](README.md)

居民可以为实际需要设计器具和建筑，再决定在哪里落地、由谁投入钱料、谁来干活。做成的工具、完工的建筑和打通的道路，都能为其他居民带来新的选择。

本文先说明现行规则，再列出待实现的设计。

## 图纸与实物

有能力表达意愿的成年居民可前往自己有使用权的桌台绘图。模型为设计选择名称、用途和可执行参数。图纸登记作者、制作地点、规格及其公开和学习状态。作者可以把图纸放到公共旅舍供人查阅。另一位居民须实际到该处阅读，之后才具备按这张图制作或提议建设的知识。

| 图纸 | 居民可以决定 | 世界中的结果 |
| --- | --- | --- |
| 工具 | 斧具、镐具、钓竿或猎矛的用料和加固方式 | 规格决定用料、工时、耐久和工具等级。居民带着材料到桌台完成制作，获得有归属和耐久的实物，再决定用哪件。 |
| 原型（有限） | 木料支架、挂网、遮盖、悬挂/干燥工序、鲜鱼投入量与照看时长 | 先制作实物，再按真实晴雨、白昼、承重与食品期限试用；记录成功、失败和耐用。作者成功验证后才可公开，别人须现场学习。[当前边界](../implementation/invention-prototypes.md) |
| 建筑 | 住宅、公共旅舍、工坊、诊所、校舍、畜舍、温室或商铺的规格、屋顶颜色和结构 | 尺寸、结构和用途影响占地、材料、工时及适用容量。图纸画好后，居民还需取得工地并施工。 |

居民可以为自己的需求调整规格、材料和用途，设计仍受山谷已有的工艺、设施功能和空间约束。图纸和实物保留来历，后来的人可以追溯谁设计、谁学会、谁制作和谁建设。

## 从选址到交付

1. **现场查看并提议。** 居民亲自到附近，决定工程类型、具体选址、名称、每小时报酬和材料采购价。现场需有可达入口，并保留现有出入、取水等必要路径。工地不能覆盖其他建筑、在用土地、牧场、公共通路或其他工程的有效预留。私人工程受产权约束，公共建筑须在符合规定的用地上选址，公共工程需经居民表决取得有限授权。
2. **筹集钱与料。** 居民可以自愿资助、捐料，或按约定价供应工地所需的木石。公共拨款从已议定的预算预留。工程保留各笔钱料的来源，未使用部分按归属退回或留在现场供权利人领取。
3. **约定施工。** 私人产权人可以亲自劳动。其他居民可以申请，负责人决定是否发出施工邀请，工人自行接受或拒绝。工资从工程款预留，按已完成的劳动支付。工人可以退出，负责人也可以结束委托。
4. **分阶段施工。** 工程记录基础与地基、梁柱与墙体、屋顶与交付三个阶段。每个阶段需要单独的材料和现场劳动，进度随实际投入增加。缺料、工程暂停、授权过期、地点不可达或施工者无法履约时，进展会中断。复工仍需负责人重新决定，并满足现场和授权条件。
5. **交付。** 现场仍满足使用条件时，完成最后阶段就能交付建筑或开通道路。已经搭起结构的废弃工地会继续占地，居民可以决定复工或拆除。

## 扩建、改作与设备

居民可以提出在原建筑旁扩建。工程保留原建筑身份和已有使用关系，增加的占地和可用空间在完工后体现。现有建筑也可以在符合条件时申请改作。原址、内部布局、占用者、库存或固定工位可能限制方案，须按现场规则解决冲突。工坊设备可实际安装和拆卸，投入的材料、适用场地和使用权决定能否开工。公共设备的拆除另行走公共授权。

新的建筑方案可用于往后的工程。既有建筑可以继续使用，也可按条件改作或扩建。[有限屋面兼容改版](../implementation/resident-upgrades.md)已支持私人住宅、工坊和商铺的产权人或承租人发起，各受影响者分别阅读和同意，提议人到场投入自己的木石和劳动。只改变外观，不改变功能、容量、屋况、库存或合同；公共场所、未成年住户和功能设备升级仍待专门实现。

## 道路、桥、码头与墓园

道路、桥梁、码头和墓园是公共地形工程。提议人需要查看具体范围，且工程须有经表决取得的授权、实际材料和各阶段施工。道路和墓园须选在合适的陆地，桥梁须接通两侧可走的岸边，码头须接入真实水域。工程完成后道路和桥才改变可达路径，码头才成为可用的水路节点，墓园才提供有位置与容量的墓位。

公共设施在使用中需要维护。失效的通道会改变居民通勤、外贸交接和运输可达性，修护需要居民再次提出并施工。渡运还需要可用的码头、水域和实际航程。墓位的使用、遗体安置与后续维护是另外的行动，随人物死亡和社区选择发生。

## 待实现设计

当前正式聚落的建设用地沿用开局划定的私人和公共地块，放牧使用已有牧场，并可按有限用地流程开辟新分区。下列规则给居民增加登记新用地、探索山谷边界、创作新用途和升级设施的途径。

### 建设用地和牧场

**当前实现：** [有限私人建设权](../implementation/land-rights.md)已接通现场勘察、一日公示、异议停止、独立表决、到场登记和到期保全。[共同土地牧场分区](../implementation/pasture-expansion.md)也已接入该流程及实际围栏、水槽、施工和护送。下述租售、续期改约、私人土地转牧场与完整移交仍是待实现设计；不以本项交付宣称整体完成。

居民可亲自勘察可达地块，提出房屋、工坊、牧场或公共用途，并列明范围、占用期限、通路、用水和施工所需条件。私人用地可以由产权人自行使用，也可经双方同意买卖或出租。空闲的共同土地需先公开边界与现有使用情况，至少留一个游戏日供相关居民提出异议，再由有资格的居民按公议规则决定是否授予约定用途和期限的建设权。登记时要保留通行、取水、现有住户与相邻土地的权益。欠缺有效议决人数时，现有公共场所仍可按救助规则临时使用，永久用地分配留待有资格的居民处理。[聚落恢复](recovery.md)

勘察和提出申请只取得议决机会。取得建设权后，居民仍须选择工程、筹措实际物资并到场施工。未开工的临时预留到期后释放。已经投入实际材料和劳动的工程转入复核，先保护现场和清点欠付工资，再由权利人决定续期、改约、移交或拆除。地权转让时，已有住户、通路、租期和工程预留仍随地块保留。需要变更这些约定时，由受影响的当事人同意。

具备使用权的居民可申请开辟或扩展牧场，选定相连的草地、牲畜可实际到达的入口和供水路线。经过现场整理后，放牧量受草料恢复和水源供给约束，畜舍空位、场地草量和照料人手分别计算。持续干旱、过度放牧或租约到期时，饲主需要选择休牧、另找饲料或迁移牲畜。撤销牧场前先安排牲畜去处，场地按当时的剩余草量继续恢复，维护责任和仍有效的通行权继续保留。[牧场与家畜](world.md)

### 连接新区域

**有限正式发起已接通。** [边界勘察与区域接入](../implementation/region-survey.md)支持东/南边界现场勘察、原有随身补给与工具、一日公示和独立表决、实际返回后有限接入。当前仅追加无资源库存的八格深、七格宽草地入口，不自动前往、不授予用地。以下复杂新地形、资源来源、道路工程和长期供给仍待后续完成。

可探索的新地带应与现有山谷相邻，并有可辨认的山口、河道或沿岸入口。居民必须走到入口勘察，记下地形、风险、资源和可能通路，再自行决定继续探索、公开路线或提出修路和架桥。遇到路障可以折返，或筹措能从现有山谷取得的工具与物资后再来。若进入矿区需要铁制器具，先要有进矿前可行的铁制器具来源。

旧地点、资源存量、设施和已登记权益沿用。开通通路后，居民还须分别争取用地、建造、运输和经营，村落发展速度取决于实际来往与供给。后续发生坍塌、洪水或设施失修时，通路可以再次阻断，既有建筑、库存和契约仍留在实际地点，由知情居民决定如何处理。

### 组合发明与兼容升级

**有限原型已接通。** [便携晾鱼工艺](../implementation/invention-prototypes.md)支持居民填写部件、有限工序、投入量与照看时间，实际制作、实测失败或产出、发布学习及再次使用。[有限居民屋面提议](../implementation/resident-upgrades.md)另已接通；原型改版、拆解、其他物理过程和功能设备升级仍按以下完整设计推进，不代表整个发明系统已经完成。

掌握相关技能的居民可以把已知部件和工序组合成原型，填写用途、投入、场所、耗时和产出。可组合的效果来自已经存在的物理过程，例如支撑、存放、遮蔽、引水、干燥和加工。图纸里的名称、用途和外观可由作者定义，能兑现的效果取决于实物、空间和工序。例如居民可把木架、晾挂和防雨遮棚组成鱼获晾架，消耗木料与工时，使用时须有鲜鱼和合适天气，产出保存期更长但数量较少的干货。

作者需有工位使用权，用实物制作一件原型，再从实际试用中观察产出、耐久和风险。试作失败要结清已经消耗的材料和时间，作者可以修订、拆解或放弃。验证过的工艺可选择公开，让其他居民到场学习、制作和使用。已有设施的升级由产权人或获授权的经营者提议，并由受影响的住户和合约当事人确认，现场按约处理原物、未完工批次和差额材料。各方可在开工前拒绝或撤回，原设施按原约继续使用。施工中止时按实际进度结算劳动和物资，由权利人决定恢复、续做或清理。[营业地点与雇佣](economy.md)
