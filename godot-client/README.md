# Godot Web 小山谷

Godot 客户端在浏览器中呈现手绘风格的 3D 山谷。Godot 编辑器用于开发和导出，玩家通过浏览器观察。[当前交付与后续玩法](../docs/godot-migration.md)

## 构建和运行

在仓库根目录准备 Node.js 22.13+、PATH 中的 Godot **4.6.3 stable** 及同版本官方 Web 导出模板：

```sh
npm ci
npm run build:godot:web
npm run demo:godot:web
```

在运行服务的同机浏览器打开 <http://127.0.0.1:3414>。页面自动读取同源快照，连接失败时可手动重连。

`npm run dev` / `npm run dev:web` 是同一规则服务的别名，不必同时启动。`npm run build` 只检查 TypeScript 并编译后台，`npm start` 启动编译后的同一服务；Web 导出必须独立执行。旧 Phaser/Vite 及原生桌面启动器已退出主线，不再提供相应启动命令。

## 当前可构建范围

本机规则演示和现有线上预览均呈现 48×36 的山谷、四位居民、三处住家与一座山居灶堂。后台负责寻路、现场耗时及资源结算，Godot 按快照呈现。

本机规则演示以每 0.5 秒一个游戏分钟的速度推进内存世界。刷新浏览器可继续观察，后台重启会创建新世界。

中键拖动、滚轮缩放、左键选择世界中的居民或场所。可在居民详情中跟随，在选中的建筑入口进入室内观察。底栏可打开居民名录、人物往来、场所列表和山居手记。镜头与查看操作只影响观察视角，步行按后台实际轨迹播放。

居民详情展示行动、需求、库存和位置。人物往来展示双方各自的好感、信任、矛盾和可追溯的变化事件。行动计划来自当前世界快照。Noto CJK 字体随资源打包。[素材与许可](art/README.md) · [字体说明](art/fonts/README.md)

## 线上持久预览

持久入口使用 SQLite 存档，可启用已授权的模型。模型失败时居民可以重选，已开始的行动继续推进。显式禁用模型时，持久世界保留观察入口并停表。配置和存档仅位于服务端。[运行与配置](../docs/configuration.md)

存档锁要求后台使用 Linux 本地文件系统，远程浏览器通过 HTTPS 连接。线上接续存档与真实模型调用已有观察记录，开发验收采用规则模式。[当前版本与证据](../docs/godot-migration.md#当前版本与证据)

## 开发验证

```sh
npm run check
npm run build
npm run build:godot:web
```

自动化测试与专属测试运行器已按要求删除，运行、验收和安全保护脚本保留；CI 仅做后台编译。Web 导出与实际浏览器操作分开记录，不把构建成功当成已可玩。

每批开发验收记录 30 分钟规则运行及实际覆盖的行为，浏览器画面与交互另记。各环境的 WebGL、中文与室内观察结果保留在分批记录中。[贡献指南](../CONTRIBUTING.md) · [浏览器验证记录](../docs/godot-web-mvp.md#验证边界)

详细 Web 环境、导出失效标记、安全边界见[浏览器 MVP 说明](../docs/godot-web-mvp.md)。
