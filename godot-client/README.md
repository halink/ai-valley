# Godot M1：原生只读观察器

本目录属于同一 ai-valley 仓库。迁移计划见 [里程碑](../docs/godot-migration.md)。这是第一条真实 API → Godot 纵向路径，不是完整重做交付，也不是最终绘本美术。旧浏览器客户端保持不变。

## 运行

已验证 Godot 4.6.3。无需模型、密钥或正式数据库：

```sh
# 仓库根目录，启动项目现有隔离预览（不会读取 .env）
node --import tsx src/server/preview-main.ts
# 另一个终端
 godot --path godot-client
```

点击 Connect。默认地址 `http://127.0.0.1:3413`；只请求 `/ai-town/api/world` 完整快照，每两秒一次，不连接模型接口、不改变世界。Connect 后修改输入框不会改变已建立的轮询目标，须再次 Connect。中键拖动、滚轮缩放、左键选居民、Recenter 归位。

真实服务也使用相同只读 API，但本轮仅验证隔离预览。地址不得包含凭据或 token；仅连接自己信任的观察服务。不要把服务端 .env、数据库或 API key 复制到客户端。关闭预览进程会清理其专用临时数据库，不影响正式世界。

## 自动检查

```sh
godot --headless --path godot-client --script tests/test_snapshot.gd
# 需要上面的隔离预览正在运行
godot --headless --path godot-client --script tests/test_http.gd
godot --headless --path godot-client --quit-after 3
```

在本工作环境使用可写临时目录指定 `XDG_CONFIG_HOME`、`XDG_DATA_HOME`、`XDG_CACHE_HOME`，避免编辑器设置目录不可写。这些路径不属于提交内容。

验证记录：Godot 原生 HTTPRequest 成功连接真实 TypeScript HTTP 服务，接收其**合成、静止、无模型**世界（640×480 地图），验证快照、选择并显示人物信息。契约测试覆盖非法快照、投影、室内排除、空时钟/外观拒绝。集成测试还覆盖编辑地址不切源、坏响应保留旧快照并标为过期、中键释放清拖动、同世界旧修订拒绝、不同世界低修订接入、重连清旧详情。修订必须是非负整数，坐标必须有限。独立 review 发现的地址污染、空字段崩溃、拖动卡住、放大命中偏移已修复。
