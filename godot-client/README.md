# Godot Web 小山谷

新版唯一交付目标是浏览器中的真 3D 手绘风格山谷，不交付原生桌面游戏，不考虑移动端。Godot 编辑器是开发与导出工具，玩家无需安装。先完成小世界闭环，再逐版增加玩法和地图，见[版本路线](../docs/godot-migration.md)。

## 构建和运行

在仓库根目录准备 Node.js 22.13+、PATH 中的 Godot **4.6.3 stable** 及同版本官方 Web 导出模板：

```sh
npm ci
npm run build:godot:web
npm run demo:godot:web
```

在运行服务的同机浏览器打开 <http://127.0.0.1:3414>，点击“连接／重新连接”。客户端固定读取页面同源快照，浏览器版不提供任意后台地址或 localhost 模型预设。这个地址不是已部署的公开网址。

`npm run dev` / `npm run dev:web` 是同一规则服务的别名，不必同时启动。`npm run build` 只检查 TypeScript 并编译后台，`npm start` 启动编译后的同一服务；Web 导出必须独立执行。旧 Phaser/Vite 及原生桌面启动器已退出主线，不再提供相应启动命令。

## 当前可构建范围

32×24 地图、两位居民、一处共屋、有限果丛与泉水。后台用**本地规则**选择行动，既有引擎负责路径、现场耗时、采集、进食、饮水、睡眠和结算。不是大模型自主生活，不是正式发布的可长期运行版本。

当前 Web 演示是内存世界，不读取 `.env`、真实存档或模型密钥，不调用模型。刷新浏览器不重置世界；后台重启则重建。服务每 0.5 秒推进一个世界分钟，客户端定时读取快照；错误状态与过期数据不能当成继续成功运行。

画面包含真实 Node3D 场景、正交相机、共屋内外、基本居民形体与动作、绘本风格材质和中文 UI。中键拖动、滚轮缩放、左键选择居民；界面按钮提供回到中心、下一位居民、进入/退出共屋观察。这些操作只改变观察视角，不指挥居民。移动回放基于后台实际轨迹，未知路径不由客户端补造。

面板展示实际行动、需求、库存、位置和事件。Noto CJK 字体随资源打包，减少对系统字体的依赖，但真实浏览器文字及布局仍需验收。素材与许可见 [art/README.md](art/README.md) 和[字体说明](art/fonts/README.md)。

## 后台保存和模型不等于当前 Web 演示

独立的持久小世界服务保留保存/恢复、主/备用模型配置、失败及未决请求保护，并已接入独立同源持久 Web 入口，**尚未完成真实浏览器验收**。默认模型禁用、停表，无规则回退。配置和存档仅位于服务器，不应复制到 Godot 资源或导出包。见[运行与配置](../docs/configuration.md)。

现有持久服务锁只支持 Linux 本地文件系统；这是后台能力限制，不是 Mac 浏览器的限制。公开 HTTPS 部署、访问控制、持久 Web 实际浏览器效果及真实模型效果均未验收。

## 开发验证

```sh
npm run check
npm run build
npm run build:godot:web
```

自动化测试与专属测试运行器已按要求删除，运行、验收和安全保护脚本保留；CI 仅做后台编译。Web 导出与实际浏览器操作分开记录，不把构建成功当成已可玩。

历史证据（测试源码已移除，不代表本版本重新验收）：Web release 已导出，静态文件和同源快照 HTTP 检查、规则短测以及 Godot headless 检查已有通过记录。后续已通过同机桌面终端启动规则服务，浏览器成功加载页面，解决先前的 loopback 连接拒绝；但该云浏览器明确报告缺少 WebGL2，因此**没有完成真实浏览器画面、GPU 和交互验收**。不能将构建成功写成已可玩。长期运行由项目所有者验证。

详细 Web 环境、导出失效标记、安全边界见[浏览器 MVP 说明](../docs/godot-web-mvp.md)。
